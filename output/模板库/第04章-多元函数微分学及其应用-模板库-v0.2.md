## 二重极限的极坐标代换通法

> 编号 **T-HS-03-S** ｜ 版本 **v0.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 极坐标把趋近值与趋近路径解耦，极径管快慢、极角遍历全部路径，角因子有界而径因子为无穷小时所有路径同时被控制 |
| 适用范围 | 二元函数在孤立点（原点型或经平移、幂次适配后可化为原点型）处的二重极限求值与存在性判定 |
| 学科 / 章节 | 高等数学 · 多元函数微分学及其应用 |
| 表面题型 | 二重极限求值；二重极限存在性判定；非齐次分式型二重极限；幂指型二重极限 |
| 对应考点 | 多元函数的极限；二元函数极限的存在性；有界量与无穷小的乘积；极坐标变换；多元函数的连续性 |
| 覆盖题量 | 0 题（分支 5 个） |

### 标准解题步骤

1. 确认趋近点为原点型，否则先平移化归；并检查表达式在趋近邻域内是否存在无定义路径
2. 依分母各项的齐次阶数选取代换方式：阶数匹配时用标准极坐标，不匹配时按主部次数令某变量的幂等于极径乘三角式
3. 代入后按极径的幂次整理，把表达式分离为仅含极径的因子与仅含极角的因子之积
4. 判定角因子的性质：有界、无界或在某些角度取不到定义
5. 角因子有界且径因子趋于零时，由有界量乘无穷小仍为无穷小直接判定极限存在并取该值
6. 角因子无界、无定义或取不同角度得不同值时，取该特定角度还原为一条趋近路径判定极限不存在
7. 需要严格作答时，把极角结论翻译成显式路径表达式并径、角两侧分别复核

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 标准极坐标求值分支 | 分子分母关于两个变量齐次或约去公因子后角部分可由三角函数有界性控制 | 代入标准极坐标并约去极径公因子 → 把余下的三角因子归为有界量 → 对极径因子用等价无穷小或泰勒展开取一元极限 → 由有界量乘无穷小得极限值 | 极径因子必须真正趋于零，若约分后仍含非零极径幂则不能判存在 |
| 加权幂次极坐标分支 | 分母含阶数不匹配的项，直线路径全部得同一值但极限仍不存在 | 按主部次数设定某变量的幂等于极径乘三角式 → 限制极角范围以保证开方与代换有意义 → 代入后检查是否仍为极径幂乘以有界角因子 → 约不去时取使角因子退化或发散的特殊角度构造反例 | 代换必须覆盖全部趋近路径的各个符号分支，开方时须同时考虑正负两支 |
| 特殊角证伪分支 | 化简后的表达式显式依赖极角，或某些极角使分母为零、对数真数为非正 | 取使角因子发散、为零或无定义的具体角度 → 把该角度还原成一条显式趋近路径 → 与直线路径所得结果比较 → 两值不同或其中之一不存在即判定极限不存在 | 单条路径存在不能证明极限存在，本分支只能用于证伪；涉及无定义路径时以考纲口径判定 |
| 平移化归分支 | 趋近点不是原点 | 先作变量平移把趋近点移到原点 → 对新变量施加极坐标代换 → 按角因子有界与径因子无穷小判定极限 → 复核平移未引入新的无定义方向 | 平移后原表达式在该邻域内须可比较阶数，分母零点方向仍需单独检查 |
| 指对型处理分支 | 表达式为幂指形式，或含对数因子、指数的负幂 | 把幂指式取对数或写成指数套内层极限的形式 → 对指数部分作极径与极角分离并求极限 → 指数极限存在且角因子有界时再指数还原得原极限 → 存在使对数真数非正的角范围时直接判定整体不存在 | 对数真数必须在去心邻域内恒正，否则相应路径无定义 |

### 失效边界

- **适用前提**：趋近点为孤立的有限点或无穷远点，且极坐标代换能遍历全部趋近路径；代入后可明确分离出仅含极径的因子与仅含极角的因子；需要在同一套操作内同时完成存在性判定与极限值计算
- **失效场景**：极径因子与极角因子不可分离（混合出现在同一运算中）时，代换后仍无法定案，本法失效；角因子无界且径因子非无穷小（既非零也非无穷）时，判定不出极限是否存在；二元极限不能用洛必达法则，代换后也不得对多个变量分别套洛必达；需要给出路径相关的渐近精度或下一阶误差项时，本法只能定主值；分母在原点附近变号或含不可约奇性时，仅取有限个特殊角不充分，仍须补充路径法验证

## 二重极限存在性的极坐标代换通法

> 编号 **T-HS-21-S** ｜ 版本 **v0.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |

| 核心本质 | 用极坐标或对变量先配幂次的代换把二重极限写成 r 趋于 0 时含 θ 的式子，值随 θ 变则不存在，与 θ 无关则存在 |
| 适用范围 | 点式二重极限（可平移化为原点）的分式函数，分子分母为幂、三角、反三角的有限次复合，尤其分母各项次数不齐的场合 |
| 学科 / 章节 | 高等数学 · 多元函数微分学及其应用 |
| 表面题型 | 分式型二重极限；分母异次幂二重极限；含三角的二重极限；二重极限不存在判定；点式趋近极限 |
| 对应考点 | 二元函数的极限；极限存在性的判定；夹逼准则 |
| 覆盖题量 | 0 题（分支 3 个） |

### 标准解题步骤

1. 把趋近点平移到原点，确认分子分母均为幂、三角复合的有限项
2. 比较分母各项的齐次次数：各项同次用标准极坐标代换；次数不齐时按次数比配权（对某个变量先取幂再代换）
3. 代入代换式并约去 r 的公因子，把结果整理成 r 的某次幂乘一个只含 θ 的因子
4. 令 r 趋于 0 正：若剩余因子随 θ 取不同值，则不同 θ 对应不同趋近路径，极限不存在
5. 若结果被一个与 θ 无关、且随 r 趋于 0 的量一致控制，则极限存在并取该值
6. 存在性结论再用夹逼准则复核一次，防止 θ 的系数在某些方向无界导致误判

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 等幂配权代换分支 | 分母各项次数不成比例（如某变量平方项与另一变量四次项并存），标准极坐标约不干净 | 按两个变量的次数比设定代换，使分母各项成为 r 的同次幂 → 规定 θ 的取值范围使代换覆盖全部趋近路径 → 代入后检查 r 的指数是否被完全约去，约不尽时读出不一致方向 | 代换必须覆盖所有路径且不退化；只覆盖部分路径时得到的「与 θ 无关」不能证明存在性 |
| 夹逼控制分支 | 分子含 sin、cos 等有界振荡因子或可放缩的高阶小量 | 用有界性与绝对值不等式放掉振荡因子 → 对放缩后的式子再用极坐标或均值不等式控制 → 两侧同趋于同一值由夹逼准则定极限 | 放缩过度会使上界发散，夹逼失效，此时须回到配权代换重新定阶 |
| 取路径否定分支 | 只需判定极限不存在 | 先沿直线型路径取不同斜率趋近 → 再沿与分母同次的曲线路径趋近 → 两条路径极限值不同即断定不存在 | 沿任意直线路径极限相同不能推出极限存在，必须补曲线路径或直接做极坐标 |

### 失效边界

- **适用前提**：趋近方式为点式（有限点）二重极限，且可平移至原点；分子分母为幂函数与三角函数的有限次复合，可用齐次次数估计主阶；代换后 θ 的系数在整个取值范围内有界
- **失效场景**：沿所有直线路径极限相同就断言存在：曲线路径可给出不同值，这是本类题最典型的错判；分母在某些方向为零（如含 x+y 型因子），极坐标约分后 θ 系数无界，「与 θ 无关」的推导不成立；趋近点为无穷远点时需先做倒代换化为点式，直接套极坐标会漏掉无穷远处的路径；被积表达式含对数、根式内趋于零的因子等非齐次结构时，配权代换无法把各项化成同次幂，需改用夹逼或极坐标放缩；约去 r 的公因子时未检查该因子可否为零，会把不存在的情形误判为存在

- **适用前提**：被求式可拆成关于该变量的一次式倒数线性组合；阶数以符号给出、可用通项表达
- **失效场景**：分式含不可分解的高次因式，通项法不适用；只求低阶导数时直接逐次求导更省

## 隐函数极值二阶定号

> 编号 **T-HS-245-I** ｜ 版本 **v0.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 由方程确定的函数求极值：先令一阶导数（偏导）为零从原方程解出驻点，再对原方程二次求导在该点取值定号 |
| 适用范围 | 由方程确定的函数（或一元隐函数）讨论驻点处的极值类型 |
| 学科 / 章节 | 高等数学 · 多元函数微分学及其应用 |
| 表面题型 | 隐函数极值判别 |
| 对应考点 | 隐函数求导；<2>已知极值点；无条件极值 |
| 覆盖题量 | 1 题（分支 0 个） |

### 标准解题步骤

1. 方程两端求一次导，代入一阶导为零的条件解出驻点坐标
2. 把驻点代回原方程确定该点的函数值
3. 方程两端再求一次导，整理出二阶导表达式
4. 在驻点取二阶值定号，正为极小、负为极大

### 失效边界

- **适用前提**：依赖变量由单一方程隐式给出且相关偏导非零；极值点处一阶导为零从而简化二阶式
- **失效场景**：二阶式在该点退化，需回到定义比较函数值；方程确定多个分支，需先选定分支
