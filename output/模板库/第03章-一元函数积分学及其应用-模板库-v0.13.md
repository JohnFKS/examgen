### 标准解题步骤

1. 把待证等式或不等式整理移项，归类为零、常数或不等式三档，标出涉及的导数阶数
2. 差式转化：两函数值之差写成导数乘区间长，按阶数与端点条件在中值定理表中锁定定理
3. 需要构造时按口诀选辅助函数（乘指数、乘多项式、积分上限函数），多次使用中值定理时逐层定中值
4. 积分不等式：定义变上限辅助函数，求导后用被积函数定号，端点值为零反推不等式
5. 端点与最值信息用有界最值、介值、零点定理收口（连续函数的三个存在性定理）
6. 代一个具体函数或区间核对构造没有漏因子

### 失效边界

**适用前提**（108 条）

- 条件含积分而结论不含积分算子时，先用积分中值定理或变限积分求导把条件化为微分形态再查表（对应三个积分类分支）；结论显含变限积分因子时把该积分当乘子并入辅助函数后照常查表（变限积分乘子辅助函数分支），不必先把结论化为微分形态
- 函数在所论闭区间连续、开区间相应阶可导
- 结论可经恒等变形移项归入等于零、等于常数、不等式三类之一
- 待证中值点为区间内一点（或可拆成两点独立处理）
- 函数在包含平移后自变量的整段闭区间上连续
- 平移步长不超过区间长度，辅助函数定义域闭合
- 题设给出两端点函数值相等或等分点取值的加和关系
- 分段点两侧表达式明确
- 各段导数方程可解
- 端点函数值相等或可凑出相等
- 辅助函数在闭区间连续开区间可导
- 端点函数值给定且函数不恒等于线性基准
- 辅助函数端点值异号
- 两段上函数满足中值定理条件
- 二阶导数在闭区间上有界
- 最小值在开区间内部取得
- 函数二阶可导、积分条件可中值化
- 参数为任意实数时辅助函数仍可导
- 两函数在闭区间连续开区间可导
- 分母函数导数在区间内不为零
- 函数连续且均值非零
- 两点位于半值点两侧
- 函数二阶可导、比值极限非零有限
- 两函数连续可导、题设给零值端点
- 函数在闭区间可导
- 单侧导数存在且可判号
- 函数二阶可导、端点值给定
- 单侧差商符号可判
- 函数可导且导函数严格单调
- 权重点落在两点之间
- 函数可导且插点方案可行
- 端点值给定且分点可任意选取
- 两函数满足柯西条件
- 二阶导恒正使一阶导严格单调
- 端点值相等
- 结论为存在性命题（存在一点或两点使某式成立/不等式成立）；目标是求极限值或定无穷小阶时归 T-HS-12-S，不用本图表法
- 只给可导时仍可对导函数使用介值性（达布定理：导函数取到两端导数值之间的任何值），据此由 f'(a) 与 f'(b) 异号定出内点驻点或导数零点
- 函数具有二阶导数且定号使一阶导单调
- 两端函数值为零使分部边界项消失
- 展开点在区间内可任意选取

### 标准解题步骤

1. 找反常来源：无穷端与瑕点逐个标出，分别定阶
2. 把被积函数（通项）等价变形为幂乘对数幂的标准型
3. 与临界值比较定敛散：反常积分按幂指数档，级数按最内层对数幂次
4. 必要条件先行：无穷端被积函数不趋于零（通项不趋于零）直接发散
5. 临界档用对数层标尺或定义（p 积分）单侧放缩复核方向

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 多瑕点分段定阶分支 | 积分区间内部或两端同时存在多个使函数无界的点 | 按每个瑕点切分子区间 → 每段以该瑕点为趋近点单独定阶 → 各段结论取交集，任一段发散即整体发散 | 切分不完备（某子段内仍有无界点）时该段结论无效；只在一端定阶会漏掉另一端的发散条件 |
| 含参反解范围分支 | 题目给出收敛或发散的结论，要求参数的取值范围 | 把参数线性组合进幂指数与对数指数 → 按收敛方向列出不等式并判断临界等号能否取 → 对各反常点的不等式取交集 | 幂指数等于一属临界档，此时必须再看对数指数；把临界等号直接写成严格不等式会丢掉或误含边界值 |
| 非幂因子定阶分支 | 被积函数含对数、反三角、指数减一、三角函数等非幂因子 | 在趋近点处把这些因子等价为其主阶幂或对数幂 → 区分对数的幂与自变量的幂，不要互相代入 → 合并各因子指数得到该段的幂指数与对数指数 | 等价式必须在所论趋近点成立（在趋于一处用另一处的等价会算错阶）；因子之间存在加减相消时不能逐项替换 |
| 分段函数积分分支 | 被积函数按区间分段给出，或在分段点处表达式改变 | 把分段点当作潜在瑕点，在其左右两侧分别定阶 → 检查分段点处函数是否有界，有界则该点不产生反常来源 → 合并各段条件 | 分段点处有跳跃但有界时不是瑕点，误当瑕点重复判别会引入多余的条件 |
| 判断积分存在且不为零 | 逐选项找出被积函数在区间内的瑕点与无穷远过程 | 对含瑕点者按瑕点分段，各段单独取极限判敛，任一段发散则整体不存在 → 对无穷限者用比较审敛法定出主部幂次是否够大 → 对存在者检查奇偶性：对称区间上奇函数积分为零 | 〈1〉对称区间；失效：把发散的奇函数积分当成零 |
| 对数因子除以下限趋于零的变限反常积分定极限 | 先用比较判别确认无穷远端积分收敛并固定一个内部分点 | 按该分点把积分拆为变限段与常数段 → 常数段除以发散的对数因子极限为零，予以舍去 → 对变限段与对数因子用洛必达，分子由变限积分求导直接得被积函数端点值 | 无穷端满足收敛判别条件；失效：无穷端不收敛时不能拆出常数段 |
| 反常积分收敛必要条件的级数视角 | 含指数与三角振荡因子的无穷区间反常积分，特别是幂对数标准型覆盖不到、常规做法需大量分类讨论的含参定范围题 | 判断被积函数在无穷端是否属于幂与对数幂的标准档；含指数或振荡因子时改用级数视角 → 求被积函数在无穷端的极限，即把其当作级数的一般项考察 → 该极限不为零或不存在（含振荡不衰减）时，直接断定反常积分发散 → 该极限为零时，进一步用主导衰减因子给出绝对值的可积控制，再判定收敛 | 可用[积分区间为无穷区间，且被积函数在无穷端有确定的极限行为；用于快速排除发散情形，或由必要条件压缩参数范围；与标准型判别互补：标准型管绝对收敛的阶，本法定振荡与指数型的必要门槛] 失效[一般项趋于零只是收敛的必要条件，据此断言收敛是错的（幂对数档中幂指数不大于零的情形即反例），必须补充分支的充分性控制；瑕积分在瑕点处被积函数必趋于无穷，不存在趋于零的必要条件，误用会把发散说成收敛；需要区分条件收敛与绝对收敛时本方法给不出结论，必须回到定义求原函数的极限] |
| 振荡不衰减排除分支 | 被积函数为纯三角函数或振幅不趋于零的振荡式 | 写出振荡因子的振幅包络 → 判断包络是否趋于零 → 包络不趋于零时原函数极限必不存在，判发散 | 振幅趋于零时本必要条件失效，不能反向断言收敛，需另做绝对收敛或狄利克雷型判别 |
| 指数主导定参分支 | 被积函数为指数因子乘有界因子，只需检验无穷端是否趋于零即可排除发散，不需要化成幂乘对数幂标准型 | 由无穷端极限为零解出使指数衰减的参数条件 → 确认有界因子只影响数值不影响敛散性 → 用分部积分或原函数表达式复核收敛值与参数范围 | 参数使指数因子退化为常数一时，衰减条件不再成立，必须回到振荡分支单独讨论 |
| 两项相消型反常积分定参并求值 | 分别写出两项的原函数（对数型与含根式的对数型），合并成单一对数比式 | 对无穷远处的比式按分子分母的净幂次讨论参数三种情形 → 只有参数使比式趋于有限非零常数时极限才存在，据此锁定参数 → 把下限处的对数值单独算出，注意不要漏掉常数项 | 两项各自的原函数可显式写出；失效：把两项分别按发散处理就断言整体发散 |
| 换元化标准型判反常积分敛散性 | 被积函数为幂、对数（含迭代对数）、指数复合的正项反常积分，包括无穷区间积分与瑕积分，以及标准型判不动的变形情形 | 定位全部反常来源：无穷区间的端点，以及使被积函数无界的瑕点（含区间内部的分母零点与对数变号点） → 以反常来源为界把积分拆成若干段，每段只含一个反常点，逐段判别后再取交集下整体结论 → 对每段选换元把趋近过程化为新变量趋于零或趋于无穷：迭代对数型令最外层对数为新变量，指数型令指数为新变量，非原点瑕点令平移量为新变量 → 把换元后的被积表达式整理成幂乘对数幂的标准形式，同步换算微分因子与积分上下限，读出该段的两个阶参数 | 可用[被积函数在每个子段上不变号（正项），可用等价定阶与比较审敛法的极限形式；换元函数在对应区间上单调可导，并把反常点映到零或无穷；各因子在趋近点处有确定的幂阶或对数阶] 失效[被积函数变号或含振荡因子时，标准型判别只回答绝对收敛，判出发散并不代表原积分发散（可能条件收敛）；换元时漏算微分因子的放大量，幂指数会整体错一个单位，边界情形直接判反；一个积分含多个反常来源却只对一处定阶，会漏掉另一处的发散条件] |
| 迭代对数换元分支 | 分母出现逐层嵌套的对数（对数套对数） | 令最外层对数为新变量 → 反解自变量并求出微分因子的指数型放大量 → 验证放大量恰好抵消原来自变量的幂，得到纯新变量的负幂形式 | 要求每层对数在新变量的取值区间内定号且换元单调；瑕点恰落在某层对数变号处时不能整体换元 |
| 指数换元分支 | 含指数因子且必须令指数（或含指数的整体）为新变量，才能把被积式化成幂乘对数幂标准型后判敛 | 令指数为新变量，把指数因子化为新变量的负幂 → 把原来自变量用对数反解，使多项自变量变成对数的幂 → 整理为幂乘对数幂后读阶参数 | 换元后新变量的下限必须仍为正数，原区间含使新变量非正的点时不可用对数反解 |
| 瑕点平移定阶分支 | 瑕点不在零或无穷处，且因子形如对数一加自变量、幂函数一加自变量 | 令平移量把瑕点移到零 → 用一加自变量的等价式把各因子换成幂或对数幂 → 各因子的阶数相加得总幂指数，对数幂单独记账 | 等价替换只能用于乘除因子；平移后括号内出现同阶相减时必须展开到下一阶，否则幂指数定错 |
| 分段与多瑕点分支 | 同一积分两端或内部同时存在多个反常来源 | 按每个反常来源切段 → 每段各自换元定阶并判别 → 全部段收敛才判收敛，任一段发散即判发散 | 只在一端定阶会漏条件；切分不完备（某子段内仍有无界点）时该段结论无效 |
| 含对数除幂的指数差型反常积分参量判敛 | 按参量的正、零、负分情形检查被积式在无穷端是否趋于零 | 不趋于零的情形直接判发散 → 参量为正时用等价无穷小把指数差换成其指数部分 → 对幂次不大于临界值的情形，用对数因子不小于常数放缩成发散界项 | 被积式在无穷区间上不变号；失效：在加减结构上作等价代换 |
| 反常积分计算与定参通法 | 无穷区间与瑕积分的求值、由积分值反解参数或系数、两项各自发散而差收敛的积分、含参积分的连续性与可导性 | 定出全部反常来源：无穷区间端点与使被积式无界的瑕点，以其为界把积分拆成每段只含一种奇异的若干段 → 对每段先按常义积分求原函数：含对数先分部把对数移到微分号外，有理式先拆成真分式差，含根式先把根式整体作新变量并同步改上下限 → 把每段写成截断区间上的差式，对每个独立趋向分别取极限，不把两个发散端分别代入后再相减 → 多个对数或反导数项彼此相消时先用对数运算法则合并成单一比值的对数，再对趋向取极限 | 可用[各段积分连续可加且被积函数在段内不变号；代换在新区间上单调；两端极限均存在] 失效[不拆段直接对整个区间用同一上下限；代换后漏掉微分带来的因子；无穷端反正切取错分支] |
| 主干流程分支 | 分段积分和式的极限化为反常积分并计算 | 用定积分对区间的可加性把和式合并成单个长区间积分 → 令段数趋于无穷，把结果写成无穷区间上的反常积分 → 按根号为零的位置把积分拆成两段，使每段只含一种奇异 | 各段积分连续可加且被积函数在段内不变号；代换在新区间上单调；两端极限均存在 |
| 指数分式与带绝对值根式的反常积分及瑕积分计算 | 把分母中随自变量增减与递减的指数项提出公共常数因子 | 分子分母同乘使分母成为平方加一形式的因子，凑出反正切型微分 → 在新变量下取上下限，代端点求反正切差并乘回常数因子 → 对绝对值型积分先解出内部表达式的零点并按其拆分区间 | 拆分点取在绝对值变号处；配方后常数项为正才能用反正弦公式，为负的平方在前时用对数公式；失效：绝对值零点不拆段直接积分；瑕点两侧符号判断弄反 |
| 含参有理函数无穷区间反常积分的值反定参数 | 把常数参数提到分母外，将分式拆成倒数因子与剩余因子的差，验证拆分后分子恰好抵消 | 对含幂次因子的第二项凑微分，把分母的导数配进微分号内 → 两项都积分成对数形式，写出带参的原函数 → 用对数运算法则把差式合并为一个比值的对数，避免分别代入发散端 | 分母为不同因子的乘积且分子次数低于分母，属可拆的真分式；拆分系数唯一确定，各项各自可积；失效：假分式未先做多项式除法就直接拆项；把两个发散的对数项分别代入无穷端，误用无穷减无穷 |
| 幂指极限等于反常积分定参数 | 把幂指式的底数写成一带分式结构，取指数凑出标准极限形 | 由标准极限定出左侧值为指数的指数函数 → 对右侧反常积分分部，把幂因子降次并保留同族指数因子 → 上下限代入时先检验无穷远处的边界项为零 | 反常积分收敛且可分部闭合；幂指式的底趋于正数；失效：无穷远处边界项不为零时不能略去；把指数因子也参与约分而忽略其随参数变化 |
| 无穷区间三角积分借分部化归已知值 | 把分母的幂写成倒数因子的微分 | 分部并逐项检查两端边界项的极限为零 → 用倍角恒等式把分子合并成单一三角量 → 对积分作伸缩代换并同步改写上下限 | 参照积分收敛且值已知；边界项在两端的极限都为零；失效：边界项非零时不能略去；参照积分本身条件收敛时随意换序会改变结论 |
| 同时对数型与有理型因子的无穷区间反常积分求值 | 把分母中的幂因子凑成某简单函数的微分，提出负号完成凑微分 | 分部积分转移对数，产生新的有理被积式 → 将新有理式拆成倒式与一次分式之差并积出对数形式 → 整理出统一的原函数，对上下两端各自的趋向分别求极限后相减 | 分部积分后剩余积分可积；两端极限各自存在（积分收敛）；失效：在未确认收敛前直接代入端点；凑微分时漏掉幂次带来的常数因子 |
| 含根式幂与对数差的无穷区间反常积分求值 | 把积分写成截断区间上的极限形式 | 按对数差拆成两个截断积分 → 对每个积分用根式幂凑微分做分部积分，转移对数 → 对分部后产生的根式有理积分做根式代换化为反正切型基本积分 | 两项发散速度同阶因而差式收敛；根式代换后分母恒正；失效：分别求值时把发散的常数项丢掉；未验证单项分部产生的积分仍收敛 |
| 两项同阶瑕积分相减的定积分求值 | 识别对数平方型分式可由对数倒数的微分直接积分 | 另一项按幂型反导写出简单分式原函数 → 在同一上限代入原函数差，下限侧写成趋于奇点的极限 → 把该极限通分为零比零型并用洛必达定出有限值 | 两项在同一位置有相同阶的奇异性；合并后的极限存在有限值；失效：两项奇点阶不同则相消失败、积分发散；分别取极限后再相减（各为无穷无意义） |
| 被积式中含整体积分常数的积分方程求该常数 | 把待求的整体积分记为常数并确认其存在 | 对等式两边在同一个无穷区间上逐项积分 → 把含该常数的因子提到积分号外，得到常数的线性方程 → 第一个反常积分用反正切型公式在无穷端取极限 | 原积分收敛保证可提出为常数；拆项后各积分在无穷端收敛；失效：未验收敛就把积分当常数提出；拆项后某项发散却仍参与合并 |
| 含参无界区域面积的无穷区间反常积分与参数最值 | 把区域面积写成从下限到正无穷的定积分，识别被积函数中对数幂与倒数因子的配对关系 | 用凑微分把倒数因子并入微分号内，积分变量改为对数整体 → 对新变量写出幂函数原函数，按幂次不为零的情形给表达式 → 在正无穷端判断幂函数的极限是否消失，由此确定反常积分收敛的参数范围 | 积分区间为无穷区间且被积函数在区间内不变号；被积函数含某整体的导数因子，可凑成新变量的幂函数；失效：幂指数恰为零时仍套用幂函数原函数，导致原函数形式失效；忽略收敛条件，把发散端当成有限值代入 |
| 标准嵌套直读分支 | 通项分母恰为项数与逐层对数若干次幂的连续连乘 | 核对对数嵌套是否逐层连续到有定义的下标 → 只读最内层对数的幂次并与临界值比较 → 外层幂次无论大小一律不写入判断依据 | 各层对数须自某下标起有定义且为正，求和起始项要相应推后，有限项不影响敛散 |
| 缺层补形分支 | 对数嵌套出现跳跃，中间缺某层因子或幂次只作用于最内层 | 把标尺层数下调到实际连续出现的层 → 利用分母少因子使通项偏大的方向做放大 → 与被放大到的那一层标尺比较，同侧即得该标尺的敛散 | 缺层只能往发散方向放缩，反向需另给收敛控制；不能凭外层幂次大就断言收敛 |
| 非对数结构定阶分支 | 通项含指数的幂、阶乘、幂指，或项数同时出现在底数与指数位置 | 先用增长层级表定出唯一主项 → 含阶乘者先化为幂指形式再比较 → 把结果落到不含对数层的幂级数标尺上判敛散 | 层级比较只给出单侧控制；底数或幂比趋于临界值时须升层或改用更细标尺 |
| 取对数化幂指分支 | 通项为幂指结构，底数与指数同时含项数或对数 | 对通项整体取对数把乘除化为加减 → 在指数部分保留增长最快的项作主项 → 还原指数后与几何级数或某层标尺比较 | 取对数比较要求通项恒正；还原时丢弃的误差项必须仍可被所选标尺控制 |
| 含参临界分类分支 | 通项含参数，敛散结论随参数取值改变 | 把参数并入定阶后的最内层幂次或指数位置 → 解出使标尺恰处临界的参数分界值 → 按参数落在分界两侧分别给结论，并单独检验恰取分界值的情形 | 恰取临界值时外层对数与低阶修正项决定结论，必须回到标准嵌套单独判别 |
| 非标准形放缩分支 | 通项不属于任何一层标尺形式，但可与某层已知敛散的标尺逐项作不等式比较 | 选定一层敛散已知的标尺级数 → 用幂与对数、幂与根式之间的已知不等式作单侧放缩 → 按比较判别法的方向直接下结论 | 放缩方向须与结论同向：证收敛要由大者控小者，证发散要由小者控大者，且不等式只在足够大的下标之后成立 |

### 失效边界

**适用前提**（72 条）

- 被积函数在每个子段上不变号（正项或定号），可用等价定阶与比较审敛法的极限形式
- 各因子在趋近点处有确定的幂阶或对数阶
- 反常来源个数为有限个
- 参数不改变各因子的档位归属
- 被积函数在可疑点邻域不变号，可应用比较型审敛法
- 等价主部是幂函数，其指数与临界值可直接比较
- 多个奇点或无穷端已拆开，逐段独立判定
- 积分区间为无穷区间且被积函数在区间内不变号
- 差式在无穷远处确为无穷小
- 等价代换只用于乘除主部
- 积分区间关于零点对称或可拆成对称部分
- 瑕点位置可确定并可分段处理
- 内部奇点处的奇异阶与分母导数的奇异阶相同
- 分母在该趋向单调发散
- 被积函数在各段不变号且可比较
- 参照幂积分的临界指数已知
- 被积函数为正且可按段主部化简
- 端点处对数主部可线性化
- 有界因子在两段极限非零有限
- 分母在区间内不为零
- 参数只改变幂次而不改变符号
- 待判别的每一段都能直接化成幂乘对数幂的标准型；须先换元才成标准型的交回换元定阶通法，只用无穷端趋零排除发散的交回必要条件通法
- 积分区间为无穷区间，且被积函数在无穷端有确定的极限行为
- 用于快速排除发散情形，或由必要条件压缩参数范围
- 与标准型判别互补：标准型管绝对收敛的阶，本法定振荡与指数型的必要门槛
- 分母在积分区间内恒不为零
- 拆项后各项对数在端点处极限存在
- 无穷端主部符号恒定
- 两项各自的原函数可显式写出
- 无穷远处的比式可归一为主部之比
- 只用于由无穷端极限行为压缩参数的候选范围；收敛侧的充分性必须交标准型定阶或原函数取极限复核，两条件取交集
- 被积函数在每个子段上不变号（正项），可用等价定阶与比较审敛法的极限形式
- 换元函数在对应区间上单调可导，并把反常点映到零或无穷
- 被积式在无穷区间上不变号
- 等价代换只用于乘除因子
- 比较界项本身敛散性已知
- 被积式在原变量下读不出幂乘对数幂的阶，必须经换元把趋近过程归到新变量的零或无穷端后才可定阶
- 各段积分连续可加且被积函数在段内不变号
- 代换在新区间上单调
- 两端极限均存在
- 拆分点取在绝对值变号处
- 配方后常数项为正才能用反正弦公式，为负的平方在前时用对数公式
- 瑕点处的极限存在
- 分母为不同因子的乘积且分子次数低于分母，属可拆的真分式
- 拆分系数唯一确定，各项各自可积
- 参数保证分母在积分区间上不变号且无零点
- 反常积分收敛且可分部闭合
- 幂指式的底趋于正数
- 参数在两侧的函数形式可比较
- 参照积分收敛且值已知
- 边界项在两端的极限都为零
- 被积函数在无穷远处可积
- 分部积分后剩余积分可积
- 两端极限各自存在（积分收敛）
- 取极限过程相互独立需分别求
- 两项发散速度同阶因而差式收敛
- 根式代换后分母恒正
- 截断上限统一取同一变量便于合并抵消
- 两项在同一位置有相同阶的奇异性
- 合并后的极限存在有限值
- 区间内部无其他奇点
- 原积分收敛保证可提出为常数
- 拆项后各积分在无穷端收敛
- 方程系数不为零
- 被积函数含某整体的导数因子，可凑成新变量的幂函数
- 参数只出现在幂指数与一次因子中，使驻点方程可解
- 题目要求算出反常积分的值、由积分值反解参数，或含整体积分常数的积分方程；只问敛散性与参数范围的交回定阶判别与必要条件两法
- 正项级数，通项分母可分解为项数幂、逐层对数幂与其他可定阶增长块的乘积
- 比较判别法与比值判别法在边界附近失效、积分判别法不易积分时，本法仍可单侧定敛散
- 求和起始项可调整（有限项不影响敛散），以保证各层对数有定义且为正
- 对标准嵌套族本身该判据是充要的；对一般正项级数只保证单侧控制，不能声称已找到收敛最慢的边界级数
- 本法的判敛对象限于数项级数（正项级数）的敛散性；行列式、矩阵多项式与向量组的问题即使化出含 n 次幂的通项（如「含参n阶行列式递推闭合通法」所得的 D_n 表达式）也不入本法，该通项的求根、判号与函数性态讨论归第7章主干

**失效场景**（86 条）

- 被积函数变号或含振荡因子时，本判别只回答绝对收敛性，判出发散并不代表原积分发散（可能条件收敛）
- 含指数衰减与三角函数混合的类型不属于幂对数标准档，套用阶参数会得错误条件，应改用收敛的必要条件或求出原函数取极限
- 只在一个反常点定阶就下整体结论，会漏掉另一端的发散条件
- 把幂指数与对数指数记反（临界档上尤其容易），会把收敛判成发散或反之
- 等价替换用于加减项或主项相消时定出的幂指数偏大或偏小，导致边界判断错误
- 分母零点位于积分区间内部却未被识别为瑕点，会漏判发散
- 被积函数在瑕点处趋于零（而非无穷）时该点不是瑕点，强行按瑕积分判别会引入不存在的要求
- 被积函数变号时用比较审敛法判绝对收敛以外的结论
- 把双侧无穷区间对称取极限当成收敛，忽略柯西主值与收敛定义的区别
- 在加减相消的结构上只看单项主部，误估真实衰减阶
- 被积函数在无穷远处不趋于零时不能用无穷小等价代换
- 在加减项上做等价代换
- 漏判临界幂相等时的发散情形
- 把发散的奇函数积分当成零
- 只判奇偶而不先判存在性
- 瑕点在区间内部却按常义积分直接求原函数代端点
- 无穷端不收敛时不能拆出常数段
- 变限求导时忽略下限位置带来的负号
- 洛必达后未验证所得比式仍为未定式
- 两段条件只取并集而不是交集
- 被积函数变号时用比较审敛法判绝对收敛之外的敛散性
- 分界等号情形未单独讨论
- 在端点处把对数当常量处理会漏掉瑕点
- 无穷远段只看对数而忽略幂次的决定作用
- 两段条件互相矛盾时未说明整体发散
- 有界因子在某段趋于零或无穷时不能剥离
- 分母变号使被积函数变号而无法用正项比较审敛
- 只看无穷远段而漏掉原点段
- 一般项趋于零只是收敛的必要条件，据此断言收敛是错的（幂对数档中幂指数不大于零的情形即反例），必须补充分支的充分性控制
- 瑕积分在瑕点处被积函数必趋于无穷，不存在趋于零的必要条件，误用会把发散说成收敛
- 需要区分条件收敛与绝对收敛时本方法给不出结论，必须回到定义求原函数的极限
- 含两个以上参数时，仅由必要条件得到的范围偏大，不复核充分性会给出错误答案
- 被积函数在无穷端无极限（振幅发散振荡）时，只能判发散，不能进一步给出收敛侧的任何信息
- 同次项系数不为零时仍按收敛计算
- 对数比式在无穷端极限误取为零的对数
- 拆项时漏掉常数倍因子
- 把两项分别按发散处理就断言整体发散
- 参数取其它值时比式趋于零或无穷却仍写对数
- 对数比值取极限时漏掉下限贡献
- 被积函数变号或含振荡因子时，标准型判别只回答绝对收敛，判出发散并不代表原积分发散（可能条件收敛）
- 换元时漏算微分因子的放大量，幂指数会整体错一个单位，边界情形直接判反
- 一个积分含多个反常来源却只对一处定阶，会漏掉另一处的发散条件
- 幂指数等于一且对数指数等于一是发散而非收敛，临界档记反是最高频错误
- 瑕点处分子分母同阶相消时，按剩余因子定阶会误判收敛或发散
- 换元把非反常点变成新的无界点（或反之）而未重新识别，段划分失效
- 被积函数含参数且参数改变阶归属（如指数为零）时，必须先按参数分类再套标准型
- 在加减结构上作等价代换
- 把对数当幂次使用临界结论
- 参量为零时仍用等价无穷小
- 不拆段直接对整个区间用同一上下限
- 代换后漏掉微分带来的因子
- 无穷端反正切取错分支
- 绝对值零点不拆段直接积分
- 瑕点两侧符号判断弄反
- 无穷端反正切取值用错分支
- 假分式未先做多项式除法就直接拆项
- 把两个发散的对数项分别代入无穷端，误用无穷减无穷
- 参数取值使分母在区间内有零点，反常积分变为瑕积分而未察觉
- 无穷远处边界项不为零时不能略去
- 把指数因子也参与约分而忽略其随参数变化
- 标准极限的内层未归一就直接代值
- 边界项非零时不能略去
- 参照积分本身条件收敛时随意换序会改变结论
- 未判敛散就直接作代换
- 在未确认收敛前直接代入端点
- 凑微分时漏掉幂次带来的常数因子
- 对数型极限未判趋于零就保留
- 分别求值时把发散的常数项丢掉
- 未验证单项分部产生的积分仍收敛
- 代换后漏掉雅可比因子
- 两项奇点阶不同则相消失败、积分发散
- 分别取极限后再相减（各为无穷无意义）
- 洛必达时分子分母求导不匹配
- 未验收敛就把积分当常数提出
- 拆项后某项发散却仍参与合并
- 方程系数为零时仍强行求解
- 幂指数恰为零时仍套用幂函数原函数，导致原函数形式失效
- 忽略收敛条件，把发散端当成有限值代入
- 把分式函数直接求导后误把极小当极大，不做两侧符号判定
- 一般项级数与交错级数不能用本法判条件收敛，本法只对正项部分给出绝对敛散
- 通项不趋于零时必须先用收敛的必要条件判发散，直接套标尺会掩盖这一更基本的检查
- 含正弦、余弦等振荡因子的通项无法定阶，标尺比较失效，须改用绝对值放缩或其他判别法
- 比值判别法在本族标尺上恒给出临界值，看似可用实则无效，不可用它否定标尺结论
- 把增长层级不等式用于有限项或起始下标之前的区间会得出反向结论，比较只在足够大下标后成立
- 缺层放缩方向搞反（用收敛标尺去控放大后的通项或用发散标尺去控缩小后的通项）会得到相反敛散
- 含参情形只检验分界一侧或漏掉恰取临界值的分类，结论不完整

### 标准解题步骤

1. 认型：把被积式归入根式、二次配方、有理分式、凑微分或分部五类
2. 根式与二次结构整体代换有理化；有理分式化真分式并拆最简分式定系数
3. 凑微分把复合整体收进微分号；分部按排序转移导数，循环型移项解出
4. 反求函数：由导数或偏导逐次积分还原，积分常数写成待定函数并由其余条件定出
5. 混合偏导相等的相容性用来核对反求结果；代回求导验算原被积式

| 未知函数与其高阶导数同现的定积分求值 | 把积分按项拆开，保留含未知函数的那一项不动 | 对含高阶导数的项把该导数写成其原函数的微分 → 分部积分一次，边界项由三角因子取零而消失 → 对新产生的积分再次把函数微分转移到三角因子上 | 函数具有所需阶数的连续导数；三角因子在区间端点取零使边界项消失；失效：边界项不消失时结果仍含未知的导数值；分部次数不够无法产生同型积分 |

| 变限积分作因子的定积分 | 把幂因子并入微分号内，使变限积分成为被求导的一方 | 对变限积分按上限求导，上限含复合表达式时必须补乘上限的导数 → 所得新积分的幂次比原外层因子低，按被积函数结构再次凑微分或换元 → 边界项由上限与下限处的取值算出，注意下限处变限积分为零 | （二）求导；被积函数连续保证变限积分可导；失效：被积函数含跳跃间断点时在其处不可求导；上限含参数时需按参数分侧讨论 |
| 指数因子与被积式拆项相消 | 先把被积式按分母幂次拆成两项之差 | 识别指数复合因子的微分形式，把它整体并入微分号 → 对余下因子找出其导数与被积式中另一项的对应关系 → 两项分别分部积分，写出展开后出现的同族积分 | 被积式可拆成含同一指数复合因子的两项；每项都能配成两个微分的乘积；失效：拆项后某项无法配微分时本法断裂；指数内层导数与三角因子不对应时会多出无法抵消的积分 |
| 只给导数时求函数本身的定积分 | 把待定积分分部，使函数被求导、幂因子被积分 | 把导数表达式中的平移量取为整体变量 → 把平移多项式拆成「整体加常数」两项分别积分 → 认出其中一项就是导数在区间上的积分，用牛顿-莱布尼茨换成端点函数值之差并与边界项抵消 | 积分和微分的互逆关系；导数在闭区间可积且已知一点函数值；失效：不知道任一点函数值时边界项无法定值；分部方向弄反会把高阶积分引入 |
| 高阶导数乘幂因子的定积分 | 把高阶导数写成其一阶低导数的微分，幂因子留在外面 | 分部一次，边界项代入区间端点的导数值 → 余下积分再次配微分并分部，边界项代入端点函数值 → 对剩下的定积分作平移换元，使积分区间与已知条件一致 | 函数在区间上有连续的二阶导数；端点处函数值与导数值已知；失效：区间内二阶导不存在时分部不合法；端点值缺失会使边界项无法定值 |
| 变限积分与三角因子的定积分 | 识别三角因子是某函数的微分，把它塞进微分号 | 分部并把边界项按该三角原函数在两端为零写出 → 对变限积分求导得被积函数在上限处的值 → 把所得乘积式凑成单一变量的微分 | （二）求导；被积函数连续；失效：边界项不为零却直接略去；三角因子与变限积分不匹配时分部会引入更高阶积分 |
| 原函数存在性与分段拼接通法 | 原函数与导函数关系的概念判断题、分段函数求原函数、含间断点时被积函数对应的变限积分性态 | 用周期把目标自变量归化到给出导数表达式的区间内 → 去掉绝对值，按分界点把导数写成分段形式 → 各段分别积分得到含各自常数的二次表达式 → 由函数在分界点连续（可导必连续）联立定出相同常数 | 可用[函数在分界点可导从而连续；周期已知且目标点可归化到一个周期内；各段导数表达式可积] 失效[只给连续而不给可导时两侧导数可不相等；分段点两侧常数不匹配导致函数跳跃；周期归化时方向弄反] |

| 分段函数原函数的拼接与常数确定 | 在每段子区间上分别求不定积分，各引入独立常数 | 求分段点处两支的极限值 → 由原函数必连续定出两常数相等，合并为同一常数 → 取该常数为零写出候选表达式 | 被积函数在分段点连续；各支在其开区间内连续；失效：被积函数有跳跃间断时仍强行拼接原函数；两支常数取成不同值 |

| 主干流程分支 | 由原函数与导数乘积关系反求函数 | 把乘积关系两边同乘二，识别为平方函数的导数 → 两边积分得到平方表达式等于一段未知积分加常数 → 对右端积分先凑出内层整体（对数或三角组合）的微分 | 所论区间内原函数符号已知或可定；右端积分可初等表出 |
| 由切线斜率函数与过定点条件求曲线方程 | 由斜率条件写出导数等式并写成不定积分 | 从根号中提出自变量的平方因子，使分母变为高次幂 → 把倒数整体作为微分变量凑微分，根号内化为单位平方差 → 套反正弦型基本积分写出带常数的原函数 | 被积式在所选分支上连续；定点落在该分支内；失效：跨分支统一写一个原函数（两分支常数独立）；提因子时把平方根写成平方 |
| 由偏导（全微分）还原函数与定参通法 | 已知全微分、一阶偏导或二阶偏导与定线条件，反求原函数表达式 | 写出与微分式配对的两个系数（或给定的两个偏导） → 先用混合偏导相等检验相容性，含参时比较分子系数定出参数 → 选定一个变量积分，把常数项写成另一变量的待定函数 → 对待定函数求导并与另一个偏导比较，解出待定函数 | 可用[附加条件足以定出全部待定项；系数在所讨论区域有一阶连续偏导且分母不为零；待定参数线性进入系数比较式] 失效[两个偏导不满足相容条件，这样的函数不存在；条件只给在边界曲线上，无法定出待定函数；区域带空洞（如去掉原点）时相容条件不再充分] |
| 相容条件定参分支 | 微分式或偏导式含待定参数，题目只问它是否为某函数的全微分（或求该参数使之为全微分），不需要把原函数表达式还原出来；要求还原表达式时按主干逐次积分而不入本支 | 令第一个系数对另一变量求偏导，与第二个系数对原变量求偏导相等 → 通分后比较分子的同类项系数 → 由系数对应关系解出待定参数并回代验证 | 系数在所讨论区域有一阶连续偏导且分母不为零；失效：区域带空洞（如去掉原点）时相容条件不再充分 |
| 由偏导等式反解未知函数 | 题给偏导满足的等式或方程，反解其中未知函数或参数 | 把待定函数（或待定参数）所在的复合与隐式关系按链式法则求出一阶以及所需的二阶偏导，抽象函数按位置编号记录 → 用题给的方程或关系把偏导式中含待定函数导数的项整体消去或合并，使偏导化到最简 → 把化简后的偏导代入题设等式（两偏导相等、满足某方程、在指定点取到极值），整理成只含一个未知函数及其单变量导数的方程 → 整理后为代数方程的直接解出未知函数或参数；为常微分方程的转交微分方程通法按特征方程定通解，未知函数以复合内层出现时先把内层整体作自变量 | 可用[题给关于导数或偏导的等式，未知量是函数本身或其中参数；化简后能把等式归成只含一个未知函数及其单变量导数的方程：既含「未知导数项整体相消」的代数型，也含化为二阶线性常微分方程的积分型（后者求解按特征方程，转交微分方程通法）；与由偏导（全微分）还原函数与定参通法的分工：题给已是偏导或全微分的具体表达式（或由其定参数）走该法，题给偏导所满足的等式且未知量是复合内层的一元函数走本法] 失效[条件不足时只能定出某点的值而非整个函数；化简后仍归不到只含一个未知函数的方程（未知函数同时跨多个自变量、或以无法分离的算子形式出现）时本法无出口；条件只给在某条定线上且不足以定出待定函数时，须改由偏导（全微分）还原函数与定参通法处理] |

### 失效边界

**适用前提**（63 条）

- 被积式可归为上述标准结构
- 分母因式分解可行
- 代换在讨论区间上单调可逆
- 有理化后分母次数高于分子或可拆
- 回代时根式取定符号分支
- 内层函数在所论区间严格单调从而可反解
- 已知式对全体内层取值一致
- 内层对数函数单调可反解
- 新解析式的对数项在讨论区间内有定义
- 被积式含根式、指数、幂指或对数等非有理结构，须经代换才把它有理化或化成基本积分；纯有理式与纯三角有理式交回有理式积分通法
- 变形后各项均为标准微分型
- 分母在讨论区间不变号
- 参数不全为零保证分母非零
- 分母可降幂为单一三角量的幂
- 分子含该三角量导数的因子
- 代换后有理式可拆成相消的两项
- 所选因子的导数比原式更简单
- 凑微分部分的原函数易写
- 循环方程的系数不为零
- 函数具有所需阶数的连续导数
- 三角因子在区间端点取零使边界项消失
- 分部次数与导数阶数匹配
- 被积函数连续使变限积分可导
- 外层积分区间端点处函数值可定（含零点使边界项消失）
- 被积函数连续保证变限积分可导
- 外层因子有原函数的幂形式
- 被积式可拆成含同一指数复合因子的两项
- 每项都能配成两个微分的乘积
- 分部后出现的辅助积分同族且符号相反
- 导数在闭区间可积且已知一点函数值
- 平移后的被积式可用幂次凑微分
- 函数在区间上有连续的二阶导数
- 端点处函数值与导数值已知
- 幂因子分部后仍可用同型积分收尾
- 被积函数连续
- 配出的微分因子在两端取零
- 函数在分界点可导从而连续
- 周期已知且目标点可归化到一个周期内
- 各段导数表达式可积
- 被积函数有界
- 间断点为第一类
- 变限积分的下限取在可积区间内
- 被积函数在分段点连续
- 各支在其开区间内连续
- 拼接后表达式在该点可导
- 讨论区间关于原点对称
- 原函数存在意味着被积函数有原函数而非连续
- 和式中至少一项连续
- 所论区间内原函数符号已知或可定
- 右端积分可初等表出
- 被积式在所选分支上连续
- 定点落在该分支内
- 开根时二次因子带绝对值需按分支定号
- 附加条件足以定出全部待定项
- 系数在所讨论区域有一阶连续偏导且分母不为零
- 待定参数线性进入系数比较式
- 给定的两个偏导（微分系数）在所讨论区域有一阶连续偏导；混合偏导相等这一相容性正由本法第2步检验——含待定参数时相容条件本身就是定参方程，不与「相容条件定参分支」互斥
- 与由偏导等式反解未知函数、变量代换化简二阶偏导两法的分工：题给为偏导或全微分的具体表达式（或其定参问题）走本法；题给偏导所满足的等式且未知量是复合内层一元函数走反解法；题给线性变量代换化简偏微分式走代换化简法，化简后回到本法收官
- 题给关于导数或偏导的等式，未知量是函数本身或其中参数
- 化简后能把等式归成只含一个未知函数及其单变量导数的方程：既含「未知导数项整体相消」的代数型，也含化为二阶线性常微分方程的积分型（后者求解按特征方程，转交微分方程通法）
- 与由偏导（全微分）还原函数与定参通法的分工：题给已是偏导或全微分的具体表达式（或由其定参数）走该法，题给偏导所满足的等式且未知量是复合内层的一元函数走本法
- 化简后含未知导数的项可整体消去
- 给定偏导连续且满足混合偏导相等的相容条件

**失效场景**（68 条）

- 未化真分式就套部分分式公式
- 拆项时漏掉某个分母幂次的待定系数
- 分部时把反三角因子积分而不是求导
- 代换后不回代原变量
- 根式分支取错导致符号相反
- 拆项时漏掉微分带来的倍数
- 内层在区间内不单调时须分段取反函数分支
- 只给函数方程而无单调信息时解析式不唯一
- 直接对复合式求导而不先定出解析式
- 忽略原自变量为正的定义域限制
- 分部时把指数因子同时求导与积分导致重复
- 真数可能为负而未加绝对值
- 不判奇偶次数盲目用万能代换造成繁复
- 拆项系数配错使两项不再互补
- 同除因子时忽略了其零点
- 分母幂次与分子导数阶次不匹配时拆项不相消
- 在分母零点处未加分段讨论会丢失定义区间
- 代换后仍含未归一的第二个三角量
- 把应保留的因子放进微分号导致更复杂
- 循环解出时漏乘系数
- 恒等变形拆项后遗漏常数项
- 边界项不消失时结果仍含未知的导数值
- 分部次数不够无法产生同型积分
- 转移时符号累计出错
- 曲线在区间内变号时面积须按零点是分块取绝对值，不能直接积分
- 分部积分的边界项不为零时必须保留而不能略去
- 被积函数符号不可判定时无法先定曲线正负
- 被积函数含跳跃间断点时在其处不可求导
- 上限含参数时需按参数分侧讨论
- 把变限积分整体当常数提出积分号
- 拆项后某项无法配微分时本法断裂
- 指数内层导数与三角因子不对应时会多出无法抵消的积分
- 在三角函数零点处不讨论分母的幂次就整体变形
- 不知道任一点函数值时边界项无法定值
- 分部方向弄反会把高阶积分引入
- 把端点函数值差写成和
- 区间内二阶导不存在时分部不合法
- 端点值缺失会使边界项无法定值
- 平移换元时漏改上下限
- 边界项不为零却直接略去
- 三角因子与变限积分不匹配时分部会引入更高阶积分
- 在cos 变号的区间上不判号就凑微分
- 只给连续而不给可导时两侧导数可不相等
- 分段点两侧常数不匹配导致函数跳跃
- 周期归化时方向弄反
- 被积函数无界时连续性结论不成立
- 第二类间断点处不能直接套用左右极限作导数
- 把变限积分的连续误当成被积函数的连续
- 被积函数有跳跃间断时仍强行拼接原函数
- 两支常数取成不同值
- 只验连续不验导数等于被积函数值
- 把可导误当成导函数连续
- 在非对称区间上判奇偶
- 因和被积函数不连续就断言不存在原函数
- 开方不加符号判断会丢分支
- 原函数变号处不可导
- 把乘积关系直接当导数关系处理
- 跨分支统一写一个原函数（两分支常数独立）
- 提因子时把平方根写成平方
- 用反余弦形式却不检查分支上的符号差异
- 两个偏导不满足相容条件，这样的函数不存在
- 条件只给在边界曲线上，无法定出待定函数
- 区域带空洞（如去掉原点）时相容条件不再充分
- 表达式根本不是全微分形式
- 条件不足时只能定出某点的值而非整个函数
- 化简后仍归不到只含一个未知函数的方程（未知函数同时跨多个自变量、或以无法分离的算子形式出现）时本法无出口
- 条件只给在某条定线上且不足以定出待定函数时，须改由偏导（全微分）还原函数与定参通法处理
- 等式含未知函数的高阶导数，须先积分还原

### 标准解题步骤

1. 对称性检查：区间或区域关于原点、坐标轴的对称性，奇偶归零折半
2. 互倒、周期因子用区间平移或取平均配不变部分
3. 黎曼和识别：把大和整理成步长乘归一化下标函数值，读出积分区间与被积函数
4. 几何物理量取微元：面积、体积（圆盘/柱壳）、弧长、侧面积、变力功、压力、质心逐项套微元公式
5. 二重积分：表示区域、定序建系（交换次序或转极坐标），化为累次积分
6. 回代验算：对一个简单区域或区间复核微元公式

- 把奇偶性判在乘积的单个因子上而非整体

- 平移时漏改上下限
- 开根未取正分支
- 反射代换后未重判函数奇偶
- 区间不对称时误用奇偶归零
- 把非圆型根式当面积处理
- 位移代换后忘记同步改上下限
- 反射代换后忘记翻上下限符号
- 把非奇偶配对的两项一并归零
- 因子在反射下改变形式时不能直接归约
- 区间长度非周期整数倍时不能平移成常数
- 把非负误写成严格为正而不检查恒零
- 分部时把指数因子微分写错符号
- 区间不对称时不能做奇偶合并
- 单调方向判反导致差式符号错
- 把二阶导条件误用于一阶结论
- 把 f(x)=f(2a-x) 误当成周期条件
- 换元时未翻转上下限导致符号错误
- 区间不对称时不能折半
- 因子不满足互倒条件时通分后无法约尽
- 奇函数情形误用同一结论
- 反射代换时漏翻上下限
- 区间不是周期整数倍时不能整段折倍
