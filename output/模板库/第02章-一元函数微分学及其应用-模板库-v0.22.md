### 标准解题步骤

1. 把待证等式或不等式整理移项，归类为零、常数或不等式三档，标出涉及的导数阶数
2. 差式转化：两函数值之差写成导数乘区间长，按阶数与端点条件在中值定理表中锁定定理
3. 需要构造时按口诀选辅助函数（乘指数、乘多项式、积分上限函数），多次使用中值定理时逐层定中值
4. 积分不等式：定义变上限辅助函数，求导后用被积函数定号，端点值为零反推不等式
5. 端点与最值信息用有界最值、介值、零点定理收口（连续函数的三个存在性定理）
6. 代一个具体函数或区间核对构造没有漏因子

### 失效边界

**适用前提**（108 条）

- 条件含积分而结论不含积分算子时，先用积分中值定理或变限积分求导把条件化为微分形态再查表（对应三个积分类分支）；结论显含变限积分因子时把该积分当乘子并入辅助函数后照常查表（变限积分乘子辅助函数分支），不必先把结论化为微分形态
- 函数在所论闭区间连续、开区间相应阶可导
- 结论可经恒等变形移项归入等于零、等于常数、不等式三类之一
- 待证中值点为区间内一点（或可拆成两点独立处理）
- 函数在包含平移后自变量的整段闭区间上连续
- 平移步长不超过区间长度，辅助函数定义域闭合
- 题设给出两端点函数值相等或等分点取值的加和关系
- 分段点两侧表达式明确
- 各段导数方程可解
- 端点函数值相等或可凑出相等
- 辅助函数在闭区间连续开区间可导
- 端点函数值给定且函数不恒等于线性基准
- 辅助函数端点值异号
- 两段上函数满足中值定理条件
- 二阶导数在闭区间上有界
- 最小值在开区间内部取得
- 函数二阶可导、积分条件可中值化
- 参数为任意实数时辅助函数仍可导
- 两函数在闭区间连续开区间可导
- 分母函数导数在区间内不为零
- 函数连续且均值非零
- 两点位于半值点两侧
- 函数二阶可导、比值极限非零有限
- 两函数连续可导、题设给零值端点
- 函数在闭区间可导
- 单侧导数存在且可判号
- 函数二阶可导、端点值给定
- 单侧差商符号可判
- 函数可导且导函数严格单调
- 权重点落在两点之间
- 函数可导且插点方案可行
- 端点值给定且分点可任意选取
- 两函数满足柯西条件

### 标准解题步骤

1. 改写定义式：把给定的极限或增量关系整理为固定点处函数值之差除以自变量之差的标准差商形式；多元时写成增量减线性主部除以距离
2. 配凑基准项：分子缺少该基准点函数值时加减该项凑出定义结构，并核对分子分母增量的倍数关系
3. 判增量阶：考察实际增量相对自变量增量的阶，同阶对应非零导数、高阶对应导数为零、低阶或振荡则不存在；含绝对值与分数幂时把各因子零点重数累加与一阶比较
4. 分侧验证：分界点与含绝对值、最大最小的表达式须分别求左右差商极限，两侧都存在且相等才能断言可导
5. 逐方向与全平面分离：多元场合先用单变量差商定各偏导是否存在，再验全平面一致趋零定可微，必要时取不同路径给反例
6. 回溯连续性：需要函数值关系时由可导（可微）直接推出连续，并检验是否误把连续当成可导的依据
7. 区分两个概念：涉及导函数在该点是否连续时回到定义单独验证，不能以导函数的极限代替该点导数

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 线性主部定量分支 | 要求写出函数增量、微分或用线性近似估计函数值的变化量 | 设导数存在并把实际增量写成线性项加高阶余项 → 用线性项作为近似值、高阶余项作为误差量 → 检验余项相对于自变量增量确为高阶无穷小 | 仅在一元范围内可微与可导等价，多元情形不能照搬此结论 |
| 概念链判断分支 | 选项式判断可导、连续、可微、左右导数之间的推出关系，且不涉及导函数极限、幂次条件组合或保号性结论 | 把每个命题翻译成增量阶的表述 → 按同阶、高阶、低阶三种情形逐一验证命题方向 → 需要否定逆向命题时用增量低于一阶或振荡型结构构造反例 | 只能由可导推连续，逆向一律不成立；导函数自身的连续性不蕴含在该点可导之内 |
| 左右导数分支 | 分段点或含最大最小的表达式处需分别求左右差商极限，题目不含待反解参数，且结构不可化为幂零因子乘积（可化的归 T-HS-09-S） | 分别按定义求左右差商极限 → 核对两侧极限都存在且相等 → 不相等时明确记为左右导数存在而该点不可导 | 分界点两侧表达式须已知；断言可导还须函数在该点有定义且取值与极限一致 |
| 定义配凑分支 | 极限式中出现该点函数值之差，但增量系数与分母形式与定义不一致 | 提取分子增量与分母增量的倍数关系 → 补成标准差商并乘回系数 → 若同时含两个不同增量，拆成两处导数的线性组合 | 必须先确认该点导数存在，否则配凑只能给出单侧信息而非极限值 |
| 一点导数与导函数极限区分分支 | 题目直接问该点导数是否存在与导函数在该点极限是否相等、能否互推 | 该点导数一律交由定义验证 → 再单独考察导函数在该点的左右极限 → 只有导函数在该点连续时两者才相等，否则只有一点导数存在可言 | 由导函数极限存在推出该点导数存在，需原函数在该点连续这一前提，缺此前提不得换算 |
| 分段点连续条件锁参数分支 | 分段函数在分段点只要求连续（或已知连续），据此反解一个待定参数 | 把连续条件改写为极限值等于分段点定义值的等式，明确方程两端 → 拆项分式逐项判断能否分别取极限，再定各部分的无穷小阶 → 用等价无穷小或凑导数定义求出拆出各项的含参极限 | 分段点处分子分母同趋于零且未定式可控；拆项后某项极限不存在时不能对和式分项取极限，相消需保留更高阶信息时只用一阶等价会出错 |
| 导数定义结构定间断分支 | 分式在分母零点处的极限可补成分子在该点的差商，且分子在该点可导 | 定位分母为零或分段规则单独规定的那一点，作为唯一可疑点 → 靠拢该点极限与导数定义的结构，用分子在该点的函数值补出差商形式 → 利用可导条件判定该极限存在且有限，从而排除第二类间断 | 前提：分子在该点可导且分母为该点的简单一次因子，函数在该点有单独规定的取值；坑点：分子在该点不可导时极限未必存在，分母为高阶零点时商式趋于无穷而变成第二类间断，把极限存在但不等于规定值当作连续 |
| 变限积分左右差商对照分支 | 分段函数中变限积分就是被判可导的那个整体，动作是把差商极限化为被积函数的左右极限 | 分参数为正、为零、为负三种情形对含参极限分别取值，写出分岔后的分段解析式 → 检验分段点处该分段函数的左右极限与定义值，标注间断类型 → 写出变限积分的增量式，利用积分对有限跳跃的抹平性判断其连续性 | 前提：被积函数在积分区间上只有有限个跳跃且处处可积，差商极限可化为被积函数单侧极限；坑点：在间断点直接套用微积分基本定理断言变限积分可导，被积函数含无穷型间断导致积分发散，忘记分岔条件把极限式当作统一解析式处理 |
| 分段点双条件锁参分支 | 分段点处有两个待定参数，须联立连续与可导两个条件求解 | 连续条件列第一个方程 → 两侧差商按定义或法则计算 → 左右导数相等列第二个方程 | 前提：只解连续方程就定参会漏参数；坑点：对数一侧差商需化简 |
| 单侧差商定性态分支 | 分段点一侧含抽象有界因子的性态判定 | 两侧分别求极限定连续 → 两侧按定义写差商 → 一侧等价替换降幂、另一侧有界乘无穷小归零 | 前提：等价替换处于乘除位置；坑点：对抽象因子用洛必达或只算一侧 |
| 复合内层差商配凑分支 | 已知导数值求含复合内层的差商极限 | 识别函数值差结构并确认内层趋于定义点 → 分母用等价替换换成同一无穷小 → 拆成差商因子与无穷小比之积 | 前提：内层必须趋于定义点；坑点：对未知函数本身作等价替换 |
| 任意倍率双点差商分支 | 差式两端是同一点不同倍率增量处的函数值 | 加减该点函数值把差拆成两项 → 每项配凑成标准方向差商并归一倍率 → 按定义分别收口后相加 | 前提：倍率为零时除法非法需单独处理；坑点：两点差不能当一个差商 |
| 已知极限反推导数再配凑分支 | 由含未知函数的极限反推其导数值再求另一差商 | 剥去已知极限的复合外壳 → 由连续性定函数值并把极限读成导数定义 → 所求式按内层增量拆成差商组合 | 前提：函数必须连续才能剥壳定值；坑点：差商不能漏除增量 |
| 单侧定义函数性态分支 | 函数仅在所论点单侧有定义 | 算单侧极限与函数值比较定单侧连续 → 按定义写单侧差商 → 判差商敛散下结论 | 前提：双侧概念不适用于单侧定义；坑点：右极限存在不等于右导数存在 |
| 函数方程差商定解析式分支 | 函数方程与高阶余项求解析式 | 把小增量识别为自变量增量 → 读出可微性与微分方程 → 分离变量积分 | 前提：余项阶数不足只知连续；坑点：分母零点单独讨论 |
| 微分与增量线性主部比较分支 | 比较微分与自变量增量的阶 | 写出微分定义式 → 作微分与增量的商 → 代该点导数值定阶 | 前提：导数值为零时阶的结论不同；坑点：把微分与增量之差当微分 |
| 洛必达一次后导数定义收口分支 | 低阶信息已知且分式可配成差商 | 确认零比零后洛必达一次 → 把分子配成导数定义差商 → 按定义代值收口 | 前提：题给只到某阶可导时严禁对更高阶洛必达；坑点：泰勒展开阶数要足 |
| 由含参极限证可导分支 | 由含未知函数的极限证明可导并求导数值 | 把极限写成极限值加无穷小 → 解出函数表达式 → 连续性定该点函数值 | 前提：未先定函数值就写差商；坑点：余项高阶性要利用 |
| 微分增量主部反求导数分支 | 题设给出微分或增量的线性主部关系，据此求含变限积分的比式极限（积分不作为待判对象） | 由增量关系读出该点导数值 → 分母等价替换成主部幂 → 变限积分求导或换元化简 | 前提：只知连续无增量阶时读不出导数；坑点：变限求导漏上限因子 |
| 可导充分条件幂次匹配辨析分支 | 选项以「某增量被 \|Δx\| 的若干次幂控制」的形式给出，动作是逐个匹配幂次与一阶的关系 | 逐项配凑差商形态 → 核对幂次匹配 → 序列趋近与对称差商只给必要 | 前提：序列极限当全极限；坑点：夹逼漏函数值先为零的论证 |
| 差商倍数反解切线斜率分支 | 由差商极限求切线斜率 | 代换统一差式方向 → 配凑导数定义的倍数关系 → 由极限反解导数值 | 前提：增量方向弄反漏负号；坑点：把极限值直接当斜率 |
| 高阶控制夹逼定导数分支 | 函数绝对值被增量的高次幂控制 | 代入增量零点定函数值 → 写差商取绝对值 → 用界控制成增量的线性函数 | 前提：控制不等式须对双侧邻域成立；坑点：夹逼方向弄反 |
| 单点导数保号性辨析分支 | 已知该点导数不为零（多为 f'(x0)>0）要判断能推出哪些邻域内结论；若题设只给导函数在去心邻域的极限而不给该点导数，归「导函数极限与可导性辨析分支」 | 写成单侧差商极限 → 保号性给右侧邻域函数值比较 → 左侧同理反向 | 前提：由一点导数推区间单调；坑点：左右保号结论混同 |
| 切线截距差商定义收口分支 | 求切线截距相关的比式极限 | 切线方程令纵坐标为零解截距 → 比值整理成零比零 → 洛必达一次 | 前提：对二阶导继续洛必达需连续性；坑点：截距化简出错 |
| 分段导函数连续性分级判别分支 | 要求一阶导连续而二阶导不存在（或按可导阶数分级），据此定参或判间断 | 连续定常数 → 左右导数相等定参数并保证导函数连续 → 分段导函数写出 | 前提：跳过导函数连续性；坑点：左右差商漏一侧 |
| 函数方程组合差商定导数分支 | 周期函数与函数方程联立求切线 | 取极限由周期性定基点函数值 → 差商配凑成导数定义组合 → 解出基点导数 | 前提：高阶余项直接丢项；坑点：周期平移点算错 |
| 系数和即导数值夹逼分支 | 三角多项式系数和的界估计 | 求导读出系数和为该点导数 → 写定义差商极限 → 用已知函数界夹住差商 | 前提：绝对值直接塞进极限；坑点：忘用定义点函数值为零 |
| 导函数极限与可导性辨析分支 | 题设只给导函数在去心邻域的极限（常为分段导函数）而不给该点导数值，要求据此判断原函数在该点可导性、连续性或间断类型 | 保号性给去心邻域导函数为正 → 两侧邻域单增 → 跳跃反例：导函数极限存在而函数不连续 | 前提：导函数极限当单侧导数；坑点：反例不满足前提 |
| 含绝对值分数幂可导性重数判据通法 | 由若干因子连乘构成、含绝对值或分数幂指数、要求在给定零点处判定可导性并求导数值的函数，亦可用于统计不可导点个数 | 圈定可疑点：把绝对值内部为零的点、分数幂因子取零的点以及分段点逐一点出，列成待判清单 → 剥出零因子：在该点把函数按因子拆成剩余部分与以该点为中心的幂零因子之积，拆分时先无视绝对值符号，把各因子贡献的重数相加得总重数 → 校验剩余部分：确认剩余因子在该点连续且取值非零，若其在该点也为零则返回上一步把多出的重数计入 → 定变号性：判断落在绝对值符号内的部分在该点两侧是否变号，不变号时绝对值符号不影响结论 | 可用[所判点是函数的零点且函数在该点有定义，导数定义中的分子可直接写成剩余部分乘以幂零因子；各因子在该点邻域内均可化为「非零连续因子乘以该点距离的某次幂」，即零点重数可定；只需判定单点可导性与该点导数值、统计不可导点的个数，或反解参数使导函数在所论点连续（该点连续仍由该点导数式的阶决定）] 失效[剥出幂零因子后的剩余部分在该点不连续、无极限或本身趋于零却未计入重数时，重数统计失真，判据失效；分段函数在分段点两侧给出互不相关的表达式且均无幂零结构时，只能回到定义分别算左右导数；所判点函数值非零时绝对值符号与分数幂都不制造可疑性，本法多余，应直接用求导法则] |
| 分数幂因子定阶分支 | 出现指数不是整数的幂或根式因子，且该因子在所判点取值为零 | 把该因子的指数直接计入该点零点重数 → 指数落在零与一之间时按低于一阶处理，判定为不可导 → 指数大于一时按高于一阶处理，判定为可导且导数为零 | 指数为负时函数在该点无定义，判据前提不成立，不能套用 |
| 绝对值变号性判别分支 | 只有一个绝对值因子，判别的实质动作是确定其内部在该点两侧是否变号 | 拆开绝对值符号，只看被它包住的那部分因子 → 统计该部分自身的零点重数：偶数重时两侧同号，绝对值不产生折点 → 奇数重（含恰好一重）时两侧异号，才真正引入折点 | 仅当被包住部分在该点为零时才需判别变号；该部分非零时绝对值符号可直接去掉 |
| 超越因子局部线性化分支 | 绝对值符号内是三角、对数、指数型等不能直接因式分解的因子，且在该点为零 | 在该点对该因子作幂展开并只取首个非零项 → 以首项的幂次充当该因子贡献的零点重数 → 首项系数为负时其符号被绝对值符号吞掉，不影响重数结论 | 该因子展开首项不是一阶（例如一减余弦型）时不能按一重计入，必须先定准首项阶 |
| 多因子同零点与参数重合分支 | 参数取某些值时不同零点相互重合，或所判点同时是多个因子的零点，需按重合与否分类 | 把每个因子在该点贡献的重数逐项相加，禁止只看单个因子的指数 → 含参数时按参数是否使零点重合分类，重合各阶的重数抬升后结论可能反转 → 对每个候选点各自独立重算重数，不得把某点的结论平移到另一点 | 各因子必须在同一趋近点展开，否则重数不可相加 |
| 零点重数与外侧因子判可导分支 | 结论要求统计不可导点的个数，动作是逐点把各因子重数累加后与一阶比较 | 拆出各绝对值因子并统计零点重数 → 检查外侧因子在对应零点是否取零 → 恰好一阶且外侧非零者为不可导点 | 前提：外侧因子取零会抬高重数使该点可导；坑点：漏拆复合绝对值 |
| 复合绝对值逐项重数分析分支 | 同一表达式里既有绝对值因子又有光滑复合层，需逐项展开定阶后合成总重数 | 逐项定绝对值内零点重数 → 光滑因子求导后在零点的行为定合成阶 → 恰好一阶折断者为不可导 | 前提：内函数首项高于一阶时绝对值不打断；坑点：忽略外层抬升会误判 |
| 绝对值乘子可导充要分支 | 绝对值因子乘抽象函数的可导充要条件 | 两侧按定义写差商 → 约去公共无穷小 → 左右相等化成外侧左右极限关系 | 前提：漏左右符号差；坑点：附加多余可导要求 |
| 零点重数定最高可导阶分支 | 含绝对值函数在一点最高可导阶数 | 邻域内去掉不变号的绝对值 → 逐项判各成分在该点的可导阶 → 定义验证临界阶 | 前提：内函数首项高于一阶时不是折点；坑点：逐项阶数判错 |
| 幂次阈值逐级判阶分支 | 含参的负幂次（倒幂）因子乘以有界振荡因子，动作是按参数阈值逐级判断商式是否趋于零 | 连续性定第一阈值 → 差商幂次定可导阈值 → 导函数极限定连续阈值 | 前提：阈值递增关系记错；坑点：对振荡因子用洛必达 |
| 参数分界点定义判可导分支 | 绝对值参数曲线在分界点的可导性 | 分参数改写绝对值成两支 → 两支分别按参数求导 → 分界点按定义算左右差商 | 前提：不回定义直接代分段导函数；坑点：漏验连续性 |
| 绝对值与积分因子逐项辨析分支 | 给出一组含绝对值或变限积分的候选函数，动作是逐个判断在所判点是否可导 | 逐项定绝对值零点重数与外侧行为 → 变限积分项看被积函数间断类型 → 逐项按定义或结论判定 | 前提：可去间断的变限积分仍可导；坑点：折点重数判错 |
| 幂次压制振荡定导连续分支 | 含参振荡因子与幂次相乘，动作是反解参数使导函数在该点连续（只需该点导数式定阶，不要求邻域内的导函数性态） | 定义求右侧单侧导数定第一阈值 → 写分段导函数 → 两支振荡项分别压制定第二阈值 | 前提：阈值取等混淆；坑点：导函数求导漏项 |
| 含参积分定义的函数在参变量奇值点处的连续性与可导性判定 | 先单独计算参数取特殊值时的积分，识别被积函数在该点的瑕点性质并用带下限极限的反常积分定义处理 | 对反常积分先求原函数，再用洛必达法则处理端点处幂乘对数的极限 → 在参数取一般值时用分部积分，把对数因子留在积分号外，剩下有理式积分 → 把余下的有理式分子配成同分母再分离常数，化为标准反正切型积分 | 含参积分在参数取特殊值时才有奇点，其余参数值下积分正常；失效：不加区分地把分部积分公式套到含瑕点的积分上，边界项失控 |
| 多元微分概念关系与可微性判定通法 | 分段（含绝对值、振荡因子）函数在原点处的偏导存在、可微与偏导连续判别 | 写出偏导、可微、连续三个定义式，标明各自控制单方向还是全平面 → 分段点用偏导定义固定其余变量取差商极限，先定该点偏导是否存在 → 偏导存在后按可微定义考察增量减线性主部除以距离，用有界乘无穷小或路径放缩定其是否趋零 → 在分段区域外求出偏导函数并取极限，检验偏导在该点是否连续 | 可用[函数在原点（或分段面）另行定义，或含绝对值与振荡因子；需要分别判断偏导存在、可微、偏导连续三件事；概念辨析题不给具体解析式，只给存在性条件] 失效[非分段点直接套求导公式即可；偏导不存在时谈不上可微与偏导连续；题设已含可微或偏导连续，可直接用强结论] |
| 概念推出关系分支 | 不给解析式，只给偏导存在或连续等存在性条件 | 由偏导定义直接推出沿坐标方向的极限存在与该方向有定义 → 对反向推断构造沿不同路径取不同值的反例 → 按选项逐条判定，排除只由单方向信息支持的弱结论 | 概念辨析题不给具体解析式，只给存在性条件；失效：题设已含可微或偏导连续，可直接用强结论 |
| 局部展开读偏导分支 | 已知函数等于可展函数加比距离高阶的无穷小 | 把主部系数与全微分定义中的线性主部对照，读出函数值与两个偏导 → 求复合函数微分时把读出的偏导代入链式法则 → 求沿路径的差商极限时把增量代入线性主部并估算余项阶 | 已知形如函数等于可展函数加比距离高阶无穷小的局部信息；失效：余项不是比距离高阶的无穷小，读不出线性主部 |

### 失效边界

**适用前提**（69 条）

- 讨论对象是一元函数在一点或一个区间内的可导性、可微性与连续性的关系
- 该点邻域内的函数表达式已知，或增量与自变量增量的阶可以直接估计
- 题目形式为概念判断、由定义求差商极限或单点（分界点）可导性讨论
- 分段点处分母趋于零且分子同趋于零，属可控的未定式
- 函数在该点的定义值以含参表达式给出
- 分子在该点可导且分母为该点的简单一次因子
- 函数在该点有单独规定的取值
- 被积函数在积分区间上只有有限个跳跃且处处可积
- 差商极限可化为被积函数单侧极限
- 分段点两侧表达式已知且参数使函数在该点连续
- 左右导数可通过定义或洛必达求出
- 两侧表达式明确且抽象因子有界
- 等价替换处于乘除位置
- 已知函数在该点可导且函数值给定
- 内层增量与分母可化为同一无穷小
- 函数在该点可导
- 倍率为任意实数
- 函数连续使复合外壳可以剥去
- 各内层增量都趋于同一被减点
- 函数在该点有定义且单侧表达式已知
- 分段点两侧表达式已知
- 参数使函数连续
- 函数方程对所论范围内任意变量成立
- 已知一点的导数值
- 已知低阶导数值且分式可配成差商
- 函数在该点连续且已知极限有限
- 无穷小余项的高阶性可利用
- 函数连续使变限积分可导
- 增量关系在被减点成立
- 各选项极限式的结构可配凑
- 增量与被减方向一致
- 存在平方型控制不等式对邻域内一切点成立
- 该点导数存在且符号确定
- 余项是增量的高阶无穷小使可微性成立
- 分离变量合法（分母不为零）
- 二阶导连续恒正使一阶导严格为正
- 各极限可分步求
- 各段表达式可求导
- 差商极限可算
- 函数周期已知且在基点可导
- 增量余项为高阶无穷小
- 各选项结构可完全分析
- 函数界对一切增量成立
- 定义点函数值为零
- 函数在该点附近二阶可导且二阶导数值非零
- 导函数在去心邻域存在
- 所判点是函数的零点且函数在该点有定义，导数定义中的分子可直接写成剩余部分乘以幂零因子
- 各因子在该点邻域内均可化为「非零连续因子乘以该点距离的某次幂」，即零点重数可定
- 只需判定单点可导性与该点导数值、统计不可导点的个数，或反解参数使导函数在所论点连续（该点连续仍由该点导数式的阶决定）
- 绝对值内因式可分解、外侧因子多项式
- 绝对值内零点结构简单可展首项
- 外侧因子有连续导数、折点因子标准
- 绝对值内函数在该点邻域不变号或其零点结构可判
- 各成分零点重数可分析
- 绝对值保证两侧对称，振荡因子有界
- 绝对值因子标准一阶零点
- 两支参数表达式明确、变限积分可求导
- 各项结构可归入标准形态
- 振荡因子有界、幂次控制可判
- 与 T-HS-11-S 的左右导数分支重叠时本法优先：凡所判点可化为「非零连续因子 × 该点距离的幂（含绝对值折算）」的乘积结构，一律按零点重数判定，不再退回逐侧算左右导数
- 含参积分在参数取特殊值时才有奇点，其余参数值下积分正常
- 分部积分后剩余积分可用标准公式显式算出
- 差商的左右极限存在但不相等，可用反正切函数的渐近值判定
- 函数在原点（或分段面）另行定义，或含绝对值与振荡因子
- 需要分别判断偏导存在、可微、偏导连续三件事
- 概念辨析题不给具体解析式，只给存在性条件
- 需区分沿方向与全平面的极限
- 已知形如函数等于一阶线性主部加比距离高阶无穷小的局部展开，主部系数可以为零（照样读出该点偏导为零）
- 要判定的极限是「增量减线性主部除以距离」是否随全平面一致趋零（可微性）或某个单方向差商是否存在（偏导），不是单纯求一个二重极限的值——后者归二重极限定路与代换判别通法

**失效场景**（124 条）

- 多元函数的偏导、可微与连续关系不适用本骨架，一元下「可微等价可导」在多元端直接失效
- 只知连续而无增量阶信息时不能推出可导，连续但增量低于一阶正是典型的反例来源
- 该点导数存在不等于导函数在该点连续，把两者混用会使极限交换与间断点判断出错
- 抽象函数只给出函数方程或不等式而无具体表达式时，判阶一步无法执行，只能回到定义逐条验证
- 分界点处只验证单侧差商极限就断言可导，属于结论超出前提的失效用法
- 拆项后某项极限不存在时不能对和式分项取极限
- 分子分母相消需要保留更高阶信息却只用一阶等价替换
- 只验一侧极限就断定连续
- 分子在该点不可导时极限未必存在，不能先验归类
- 把极限存在但大于零直接当作连续
- 分母为高阶零点时商式趋于无穷而变成第二类间断
- 在间断点直接套用微积分基本定理断言变限积分可导
- 被积函数含无穷型间断导致积分发散时讨论失效
- 忘记分岔条件，把极限式当作统一解析式处理
- 左右极限不相等时连续性已破坏，可导无从谈起
- 只验左右导数相等而不先验连续，会把参数解错
- 含绝对值一侧直接用求导法则忽略折点
- 对含抽象因子的差商用洛必达
- 只算一侧就下结论
- 等价替换用于加减结构
- 内层不趋于定义点时不能配凑导数定义
- 对未知函数本身作等价替换
- 把复合差商当连续函数直接代值
- 把两点差直接当一个差商配凑
- 倍率为零时除法非法未单独处理
- 漏掉其中一项
- 函数不连续时壳内极限不能拆项
- 把函数值差直接当导数而不除以增量
- 两个差商混成一项丢失增量比的差异
- 双侧概念用于单侧定义函数
- 把右极限存在误当右导数存在
- 题目要求可导（或须联立连续与可导两条件）时只解连续方程定参，会漏解或增解；只要求连续或已知连续时解连续方程本身就是正解
- 对数一侧差商不化简
- 联立时漏解或增解
- 增量必须使复合变量落在定义域内
- 把差商直接当导数而不配凑已知点
- 积分常数定错
- 把微分与增量差当成微分本身
- 导数值为零时阶的结论不同
- 题给只到某阶可导却对更高阶用洛必达
- 把导数极限当导数值
- 泰勒展开阶数不足
- 未先定函数值就写差商
- 忽略余项项的高阶性
- 对未知函数作等价替换
- 只知连续而无增量阶信息时读不出导数
- 变限积分求导漏乘上限的导数
- 对未知函数部分作等价替换
- 把对称差商当可导充要条件
- 忽略无穷小乘有限量的干扰
- 配凑时增量方向弄反
- 增量方向弄反漏负号
- 把极限值直接当斜率而忽略倍数
- 变量代换后未同步改极限过程
- 控制不等式只在单侧成立时结论变弱
- 夹逼方向弄反
- 由一点导数正推区间单调
- 左右两侧的保号结论混同
- 余项阶数不足时只能得连续不能得可微

### 标准解题步骤

1. 识别函数的表示方式（显式、隐式、参数、幂指），选对应的链式重排
2. 乘积因子在零点求导时只留非零因子项收缩计算量
3. 多元场合按依赖图画通路，每条通路链式相乘后相加；隐式方程组先判能否解出因变量
4. 高阶导数：归纳出通项公式、对乘积用莱布尼茨取低阶截断、或在泰勒展开中读系数，三径择易
5. 相关变化率与几何量：把目标量对时间或参数求导，用链式法则串起各变化率
6. 代一个具体点核对链式通路没有漏乘

| 显式固定变量求偏导分支 | 函数由初等表达式显式给出、所求点不在分段处，且只求一阶或具体低阶偏导（阶数以符号 n 给出时改走拆项套通项支） | 化简偏导式，幂指因子先取对数或用乘积法则展开 → 按全微分公式把各偏导与对应微分相乘后相加 → 代入指定点得到该点的全微分或偏导值 | 函数由初等表达式显式给出且偏导在求值点连续；失效：分段点或绝对值内为零处需改用定义 |
| 拆项套通项求高阶分支 | 求以符号阶数 n 给出的高阶偏导，且被求式可拆成关于该变量的一次因式倒数之和，可直接套 (1/t)^{(n)} 的通项 | 写出倒数求任意阶导数的通项（含交错符号与阶乘因子） → 逐项套用通项，只对指定变量累次求导 → 代入该点坐标并合并同类项得闭合表达式 | 被求式可拆成关于该变量的一次式倒数线性组合；失效：分式含不可分解的高次因式，通项法不适用 |
| 隐式方程（组）确定函数的求导通法 | 单一方程确定单一依赖变量，求其一阶偏导、全微分或代点二阶导 | 把方程（组）写成整体等于零的形式，验证已知点满足 → 检验各变量对应偏导是否非零，据此确定可解出的因变量与求导合法性 → 两端对目标自变量求导，依赖变量的导数作为未知量 → 单方程解单个导数（或用两端偏导之比），方程组整理成线性组后用消元或克莱姆公式解出各导数 | 可用[单一方程确定单一依赖变量，且其对应变量的偏导不为零；约束方程个数与待定因变量个数相同；所求导数在求导后的方程组中线性出现] 失效[相应偏导为零，隐函数定理条件不满足；分段或绝对值使代点处偏导不存在；系数行列式为零，导数不唯一或不存在] |
| 方程组定一元导数分支 | 多个方程确定同样多个一元函数，导数在求导后线性出现 | 各方程两边对自变量求导，把所求导数当未知量 → 整理成关于未知导数的线性方程组 → 用克莱姆公式或消元解出各导数并写回原函数记号 | 约束方程个数与待定因变量个数相同；失效：系数行列式为零，导数不唯一或不存在 |
| 存在定理选因变量分支 | 只问某邻域内能确定哪个因变量的隐函数，不需求导数值 | 分别求它对每个变量的偏导并在已知点取值 → 凡偏导非零者即可作为该邻域内隐函数的因变量 → 把不可解出的变量排除后与选项逐条比对 | 各偏导连续且只讨论某点的局部可解性；失效：所有相关偏导都为零，定理给不出结论 |
| 对合代换闭合函数方程求解析式 | 未知函数只出现在互为对合的两个自变量处（x与负x、x与一减x、x与x分之一等）的函数方程求解析式及奇偶判定 | 识别函数方程中自变量的变换规律并验证两次作用回到自身 → 用该变换替换原方程中的自变量，写出第二个同型方程 → 视两式为以两处函数值为未知量的线性方程组并消元求解 → 检验消元所用系数之差非零，确认题设条件正对应此可解性要求 | 可用[未知函数只出现在互为对合的两个自变量处；消元所需的系数行列式在题设条件下不为零；自变量取值范围对该变换封闭] 失效[变换不可逆或迭代产生新未知点时方程组无法闭合；系数行列式为零时解不唯一或不存在；忽略自变量取值范围把结果推广到使原式无意义的点] |
| 变量代换化简二阶偏导 | 线性变量代换下化简二阶偏微分表达式、比较系数定参数或还原函数 | 由新变量与自变量的关系用链式法则求一阶偏导 → 再求一次得二阶偏导，注意一阶结果本身仍是复合函数 → 把二阶式代回原方程，按新变量的二阶偏导合并同类项 → 比较系数确定参数或读出目标形式的偏导值 | 可用[代换为自变量的线性组合且函数有二阶连续偏导；代换后的目标形以「消去一个或若干个纯二阶偏导、只留混合偏导」或化成标准波动型为限，其他目标形须重设代换（系数无法全配即入失效场景）；本法止于比较系数定参数或读出目标形式的偏导值；化简后需要由偏导信息（或标准形方程加定线条件）反求函数表达式的，交由偏导（全微分）还原函数与定参通法] 失效[代换的雅可比为零时新变量不独立；系数无法全部匹配，需重设代换] |

### 失效边界

**适用前提**（69 条）

- 函数在各层可导且表示形式明确
- 隐式方程可确定可导函数
- 相关变化率中各量都是同一变量的可导函数
- 方程各项为正可取对数
- 一阶导数可显式解出
- 三角参数可用半角公式化简
- 指定极角处横坐标参数导数不为零
- 极径表达式可代入
- 横坐标参数导数不为零（摆线在尖点除外）
- 半角公式化简方向正确
- 函数在关于原点对称的区间上有相应阶导数
- 各几何量都是时间的可导函数
- 恒等式在全程成立
- 曲线方程确定坐标间可导关系
- 指定点各量已知
- 所求点使至少一个因子取零且动作是算出该点或该阶的导数值（判该点可导性、统计不可导点个数归 T-HS-09-S）
- 其余因子在该点有定义
- 内层函数单调使变量代换可逆
- 内层取值范围覆盖所求范围
- 恰有一个因子在所求点取零
- 几何相似比例恒定
- 两容器内液体总量守恒
- 原函数导数在所论点非零
- 各阶导数存在
- 增量方向与参数区间端点一致
- 参数导数在该点存在
- 交点可解且外层因子在该点为正
- 〈1〉原函数的概念
- 内层函数在讨论点可导
- 变限积分的被积函数连续，积分对参数可导
- 横坐标对参数的导数在关注点非零，保证参数可反解
- 关注点处低阶导数依次归零，展开存在首个非零项
- 低阶导数呈现规律
- 乘积因子之一为低次多项式
- 函数在该点存在足够阶展开
- 指数型因子在无穷远处衰减快于任意幂次增长，使各阶导数在该点的极限为零
- 各阶商式可化为同一标准形态
- 方程使每阶导数可写成同型函数的幂
- 函数在零点邻域存在到所需阶的展开
- 一阶导数可化为标准初等函数
- 内层为线性函数使链式因子恒定
- 函数可分解为 (x−a)^m·g(x) 且 g(a)≠0，重数 m 与目标阶数 n 可对照：n<m 时该阶导数为零，n=m 时取 m!·g(a)，n>m 时须再用莱布尼茨逐项补齐
- 导数关系可整理成多项乘积
- 特殊点使二次因子取零
- 结论要求给出某阶导数的具体值或 n 阶通式；若结论只问该点最高可导阶数或是否可导，归 T-HS-09-S 的零点重数判据
- 外层为抽象多元函数、内层为可求导的具体表达式
- 中间变量与自变量个数都能明确写出
- 显式初等式走固定变量法时要求偏导在求值点连续且求值点不在定义域边界或分段点上；落在分段点的偏导与可微性一律交多元微分概念关系与可微性判定通法
- 拆项套通项仅限被求式可拆成关于该变量的一次式倒数之和且阶数以符号给出的那一支；其余高阶偏导把一阶结果重新当作待求式逐次求导，只求低阶时直接逐次求导更省
- 依赖变量的导数由方程（组）隐式给出的复合求导交隐式方程（组）确定函数的求导通法，本法只处理依赖关系由显式代换或初等表达式给出的复合
- 单一方程确定单一依赖变量，且其对应变量的偏导不为零
- 约束方程个数与待定因变量个数相同
- 所求导数在求导后的方程组中线性出现
- 各偏导连续且只讨论某点的局部可解性
- 题目问能确定哪些隐函数而非求导数值
- 所求导数的阶数不超过二阶（包括混合偏导的一般表达式与代点值两种），更高阶本法只保证逐层求导而不保证闭式
- 与多元函数求偏导与全微分通法的分工：依赖变量的导数由方程（组）隐式给出时走本法，由显式代换给出时走该法；本法第3步内的链式求导仍按该法的通路相加规则执行
- 未知函数只出现在互为对合的两个自变量处
- 消元所需的系数行列式在题设条件下不为零
- 自变量取值范围对该变换封闭
- 方程中未知函数只出现在互为对合的两个自变量处
- 代换为自变量的线性组合且函数有二阶连续偏导
- 代换后的目标形以「消去一个或若干个纯二阶偏导、只留混合偏导」或化成标准波动型为限，其他目标形须重设代换（系数无法全配即入失效场景）
- 本法止于比较系数定参数或读出目标形式的偏导值；化简后需要由偏导信息（或标准形方程加定线条件）反求函数表达式的，交由偏导（全微分）还原函数与定参通法
- 内层为非线性整体（如指数因子乘三角因子）且待求的是那个一元函数本身时，归由偏导等式反解未知函数通法，不入本法
- 函数由初等表达式显式给出且偏导在求值点连续
- 求值点不在定义域边界或分段点上
- 只需求一阶偏导、一阶全微分或代点二阶导
- 目标形只含混合偏导或标准波动型算子

### 标准解题步骤

1. 判参数位置：被积函数含参先做整体换元把参移出，上限含参按复合求导
2. 标准形直接套「上限函数值乘上限导数减下限函数值乘下限导数」
3. 对称区间或奇偶被积式先用对称性整块削零再求导
4. 含参方程两边对参数求导，解出目标导数或定出参数
5. 代回验算：对一个具体被积函数复核求导公式

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 积分方程化微分方程分支 | 积分方程确定函数再求导数或高阶导数，上下限同时含变量时对上限与下限各乘其导数复合求导 | 两端求导消积分号 → 取初始条件 → 解方程并展开读系数 | 漏初始条件是高频错 |
| 被积函数为参数与变量组合的变限积分求导 | 观察组合式的微分，把余下因子并入微分号内并记录倍率 | 以组合式为新变量代换，上下限随之改为参数表达式 → 整理成常数倍的标准变限积分 → 对上限求导并乘上限的导数 | 被积函数只通过单一组合依赖参数与变量；失效：组合式与余因子不匹配时无法整体代换 |
| 变限积分与幂的比式极限 | 按组合代换把积分化为变限积分的标准形式 | 由被积函数在零点的线性主部定出其阶 → 对主部积分得到积分整体的阶与系数 → 与分母的幂比较，同阶时写出系数比 | 被积函数在零点可导且零点值为零；失效：被积函数在零点非零时积分阶为一，与高阶分母之比发散 |
| 含反函数的变限积分方程反求原函数并定值 | 对被积函数的平移自变量做换元，同时把上下限同步平移，使积分号内只剩反函数 | 写出化简后的等式，两侧同对新变量求导 → 左侧用变限积分求导法则，上限为复合函数时补上其导数因子 → 利用反函数与原函数互为逆映射的关系，把反函数在原函数处的取值还原为自变量 | 函数可导且存在反函数，使复合取值能还原为自变量；失效：反函数不存在或多值时把逆映射关系当成恒等式使用 |
| 两个变限积分之比的极限 | 确认分子分母在上限趋于同一点时都趋于零，判定为零比零型未定式 | 对分子求导：被积函数取上限处的值再乘上限对自变量的导数 → 对分母求导：同样先代上限再乘其导数，注意上限本身是三角函数 → 把求导后的表达式按因子拆开，识别出可单独求极限的连续因子 | 被积函数在上限趋向点附近连续或有可去型极限；失效：被积函数在积分路径上变号或无界，先估阶再约项导致结论错误 |
| 上限为三角函数、分母为高次幂的变限积分极限 | 用积分上下限交换把分子改写成下限固定于极限点的形式并补负号 | 确认分子分母同时趋于零，对两者分别求导 → 分子求导：被积函数代上限值，再乘上限对自变量的导数 → 分母求导：幂函数降次，得到低一阶的幂 | 被积函数在上限附近连续，变限求导法则可用；失效：被积函数在对数内部趋于无穷时忽略其符号，导致上下限交换漏负号 |
| 嵌套变限积分与三角幂分母的极限 | 把分母中的三角差式用等价无穷小改写成幂函数乘常数，减少求导轮次 | 确认整体为零比零型，对分子分母各求一次导 → 外层求导时把内层变限积分整体作为被积函数代入外层上限 → 此时分子仍趋于零，对内层变限积分再求导：被积函数代内层上限值 | 各层被积函数在相应上限趋向点连续，逐层求导合法；失效：把内层积分当成常数求导，遗漏其上限依赖 |
| 被积函数含参数幂的变限积分求导及其导数的连续性讨论 | 把被积函数中含参数的整体作为新变量，同步改写上下限并提出参数因子 | 在非零参数处按乘积求导法则展开，包含变限积分求导项与倒数因子求导项 → 在参数为零处改用导数定义，把函数值写成积分除以幂次形式 → 对该未定式用洛必达，分子由变限积分求导直接给出被积函数端点复合值 | 被积函数连续保证变限求导可用；失效：在零点直接用求导法则（表达式无定义） |
| 由极限存在且非零反定变限积分下限与参数取值 | 由分母在极限点的趋向判断分子必须趋于零，据此确定变限积分下限取极限点 | 把分子按变限积分求导的思路估计其无穷小阶，被积函数在零附近的幂次加一即为阶数 → 写出分母在极限点的展开，若参数不取使线性项抵消的值，分母保持低一阶的量级 → 用阶数不匹配会迫使极限为零或无穷这一逻辑，反证参数必须取特定值 | 极限点在分母的零点处，且题设给出极限存在且非零；失效：极限允许为零时，不能用阶数不匹配反推参数 |
| 变限积分型函数在闭区间上的最值 | 对变限积分求导得到端点处的被积表达式 | 解导数为零的方程，检查分母恒正使符号只由分子决定 → 按驻点划分区间判断导数符号与单调走向 → 把驻点与区间两端点列为候选 | 被积函数连续使求导法则成立；失效：只验驻点漏验端点 |
| 由曲边梯形面积公式反推其绕变动竖直轴旋转体体积 | 由面积表达式求导得出该处曲线高度 | 以壳的横坐标为微元变量，写出半径为边界减壳位、高为曲线值的柱壳微元 → 把体积写成上限为边界的定积分并拆成两项 → 对边界变量求导，上限处两项恰好抵消只剩面积的倍数 | 函数非负连续保证柱壳高单值；失效：轴穿入区域时半径变号需分段 |
| 积分整体平移差商的极限 | 把含增量的被积积分按平移代换改写，同步移动上下限 | 与原积分相减，整理成同型积分之差 → 确认分子分母同时趋于零，对增量用洛必达 → 分子由变限积分对上限与下限分别求导，注意下限项带负号 | 被积函数连续保证求导与取极限合法；失效：把极限号与积分号随意交换（函数未必可导） |
| 由幂指型极限关系反解函数表达式 | 把幂指式写成以指数乘对数的形式并整体取对数 | 识别该式为对数复合函数的差商，补上内层因子得出导数 → 与已知右端指数对数后令导数相等，得一阶导数方程 → 把右端分式拆成可分别积分的两项 | 函数恒正才能取对数；失效：直接对幂指式取极限漏掉对数化步骤 |
| 积分号内含参量因子的极限求值 | 把积分变量与被积函数中随极限过程变化的因子组合成整体并作代换 | 同步改写上下限，把原因子从被积函数中消去 → 分母用带分数指数的等价无穷小化成单幂次 → 对所得零比零型用洛必达，分子由变限积分求导直接给出端点值 | 代换后的上限随过程量趋于定点；失效：把过程量当积分变量直接求导 |
| 平移卷积型变限积分商式的极限 | 识别被积函数中只依赖上限与变量之差，做平移代换还原成常规积分 | 把带自变量权的项按差式拆成两部分 → 将提出的函数因子按其趋于零的阶单独分离成已知极限 → 对含积分的商式分子分母同乘或同除合适的幂次 | 被积函数连续且在该点取零使积分阶高于二；失效：把上限变量与积分变量混同求导 |
| 由导数定号判定变限积分型不等式的真伪 | 识别积分号内可提出的参量因子，把不含上限的积分化成常数乘该因子 | 比较仅剩的幂次大小，必要时用特殊函数验证排除选项 → 对含变上限的一组把差构造成辅助函数 → 求导时把上限处的乘积项按求导法则展开并合并同类项 | 被积函数连续保证中值定理可用；失效：把参变量当积分变量求导 |
| 由复合自变量处的导数关系式反求原函数 | 把导数条件中的复合自变量整体设为新变量，并用反函数关系改写原自变量 | 同步把等式右端的因子换成新变量的表达式，得常规导数形式 → 对新变量积分求原函数 → 识别对数与倒数的乘积恰为对数的微分，凑微分写成幂形式 | 整体代换的映射单调可逆；失效：只换左端自变量不换右端 |
| 由含参差式的积分方程反解被积函数并求极值 | 把被积函数的自变量整体视为新变量，用凑微分提出常数因子 | 按新变量改写上下限，使积分成为下限随参数变动的变限积分 → 把变动的下限整体换成新参数，等式改写成纯变限积分形式 → 两端对参数求导，用变限积分求导法则直接解出被积函数 | 被积函数连续保证求导合法；失效：把参数与积分变量同时求导 |
| 由含参差商极限关系式反解函数表达式 | 把分母中自变量因子移到右边，使极限式只剩差商结构 | 在分子中同加同减同一中间函数值，拆成两个差商 → 对第一个差商把内层增量视为整体，凑出复合函数导数并补上内层导数 → 第二个差商直接是函数在该点的导数 | 公共因子在讨论范围内不为零才可约去；失效：约去可能为零的公共因子 |
| 含反函数的积分恒等式定导数值 | 对恒等式两边求导，上限代入被积函数并乘上限的导数 | 用反函数关系把上限代入处的函数值化简为已知量 → 由所得导数等式换元定出原函数的导数表达 → 积分还原原函数并用给定点的函数值定积分常数 | 〈1〉原函数的概念；失效：反函数不可导时倒数关系失效 |
| 隐函数定点导数与变限积分定阶求极限 | 由方程直接代出零点处的函数值 | 方程两边对自变量求导，代已知点解出该点导数值 → 把积分中的倍率因子作为新变量整体代换，同步改写上下限并把倍率提到积分号外 → 将剩余的极限式拆成标准极限与变限积分比式两部分 | 函数在零点可导且函数值为零；失效：被积函数在零点不为零时积分阶为一，与分母不匹配 |

### 标准解题步骤

1. 确定定义域并找全部可疑点（驻点、不可导点、无定义点）
2. 一阶导数定号列区间表：单调区间与极值候选一次读出
3. 二阶导数定号：凹凸区间、拐点（须两侧变号）与极值的第二判据
4. 最值在候选点与端点间比较；含约束的最值先代入消元或配乘数方程组
5. 渐近线穷尽垂直与斜两个方向（比值极限与差值极限），曲率按公式代入
6. 方程根的个数与分布用单调性加零点定理夹逼
7. 代一个特殊点核对符号表没有填错

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 比式极限定极值分支 | 题设只给 [f(x)-f(x0)] 与某幂次之比的极限值，无各阶导数信息，据保号性直接定两侧符号 | 拆差商得导数值 → 保号性定邻域符号 → 对照定义下结论 | 只算导数不查邻域符号会漏判 |
| 驻点参数化分支 | 驻点随参数变化并求相关极限或切线 | 令导数为零解驻点 → 解含参表达式 → 化归基本极限或点斜式 | 驻点不唯一按题设取 |
| 构造差函数判号分支 | 结论是对给定两点或整个区间恒成立的大小比较，须作差构造辅助函数并用单调性定号；结论含待证中值点时归 T-HS-02-S | 移项构造辅助函数 → 求导判号定单调 → 端点或基准点比较 | 幂指先取对数；判号所需基本不等式方向要对 |
| 参数混合极值分支 | 参数方程与隐式方程共同确定函数 | 分别求参数与隐式变化率 → 合成一阶导数 → 判号定极值 | 判号后把参数区间换算回自变量 |
| 综合性态分析分支 | 要求完整给出单调区间、极值、凹凸、渐近线等性态（或据性态说明方程根的个数），本法只负责一阶导的单调与极值最值，凹凸拐点取 T-HS-46-I、渐近线取 T-HS-63-I、曲率取 T-HS-65-I，各段结论并列后合并，且不以反解参数为目标 | 驻点分段判单调 → 极值与端点极限定形 → 渐近线或根数随之确定 | 两侧不对称须分别算；根计数要存在加唯一 |
| 约束最值分支 | 等式约束或恒成立条件下求最值或反求参数 | 约束消元或驻点联立 → 最值表达式化参数不等式 → 解参数范围 | 临界取等要单独核对 |
| 水平线交点反参分支 | 已知方程根的个数或极值点个数，须反解参数取值范围，动作是把根个数化为水平线与已知曲线的交点数 | 导数方程参数分离 → 研究已知函数性态 → 端点极限与极小值定交点数 | 临界取等要单独核对 |
| 积分因子保序分支 | 一阶线性微分不等式保序 | 乘积分因子配成乘积导数为正 → 乘积单加初值给函数恒正 → 回代得单调并排序 | 积分因子恒正且连续 |
| 高阶泰勒余项定极值分支 | 已知该点各阶导数值（低阶全为零、某阶非零），用泰勒展开的最低次项定极值 | 写带拉格朗日余项展开 → 余项主导 → 保号定增量符号 | 余项符号判断错则极值类型反 |
| 定义与保号辨析分支 | 由极限、增量或单侧信息判定可导性与局部性态 | 配凑导数定义或比式 → 保号性定邻域符号 → 反证或反例排除错误方向 | 单点信息推不出区间单调；图形信息要读全 |
| 由平方量级的绝对值控制与凸性定积分符号 | 由控制式在该点取极限定出函数值为零 | 把该点导数写成差商极限，用控制式夹逼得导数为零 → 由二阶导定号判定一阶导单调，定出该点两侧导数符号 → 推出函数在该点两侧单调方向并确认该点为极小点 | 控制量为比函数更高阶的无穷小；失效：控制式仅为同阶时导数不定 |
| 凹凸拐点判据通法 | 曲线凹凸区间、拐点判定与计数、由高阶导数与凸性得出的不等式与取值范围 | 求二阶导数并解零点与不存在点 → 逐候选点检验两侧符号是否改变 → 变号者为拐点并定凹凸区间 → 高阶导非零时用泰勒展开定局部形态 | 可用[函数二阶可导，或二阶导数仅在有限个点不存在而这些点可逐个检验（不存在点同样是拐点候选，不得先排除）；二阶导性态也可从图形读出；函数连续且二阶导数的图形信息（零点、不存在点、符号）明确；函数二阶可导且二阶导在区间恒正] 失效[只数二阶导零点不验变号；拐点候选漏掉不可导点；凸性不等号方向弄反] |

| 渐近线穷尽检验通法 | 显式、含参、参数方程与复合结构曲线的渐近线判定与计数 | 列出全部无定义点逐个验铅直 → 各无穷方向先验水平 → 水平不存在时分别求斜率与截距 → 参数曲线先把无穷远翻译成参数趋向 | 可用[无定义点与无穷方向可穷尽；各极限可求；根号内最高次项系数为正保证单侧讨论成立] 失效[漏掉单侧渐近线；水平存在仍继续算斜；参数趋向与自变量趋向混同] |
| 穷尽计数分支 | 函数表达式已知，动作是逐个无定义点与无穷方向穷尽检验并按条数汇总 | 无定义点验铅直 → 无穷方向先水平后斜 → 计数 | 漏单侧是高频错 |
| 差式读渐近线分支 | 题设只给出某含参表达式的极限存在或为常数，须先由此读出曲线与直线之差的衰减结构，再定渐近线或参数 | 商形式识别分母衰减 → 推分子趋于零 → 整理成函数减线性式 | 渐近线的差式定义要牢记 |
| 参数曲线无穷远翻译分支 | 参数方程曲线的渐近线 | 找使横坐标趋于无穷的参数趋向 → 斜率截距化为参数极限 → 核对其余趋向 | 参数趋向可能多个 |
| 曲率与曲率圆通法 | 曲线在一点的曲率、曲率半径最值、曲率圆方程以及由曲率条件反求导数信息 | 求一阶二阶导数代入曲率公式 → 曲率半径取倒数并求其最值 → 由二阶导符号定凹向 → 圆心沿法线取在凹侧按半径定圆 | 可用[曲线二阶可导；参数方程曲线横坐标导数不为零；参数点对应曲线上一点且各导数存在] 失效[曲率与曲率半径弄反；圆心方向与凹向弄反；二阶导漏乘链式因子] |
| 参数曲线曲率分支 | 参数方程曲线在一点求曲率 | 一阶导为参数导数之商 → 二阶导补链式因子 → 代公式 | 二阶导漏乘链式因子是高频错 |

| 方程定隐函数极值分支 | 依赖变量由单一方程或方程组隐式给出且相应偏导（或系数行列式）非零，可把一阶导为零代回原方程定候选点并再求一阶得二阶判别式 | 把驻点代回原方程确定该点的函数值 → 方程两端再求一次导，整理出二阶导表达式 → 在驻点取二阶值定号，正为极小、负为极大 | 依赖变量由单一方程隐式给出且相关偏导非零；失效：二阶式在该点退化，需回到定义比较函数值 |

| 闭区域最值内外分线 | 二元函数在有界闭区域（或补了无穷远估计的无界区域）上求最大最小值 | 在区域内部令一阶偏导为零求驻点并算函数值 → 把每段边界方程代入目标化为一元函数（或建乘数式）求边界候选点 → 补齐各段边界的端点与交点 → 列表比较全部候选函数值，最大者为最大值、最小者为最小值 | 可用[边界条数有限且每段可参数化或消元；区域为闭区域：有界且函数连续时最值必存在；区域无界但函数在无穷远趋于同一值（或趋于无穷）时，最值存在性由主干第5步的无穷远估计补出，此时本法仍适用；题目需要同时比较区域内部驻点与全部边界段的候选值；只有等式约束而无内部/边界之分时交条件极值与拉格朗日乘数法通法，开区域内给单点定类型时交多元函数极值判别与反求通法] 失效[区域无界时不补无穷远估计可能取不到最值；内部驻点判别不能代替边界比较] |
