### 标准解题步骤

1. 把方程化为 y′+P(x)y=Q(x) 标准形，首系数不为 1 时先同除并核对定义区间
2. 写积分因子 e^{∫P dx}，两端同乘使左端合并成一个乘积的导数
3. 一次积分得 y=e^{-∫P dx}[∫Q e^{∫P dx}dx+C]，先算内层积分再乘外层因子
4. 内层积分出现分部、换元或有理拆项时按不定积分通法积出，勿漏积分常数
5. 代初值定出 C，需要讨论解的极限或渐近性时把 C 项与积分项分开取极限
6. 系数含参时按参数分情形讨论积分是否存在、通解是否有界

### 失效边界

**适用前提**（3 条）

- 方程关于未知函数及其一阶导数都是一次的
- P、Q 在同一区间上连续，积分因子可写出
- ∫P dx 与 ∫Q e^{∫P dx}dx 均可用初等函数表出

**失效场景**（3 条）

- 方程含 y 的非一次幂或 y′ 的非线性因子，属伯努利或可降阶型而非本法
- 首系数为零的点使标准形的除法失效，须分区间讨论
- 积分因子写反符号会把通解整式变倒

| 适用范围 | 不显含 x 或不显含 y 的二阶方程，含由降阶后的一阶类型与两个初值的分工 |

| 覆盖题量 | 3 题（分支 0 个） |

### 标准解题步骤

1. 判定方程缺哪个变量：不含 y 用 y″=p′，不含 x 用 y″=p·dp/dy
2. 作代换把二阶方程降为关于 p 的一阶方程并识别其类型（可分离、线性或齐次）
3. 解出一阶方程得 p 的通解（含第一个常数）
4. 把 p 换回 dy/dx 再积分一次还原 y，写入第二个常数
5. 有两个初值（或切线、拐点等几何条件）时代入定出两个常数并检验解的区间
6. 降阶后的一阶方程仍需代换时，把该代换动作交整体代换或一阶线性各法执行

### 失效边界

**适用前提**（3 条）

- 方程明确不显含 y 或不显含 x，或经代换后可化为这种形式
- 降阶后的一阶方程可用本法族标准形求解
- 初值条件个数与方程阶数匹配

**失效场景**（3 条）

- 方程同时显含 x、y 与 y′ 的非线性组合时降阶不闭合，须另寻代换
- p=0 的常值解在约分时被丢，须单独补查
- 只给一个初值时无法定出两个常数，通解不能强行特化

### 标准解题步骤

1. 移项整理，把只含 y 的因子（含 dy）与只含 x 的因子（含 dx）分到等式两侧
2. 两侧各取不定积分，积分常数只在一侧写出并合并成单个常数
3. 出现对数或反三角形式时先合并常数再指数化，把解写成乘积或幂的形式
4. 分离时除以的因子可能恒为零，单独补查该常值解是否被漏掉
5. 有初值时代入定出常数，需要显式解时再开方或取对数并按初值选分支符号

### 失效边界

**适用前提**（3 条）

- 方程可写成两因子分别只含 x 与只含 y 的乘积形式
- 分离后两侧积分均可用基本公式积出
- 初值给出后可在积分式上直接代入定常数

**失效场景**（3 条）

- 两侧变量耦合无法分离，须先作整体代换或改判其他类型
- 分离时约去含未知函数的因子会丢常值解
- 积分含变限或含参时不能当作一元积分直接积出

### 标准解题步骤

### 标准解题步骤

1. 按题给变换或方程结构选定新自变量（欧拉型取 x=e^t，含 e^{kx} 型取该指数为 t）
2. 用链式法则逐层求导：一阶换成 dy/dt·dt/dx，二阶展开并把 dt/dx 的导数一并代入
3. 把换出的各阶导数代回原方程，合并同类项化成新变量下的常系数线性方程
4. 解新变量下的方程得通解（特征方程法或待定系数法）
5. 把 t 换回原自变量写出 y(x)，并核对代换在定义区间内是否单调可逆
6. 欧拉型方程无题给变换时自行取 x=e^t 代换（数一内容），代换后仍为常系数线性

**适用前提**（3 条）

- 方程是变系数但系数为 x 的同次幂乘各阶导数（欧拉型）或含可整体代换的指数因子
- 代换后各阶导数能化成关于新变量的线性组合
- 代换在所论区间单调可逆，可回代定初值

**失效场景**（3 条）

- 系数无法被同一代换统一约去时本法不能化常系数
- 代换非单调或跨奇点时未分段回代得到错解
- 换元后只换一阶导数漏二阶附加项会使方程形式走样

2. 用反函数导数关系把原方程的 y′、y″ 换成 x′、x″ 的表达式

- 导数可作反函数变换且 x′(y)≠0
- 初值可在新变量下直接代入

- x′=0 的特解（竖直直线解）在换元中被约去须补回

## 整体代换化一阶标准形

### 标准解题步骤

1. 圈出方程中反复整体出现的复合式，检查它的导数是否只差一个已知因子
2. 令该整体为 u 并把原方程改写成关于 u 的一阶方程（一般为线性或可分离）
3. 按改写后的类型解出 u 的通解
4. 把 u 换回原复合式，必要时取对数、指数或开方还原未知函数，按初值定分支符号
5. 还原后核对是否漏掉使代换失效的常值解（分母或幂因子为零处）

### 失效边界

**适用前提**（3 条）

- 含 y 的某个复合式与其导数同时出现，且导数只差已知因子（如 2yy′=(y²)′）
- 代换后方程关于新变量是一阶线性或可分离
- 初值使还原时的开方分支唯一确定

**失效场景**（3 条）

- 复合式的导数还含无法消去的第三个未知函数，代换不能闭合
- 代换后需分情形的分支未讨论会得到丢解
- 把方程两侧同乘含未知函数的因子会引入增解
