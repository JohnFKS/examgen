## 嵌套对数标尺级数审敛通法

> 编号 **T-LA-03-S** ｜ 版本 **v0.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 存在一族每加一层对数才把收敛边界推进一格的边界级数，正项级数只要被某一层标尺单侧控制，其敛散就完全由该标尺最内层对数因子的幂次是否越过临界值决定，因为这一族的边界由逐层对数的增长速率唯一刻画 |
| 适用范围 | 正项级数（通项最终同号）的敛散性判别，尤其适用于比较判别法与比值判别法在边界附近失效、积分判别法不易执行的含对数嵌套、含阶乘与幂指的通项；不用于条件收敛与一般项级数的讨论 |
| 学科 / 章节 | 线性代数 · 行列式 |
| 表面题型 | 正项级数敛散性判别选择题；嵌套对数型级数敛散判别；含阶乘或指数的级数；判定含参级数的参数范围；比较判别法放缩证明题 |
| 对应考点 | 常数项级数的收敛与发散概念；级数收敛的必要条件；正项级数的比较判别法及其极限形式；正项级数的比值判别法；p 级数与广义对数型级数的敛散性；积分判别法；无穷大量阶的比较；斯特林公式 |
| 覆盖题量 | 0 题（分支 6 个） |

### 标准解题步骤

1. 判正项：确认通项最终同号且不趋于非零值，否则本法只能提供绝对意义上的敛散信息
2. 查必要条件：先检验通项是否趋于零，不趋于零者直接判发散，不必再比标尺
3. 化通项结构：把通项整理为分母连乘形式，分离出项数幂、逐层对数幂、指数的幂、阶乘与幂指因子
4. 按增长层级定阶：用对数远慢于幂、幂远慢于指数、指数远慢于阶乘、阶乘远慢于幂指的固定顺序取主项，含阶乘先化为幂指形式
5. 选标尺层数：以通项中实际连续出现的对数层数确定对应标尺级数，层数由外向内逐层核对
6. 补层或降层：嵌套不连续（缺中间某层对数因子）时把标尺降到实际连续出现的层，或用不等式把通项压到某层标尺的一侧
7. 读最内层幂次下结论：仅由最内层对数因子的幂次与临界值比较定敛散，外层幂次不改变结论，最后用单侧放缩复核方向

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 标准嵌套直读分支 | 通项分母恰为项数与逐层对数若干次幂的连续连乘 | 核对对数嵌套是否逐层连续到有定义的下标 → 只读最内层对数的幂次并与临界值比较 → 外层幂次无论大小一律不写入判断依据 | 各层对数须自某下标起有定义且为正，求和起始项要相应推后，有限项不影响敛散 |
| 缺层补形分支 | 对数嵌套出现跳跃，中间缺某层因子或幂次只作用于最内层 | 把标尺层数下调到实际连续出现的层 → 利用分母少因子使通项偏大的方向做放大 → 与被放大到的那一层标尺比较，同侧即得该标尺的敛散 | 缺层只能往发散方向放缩，反向需另给收敛控制；不能凭外层幂次大就断言收敛 |
| 非对数结构定阶分支 | 通项含指数的幂、阶乘、幂指，或项数同时出现在底数与指数位置 | 先用增长层级表定出唯一主项 → 含阶乘者先化为幂指形式再比较 → 把结果落到不含对数层的幂级数标尺上判敛散 | 层级比较只给出单侧控制；底数或幂比趋于临界值时须升层或改用更细标尺 |
| 取对数化幂指分支 | 通项为幂指结构，底数与指数同时含项数或对数 | 对通项整体取对数把乘除化为加减 → 在指数部分保留增长最快的项作主项 → 还原指数后与几何级数或某层标尺比较 | 取对数比较要求通项恒正；还原时丢弃的误差项必须仍可被所选标尺控制 |
| 含参临界分类分支 | 通项含参数，敛散结论随参数取值改变 | 把参数并入定阶后的最内层幂次或指数位置 → 解出使标尺恰处临界的参数分界值 → 按参数落在分界两侧分别给结论，并单独检验恰取分界值的情形 | 恰取临界值时外层对数与低阶修正项决定结论，必须回到标准嵌套单独判别 |
| 非标准形放缩分支 | 通项不属于任何一层标尺形式，但可与某层已知敛散的标尺逐项作不等式比较 | 选定一层敛散已知的标尺级数 → 用幂与对数、幂与根式之间的已知不等式作单侧放缩 → 按比较判别法的方向直接下结论 | 放缩方向须与结论同向：证收敛要由大者控小者，证发散要由小者控大者，且不等式只在足够大的下标之后成立 |

### 失效边界

**适用前提**（4 条）

- 正项级数，通项分母可分解为项数幂、逐层对数幂与其他可定阶增长块的乘积
- 比较判别法与比值判别法在边界附近失效、积分判别法不易积分时，本法仍可单侧定敛散
- 求和起始项可调整（有限项不影响敛散），以保证各层对数有定义且为正
- 对标准嵌套族本身该判据是充要的；对一般正项级数只保证单侧控制，不能声称已找到收敛最慢的边界级数

**失效场景**（7 条）

- 一般项级数与交错级数不能用本法判条件收敛，本法只对正项部分给出绝对敛散
- 通项不趋于零时必须先用收敛的必要条件判发散，直接套标尺会掩盖这一更基本的检查
- 含正弦、余弦等振荡因子的通项无法定阶，标尺比较失效，须改用绝对值放缩或其他判别法
- 比值判别法在本族标尺上恒给出临界值，看似可用实则无效，不可用它否定标尺结论
- 把增长层级不等式用于有限项或起始下标之前的区间会得出反向结论，比较只在足够大下标后成立
- 缺层放缩方向搞反（用收敛标尺去控放大后的通项或用发散标尺去控缩小后的通项）会得到相反敛散
- 含参情形只检验分界一侧或漏掉恰取临界值的分类，结论不完整

| 题号 | 表面题型 | 本质要点 |
| --- | --- | --- |
| seed | 分子为指数的幂、分母为项数幂的级数 | 非对数结构定阶分支：指数压倒幂次，发散 |
| seed | 含正参数的「参数幂乘阶乘除以幂指」型通项 | 含参临界分类分支：以定阶后的分界参数分类，恰取分界值单独判发散 |
| seed | 分母仅为对数某次幂的级数 | 非对数结构定阶分支：对数远慢于一次幂，与调和标尺比较发散 |
| seed | 分母为多层对数连乘而不含一次幂因子的级数 | 取对数化幂指与定阶分支：各层对数之积仍远慢于一次幂，发散 |
| seed | 分母为项数与前两层对数连续连乘的标准嵌套级数 | 标准嵌套直读分支：最内层幂恰为临界值故发散 |
| seed | 分母为项数乘最内层对数高幂但缺中间对数层 | 缺层补形分支：向发散方向放缩，与低一层标尺同侧 |

| seed | 项数既作底又作对数指数的幂指混合型通项 | 取对数化幂指分支：取对数后主项增长快于任意指数，收敛 |
