## 矩阵秩的定秩与降秩关系通法

> 编号 **T-LA-21-I** ｜ 版本 **v0.4** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 核心本质 | 秩只有两种定法：一是把阵化成阶梯直接数非零行（先用一个明显的低阶非零子式给下界、再用行变换给上界，两界夹住即定值）；二是把结论翻译成少数几条不等式的实例——r(AB)≤min{r(A),r(B)}、AB=O ⇒ r(A)+r(B)≤n、r(A+B)≤r(A)+r(B)、r(A^T)=r(A)、可逆块左右乘不改变秩——再用"非零矩阵""A≠E""某阵秩为定值"这些排除条件把另一侧顶到最小；伴随的秩是这条链上唯一按档跳变的量：r(A)=n、n-1、<n-1 时 r(A*) 分别为 n、1、0，于是"降一等"的秩反翻译成 \|A\|=0 加上一个 n-1 阶子式非零的方程与不等式组；等价关系最终也归结为两阵秩相等 |

### 标准解题步骤

1. 先判秩的来源：阵为具体（或低阶含参）元素可化阶梯实算，还是只给矩阵等式与秩的关系、需用不等式链卡界，抑或条件以 r(A*) 给出需按档反推
2. 实算型：只做不改变秩的初等行变换化成阶梯形数非零行；含参数时按"哪一行会被消成零"分档，每档单独给出秩
3. 夹逼型：先指出一个明显的低阶非零子式（或行成比例的观察）给出秩的下界，再用阶梯形给上界，两界相等即定值
4. 不等式型：把题给等式整理成 XY=O、AB=C 或 (E+X)(E-X)=O 的标准形，写出对应的秩不等式并代入已知的秩值
5. 用排除条件（非零矩阵、A≠E、r(B) 为定值）给出被卡一侧的下界，从而把另一侧压到不足阶数，得出秩的值或取值范围
6. 伴随分档型：由 r(A*) 的值反推 r(A) 落在哪一档，把 r(A)=n-1 翻译成 \|A\|=0 求参数候选值、再用"至少一个 n-1 阶子式非零"排除更低档
7. 分块与转置需要时先用块初等变换或 r(A^T)=r(A) 把对象搬成可数形式，再回到原问；结论为两阵等价时转成秩相等的方程
8. 用具体低阶例子（秩一、幂零、对合、只含零块的拼法）代一次，检查每条不等式取等的条件是否真被满足，避免把范围误写成等值

### 失效边界

**适用前提**（9 条）

- 三档入手方式各属一支，命中其一即本法可用：阵以具体数字或低阶含参元素给出、可做行变换（含用明显低阶非零子式给下界、阶梯形给上界的夹逼）→ 实算定秩与等价参数档；条件给的是矩阵乘积、和、转置与秩的数值或不等关系并含"非零""A≠E""某阵秩为定值"这类可作下界的排除条件 → 不等式夹逼档；题给 r(A*)、A*=O 或 A* 的非零元素个数，阵元素含参数且其行列式可分解成少数因子、阶数 n 明确 → 伴随秩分档反推参数
- 结论落在秩上：秩的值、秩随参数的分档、秩的取值范围，或两阵等价的参数条件（等价最终翻译成同型且秩相等）
- 阶数 n 与各阵形状明确：不等式链要用方阵阶数，伴随秩三档要用 n 与 n−1 的对应，长方阵只能数阶梯非零行
- 夹逼的两翼可分别来自不同性质：上界由乘积型不等式（r(AB)≤min{r(A),r(B)}、XY=O ⇒ r(X)+r(Y)≤n）给出，下界除明显低阶非零子式外还可由"和的秩"r(X)+r(Y)≥r(X+Y) 给出（X+Y 化成数量阵或已知秩阵时该下界可直接取值，如 (E+BA)+(E−BA)=2E）
- 长方阵的保秩引理：A 列满秩（A 为 m×n 且 r(A)=n）时 AB 与 BX 同解（ABα=0 ⇒ A(Bα)=0 而 AX=0 只有零解 ⇒ Bα=0），故 r(AB)=r(B)；B 行满秩时右乘同理保秩。该结论只给秩相等，不得据此写"存在 A^{-1}"（A 非方）
- 与「分块初等变换降阶通法」的分工：分块阵的块行块列消元、化块三角与数对角块秩之和由该法给出，本法只接管消元之后落在秩不等式链上的比较（r(AB)≤r(A)、AB=O ⇒ r(A)+r(B)≤n 等）；同一道题不重复做一次块消元
- 结论是可逆性、行列式是否为零、或由乘积秩条件定参数
- 矩阵乘积的两侧维数已知，秩不等式与维数夹逼可用的场合
- 题给乘积秩与因子秩的数值关系

**失效场景**（15 条）

- 由 AB=O 直接断言 A=O 或 B=O 是错的（零因子），只能得秩的不等式
- r(A)+r(B)≤n 需 AB=O 且阶数相容，维数不匹配时不能套用
- AB=E 只说明 r(A)=r(B)=m（方阵情形才可互逆），长方阵时不等于 B 是 A 的逆
- 不等式给出的界未必取到，未验证存在性就写成等号会放大结论
- 对含参数的行做"乘以含参式"的变换会改变秩的取值分档，只能做加倍与对换
- 把 r(A) 与 \|A\| 混用：非方阵没有行列式，只能数阶梯非零行
- 只验证行列式为零就断言秩为 n-1，未再核有一个 n-1 阶子式非零
- 等价要求同型且同秩，形状不同的矩阵不构成等价
- 只用 \|A\|=0 定参数而不排除 r(A)≤n-2，会把 A*=O 的情形一并纳入
- n=2 时 r(A)=1 ⇒ r(A*)=1 与 n≥3 的写法一致，但 (A*)*=\|A\|^{n-2}A 的幂次为零需单独处理
- 把 r(A*) 与 \|A*\| 混用：\|A*\|=0 只说明降秩，不能定出秩为几
- 把 r(AB)≤r(A) 用成 r(AB)≥r(A)：方向写反全盘皆错
- 维数夹逼只对「内维小」成立，外维小不降秩（行满秩乘积可以满秩）
- 由 AB=E 写 \|A\|\|B\|=1 判可逆时忘了对长方阵 E 的阶数须与乘积一致
- 参数方程漏掉使秩更低的档（行列式为零只是必要条件）

### 标准解题步骤

1. 把「能否表示」翻译成线性方程组：向量组的向量作列，待表示向量作右端

### 失效边界

**适用前提**（9 条）

- 结论是能否由某组线性表示、表示是否唯一、或含参时按参数分档
- 向量组与待表示向量以具体数字或含参分量给出
- 参数只影响个别行，阶梯形里能直接读出消零条件
- 方程组系数或右端含参数，要求按参数讨论解的档位或定参数值
- 方阵情形行列式可分解出参数因子，非方阵情形阶梯形可读出消零条件
- 结论为无解、唯一解、无穷多解的分档或通解
- 题面给表示性条件（可由列表示、不能由行表示）判秩的关系或命题组合
- 条件与结论都在表示与秩的语言层，不需具体元素
- 真伪可由增广秩的关系与低阶反例完全判定

**失效场景**（12 条）

- 只比较系数秩不看右端：有解要求增广秩与系数秩相等，须对增广矩阵验证
- 对增广矩阵做列变换：右端列参与变换后条件被破坏
- 参数分档漏档：使行列式为零与使某行消零的参数值要分别核，不能只取其一
- 无穷解档只写特解：全部表示须是特解加齐次通解的组合
- 只用行列式为零定参而不回验增广秩：行列式为零只说明降秩，可能唯一、无穷也可能无解
- 非方阵时套用行列式判据：行列式不存在，只能化阶梯比较秩
- 参数分档漏档：使行列式为零与使某行消零的参数值要分别核
- 无穷多解档漏写基础解系或把特解当通解
- 把「行向量不能表示」与「列方程组无解」的方向搞反（转置后角色互换）
- 由 AX=α 有解推 BX=β 有解：两方程组的列空间不同，须另行验证
- 增广秩「加一」只在确实无解时成立，未验相容就写加一
- 举例确认真命题（举例只能否证）

### 标准解题步骤

1. 写出增广矩阵，只做初等行变换化成行阶梯形，判相容性（有无矛盾行）
2. 数出系数秩与未知量个数：相等则唯一解（无自由变量），小于则有自由变量
3. 继续化成行最简形，主元变量用自由变量线性表出
4. 自由变量全取零读出非齐次的一个特解
5. 每个自由变量轮流取给定值（其余取零），读出齐次方程组的基础解系，个数等于自由变量个数

### 失效边界

**适用前提**（3 条）

- 方程组以具体数字给出，可对增广矩阵做初等行变换
- 结论要求通解（或判无解、唯一解）
- 未知量个数不多，行变换代价可控

**失效场景**（4 条）

- 对增广矩阵做列变换：未知量的对应关系被破坏（最后一列是右端，参与列变换无意义）
- 只化到行阶梯就写通解：自由变量的系数须在行最简形下才读得准
- 把齐次解当特解或漏掉特解：通解必须是非齐次特解加齐次通解的结构
- 基础解系的取值方式不统一（某个自由变量取值时其余必须全取零），混取会得到相关向量组

## 伴随秩三档定方程组解结构

### 标准解题步骤

1. 把题给条件翻译成原阵秩的档位（行列式为零加一个高阶子式非零、解的个数、或对任意向量成立）
2. 按伴随秩三档写出 r(A*)：满秩给满秩、秩降一等给一、其余给零
3. r(A*)=n 时 A*X=0 只有零解；r(A*)=0 时任意向量都是解
4. r(A*)=1 时把 A*X=0 化成一行方程（按列读代数余子式），由一个非零系数构造出全部基础解系

**失效场景**（4 条）

- 原阵满秩时 A*=\|A\|A⁻¹ 的除法可用，但降秩时不能除，三档要分开处理

### 标准解题步骤

1. 把每个「某向量是解」的条件按列组合翻译成系数等式（矩阵乘列向量等于列向量的组合）
2. 非齐次解的系数和为一的组合仍是非齐次解，系数和为零的组合是齐次解，用这条把已给解改造成特解与齐次解
3. 由通解结构数基础解系应有的个数（未知量个数减系数秩），与已给的无关齐次解个数对照
4. 用已给无关解的个数与题给无关列（或部分组）的无关性把系数秩夹逼出来
5. 把新问题（新矩阵、新右端）的解用原方程组的解与列向量组合表示出来

### 标准解题步骤

1. 认清两方程组的关系类型：求公共解、判同解、或一方解集含于另一方
2. 求公共解时把两组系数阵上下叠拼，解联立齐次方程组，非零解即公共解
3. 已给两方通解时令两个通解表达式相等，解出组合系数的关系得公共解
4. 判包含或同解时翻译成秩：包含 ⇔ 叠加后秩不升高；同解 ⇔ 两方秩相等且互相包含

- 至少一组可显式求解或其秩可读出（数值阵、已给基础解系或秩条件）
- 含参时参数只影响个别行，秩条件可解出

**失效场景**（4 条）

- 把「解集包含」当成「同解」：同解还要求反方向包含（秩相等且互相表示）
- 求公共解时只解其中一个方程组：公共解必须同时满足两组方程

## 满秩方向的解结构判定

> 编号 **T-LA-57-I** ｜ 版本 **v0.1.2** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 系数阵的满秩方向决定解的结构：行满秩（秩等于方程个数）时增广秩必等于系数秩，任意右端都有解（唯一或无穷由列数定）；列满秩（秩等于未知量个数）时齐次方程组只有零解、非齐次若有解必唯一。判定题就是把每个命题翻译成「秩等于哪个数」再核对方向。 |
| 适用范围 | 由行满秩、列满秩（或其乘积条件）判方程组解的存在性与唯一性 |
| 学科 / 章节 | 线性代数 · 线性方程组 |
| 表面题型 | 行满秩与列满秩的解结构判定 |
| 对应考点 | 解的判定；（三）非齐次线性方程组的解；必备知识点；（二）齐次方程组的解；（三）具体方程组求解；解题连招 |
| 覆盖题量 | 3 题（分支 0 个） |

### 标准解题步骤

1. 写清矩阵的行数、列数与秩（行满秩 r=m，列满秩 r=n）
2. 行满秩时 r(A)=r(A,b)=m 对任意右端成立：Ax=b 必有解，列数大于行数时无穷多解
3. 列满秩时 Ax=0 只有零解；非齐次若有解则唯一（无自由变量）
4. 乘积或转置的秩经 r(Aᵀ)=r(A)、r(AᵀA)=r(A) 搬运后再判
5. 把每个选项的结论翻译成秩等式核对，反例用「行满秩但右端不属于列空间」构造（转置方程组）
6. 汇总真伪，注意「必有解」与「必有唯一解」的强度差别

### 失效边界

**适用前提**（3 条）

- 题给矩阵的行（列）满秩性或由乘积条件可推出满秩性
- 结论为解的存在性、唯一性或齐次解的个数
- 不需具体元素，纯秩与维数的推理

**失效场景**（4 条）

- 行满秩保证有解，但「有解」不等于「唯一解」（列数多于行数时无穷多解）
- 列满秩的 Ax=b 未必有解：右端可能不在列空间里（转置方程组的情形）
- 把 r(AᵀA)=r(A) 用到复矩阵或非实矩阵上（实矩阵才成立）
- 长方阵的「满秩」必须指明方向（行满秩与列满秩不可混称）

2. 两边左乘 Xᵀ，把条件里的结构性质（反对称 XᵀAX=0、正定内积为正）代入
3. 用实向量的性质收口：范数平方为零 ⇒ X=0，或内积恒正 ⇒ 矩阵作用非零 ⇒ 可逆
4. 由可逆性把解的档位翻成唯一解或只有零解
5. 对判为「只有零解」的项，检查相反情形（另一特征值档）是否同样成立，避免只验一半
6. 汇总各选项真伪，必要时举低阶反例否证

### 失效边界

**适用前提**（3 条）

- 题给矩阵的结构性质（反对称 Aᵀ=−A、正定型内积恒正、实对称等），判解的档位
- 候选项可改写成 (A−λE)X=0 的形状
- 实向量内积技巧可用（实矩阵前提）

**失效场景**（4 条）

- 内积技巧要求实矩阵：复矩阵的 XᵀX 不再是范数，不能由其为零推 X=0
- 反对称只给 XᵀAX=0，正定的结论属于另一矩阵，不能互相挪用
- 由「对任意非零 α 内积为正」推可逆时，漏掉 α=0 的平凡档不影响结论但表述要全
- 把「只有零解」写成「无解」：齐次方程组永远有零解

## 正交矩阵方程组求解

> 编号 **T-LA-63-I** ｜ 版本 **v0.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 正交矩阵的逆就是转置，于是 Ax=b 的解一步写成 x=Aᵀb：先用列向量单位正交条件（列自内积为一、两两内积为零）定出正交矩阵的待定参数，再转置乘右端得解；唯一性由 \|A\|²=1（可逆）保证。 |
| 适用范围 | 由正交条件定参数并解 Ax=b（x=Aᵀb） |
| 学科 / 章节 | 线性代数 · 线性方程组 |
| 表面题型 | 正交矩阵方程组的求解 |
| 对应考点 | （三）具体方程组求解；解的判定；必备知识点；（二）齐次方程组的解；解题连招 |
| 覆盖题量 | 1 题（分支 0 个） |

### 标准解题步骤

1. 写出正交条件的两组方程：各列自内积为一、不同列内积为零
2. 解参数方程组定出正交矩阵的待定参数，并验行（列）方向的同一条件
3. 由正交性写 A⁻¹=Aᵀ，方程组 Ax=b 的解为 x=Aᵀb
4. 转置后与右端相乘，逐分量算出解
5. 由 \|A\|≠0（正交阵必可逆）判解唯一
6. 把解代回 Ax=b 验算一次

### 失效边界

**适用前提**（3 条）

- 系数阵为正交矩阵（或含参数的正交矩阵），右端具体给出
- 结论为参数值与方程组的解
- 阶数不高，内积可手算

**失效场景**（4 条）

- 正交条件只对列（或只对行）写全：须两组都验或说明由转置自动成立
- 把 A⁻¹=Aᵀ 写成 A=Aᵀ（对称与正交是两回事）
- 参数解出后未验「单位」条件（只验了正交），得到非正交的参数档
- 解的向量式漏掉转置（x=Aᵀb 不是 x=Ab）

## 无关组坐标化抽象方程组

> 编号 **T-LA-64-I** ｜ 版本 **v0.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 抽象系数阵由无关向量组的组合构成时，把组合系数抽出来：B=(α组)C 且 α组无关，则 r(B)=r(C)、Bx=β ⇔ Cx=c（c 是 β 的坐标）；无关性充当了「消去 α组」的左逆，抽象方程组就此化成数值方程组，秩、相容性与通解全部在 C 上读。 |
| 适用范围 | 把由无关向量组组合成的抽象方程组坐标化成数值方程组求解 |
| 学科 / 章节 | 线性代数 · 线性方程组 |
| 表面题型 | 无关向量组坐标化抽象方程组 |
| 对应考点 | （三）具体方程组求解；解的判定；解的结构；必备知识点；（二）齐次方程组的解；解题连招 |
| 覆盖题量 | 1 题（分支 0 个） |

### 标准解题步骤

1. 把抽象系数阵写成无关向量组乘系数阵的形式 B=(α1,…,αs)C
2. 由 α组无关（可逆坐标化）得 r(B)=r(C)，Bx=β 化成 Cx=β 的坐标
3. 在数值系数阵 C 上判定相容性与秩，按参数分档（行列式或消零条件）
4. 解出数值方程组的特解与基础解系
5. 坐标不需要还原成 α 的组合（解向量本身就是数值坐标）
6. 回代 Bx=β 验算：用 B=(α组)C 与 Cx=c 的对应关系核对

### 失效边界

**适用前提**（3 条）

- 抽象系数阵的列都是某无关向量组的线性组合，系数阵具体给出
- 右端也是该向量组的组合（坐标可读出）
- 结论为参数、相容性或通解

**失效场景**（4 条）

- α组相关时不能坐标化（消不去 α组）：须先确认无关性
- 右端坐标读错列序（组合系数按列对齐）
- 把 Bx=β 的解当成 α组上的组合系数（解是 C 的坐标变量的取值）
- 系数阵 C 的行列数与乘法不匹配时整个坐标化失效

## 行列式非零判唯一解

> 编号 **T-LA-65-I** ｜ 版本 **v0.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 核心本质 | 方阵方程组唯一解的充要条件是系数行列式不为零（克拉默法则的判定面）：抽象方程组的唯一性判定就化成系数行列式的计算与估计——行列式经恒等变形、因式分解或分析工具（中值定理、单调性）判出非零即得唯一解，判不出非零时只能回到秩的分档。 |
| 适用范围 | 由系数行列式非零（克拉默条件）判抽象方程组唯一解 |
| 学科 / 章节 | 线性代数 · 线性方程组 |
| 表面题型 | 行列式非零判唯一解 |
| 对应考点 | （四）克拉默法则；（二）判定方程组的解；必备知识点；解题连招 |
| 覆盖题量 | 1 题（分支 0 个） |

### 标准解题步骤

1. 确认系数阵是方阵，把「解的档位」问题转成系数行列式的符号问题
2. 对行列式做恒等变形（行加减、按行展开）化成因式乘积或可估计的形式
3. 需要分析工具时用中值定理、单调性等判各因子非零且互不相同
4. 行列式非零判唯一解（克拉默），并指出唯一解存在但不必求出
5. 行列式为零或含参时回到增广秩的分档讨论
6. 回代一个特殊情形核验行列式的变形没有漏项

### 失效边界

**适用前提**（3 条）

- 系数阵为方阵且行列式可算出或可估计
- 结论是唯一解的判定（克拉默条件）
- 行列式结构便于因式分解或与函数性质结合

**失效场景**（4 条）

- 行列式为零只说明降秩，可能是无解也可能是无穷多解，不能直接写「无解」
- 非方阵没有行列式，唯一性判定改用列满秩（秩等于未知量个数）
- 分析工具（中值定理）使用前须确认可导与区间条件
- 把「唯一解存在」与「解的具体值」混同：克拉默判定只给存在唯一性
