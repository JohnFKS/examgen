### 标准解题步骤

1. 确认两矩阵同阶且元素已知；含参数时先用必要条件（迹、行列式、秩）把参数定出来
2. 比较两矩阵的迹与行列式（必要时再比秩），不相等者直接排除
3. 分别求特征值（含重数），特征多项式不同者排除
4. 对每个重数不小于 2 的特征值，分别计算两个矩阵在该特征值处特征矩阵的秩，由阶数减秩得到线性无关特征向量个数
5. 两矩阵在每个特征值处的特征向量个数全部对应相等则判相似，只要有一个不相等即判不相似
6. 若还需给出相似变换矩阵，按同一特征值下两矩阵特征向量的对应关系逐列拼出可逆矩阵并回代验证

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 可对角化速判分支 | 两矩阵均可对角化（特征值互异，或每个特征值的几何重数等于代数重数） | 分别求出两矩阵的全部特征值 → 特征值（含重数）完全相同即判相似 → 需要写出变换矩阵时，令两者同时相似于同一对角阵，用特征向量拼出各自的过渡矩阵再复合 | 仅在两侧都可对角化时成立；一侧不可对角化时特征值相同推不出相似 |
| 重特征值处秩判分支 | 特征值已相同且存在二重及以上特征值，双方均不可对角化 | 对每个重特征值写出两矩阵的特征矩阵并化行阶梯 → 比较两个特征矩阵的秩，秩相等则对应特征向量个数相等 → 秩不相等即断定不相似，全部相等再回到特征向量对应关系确认 | 秩相等只说明特征向量个数相等，若还需构造变换矩阵必须验证特征子空间之间存在把一组基映到另一组基的可逆映射 |
| 必要条件逐层排除分支 | 选择题给出多个候选矩阵，需要以最小计算量排除 | 第一层比迹 → 第二层比行列式与秩 → 第三层比特征值 → 第四层比重特征值处特征矩阵的秩 → 每层只保留通过的候选，逐层收缩到唯一选项 | 前三层全部通过仍不能肯定相似，必须进入第四层；只用前三层下结论会误判 |
| 由相似反推特征向量分支 | 已知两矩阵相似（或已知变换矩阵），要求另一矩阵的特征值或特征向量 | 设其中一个矩阵在某特征值处的特征向量 → 利用相似等式把该向量经变换矩阵作用后对应到另一矩阵的同一特征值 → 由特征向量的线性组合关系还原所求特征向量，特征值保持不变 | 特征子空间维数大于 1 时变换矩阵不唯一，不能把某一对应关系当作唯一答案；重特征值处需整组基对应，单个向量映射可能退化 |
| 成对判定与过渡矩阵分支 | 判别两个同阶方阵是否相似（特征多项式可算、重根秩档可读），相似时需给出过渡矩阵 | 先核必要条件：特征多项式相同（特征值及重数一致），不同直接判不相似 → 两侧都可对角化时特征值一致即相似；有重根且不可对角化时逐个重根比较 r(λE−A) 与 r(λE−B) → 相似成立后分别求两矩阵到同一对角形（对角元顺序对齐）的过渡矩阵 P₁、P₂，拼 P=P₁P₂⁻¹ | 适用前提：同阶方阵、特征多项式可算；坑点：实对称之间特征值一致即相似的判据不能照搬到非对称矩阵；过渡矩阵的求逆方向不要写反。 |

### 失效边界

**适用前提**（7 条）

- 同阶方阵之间的相似关系判定
- 矩阵元素为具体数值，或参数已由必要条件唯一确定
- 两矩阵均可对角化，或虽不可对角化但可用特征矩阵的秩比较特征向量个数
- 实对称矩阵之间（此时特征值相同即为充要条件）
- 题面判别两个同阶方阵是否相似（含四选一选择题）
- 特征多项式可算，重根的秩档可读
- 相似时需要给出过渡矩阵

**失效场景**（10 条）

- 特征值相同而一个可对角化、一个不可对角化时，只比特征值会误判为相似，必须比较特征矩阵的秩
- 把等价（秩相同）、合同、相似混为一谈：秩相等只是相似的极弱必要条件，反向使用必错
- 三阶及以上矩阵只比迹与行列式相等不能推出特征值相同，还需特征多项式（全部初等对称式）一致，漏比会漏判
- 矩阵为抽象形式（未给具体元素）时无法求特征值与秩，本流程整体不可用，须改用定义构造或举反例
- 判定「不相似」时若必要条件全部通过而直接宣布相似，属于把必要条件当充分条件的错误
- 复矩阵与实矩阵混用（实相似与复相似不同）时，仅比实特征值会漏掉复特征值成对出现的约束
- 特征值相同不等于相似：不可对角化时还须比几何重数
- 只比较迹与行列式就下结论：必要条件不充分
- 实对称之间特征值一致即相似，但此判据不能照搬到非对称矩阵
- 过渡矩阵的两次求逆方向写反（P=P₁P₂⁻¹ 与 P₂P₁⁻¹ 之别）

## 特征多项式代值猜根分解通法

> 编号 **T-LA-02-S** ｜ 版本 **v0.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 整系数特征多项式在某整数点的值等于该点与诸根之差的乘积，整数根必为该点值的因数与代点之差，试根范围因此有限 |
| 适用范围 | 低阶（考研以三阶为主）数值矩阵求特征值，特征多项式系数全为整数且至少有一个整数根、直接因式分解无思路的情形 |
| 学科 / 章节 | 线性代数 · 相似矩阵（特征值与特征向量） |
| 表面题型 | 三阶实对称矩阵求特征值；一般三阶矩阵求特征值；元素数值较大的矩阵求特征值；特征多项式难以因式分解 |
| 对应考点 | 矩阵的特征值与特征向量；特征多项式；行列式的计算；矩阵的迹 |
| 覆盖题量 | 0 题（分支 4 个） |

### 标准解题步骤

1. 先扫描矩阵结构：行（列）和相等、实对称、有明显可抵消行列等能一眼凑出因式的，直接分解后跳过代值法
2. 按定义硬算特征多项式，整理为降幂排列且各项系数为整数，核对首项系数、一次项系数与常数项
3. 选一个便于口算的整数点代入，把该点函数值算成一个确定的整数并分解质因数
4. 依据该点函数值等于各「该点减根」之积，把质因数分组配成该点加减某因数的形式，列出根候选
5. 逐个把候选代回多项式检验是否归零，确认第一个特征值；分组配不出时换一种质因数组合或另取代入点
6. 用已确认的根对多项式拆项分组、提出公因式（或做多项式除法），把三次式降为二次因式
7. 解二次因式得其余特征值，并用三根之和等于矩阵的迹、三根之积等于行列式复核

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 代值定候选分支 | 特征多项式系数全为整数，常规凑因式与观察均无思路 | 选定便于口算的整数点并算出该点多项式值 → 把该整数值分解质因数 → 将质因数分组配成该点加减某因数的形式 → 把对应因数作为根候选逐个代回原多项式检验 | 特征多项式含参数时该点取值为含参式，无法做质因数分解，本分支不成立 |
| 多组因数试根分支 | 质因数分解结果因子多、分组方式不唯一 | 列举该点函数值因数与代入点的加减组合，形成候选集合 → 按绝对值由小到大依次检验 → 一次只确认一个根，其余根留待降次后处理 → 全部候选失败时更换代入点重新取值再分解 | 候选集合必须覆盖因数与代点加减两种形式，否则会漏掉负根 |
| 降次求余根分支 | 已验证确认一个特征值 | 按该因式把多项式重新拆项分组并提公因式 → 得到二次因式后用求根公式求解 → 判别式非完全平方时保留无理根形式，不再继续猜根 → 用迹与行列式校核三根之和与三根之积 | 只在确认的根正确时降次才成立，首根验算未通过不可先降次 |
| 结构观察优先分支 | 矩阵元素小、行（列）和相等或实对称且有明显零因子 | 先对特征行列式作行列加减，尝试把某行（列）凑成含公共因式的形式 → 凑出公共因式即直接分解得根 → 短时间内凑不出立刻回到代值法，不在试错上恋战 | 叠加型（需多次尝试才能凑零）时试错成本高，应直接改用代值法 |

### 失效边界

**适用前提**（3 条）

- 矩阵为低阶数值矩阵且特征多项式展开后系数全为整数
- 至少一个特征值为整数，使该点函数值可被分解为整数因数组合
- 只求特征值的数值，允许在草稿上完成试根与验算

**失效场景**（5 条）

- 特征多项式含参数，代入点取值为含参表达式，无法分解质因数，整条方法失效
- 特征值全为无理数时任何整数点取值都拆不出对应整数因子，猜根必然失败，只能靠降次后的求根公式
- 存在重根时按单一因式降次得到的二次式仍可再分解，若不复查判别式易漏判重根结构
- 矩阵阶数明显高于三阶时因数组合数量激增，试错成本超过直接分解
- 题目同时要求特征向量、相似对角化或二次型标准化时，本法只给特征值，不能替代后续求解

## 矩阵幂降次闭合通法

> 编号 **T-LA-20-I** ｜ 版本 **v0.5.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 求 A 的高次幂只有一条路：先靠低次乘法认出 A 的幂与 A、E（或更低两阶幂）之间的固定关系，再把任意次幂折回这个组合——秩一形 A=(alpha)(beta)^T 把中间内积提成数得 A^n=(tr A)^{n-1}A；E 加幂零形用二项式展开并在幂零阶处截断；具体低阶阵先实算 A^2、A^3 认关系并按奇偶或周期分档；块副对角形平方后变块对角再分档；题给相似关系时把幂搬到易算一侧写成 P^{-1}B^nP；已验得递推式时用归纳把 A^n 定成低两阶的组合。六种入口的共同点是高次幂从不独立计算，只由低次幂与少数常数决定 |
| 适用范围 | 列乘行的秩一矩阵及其与 E 之和的任意次幂、含其幂的向量方程 |
| 学科 / 章节 | 线性代数 · 矩阵、向量、相似矩阵（特征值与特征向量） |
| 表面题型 | 秩一矩阵的整体降幂；算低次幂认关系分档写通项；单位阵加幂零块二项式截断；相似关系将幂搬到易算一侧；副对角分块平方化块对角求幂；矩阵幂的递推归纳与高次求值；列分块分解与低阶方阵降幂；相似对角化的应用（幂、数列与极限） |
| 对应考点 | 运算；矩阵及相关概念；（一）概念及运算；必备知识点；逆矩阵；（三）伴随与逆；（二）伴随矩阵与求逆；解题连招；（三）分块矩阵；（五）极大无关组；（一）线性表示；（一）求特征值；可对角化；（二）相似矩阵 |
| 覆盖题量 | 15 题（分支 7 个） |

### 标准解题步骤

1. 先定降次入口：按结构判它属于秩一形、E 加幂零形、低阶可直接实算形、块副对角形、题给相似形，还是已验得递推关系形
2. 秩一形：把矩阵写成列乘行并先算该内积（即 tr A），由 A^2=(tr A)A 逐次相乘得 A^n=(tr A)^{n-1}A；原阵写成 E 加秩一块时先把 E 与秩一块分开再降幂
3. 幂零形：拆成 E+N（或 kE+N），逐次相乘到 N 为零记下幂零阶，二项式展开只保留到该阶前一项；求逆按 E-N+N^2-… 的有限和写出
4. 实算认关系形：先算 A^2、A^3 并与 A、E 逐项对照出数量线性关系，据此逐级降幂；关系随 n 摆动时按奇偶或周期分档写出，并注明各档的取值范围
5. 块副对角形：按非零块划块后先平方得块对角（块内为秩一阵或数量阵），再按 n 的偶档取块对角的 k 次方、奇档在其后多乘一次原阵
6. 相似形：确认 A=P^{-1}BP 的方向（勿把两侧写反），由连乘相消写 A^n=P^{-1}B^nP，只在易算一侧取幂后用同一个 P 搬回；易算一侧的幂化成数量阵（含 E）时共轭即退回同一数量阵，P 的具体值无需求出；待求式里另一阵自身的幂不参与共轭，须留在原侧直接实算，不得把它也搬进 P^{-1}(…)P
7. 递推形：把已验得的 A^n 与 A^{n-1}、A^{n-2} 的关系用数学归纳法对全体 n 固定，再按右端形状选闭合档——齐次关系按特征根或周期写通项；右端为与 n 无关的常矩阵加项（A^n=A^{n-2}+C 一类）时奇偶两档各成等差：偶档 A^{2k}=A^0+kC（自 E 起算）、奇档 A^{2k+1}=A^1+kC，最后代最小两档与直接相乘核对
8. 统一回代校验：代最小的两档与直接相乘核对，逐项检查内积是数不是阵、幂零截断没有漏掉非零项、奇偶档与块阶数没有写串

### 二级分支（按表面题型适配）

| 低阶实算幂认关系分档分支 | 阵以具体数字给出且阶数不高，实算 A^2（必要时 A^3）即与 A、E 呈数量线性关系，可直接写出 A^n=f(n) 的闭式并按 n 的奇偶或周期分档（A²=4E ⇒ 奇档 4^{k-1}A、偶档 4^{k}E 一类）；题目要求对全体 n 归纳证明该关系或计算一个大指数幂者归「低次幂递推经归纳降次分支」，不入本支 | 认出幂之间的线性关系：A^2=cA、A^2=cE、或 A^m 与 A^{m-1}、A^{m-2} 的递推式 → 按该关系逐次降幂，把 A^n 写成 A 与 E 的数量组合（或两个不同幂的差） → 结果随奇偶或周期变化时按 n=2k-1、n=2k（或模周期）分档写出，并注明 k 的取值范围 | 矩阵以具体数字给出且阶数不高，直接相乘代价可控；低次幂之间确存在数量系数的线性关系（含幂零、对合、数量乘 E 三种特例）；失效：A^2、A^3 与 A、E 都线性无关时无法用两步降幂闭合，须改走相似对角化或 Cayley-Hamilton 路线；含参数的矩阵未先定参数就找规律，规律会随参数分档改变 |

| 块副对角平方化块对角分支 | 非零元集中在副对角块位置、可按块划分且副对角块之积为秩一阵或数量阵；块内不满足列乘行结构时不入本支 | 用分块乘法算 A^2，确认结果是块对角且块内为列乘行或数量阵 → 把块内的列乘行按秩一降幂式换成数乘该块，得 A^2 为数乘一个可再乘的块阵 → 按 n=2k 与 n=2k+1 分档：偶次幂为块对角之 k 次方，奇次幂再多乘一次原副对角块 | 非零元集中在副对角块位置，可按块划分且块阶数明确；副对角块之积为秩一阵或数量阵，能继续降幂；失效：块内元素不满足列乘行结构时平方后仍为稠密块，降幂链断开；行列分块尺寸不匹配（块不能相乘）时整个分块乘法不成立 |
| 低次幂递推经归纳降次分支 | 已验得 A^m 可由更低两阶幂与 E 常系数线性表出，题目要求证明该递推并计算一个大指数幂；右端为常矩阵加项（A^n=A^{n-2}+C 一类）时奇偶两档各成等差闭合（A^{2k}=E+kC、A^{2k+1}=A+kC），右端与 n 有关时不入本支 | 假设对 n-1 成立，两端同乘 A（或同减），把 A^n 化成低阶组合，完成归纳步骤 → 写出该递推的特征方程与特征根，判断是等比档、等差档还是周期档 → 按档把目标高次幂逐级降下来（或写成低次幂的线性组合），代已算出的低次幂得数 | 已验得 A 的某次幂可由更低的两次幂与 E 线性表出；递推系数为常数、与 n 无关，初值（A、A^2）可直接算出；失效：关系式右端含与 n 有关的系数时不能按常系数递推闭合；只验 n=3 一档就断言全体成立，缺归纳步骤 |
| 列分块分解降幂分支 | 矩阵按列给出且列向量组秩低于列数（大量列可由极大无关列表示），要求分解或求高次幂 | 用行变换求列向量组的极大无关组并读出其余列的表示系数，把矩阵分解成极大无关列阵 G 乘系数阵 H → 写 Aⁿ=(GH)ⁿ=G(HG)^{n-1}H，把幂转移到低阶方阵 HG 上 → 对 HG 求幂（认低次幂关系、二项式截断或递推闭合），首尾乘回 G 与 H 得结果 | 适用前提：G 所取的列构成极大无关组（列满秩），且 HG 的幂可闭合；坑点：夹心幂不可拆成 GⁿHⁿ，系数阵的行序须与极大无关列的列序对应，分解先经乘回验证再用。 |
| 对角化求幂与数列通项分支 | 矩阵未给相似关系、需自证可对角化后求 Aⁿ，或目标是线性递推数列的通项与极限 | 把递推关系写成矩阵形式 αn=Aαn-1，求 A 的特征对并拼 P 与 Λ（确认可对角化） → 写 Aⁿ=PΛⁿP⁻¹，代入初值把通项表成各特征值幂的线性组合 → 比值极限按特征值增长速率分层，由最大绝对值档控制，代小 n 值验算通项 | 适用前提：A 可对角化（重根几何重数达标）；坑点：Aⁿ 不可写成 PⁿΛⁿ(P⁻¹)ⁿ，负特征值档的符号摆动单独核，初值代入 P⁻¹ 的系数容易错位。 |

### 失效边界

**适用前提**（23 条）

- 矩阵可写成列向量与行向量之积，或行向量组（列向量组）彼此成比例
- 内积 (beta)^T(alpha) 可先算出且为一个数（可含参数）
- 待求式为 A 的高次幂、A 与 E 之和的幂，或含 A 的幂与向量之积的方程
- 矩阵以具体数字给出且阶数不高，直接相乘代价可控
- 低次幂之间确存在数量系数的线性关系（含幂零、对合、数量乘 E 三种特例）
- 题目要求 A^n 的表达式或某个具体高次幂的值
- 矩阵可拆成单位阵（或数量乘单位阵）加一个严格三角形／幂零块
- 幂零阶可由直接相乘确定（不超过矩阵阶数）
- 待求式为 (E+N) 的正整数幂或它的逆矩阵
- 题面显式给出相似关系与可逆矩阵 P（或说明 P 可逆但未给具体值）
- 非零元集中在副对角块位置，可按块划分且块阶数明确
- 副对角块之积为秩一阵或数量阵，能继续降幂
- 题目要求 A^n 的表达式（按 n 的奇偶分档）
- 已验得 A 的某次幂可由更低的两次幂与 E 线性表出
- 递推系数为常数、与 n 无关，初值（A、A^2）可直接算出
- 题目要求证明幂的递推关系并计算一个很大的幂次
- 题面显式给出相似关系 A=P^{-1}BP（或 B=P^{-1}AP）且 P 只需可逆、不必给出元素，一侧具对角、置换、分块或低阶周期等易算幂的结构，待求式只含这两阵的幂与其数乘、加法；易算一侧的幂化成数量阵时共轭退回同一数量阵（P 的具体值无需求出），另一阵自身的幂留在原侧直接实算，不得搬进 P^{-1}(…)P
- 矩阵列向量组的秩明显低于列数（存在大量可表示的列），具体数值给出
- 题目要求分解成「极大无关列阵乘系数阵」，或求高次幂
- 降成的低阶阵之积的幂可闭合（数量关系、幂零、递推）
- 数列（向量组）的线性递推关系，要求通项公式或极限
- 递推矩阵可对角化（特征值互异或重根几何重数达标）
- 结论为 Aⁿ、通项或极限值

**失效场景**（27 条）

- 秩大于一时中间内积不是数而是矩阵，不能提到前面整体降幂，须改按相似对角化或递推处理
- 把 (beta)^T(alpha) 与 (alpha)^T(beta) 混用或写成矩阵形式会使乘法不闭合，二者均为数但顺序须与内积定义一致
- 展开 (kE+A)^n 时漏掉 n=1 档的 E 项，或把 A^m 仍留在幂次上不降到底
- 内积为零时 A^2=O 属幂零形，(tr A)^{n-1} 在 n=1 处给出 0^0，须单独按幂零截断处理
- A^2、A^3 与 A、E 都线性无关时无法用两步降幂闭合；此时若列向量组的秩低于列数，先改走列分块分解降幂分支，再考虑相似对角化或 Cayley-Hamilton 路线
- 含参数的矩阵未先定参数就找规律，规律会随参数分档改变
- 把只在前几阶成立的"规律"外推而未回代校验，偶数档与奇数档混写成同一式
- N 不幂零（主对角线有非零元且不可分离）时二项式展开不截断，须改走相似对角化
- 把 A 本身当幂零块而忘记先减去对角部分，导致展开式多出无穷项
- N 与 E 之外的部分不满足所需幂零阶，仍按低阶截断会丢非零项
- P 不可逆或未给时不能建立幂的搬移，须先证可逆
- 关系式两侧写反（把 A=P^{-1}BP 当成 A=PBP^{-1}）会使共轭方向颠倒、结果不符
- 待求式含 A 与 B 的乘积但两者不在同一 P 下相似，不能逐项搬移
- 把 P^{-1}B^nP 误写成 P^{-1}B^n 或 B^nP，丢掉一侧的搬运矩阵
- 块内元素不满足列乘行结构时平方后仍为稠密块，降幂链断开
- 行列分块尺寸不匹配（块不能相乘）时整个分块乘法不成立
- 关系式右端含与 n 有关的系数时不能按常系数递推闭合
- 只验 n=3 一档就断言全体成立，缺归纳步骤
- 递推闭合要按右端形状选档：右端为与 n 无关的常矩阵加项时奇偶两档各成等差（偶档自 A^0=E 起算 A^{2k}=E+kC、奇档自 A^1=A 起算 A^{2k+1}=A+kC），右端等比时化成等比，齐次关系才按特征根写通项；把偶次幂的块对角形式直接当成 A^n 的一般式、把该走等差档的题硬套特征根、或特征根为重根与共轭复根时仍按两相异实根写通项，都属闭合方式选错
- 极大无关列阵不列满秩：分解虽在，幂的转移失效
- 把夹心幂写成两因子各自求幂再相乘：矩阵不可交换，只有夹心式成立
- 系数阵的行序与极大无关列的列序错位，乘回去不等于原矩阵
- 低阶阵的幂结构认错：幂零阶数多截或少截、周期档漏档
- 递推矩阵不可对角化时 PΛⁿP⁻¹ 不成立，须改若当形或递推法
- 把 Aⁿ 写成 PⁿΛⁿ(P⁻¹)ⁿ 或丢掉一侧的搬运矩阵
- 极限只看最大特征值的绝对值，负值档的符号摆动要单独核
- 初值向量代入 P⁻¹ 的计算错位导致通项系数错

### 标准解题步骤

1. 认型：待求是 f(A) 的特征值/特征向量、矩阵等式限制下的特征值取值，还是行列式与迹
2. 由定义 Aα=λα 对等式两侧作用同一多项式或矩阵运算，把对象换算到 λ 的代数式
3. 矩阵多项式恒等于零阵时，令 λ 满足同一多项式方程，解出特征值的候选取值
4. 需要特征向量时沿用原向量：f(A) 与 A+kE 的特征向量不变，P⁻¹AP 的为 P⁻¹α
5. 行列式与迹经特征值乘积与和换算：\|A\|=各 λ 之积（含重数）、tr A=各 λ 之和
6. 代一个具体值或低阶矩阵核对换算系数与幂次没有错位

### 失效边界

**适用前提**（4 条）

- 题给矩阵满足矩阵多项式等式，或要求 f(A)、A⁻¹、A*、Aᵀ、P⁻¹AP 的特征对象

- 不需要解出全部特征向量
- 特征值档位的重数确定与可对角化论证（秩账）归 T-LA-77-I（多项式约束特征档与重数），本族管特征对象的换算与取值读取

**失效场景**（4 条）

- λ=0 时 A⁻¹、\|A\|/λ 的换算失效，须单独讨论零特征值
- 矩阵多项式为零只给出特征值「取值于」方程的根，不能断定每个根都出现（重数另定）
- 不同特征值的特征向量之和不再是原矩阵的特征向量，换算规则不适用于新造向量
- 把 \|A+E\| 直接当 \|A\|+\|E\|：行列式须经特征值乘积换算

### 标准解题步骤

1. 算特征多项式读出特征值及重数
2. 逐个特征值解 (λE−A)x=0 得特征向量
3. 不同特征值之间自动正交，不重复处理
4. 同一重根内的特征向量做施密特正交化（内积除以平方长度再乘投影）
5. 全体单位化，按对角元顺序拼成正交矩阵 Q
6. 写 QᵀAQ=Q⁻¹AQ=Λ，并用 Q 的列两两内积为零验算一遍

### 失效边界

**适用前提**（3 条）

- 实对称矩阵要求正交矩阵 Q 使 QᵀAQ=Λ（或 Q⁻¹AQ=Λ）
- 特征多项式与特征方程组可手算，重根内可施密特
- 结论含 Q 与 Λ

**失效场景**（4 条）

- 重根内不做施密特而直接拼 Q：列不正交，Q 不是正交矩阵
- 不同特征值的向量不必正交化（已自动正交），重复改造反而引入计算错误
- 单位化漏除长度，QᵀQ 不是单位阵
- 把 Q⁻¹AQ 与 QᵀAQ 混写而未验证 Q 正交

## 特征信息反求矩阵

> 编号 **T-LA-68-I** ｜ 版本 **v0.1.7** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

### 标准解题步骤

1. 清点已知的特征值与特征向量，数出缺口（还差几个无关特征向量）
2. 实对称时用正交条件（与已知特征向量分别正交）解方程组补出缺口向量
3. 一般矩阵用重数与秩档（r(λE−A)=n−k）或解结构补齐
4. 把特征向量按列拼成 P，对角元按对应顺序拼成 Λ，确认 P 可逆
5. 计算 A=PΛP⁻¹（实对称已正交化时 A=QΛQᵀ），需要伴随或逆时一并换算
6. 代回验算：A 乘每个特征向量确得特征值倍数

### 失效边界

**适用前提**（3 条）

- 题面给出矩阵的部分特征值与特征向量（或解结构、秩条件），反求矩阵
- 特征向量组可补齐到 n 个无关
- 结论为 A 本身或其伴随、逆的某种组合

**失效场景**（4 条）

- 特征向量未补齐 n 个就写 A=PΛP⁻¹：P 不可逆
- 实对称的正交补漏解（与每一个已知特征向量都要正交）
- P 的列与 Λ 的对角元对应错位
- 由「特征值互异」误推非对称矩阵的向量自动正交

### 标准解题步骤

1. 分别求 A 与 B 的特征值，确认一致（或重排后一致）
2. 分别解特征向量，拼出 P₁ 与 P₂，使两者对角化到同一个 Λ（对角元顺序对应）
3. 由 P₁⁻¹AP₁=P₂⁻¹BP₂ 移项得 B=(P₁P₂⁻¹)⁻¹A(P₁P₂⁻¹)，令 P=P₁P₂⁻¹
4. 两侧都是正交对角化时 P=Q₁Q₂ᵀ（利用正交阵的逆即转置），并验 P 仍正交
5. 需要 Aᵀ 或 AB=P² 类目标时，把关系式按目标改拼（如 P=AQ 再验 (Qᵀ)²=E）
6. 代回验算 P⁻¹AP 等于目标矩阵

### 失效边界

**适用前提**（3 条）

- 题面要求过渡矩阵 P 使 P⁻¹AP 等于一个给定的具体矩阵 B（或 Aᵀ）
- A 与 B 有相同特征值且都可对角化（或同为实对称）
- 各自的特征向量可求

**失效场景**（4 条）

- 两段对角化的对角元顺序不一致时拼接错位，必须重排对齐
- P=P₁P₂⁻¹ 的方向写反成 P₂P₁⁻¹
- 正交版用逆而非转置（Q₂⁻¹=Q₂ᵀ 是正交性给的，须先验证 Q₂ 正交）
- A 或 B 不可对角化时此桥不成立

### 标准解题步骤

1. 由 A 的特征值算 \|A\|（乘积），确认 \|A\|≠0 后启用 A*=\|A\|A⁻¹ 的换算
2. 把 A 的每个特征值 λ 换算成 A* 的特征值 \|A\|/λ（特征向量不变）
3. 涉及 (A*−kE)X=0 时：把 k 与 \|A\|/λ 对照，命中的特征值给出零空间的维数与基础解系
4. 需要 tr(A*)（即代数余子式对角和）时用 A* 特征值之和直接读出
5. 实对称情形特征向量缺口用正交补补齐后再换算
6. 代回验算：A*X=\|A\|/λ X 对每个换算档成立

- 题给 A 的特征值（\|A\|≠0），涉及 A*、(A*−kE)X=0 或 tr(A*)
- 特征向量已知或可由实对称正交补补齐
- 结论为伴随的特征值、方程组通解、或代数余子式之和

**失效场景**（4 条）

- \|A\|=0 时换算式 \|A\|/λ 失效，须改按伴随秩三档处理
- 把 A* 的特征向量与 A 的特征向量弄混（可逆时相同，降秩时不同）
- 由特征值换算读几何重数时漏了「特征向量不变」这一前提的适用条件

## 特征向量组合与判别

> 编号 **T-LA-76-I** ｜ 版本 **v0.1.2** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

### 标准解题步骤

1. 写出每个向量的特征关系：Aαi=λiαi 及其对应的特征值
2. 同一特征值内：非零倍数与非零线性组合仍是该值的特征向量
3. 跨特征值组合：代入定义展开，按无关性比较系数，判定是否消成单一特征值的作用
4. 对 f(A) 的情形用 f(λi) 加权：组合向量是 f(A) 的特征向量当且仅当各 f(λi) 相等或组合单侧
5. 判组合向量非零（特征向量不得为零），零组合直接排除
6. 过渡矩阵的列逐一核对：列必须是特征向量、列序与对角元顺序一致、列组线性无关

### 失效边界

**适用前提**（3 条）

- 题给若干特征向量及其特征值，判组合向量或倍数向量的特征归属
- 判过渡矩阵 P 的候选取值是否正确（列须为特征向量）
- 不同特征值的无关性可判

**失效场景**（4 条）

- 零向量不是特征向量：k 取零或组合相消成零向量的情形必须排除
- 不同特征值的特征向量相加一般不是特征向量，不得照搬「同一特征值内可组合」
- 组合向量是 f(A) 的特征向量不等于它是 A 的特征向量（f(λi) 是否全等要单独核）
- 过渡矩阵的列序与对角矩阵的元序错位

## 多项式约束特征档与重数

- 结论为特征值档、\|kE−A\| 或相似对角形
- 特征对象的换算值（f(A)、A⁻¹、A* 的特征值与特征向量对应）归 T-LA-66-I（特征对象换算与取值读取），本族管重数与可对角化论证

**失效场景**（4 条）

- 多项式的根只是候选档，未证「出现」就写全部特征值（重数须另定）
- 一般矩阵没有实对称性时，重数论证须补可对角化（秩账）而非直接照搬

## 链式作用与幂零结构

2. 设线性组合为零，用链末端的幂（A 的最高次或 (λE−A) 的最高次）左乘，逐个收出组合系数为零
3. 由无关性把矩阵写成 A P = P B（P 以链向量为列），读出 B 的上三角幂零结构

- 题面给链式作用等式（Aαi=αi+1 或 (λE−A)²α=0 型），要求无关性、相似形或秩
- 链的末端向量非零（或矩阵幂为零）
- 结论为线性无关、P⁻¹AP 为上三角/幂零、或特征向量个数

**失效场景**（4 条）

- 链必须「到底」（末端非零且再作用为零），断了链的无关性论证不成立
- 幂零矩阵的特征值全为零，但仍可能有非零的若当块结构（不可对角化）
- 左乘的幂次用错一档，系数收不全
- 由 X²=O 断言 X=O（零因子），只能得特征值与秩的信息

## 相似与合同双重判定

> 编号 **T-LA-79-I** ｜ 版本 **v0.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 两个实对称矩阵的关系要分两层核对：相似要求特征值全体一致（同特征多项式），合同只要求正负惯性指数一致（正、负特征值的个数分别相等）；既相似又合同当且仅当特征值全体一致（此时惯性指数自动一致）。非对称矩阵谈合同无意义（合同以对称二次型为对象），判定题就是逐层核对特征值档与惯性档。 |
| 适用范围 | 判候选矩阵与目标矩阵是否既相似又合同（特征值层与惯性层分别核对） |
| 学科 / 章节 | 线性代数 · 相似矩阵（特征值与特征向量） |
| 表面题型 | 相似与合同的双重判定 |
| 对应考点 | （三）相似的判别与使用；（五）实对称矩阵；必备知识点；解题连招 |
| 覆盖题量 | 1 题（分支 0 个） |

### 标准解题步骤

1. 分别算各候选矩阵的特征值（或至少算出正、负、零特征值的个数）
2. 相似层：特征值全体（含重数）与目标一致才可能相似
3. 合同层：正惯性指数与负惯性指数分别与目标一致才合同
4. 非对称的候选直接排除合同可能（除非题目限定在对称类内）
5. 两层都过的候选即「既相似又合同」，其余按层排除
6. 用迹或行列式的差快速否证候选（数值不等必不相似）

### 失效边界

**适用前提**（3 条）

- 题面在若干候选中判「与目标矩阵既相似又合同」（或只判其一）
- 目标与候选的特征值（或惯性指数）可算
- 结论为选哪一项或判两层关系

**失效场景**（4 条）

- 相似与合同的判据不同：相似看特征值全体，合同只看正负个数，不能互相替代
- 对非对称矩阵使用惯性指数（合同以对称矩阵为对象）
- 由「特征值个数相同」就判相似：重数也须一致
- 用迹快速否证时只排了相似层，合同层要另判

## 低秩矩阵特征值与平移

> 编号 **T-LA-80-I** ｜ 版本 **v0.1.2** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 秩一矩阵 A=αβᵀ 的特征值由内积一步读出：非零特征值至多一个，即 βᵀα=tr A，其余全是零（由 A²=(βᵀα)A 的多项式方程亦可读）；可对角化等价于 βᵀα≠0（非零特征值是单根）。数量阵加秩一的和 (a−1)E+B 平移特征值；两个正交秩一块的和 αβᵀ+βαᵀ 在 α±β 上直接读出特征值，特征向量由 α、β 及正交补构造。 |
| 适用范围 | 秩一形、数量阵加秩一、正交秩一块之和的特征值读取、可对角化条件与特征向量构造 |
| 学科 / 章节 | 线性代数 · 相似矩阵（特征值与特征向量） |
| 表面题型 | 低秩矩阵的特征值与平移拆分 |
| 对应考点 | （一）求特征值；可对角化；必备知识点；（二）相似矩阵；解题连招；（四）求相似的可逆矩阵 |
| 覆盖题量 | 3 题（分支 0 个） |

### 标准解题步骤

1. 把矩阵认成秩一形（列乘行）或数量阵加秩一的和，指出内积因子 βᵀα
2. 由 A²=(βᵀα)A 或定义法读出特征值：βᵀα 与零（零为 n−1 重）
3. 数量平移：A=kE+B 时特征值为 k 加 B 的各特征值，特征向量不变
4. 两个正交块的对称和：直接作用在 α+β、α−β 上读出对称特征值，秩的账给出剩余零特征值
5. 判可对角化：非零特征值是单根（βᵀα≠0）才可对角化；βᵀα=0 时 n 重零根只有 n−1 个无关向量
6. 构造特征向量：非零档取 α（或 α±β），零档取 βᵀx=0 的基础解系，拼 P 写 Λ

### 失效边界

**适用前提**（3 条）

- 矩阵为秩一形 αβᵀ、数量阵加秩一、或正交秩一块之和
- 结论为特征值、可对角化条件、或 P⁻¹AP=Λ
- 内积与秩可直接计算

**失效场景**（4 条）

- βᵀα=0 时秩一矩阵不可对角化（n 重零根只有 n−1 个无关向量），不能写 P⁻¹AP=Λ
- 把 βᵀα 与 αᵀβ 的书写顺序搞混（两者数值相等但作用方向不同）
- 数量平移时特征向量不变，但不得把平移后的值当原矩阵的特征值
- 秩的账漏算：r(αβᵀ+βαᵀ)≤2 用来夹出零特征值

## 零乘积读特征值档位

> 编号 **T-LA-81-I** ｜ 版本 **v0.1.2** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 矩阵等式化成 XY=O 后，Y 的非零列就是 (·)x=0 的解，从而把特征值的存在性与几何重数直接读出：XY=O 且 r(Y)=t 给出特征值零（或对应值）至少 t 个无关特征向量；两侧秩的账（r(X)+r(Y)≤n、非零子式给下界）把每个特征值的重数与秩档夹出，n 个无关特征向量齐了就完成对角化论证。 |
| 适用范围 | 由零乘积矩阵等式读特征值档位与几何重数，凑齐无关特征向量完成对角化论证 |
| 学科 / 章节 | 线性代数 · 相似矩阵（特征值与特征向量） |
| 表面题型 | 零乘积等式读特征值档位 |
| 对应考点 | 可对角化；（三）相似的判别与使用；必备知识点；（二）相似矩阵；解题连招；（一）求特征值 |
| 覆盖题量 | 3 题（分支 0 个） |

### 标准解题步骤

1. 把题给矩阵等式整理成 XY=O 的标准形（必要时转置）
2. 由 r(Y)=t 读出对应特征值至少有 t 个线性无关的特征向量
3. 用秩的账夹档：r(X)+r(Y)≤n、题给秩或非零子式给出另一侧
4. 把各特征值的代数重数与几何重数对照，凑齐 n 个无关特征向量
5. 凑齐后写 A~Λ（对角元按特征值与重数排列），并给出 P 的列来源
6. 需要矩阵的幂或逆时由相似形直接换算（A²=PΛ²P⁻¹ 一类）

### 失效边界

**适用前提**（3 条）

- 题给矩阵等式可整理成 XY=O（含转置版），且一侧的秩已知或可夹
- 结论为特征值档位、可对角化、相似对角形、或矩阵的幂
- 两侧秩的信息足以定档

**失效场景**（4 条）

- 由 XY=O 只能读「Y 的列是解」，不能断言 X 或 Y 本身为零
- 几何重数读出后仍须与代数重数对照，漏比会误判可对角化
- 转置时左右角色互换（XY=O 与 YᵀXᵀ=O 的读法不同）
- 秩的账维数不匹配时不能套用

## 交换性与同时对角化

> 编号 **T-LA-82-I** ｜ 版本 **v0.1.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 可交换矩阵共享特征向量：AB=BA 时 A 的特征向量经 B 作用仍是同一特征值的特征向量（或零），于是 A 的特征子空间被 B 保持；A 有 n 个互异特征值时每个特征子空间是一维的，B 的作用只能数乘，公共特征向量拼成 P 使 P⁻¹AP 与 P⁻¹BP 同时对角。可交换性本身常由矩阵等式「两侧同乘后凑成互逆」得到。 |
| 适用范围 | 由矩阵等式证交换性与可逆性，证两个矩阵可同时相似对角化 |
| 学科 / 章节 | 线性代数 · 相似矩阵（特征值与特征向量） |
| 表面题型 | 交换性与同时对角化 |
| 对应考点 | 定义；可对角化；必备知识点；（一）定义及其性质；（二）相似矩阵 |
| 覆盖题量 | 2 题（分支 0 个） |

### 标准解题步骤

1. 把题给矩阵等式整理成 XY=YX（可交换）或 (A+E)(E−B)=E 一类的互逆形式
2. 互逆形式直接给出交换性与可逆性（\|·\|≠0 读出特征值不取某值）
3. 设 Aαi=λiαi，由交换性推出 A(Bαi)=λi(Bαi)：Bαi 落在 A 的同一特征子空间
4. 特征值互异（子空间一维）时 Bαi=μiαi，αi 就是 B 的特征向量
5. 公共特征向量组拼 P，写出 P⁻¹AP 与 P⁻¹BP 同时为对角阵
6. Bαi=0 的情形按特征值零处理，不破坏论证

### 失效边界

**适用前提**（3 条）

- 题面给可交换条件或可化为互逆/交换的矩阵等式，要求同时对角化或特征值排除
- 一侧矩阵有 n 个互异特征值（或每个特征子空间一维）
- 结论为同时相似对角化、或某矩阵不可取某特征值

**失效场景**（4 条）

- 交换性必须先证（由互逆等式给出），不能默认 AB=BA
- 特征值有重根时特征子空间维度大于一，B 在其上未必数乘，须另证
- 由 AB=A−B 型等式凑互逆时符号写错（(A+E)(E−B)=E 的展开核对）
- Bαi=0 的档漏讨论导致特征向量不完整
