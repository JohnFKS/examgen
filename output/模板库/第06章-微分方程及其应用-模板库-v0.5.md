## 一阶线性积分因子定解通法

> 编号 **T-HS-265-I** ｜ 版本 **v0.2.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 核心本质 | 把方程整理成 y′+P(x)y=Q(x) 后乘积分因子 e^{∫P dx}，左端恰成为 (y·e^{∫P})′，一次积分即得通解，变系数问题因此归结为两个一元积分；凡含 y 的幂、tan y、e^{f(x)} 等整体连同其导数一起出现的方程（伯努利 n≠0,1 型在内），先把该整体设为新变量即化为同一标准形；反过来由已知特解代入可定出 P(x) 与参数，由含任意常数的通解逐次求导消去常数可还原原方程，常数与初值都代回同一表达式取出 |

| 覆盖题量 | 12 题（分支 2 个） |

### 标准解题步骤

1. 整理成 y′+P(x)y=Q(x)，核对 P、Q 只含自变量；首系数含 y 的非一次幂或 y′ 的非线性因子时先改判其他类型
2. 导数项带 f′(y)·y′ 形式（2yy′=(y²)′、y′sec²y=(tan y)′、e^{f}f′=(e^{f})′）时把 f(y) 设为新变量，伯努利型先乘 y^{-n} 再作同一代换
3. 写积分因子 e^{∫P dx}，两端同乘并把左端合写成 (y·e^{∫P})′，一次积分得通解，∫P 含对数时把绝对值与常数因子整理干净
4. 由题给初值或隐含条件（极限存在、奇偶、有界）定出常数，积不出来的被积式保留积分形式并说明其连续性
5. 需要显式解时回代原变量并开方或取对数选分支，检查代换中的约分是否丢常值解
6. 反问题：把已知特解代入方程，按自变量的独立因子比较系数定出未知系数；给通解时逐次求导使任意常数的系数成比例，两式相减把常数消去还原方程
7. 把所得解代回原方程与初值双向验证，确认反推出的方程阶数、系数与解所含独立常数个数相匹配

### 失效边界

**适用前提**（11 条）

- 方程关于未知函数及其一阶导数都是一次的
- P、Q 在同一区间上连续，积分因子可写出
- 含 y 的某个复合式与其导数同时出现，且导数只差已知因子（如 2yy′=(y²)′）
- 代换后方程关于新变量是一阶线性或可分离
- 初值使还原时的开方分支唯一确定
- 所给解的个数与待定未知量个数相匹配，其导数可显式算出
- 未知量只以系数形式出现，比较系数后化为线性方程组
- 通解所含任意常数个数等于方程阶数，逐次求导可全部消去
- P、Q 在所论区间连续即可写出通解；∫Q e^{∫P dx}dx 不能表为初等函数时保留变限积分形式，其极限与有界性交「由通解表达式定解的性态」主干继续处理
- 本法与「一阶方程定型化归可分离通法」的分档：右端可写成 y/x 的函数、含 x±y、xy、x²±y² 的整体复合，或需反视自变量才成标准形者由该法完成化归；一旦方程呈 y′+P(x)y=Q(x)（含换元后关于 x(y) 的一阶线性、伯努利乘 y^{-n} 后、f(y) 整体代换后）即由本法收口，两法不重复给出同一通解
- 与「由导数（偏导）信息反求函数通法」的分档：P(x)≡0、y′ 已是自变量的显式函数只需积分还原者归该法；P(x) 不恒为零、y′ 与 y 在等式两端耦合者归本法

**失效场景**（10 条）

- 首系数为零的点使标准形的除法失效，须分区间讨论
- 积分因子写反符号会把通解整式变倒
- 复合式的导数还含无法消去的第三个未知函数，代换不能闭合
- 代换后需分情形的分支未讨论会得到丢解
- 把方程两侧同乘含未知函数的因子会引入增解
- 所给解个数少于未知量个数时只能定出约束关系式而非具体方程
- 解中含无法显式求导的变限积分时比较系数法失效
- 非齐次项本身待定时比较系数会引入非线性方程组，须另补条件
- 变系数方程的解不能反读特征根，此路线只适用于常系数线性场合
- 方程含 y 的非一次幂且不成 f′(y)·y′ 配对（如 y′=x+y²、y′=e^{xy}），既不能整体代换也不能分离时本法失效；伯努利 n≠0,1 型因可乘 y^{-n} 配成 (y^{1−n})′ 而确属本法

## 缺x缺y的二阶方程降阶求解

> 编号 **T-HS-266-I** ｜ 版本 **v0.2.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 方程不显含 y 就令 y′=p 把二阶降为关于 p 的一阶方程；不显含 x 就令 y′=p 并把 y″写成 p·dp/dy，降为以 y 为自变量的一阶方程。降阶后按一阶类型求解，再积分一次还原 y，两个常数由两个初值条件分别定出。 |
| 适用范围 | 不显含 x 或不显含 y 的二阶方程，含由降阶后的一阶类型与两个初值的分工 |
| 学科 / 章节 | 高等数学 · 微分方程及其应用 |
| 表面题型 | 二阶方程缺 y 或缺 x 时降阶为一阶 |
| 对应考点 | （一）二阶可降阶微分方程；（一）变量可分离型；一阶方程；必备知识点；高阶方程；（三）一阶线性方程 |
| 覆盖题量 | 3 题（分支 0 个） |

### 标准解题步骤

1. 判定方程缺哪个变量：不含 y 用 y″=p′（p 为对 x 的导数），不含 x 用 y″=p·dp/dy（p 为对 y 的导数）
2. 作代换把二阶方程降为关于 p 的一阶方程，并识别其类型：可分离、一阶线性或齐次
3. 解出 p 的通解并写入第一个常数：题给该点导数值时直接代入，缺 x 型要用同一点的 (y₀, p₀) 成对代入而非把 x₀ 代进去；只给函数值时把该常数留到第四步还原后联立
4. 把 p 换回 dy/dx 再积分一次还原 y，写入第二个常数，出现对数或根式时先合并常数再显化并按初值选分支符号
5. 用其余初值（或切线、拐点、弧长等几何条件翻译出的导数值）定出第二个常数；两个条件同为函数值时分别代入还原后的表达式联立解出，并检验解所在区间上根式与分母的符号限制
6. 降阶后的一阶方程仍需代换或需积分因子时，把该动作交「一阶方程定型化归可分离通法」与「一阶线性积分因子定解通法」两条主干执行

### 失效边界

**适用前提**（5 条）

- 方程明确不显含 y 或不显含 x，或经代换后可化为这种形式
- 降阶后得到的一阶方程属可分离、一阶线性或齐次三者之一，其求解分别由「一阶方程定型化归可分离通法」与「一阶线性积分因子定解通法」承担；三者都不是（如 p′ 与 p 的非线性耦合无法分离）则本法无出口
- 条件个数与方程阶数匹配，且按其落点分档：给在某点的 (y₀, y′₀) 成对值用于缺 x 型的第一个常数，只给函数值时两个常数一律留到还原积分之后联立
- 与「常系数线性微分方程求解通法」的分档：方程对各阶导数线性且系数为常数（或经一次自变量代换化为常数）者归该法；非线性方程、或线性但系数变且不可统一代换者，按是否缺 x、缺 y 归本法
- 本法只接收已给出的方程：等式由变限积分、几何量或物理定律先建出的二阶方程，建方程动作归「积分与偏导条件建微分方程通法」与「几何与物理条件建微分方程通法」，本法负责建成之后的判缺项与降阶

**失效场景**（3 条）

- 方程同时显含 x、y 与 y′ 的非线性组合时降阶不闭合，须另寻代换
- p=0 的常值解在约分时被丢，须单独补查
- 只给一个初值时无法定出两个常数，通解不能强行特化

### 标准解题步骤

1. 判型：先看能否把只含 y 的因子（含 dy）与只含 x 的因子（含 dx）直接分列两侧，能则进入积分
2. 右端可整体写成 y/x 的函数时设 u=y/x，用 y=ux 把导数换成 u+xu′，两端 u 项相消后化为只含 u 与 x 的可分离形
3. 式中出现 f(x±y)、f(xy)、f(x²±y²)、f(ax²+by+c) 等只含变量整体组合的复合项时，把该整体设为新变量 u，连同 du/dx 的上乘因子一并代入，方程化为 u 与单个自变量的可分离形
4. 对 x 非线性而对 y 为一次（或题要求视 x 为因变量）时用 dx/dy=1/y′ 改写；方程显含 y″ 时另用 d²x/dy²=−y″/(y′)³（要求 y′≠0、x′(y)≠0），换元后得到的是关于 x(y) 的二阶方程，须交回缺项降阶或常系数结构主干继续处理
5. 化到可分离形后两侧各取不定积分，积分常数只在一侧写出并合并成单个常数
6. 分离时约去或除以含未知函数的因子，单独补查该常值解是否被漏掉，并按凹凸与初值选定开方与取对数的符号分支
7. 出现对数或反三角形式时先合并常数再指数化，把解写成乘积或幂的形式，需要时显化成 y 关于 x 的单值函数
8. 代回原变量并用初值定出常数，最后把解代回原方程两端核对恒等，并检查旧变量是否已全部换尽

### 失效边界

**适用前提**（10 条）

- 方程可写成两因子分别只含 x 与只含 y 的乘积形式
- 分离后两侧积分均可用基本公式积出
- 初值给出后可在积分式上直接代入定常数
- 右端各项关于 x、y 同次（齐次）或可整理成 y/x 的函数
- 分离后 du/(φ(u)-u) 可积出
- 初值使 u 落在 φ(u)-u 不变号的区间内
- 原方程关于 y 非线性、但视 x 为未知函数时是一阶线性
- 导数可作反函数变换且 x′(y)≠0
- 本法第3步的整体代换只针对 x 与 y 的组合整体（x±y、xy、x²±y²、ax²+by+c），代换后须化为只含新变量与单个自变量的可分离形；f(y) 与 f′(y)y′ 配对、代换后成一阶线性者归「一阶线性积分因子定解通法」
- 初值可在新变量下直接代入，代回原变量时以初值确定开方或取对数的分支

**失效场景**（9 条）

- 分离时约去含未知函数的因子会丢常值解
- 积分含变限或含参时不能当作一元积分直接积出
- 含 x、y 的非齐次项（如常数项或单独的一次项）时该代换不能消去自变量
- φ(u)-u 有零点时约分会丢常值解
- 根式内符号随 x 变化时未分区间定号会得到错的分支
- 两种视角都非线性也不可分离时本法无出口
- x′=0 的特解（竖直直线解）在换元中被约去须补回
- 反解 x 出现多分支时未定分支会得到多值解
- 齐次比、变量整体代换、反视自变量三种动作都用尽后仍既不可分离也不成线性者（如 y′=sin(xy) 型），本法无出口，须交「一阶线性积分因子定解通法」或改判可降阶型

### 标准解题步骤

1. 判型：等式含变限积分、含参上限、二重积分或偏导关系时归入「由条件建方程」，不当作已给定的微分方程直接求解
2. 把积分号内与积分变量不成对的因子用整体换元（xu=t、x+y=u）或交换积分次序化成标准变限形式，区域对称时先把奇项整块削零并把区域折到对称半区
3. 两端对变量求导：上限代被积函数并乘上限对变量的导数，下限项取负号，需要时逐次再导直到被积式只剩单变量形式
4. 偏导场合先按链式法则写出所需一阶与二阶偏导，代入题给方程或混合偏导相等的相容条件，再把复合自变量整体设为新变量约成常微分方程
5. 从原方程代特殊点（x=0、上限与分点重合、令两自变量相等）取出与阶数匹配的初值，勿把变限积分在下限处的零值误当作已知函数值
6. 解所得常微分方程：不显含 x 或 y 者先降阶，其余按类型交回一阶或常系数主干，分段表达式的各支常数由连续性绑成同一值
7. 把所得函数代回原等式双向验证，检查积分号是否确已消尽、初值是否全部用足、旧变量是否已换成新变量
8. 需要进一步求值或判性态时，把解代回原表达式或按通解表达式取极限，结论由主部的阶与符号定出

- 与「含参变限积分的求导与定数通法」的分档：求导之后必须再解一个微分方程（或需由全微分相容条件建方程）者归本法；只求变限积分的导数、比式极限、最值、奇偶与性态而不解微分方程者归该法；该法的「积分方程化微分方程分支」与本法同源，跨章合并时二者比一次本质再定归属
- 与「几何与物理条件建微分方程通法」的分档：等式由切线截距、曲率、弧长、面积或物理定律给出者先由该法翻译成含变限积分的关系式，本法接手消积分并解方程；等式直接以变限积分、含参积分、二重积分或偏导（全微分）相容条件给出者归本法全程处理

**失效场景**（6 条）

- 积分上限也含未知函数时求导会引入无法消去的项，本法失效
- 只取一个初值就解二阶方程会留下定不出的常数
- 内层不止一个独立组合时约不成常微分方程
- 定线条件只给函数值不给导数值时高阶方程常数定不全
- 区域含空洞时相容条件不再充分，须另案处理
- 被积函数含 xu、x+y、x−y 等复合整体时未先按第2步换元即对上限求导会漏乘子；只有当该整体在任何换元下都不能与积分变量分离（例如上限与被积变量以不可解形式耦合）时本法才失效

## 抽象函数方程按定义建导数式

> 编号 **T-HS-271-I** ｜ 版本 **v0.1.3** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 函数由加法或乘法形式的抽象等式给出而无解析式时，先在特殊取值（令其中一个变量为零或 1）定出该点函数值，再用导数定义把增量差商中的抽象等式代入，把 f′(x) 表成 f(x) 与已知函数的组合，得到一个一阶（或高阶）微分方程，最后用已定出的初值求解。 |
| 适用范围 | 函数只由加法或乘法形式的抽象等式给出、无解析式，需定特殊点值并用导数定义建模 |

| 对应考点 | （三）一阶线性方程；一阶方程；必备知识点；（一）变量可分离型 |
| 覆盖题量 | 3 题（分支 0 个） |

### 标准解题步骤

1. 在函数方程中令自变量取特殊值（0、1、相等）定出该点函数值与必要关系
2. 按导数定义写差商，把函数方程代入分子，拆开含增量与含 f(x) 的两部分
3. 取极限得 f′(x) 关于 f(x) 的方程，识别其类型（一阶线性、可分离或齐次）
4. 按该类型解出通解并用第一步定出的函数值定常数
5. 回代原函数方程检验所得解满足原等式，并检查可导性假设是否成立

### 失效边界

**适用前提**（4 条）

- 未知函数只由抽象函数方程与某点导数或函数值给出，无解析表达式
- 函数方程对增量线性可拆，取极限后能闭合
- 特殊值代入可定出积分常数所需的初值
- 本法止于把抽象等式建成 f′(x)=F(x, f(x)) 的一阶方程（含用 f(0) 或某点导数值把系数定成的情形）；建成后的求解由「一阶方程定型化归可分离通法」（可分离终端形）与「一阶线性积分因子定解通法」（y 与 y′ 呈一次）承担，例题实证按建模主干归档不重复计入求解主干

**失效场景**（3 条）

- 题面未给可导条件时不能假设导数存在
- 只用函数方程定值不定常数会漏解族
- 加法型（f(x+y)）与正切型（f(x+y) 为分式）可直接把 f(x+Δx) 整项代出；乘法型（f(xy)）须先归一（提因子 x(1+δ) 或两边同除 xy）再拆增量；两种归一都造不出差商、或等式并非对所有自变量取值成立时本法失效

### 标准解题步骤

1. 核对各阶导数系数为常数（或可经自变量代换化为常数），先解对应齐次方程的特征方程并定根的类型：相异实根、重根、共轭复根

3. 系数呈 x^k 幂乘 y^{(k)}（欧拉型）或 e^{kx} 型时，按题给或自选代换 x=e^t、t=e^{-x}、x=sin t 把各阶导数换成对新变量的导数并记录回代关系
4. 把非齐次右端按加法拆成指数、多项式、三角各块，逐块判该指数（或 α±iβ）是否落在特征根上，据此决定特解是否乘 x 的幂
5. 将设出的带待定系数特解代入原方程，按独立因子比较系数解出待定项，各块特解相加得非齐次特解
6. 由初值、有界性、极限或指定趋向定出全部常数；只给若干特解时先作差造齐次解并检查线性无关，再写「齐次通解加一个非齐次特解」的结构

8. 换回原自变量并代回原方程验证，核对特解未与齐次解重复、阶数与独立常数个数匹配

- 方程为线性（齐次或非齐次）且已知若干具体解或解的组合形式
- 所给解的个数与线性无关性能凑足阶数所需的独立解
- 判定组合是否仍为解时系数条件唯一
- 方程是变系数但系数为 x 的同次幂乘各阶导数（欧拉型）或含可整体代换的指数因子
- 代换后各阶导数能化成关于新变量的线性组合
- 代换在所论区间单调可逆，可回代定初值
- 本法负责写出特征根表出的通解、定出待定系数与反定方程；只判解的极限、有界性、渐近线或据此反解参数范围而不需要写出特解时，交「由通解表达式定解的性态」主干

**失效场景**（12 条）

- 特征根实部符号随参数变化时有界性结论需分情形，不能一概而论
- 把非齐次的特解项当齐次解读会多算自由度
- 右端含 ln、arctan 等无对应待定形时本法不可设，须用常数变易或积分表达
- 变系数方程不能比较系数定待定值
- 齐次解与所设特解重合而未升 x 幂次会使代入恒为零
- 非线性方程不满足叠加原理，作差与线性组合都会失效
- 已知解线性相关时不能据其张出齐次解空间，须另找独立解
- 把非齐次解的组合系数和条件写成 0 会把特解误当齐次解
- 系数无法被同一代换统一约去时本法不能化常系数
- 代换非单调或跨奇点时未分段回代得到错解
- 换元后只换一阶导数漏二阶附加项会使方程形式走样
- 系数含自变量且不存在任何单一自变量代换能把各阶导数的系数统一约成常数时不能设 e^{rx}，本法失效（缺 x 或缺 y 的二阶方程交「缺x缺y的二阶方程降阶求解」）

### 标准解题步骤

1. 先把解写成通解公式的形式（一阶线性用积分因子表达式，常系数用特征根表出的组合）
2. 把待定项与含积分项分开，判断各部分在极限处的阶与符号
3. 未定式用洛必达或积分中值定理处理，把积分主部换成被积函数在极限点的值；被积函数只给连续性或仅有界时改用中值定理提出或夹逼放缩
4. 常系数场合按特征根的实部与重数分四档：实部全负则每一个解一致趋零；相异纯虚根给等幅振荡，有界而不趋零；单零根给出常数项、重零根给出 x 的一次幂项；出现正实部根则发散
5. 判「每一个解都有界（或趋零）」时须对全部根同时立条件：实部小于零，或实部恰为零且均为相异纯虚根；含参数时按判别式分档联立反解参数范围
6. 由极限定水平或斜渐近线时核对 y/x 与 y−ax 两个极限都存在，斜率可由 lim y/x 存在这一条件先反定参数再算截距，并比较指数衰减因子与变限积分增长的阶谁占优

### 失效边界

**适用前提**（6 条）

- 指数衰减与积分增长的阶可比较
- 特征根与参数之间的关系可判实部符号
- 解可写成积分因子形式或特征根表出的组合（含只含变限积分、不可初等表出的形式），被积函数在极限点存在有限极限，或整体有界可用积分中值定理提出
- 特征根按实部与重数分四档可判：实部全负（一致趋零）、相异纯虚根（等幅振荡、有界不趋零）、单零根与重零根（常数项与 x 的一次幂项）、正实部根（发散）；含参数时按判别式分档

- 被积函数无界或极限不存在时不能把主部换成定点值
- 通解含变限积分不是障碍，本法要取的正是其主部；只有被积函数无界、极限不存在，或衰减因子与积分增长不可比较（如指数与 e^{x²} 混排）时本法给不出结论

- 题面用几何语言给出曲线满足的等量关系且可唯一翻译成坐标与导数
- 初值条件个数与方程阶数匹配
- 变化率与某个可表出的量成正比，且物理定律给出方程结构
- 力或压强只依赖位置，可用 v·dv/dx 换元
- 初值（或切线、拐点、弧长、面积比、物理初始量）条件个数与方程阶数匹配，且落点分档：给在同一点的 (y₀, y′₀) 用于降阶后的第一个常数，两个纯函数值留到还原之后联立
- 符号按对象分档判定：曲率题由凹凸性定 y″ 的正负再展开绝对值，含倾角时由 cosα=1/√(1+y′²) 的取值范围定号；弧长微元 √(1+y′²) 恒正；面积与截距题先由单调性与初值确定 y、y′ 的正负再写表达式
- 与「积分与偏导条件建微分方程通法」的分档：等式由切线截距、法线、曲率、弧长、面积或物理定律给出者归本法全程（其含变限积分的子步骤即该法第3步的动作，不重复计入该法）；等式直接以变限积分、含参积分、二重积分或偏导相容条件给出、不含任何几何或物理量名者归该法
- 与旋转体体积、面积、弧长、形心等几何物理量计算主干（T-HS-142-I、T-HS-146-I、T-HS-143-I、T-HS-256-I）的分档：这些量作为题给条件反求曲线或运动规律时归本法，本法只管到建出并解出方程；曲线或运动规律已知、只要求这些量本身时归相应的几何应用主干

**失效场景**（6 条）

- 去掉绝对值不判凹凸或倾角范围会得到符号相反的解
- 几何关系中含未知切点而未先解切点时方程无法闭合
- 用整条曲线的对称量代替微元会丢失导数信息
- 阻力依赖速度高次幂时换元后不可分离，本法无出口
- 把速度平方当位移微分漏乘 1/2 因子会使系数差一倍
- 忽略方向符号会把衰减写成发散
