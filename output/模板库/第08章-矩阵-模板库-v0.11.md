### 标准解题步骤

1. 定型：行和相等、爪形、分块、含参递推、范德蒙或抽象矩阵式
2. 行和相等加合一列提因子；爪形消平；分块按块取积并核对符号与幂次
3. 含参递推：按最后一行展开建递推式，一阶依次代入、二阶按特征根闭合；范德蒙直接写结果
4. 抽象式：E 补形成乘积、单侧提因子、伴随与逆转成 \|A\| 的幂，不可分解因子联立
5. 特征值档：行列式取积、迹与对角代数余子式之和取和
6. 代一个具体低阶或具体值复核幂次与符号

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 各行（列）和相等加列提因子分支 | 每行（列）元素之和与行号无关（对角为 b、其余全为 a 一类），一次加列即可造出同一常数 | 把其余各列（行）全部加到第一列（行），并声明这一倍加不改变行列式的值 → 提出第一列（行）的公因子 s；同类操作做过 k 次时提 s^k，并按阶数核对幂次 → 用提走后全为 1 的那一列（行）把其余各列（行）逐一消成零（各减去它的适当倍数） | 每行元素个数相同且和式对称，能一次加出同一常数；对角元特殊而其余全同（如对角为 b、其余为 a），和为 b+(n-1)a 这类与行号无关的量；失效：各行和依赖行号（含互不相同的 a_i）时加出来的列不统一，本法失效；s=0 时提出 s 等于除以零，此时行列式本身为零或须改判其他结构 |
| 爪形用归一对角元消去一爪分支 | 非零元恰为一条整行（列）加主对角线，且主对角元全不为零可作归一与消元的除数 | 把主对角元逐个提出行列式（记在行列式外），使其归一为可用的消元系数 → 用归一后的第 i 行（列）倍加消去爪所在行（列）的第 i 个元素，逐列执行直到爪上只剩一个非零元 → 按只剩一个非零元的爪行（列）展开，余下的三角行列式取对角元之积 | 非零元恰为一条整行（列）加主对角线；主对角元全不为零，可作为归一与消元的除数；失效：主对角线出现零元时无法归一消元，须先行列互换或按该行列展开；两爪相接（例：除对角外每行两个非零元）时消元不闭合 |
| 行（列）互换重排成分块分支 | 非零元成团分布，交换若干对行（列）后出现整块零，可按对角子块取行列式之积 | 按目标次序逐次交换相邻两行（列），每换一次记一个负号；或直接按行（列）排列的逆序数 τ 一次定号 (-1)^τ → 把换好的行列式写成对角分块或上（下）三角分块形状，确认非对角块整块为零 → 对角分块与三角分块的行列式取各对角子块行列式之积 | 非零元集中在少数行（列），交换后出现整块零；交换次数（或置换的逆序数）可准确统计；失效：副对角分块（楚河汉界形）不能只取子块行列式之积，还须乘 (-1)^{mn}；交换过程未记录符号，结果整体差一个负号 |
| 副对角分块定号取子块积分支 | 零块占据两个对角块位置（楚河汉界形），或两侧各自元素相同可先相减退化成爪形 | 副对角块形：数出把行块整体下移所需的相邻交换次数（mn 次）定符号，再取两子块行列式之积 → 子块含伴随、逆或数乘时，按 \|kA\|=k^n\|A\|、\|A*\|=\|A\|^{n-1}、\|A^{-1}\|=\|A\|^{-1} 把子块行列式化为已知行列式的幂 → 两侧各自相同的形先把相邻两行（列）相减，把一侧化成爪形或全同列，再转爪形或各行和相等处理 | 零块占据两个对角块位置，其余块为同阶方阵；两侧块阶数 m、n 明确，交换次数可数；失效：把副对角分块直接写成 \|A\|\|B\| 而漏掉 (-1)^{mn} 是决定性错误；子块不是方阵时不存在子块行列式之积 |
| 按列拆分与列向量组合取行列式分支 | 待求行列式的某一列（行）明确写成两个（或少数几个）向量之和，其余各列（行）为同一组向量或其常数倍数——拆分与整列提因子可在同一步进行（如 \|A+B\| 的首列为 β1+β2 而其余列带 2、4、2 倍数）；或存在 (b)=(a)C 型组合关系且向量组线性无关；先用 \|A^T\|=\|A\| 整体转置再按本支处理不算行列混用，但本支不处理行列两侧对换的符号记账，该动作归「按行（列）变换序列比较两行列式分支」 | 需要调整列序时用相邻交换把目标列序排成已知列序，只按交换次数定最终符号 → 出现同一列是两个向量之和时按该列拆成两个行列式之和，逐个回落到已知行列式 → 某列各元素同倍数时把倍数提出（n 列同时提出即 k^n 因子），一次提清再比系数 | 对象明确是列向量拼成的行列式，维数与阶数匹配；列向量组线性无关使 C 可逆、可作除法；失效：维数与阶数不匹配（少给一个列向量）时行列式不能确定；行向量与列向量混用：行的多线性规则与列的符号规则不可同时套用 |
| 按行（列）变换序列比较两行列式分支 | 两个行列式由同一组元素构成，只是行（列）次序、某行（列）的倍数或"某行加上另一行"不同；按题给变换序列逐动作记账——行对换与列对换各记一个 −1、倍乘记 k、倍加不记，行侧与列侧的符号与倍数分别累计后相乘即定出 \|B\|=c\|A\|，不必展开任何元素；待求式还需把某列写成两向量之和才能回落者改走按列拆分支，元素集合不同或含未知变量时不入本分支 | 对每一次行（列）对换记一个负号，对每一次单行（列）乘 k 记因子 k，倍加不动值 → 需要时先用"行均可换为列"把列上的操作转成行的操作再记账 → 把累积的符号与系数写成 \|B\|=c\|A\| 的关系式，与题给选项或数值对照 | 两行列式由同一组元素构成，仅行（列）次序或倍加、倍乘不同；阶数相同且对应位置的元素关系可逐条读出；失效：两行列式的元素集合不同（多出一个变量或换了元素来源）时不存在这种倍数关系；把整块"倍加"当成改变行列式的操作，或把对换次数按行与列分别重复计数 |
| 三对角二阶递推化特征根等比分支 | 按首行（列）展开后同时出现 D_{n-1} 与 D_{n-2} 两项（非零元落在主对角线与紧邻两条对角线上，首尾行特殊时最后两阶单独核算），递推系数 p、q 与阶数无关且 t²-pt-q=0 的根可显式解出；展开后只含 D_{n-1} 者不入本支，改按主干第3步一阶递推依次代入或除以 pⁿ 求和 | 由一阶与二阶行列式直接算出 D_1、D_2 两个初值 → 解特征方程 t²-pt-q=0 得 α、β，把递推改写成 D_n-αD_{n-1}=β(D_{n-1}-αD_{n-2})；两根相等时改用 D_n-αD_{n-1} 为等差 → 对等比式从 2 到 n 累乘（或两边同除 α^n 作差），把 D_n 表成 α^n 与 β^n 的线性组合 | 非零元只落在主对角线与紧邻的两条对角线上；递推系数 p、q 与阶数无关；失效：首末行出现不相邻的额外元素时递推式多出不含 D 的余项，须先消元或拆项；系数依赖 n 时特征根法失效 |
| 加边升阶消秩一扰动分支 | 每行除对角元外的元素可写成（该行因子）×（同一组公共量），或除对角外各列元素彼此相同，补一行一列后新增首行（列）只含 1 与 0 且按它展开即回原式；补边后仍需展开成多个同族行列式者不入本支改走递推档，与「各行（列）和相等」同时成立时以能否一次提出全部列公因子化为单位阵为准 | 加一行一列构成 n+1 阶行列式，使新增的第一行（列）只含 1 与 0，并声明按它展开即回到原式 → 把升阶式读成对角阵（或单位阵）加若干列乘行的秩一块，指出每一块的列向量与行向量 → 从各列（行）提出公因子使主块变为单位阵，再用倍加把爪式元素逐个消零 | 行列式可视为单位阵（或对角阵）加上少数秩一块；补出的边使第一行（列）只有一个非零元且展开即回原式；失效：加边后仍需展开成多个同族行列式时本法不省算力，应改走递推；补的行列取值未配平（第一行取 1 却留下新增列的其余非零元）会改变原式的值 |
| 等比幂次直取范德蒙乘积分支 | 存在一行（列）全为 1 而其余各行（列）按下标成连续等比幂次且幂次不缺档，或首行（列）为含参多项式可按该行拆成若干低阶范德蒙之和；幂次不连续、某行混入不同幂次，或按首末行展开后余子式同族且含 D_{n-1}、D_{n-2} 者不入本支 | 列（行）顺序与幂次顺序不符时先做行列互换，并按交换次数或逆序数补上整体符号 → 按"后减前"的下标约定直接写 Π_{i<j}(x_j-x_i)，成对列出全部因子以免漏项或反号 → 首行（列）是含参多项式而非全 1 时，先按该行（列）拆成若干个低阶范德蒙之和 | 存在一行（列）全为 1，其余各行（列）按下标成连续等比幂次；变量两两不同时行列式非零，可据此判向量组线性无关；失效：幂次不连续或某行混入不同幂次时不是范德蒙，须改判加边或递推；因子写成 (x_i-x_j) 与下标约定不符会整体差一个符号 |
| 伴随与逆整体代换成 \|A\| 的幂分支 | 待求式在把 A* 换成 \|A\|A^{-1}（或 A^{-1} 换成 A*/\|A\|）之后可整体合并成 k·A 或 k·A^{-1} 的单一数乘——含 −3E 这类不可并入的加项时合并失败即不入本支；A 的可逆性已由题面直接给出、或由非零条件与平方和展开证得、或由"乘 A 消伴随 + 伴随秩三档排除零根"证得（可逆性完全未定时不入本支，先走主干的乘 A 消伴随档）；阶数 n 明确 | 把式中的 A* 一律换成 \|A\|A^{-1}（或把 A^{-1} 换成 A*/\|A\|），使待求矩阵只剩 A^{-1}（或 A）的线性组合 → 合并同类项成 k·A^{-1} 或 k·A 的单一数乘形式 → 取行列式：用 \|kA\|=k^n\|A\|、\|A^{-1}\|=\|A\|^{-1}、\|A*\|=\|A\|^{n-1} 把结果写成 \|A\| 的幂与常数之积 | 式子只含 A 的逆、伴随、转置与数乘，不混入 A 的高次多项式加法；A 可逆，或可由非零条件与平方和展开证明可逆；失效：A 奇异时 A* 仍存在但不可作除法，多数步骤失效；混入 A 的多项式加 E（如 A²-A-3E、2A*-3E 的行列式）时应改走特征值路线 |
| 秩不足或维数降秩直接判零分支 | 结论只要求判断行列式是否为零：题给矩阵多项式等于零矩阵（可整理成 XY=O 并用"非零矩阵""≠E"等排除条件推出 r(X)<n），或维数使 r(AB)≤min{m,n}<m；一旦题目要求给出具体的非零数值即不入本支，改走乘积分解或特征值档 | 用 XY=O 时的秩关系 r(X)+r(Y)≤n，配合题面的"非零""不等于 E"等排除条件（r(Y)≥1）推出 r(X)<n → 对乘积型 AB 用 r(AB)≤min{r(A),r(B)} 与 r(B)≤min{m,n}，与阶数 m 比较是否严格偏小 → 秩严格小于阶数即断言行列式为零，不再展开任何元素 | 题面给出矩阵多项式等于零矩阵，或维数使乘积必然降秩；有"非零矩阵""A≠E"这类排除性条件可用来说明秩不为满；失效：秩等于阶数时行列式可为任意非零值，本法给不出数值；由 A(A-E)=O 直接断言 A=O 或 A-E=O 是错的（矩阵环有零因子） |
| 由特征值取矩阵多项式的行列式分支 | 条件全部以 \|aE+bA\|=0 或已知特征值给出且能凑齐 n 个（不足时由 \|A\|=Πλ_i 补出），待求量为 f(A)、A*、A^{-1} 的行列式（对 f(λ_i) 取积）或其迹、主对角线上代数余子式之和（取和）；待求式能整体合并成单一数乘者改走伴随与逆代换支 | 用 \|A\|=Πλ_i 或题给的其他行列式值补出尚未确定的特征值，并核对个数等于阶数 → 把待求矩阵式写成 f(A)（如 A²-A-3E、2A*-3E），把每个特征值代入 f 得到 f(A) 的特征值 → 含伴随或逆时先用 λ(A*)=\|A\|/λ_i、λ(A^{-1})=1/λ_i 变换，再代入所要的组合 | 条件全部以 \|aE+bA\|=0 或已知特征值给出；待求量是矩阵多项式、伴随或逆的行列式，可由特征值的像求出；失效：已知特征值个数不足且 \|A\| 未知时补不出全部特征值，行列式不定；f 含 A^{-1} 而某特征值为零时不合法，须先证可逆 |
| 矩阵恒等变形与正交条件算抽象行列式分支 | 阵为抽象给定（只有阶数、矩阵等式与若干行列式值），待求量是一个数（行列式或迹），且需要先用 E=AA^{-1}、AA^{T}（正交时）或 A·A*/\|A\| 补形把和式变成乘积；矩阵层面已成乘积、只差按 \|XY\|=\|X\|\|Y\| 与 \|A*\|=\|A\|^{n-1} 取幂者同归本分支；A 的可逆性未经确认而式中含 A* 时先按主干第4步乘 A（或 A*）消伴随，再回到本支 | 把式中的 E 补成 AA^{-1}、AA^{T} 或 A·A*/\|A\|，按左提或右提公因子整理成若干矩阵之积 → 伴随与逆一律代成 \|A\|A^{-1}（或 A*/\|A\|），合并成数量乘单一矩阵，再用幂次公式化成已知 \|A\| 的幂 → 不可再分解的因子（如 \|A+E\|、\|A-B\|）整体记为未知量，与题给行列式等式联立解出或直接判零 | 矩阵为抽象给定（只有阶数与若干行列式值或矩阵等式），无法逐元素展开；待求式中各项含公共单侧因子，或可由 E 的等价形补出公因子；失效：把 \|A+B\| 直接写成 \|A\|+\|B\| 是最常见的违反；只有单列（单行）呈两向量之和时才可拆分；矩阵不可交换，左右提取得到的乘积不同，须取行列式后再比较 |

### 失效边界

**适用前提**（43 条）

- 行列式为具体数字或低阶含参阵列，可显式展开到二三层
- 存在成比例、相同或多数为零的行（列），一次倍加能造出两个以上零
- 允许对行（列）做倍加与整列提因子
- 四条入手方式各属一个二级分支，命中其一即本法可用：各行（列）元素之和与行号无关（对角 b 其余 a 型在内）→ 加列提因子分支；非零元恰为一条整行（列）加主对角线且对角元全不为零 → 爪形分支；非零元成团、行（列）各自重排后出现整块零 → 换块分支；某一个或两个对角块位置整块为零且子块同阶 → 分块取积分支
- 阶数为具体数字或低阶含参（结果是一个数值或多项式），或题目要求幂次系数、参数方程的根；按定义展开时非零排列项的个数可数
- 交换次数或两个排列各自的逆序数可准确统计，行换与列换的符号分别累计
- 子块与低阶余式的行列式可由已给 \|A\|、\|B\| 及 \|kA\|=k^n\|A\|、\|A*\|=\|A\|^{n-1}、\|A^{-1}\|=\|A\|^{-1} 求出（该代换本身由「矩阵到数的行列式同态通法」给出）
- 与「矩阵到数的行列式同态通法」的分层：本法承担分块的定型、块行块列的交换定号与降阶展开；子块中含 A*、A^{-1}、数乘时其行列式化为已知行列式的幂（\|kA\|=k^n\|A\|、\|A*\|=\|A\|^{n-1}、号外整体数乘按全矩阵总阶数取幂）由该法给出，两法对同一子块不得各取一次幂
- 与「含参n阶行列式递推闭合通法」的分档：阶数为具体数字或低阶含参（如 4 阶带参数 a，最终是一个多项式或一个系数值）者归本法一次或两次展开到底；阶数写成 n、要求通项公式或据通项求根判号讨论性态者归该法
- 所求量是若干代数余子式的定系数线性组合，且下标同属一行或一列
- A 可逆时可经 A*=\|A\|A^{-1} 把代数余子式整批读出
- 对象明确是列向量拼成的行列式，维数与阶数匹配
- 列向量组线性无关使 C 可逆、可作除法
- 同一列至多是两个向量之和（更多时拆项数量成倍增长）
- 替换（或补出）后的新行列式由相应的行列式计算主干出数：具体元素或低阶含参交「行列式定型化简降阶计算通法」，n 阶给通项交「含参n阶行列式递推闭合通法」，含 A 的逆与伴随交「矩阵到数的行列式同态通法」，本法只负责把代数余子式的组合换成一个行列式
- 代数余子式组合按下标分布分档：下标同属一行（或一列）者由本法作行（列）替换；要求全部 n² 个之和者由 A*=\|A\|A^{-1} 的元素总和读出；下标取遍主对角线（既跨行又跨列）者其和等于 tr(A*)，须由特征值取和，归「矩阵到数的行列式同态通法」，本法不再判其逐个计算
- 两行列式由同一组元素构成，仅行（列）次序或倍加、倍乘不同
- 阶数相同且对应位置的元素关系可逐条读出
- 与「矩阵到数的行列式同态通法」的接力边界：本法的动作止于"把所求量换成一个行列式（或一个已知行列式的倍数）"；该行列式内若含 A 的逆、伴随或数乘，其幂次代换（\|kA\|=k^n\|A\|、\|A^{*}\|=\|A\|^{n-1}、\|A^{-1}\|=\|A\|^{-1}）一律由该法给出，本法不得在其上再取一次幂
- 存在只含少数非零元的行（列），展开后余子式不超过两个
- 余子式与原式同族，或为可一眼看出的三角阵
- 阶数以 n 给出且要求通项公式（或据通项求根、判号、转成函数讨论性态），按首末行（列）展开后余子式与原式同族或为可一眼看出的三角阵
- 四种闭合方式各属一支，命中其一即本法可用：展开含 D_{n-1} 一项者可依次代入闭合；展开同时含 D_{n-1}、D_{n-2} 且 t²-pt-q=0 的根可显式解出者走三对角分支；单位阵（对角阵）加少数秩一块、补边后首行只含 1 与 0 且各列有可提公因子者走加边分支；存在一行（列）全为 1 而其余按下标成连续幂次者走范德蒙分支（含用"变量两两不同时行列式非零"判向量组线性无关的用法，以及首行为含参多项式时按该行拆成若干低阶范德蒙之和）
- 初值个数与递推阶数匹配：一阶递推只需由一阶行列式算出 D_1，二阶递推需由一二阶行列式算出 D_1、D_2
- 与「行列式定型化简降阶计算通法」的分档与退回判据：本法只在阶数写成 n、必须靠同族低阶式或已知乘积式闭合时启用；阶数固定且一次或两次展开即可落到二三阶者归该法。加边升阶与消零降阶方向相反，同一题内不得既补一行一列又逐列消零而重复计入提出的因子
- 待求矩阵式各项含同一可逆单侧因子（或其逆、伴随、转置）
- 题给若干行列式的数值，足以定出每个因子
- 矩阵等式可因式分解（如 A²B-A-B=E 整理成 (A²-E)B=A+E）
- A 可逆，或可由非零条件与平方和展开证明可逆
- A 的阶数 n 明确已知（\|A*\| 与 \|kA\| 两式都依赖 n）
- 题面给出矩阵多项式等于零矩阵，或维数使乘积必然降秩
- 有"非零矩阵""A≠E"这类排除性条件可用来说明秩不为满
- 结论只要求判断行列式是否为零或给出零值
- 条件全部以 \|aE+bA\|=0 或已知特征值给出
- 待求量是矩阵多项式、伴随或逆的行列式，可由特征值的像求出
- 行列式等于特征值之积对任意方阵成立（复特征值共轭成对，乘积仍为实数）
- 矩阵层面能化成若干因子之积（含把 E 补成 AA^{-1}、AA^T、A·A*/\|A\| 后单侧提因子）者走乘积分解档；含 A 的多项式加 E（A²−A−3E、2A*−3E 一类）或条件全以 \|aE+bA\|=0 给出者走本法的特征值档，两者同属本法而非失效
- 与「单行列线性拆项与逆用展开通法」的分层：本法负责把 \|A^{-1}+B^{-1}\|、\|A+B^{-1}\| 这类矩阵和化成若干因子之积；积中出现的 \|A+B\| 若其列呈"首列为两向量之和、其余列为同一组向量的常数倍数"，该数值由该法按列拆分与整列提因子求出，两法在同题上接力而非重复认领；本法的相应失效条只禁止不看列结构直接写 \|A+B\|=\|A\|+\|B\|
- 矩阵为抽象给定（只有阶数与若干行列式值或矩阵等式），无法逐元素展开
- 待求式中各项含公共单侧因子，或可由 E 的等价形补出公因子
- 涉及伴随、逆、转置、数乘与多项式的行列式或迹
- 与「矩阵可逆性判定与逆的构造通法」的分工：本法的产物是一个数（行列式或迹），凡待求式外面套着 \|·\| 或 tr 者归本法出数；28-I 的产物是一个矩阵（逆、伴随、参数值）或"是否可逆"的结论，把 A* 代成 \|A\|A^{-1} 后仍需比较元素、反解参数或写出阵本身者归该法；同一题先由本法出数、再由该法出阵时按动作分步接力，不得在两处各自代换一次
- 与「矩阵秩的定秩与降秩关系通法」的分工：本法只在"秩严格不足是为了断言某个行列式为零"时启用秩判零档（结论是 \|X\|=0 或判 X 不可逆）；结论停在秩的值、秩的范围或秩相等的参数条件（r(A*) 反推参数、两阵等价）归该法，本法不再取一次行列式

**失效场景**（50 条）

- 既无稀疏行又各列和不等时倍加只会增加非零元，应改判加边升阶或递推
- n 阶一般项结构按一行展开后子式的形状随之改变，不能逐阶降下去
- 把某行的倍数加到该行自身，或对已提走的因子又乘回，行列式的值被同时改动
- 各行和依赖行号（含互不相同的 a_i）时加出来的列不统一，本法失效
- s=0 时提出 s 等于除以零，此时行列式本身为零或须改判其他结构
- 把行加到列后再按列提因子，行列式的行列对应关系被破坏
- 主对角线出现零元时无法归一消元，须先行列互换或按该行列展开
- 两爪相接（例：除对角外每行两个非零元）时消元不闭合
- 消元时把倍数加到自身所在行，行列式值被改动
- 交换过程未记录符号，结果整体差一个负号
- 换后子块之间仍有耦合元素即非分块三角，本法失效
- 把副对角分块直接写成 \|A\|\|B\| 而漏掉 (-1)^{mn} 是决定性错误
- 子块不是方阵时不存在子块行列式之积
- 含整块零的分块只取子块行列式之积而漏乘定号因子是决定性错误：零块已在本位（分块三角）不额外变号，需交换 m 行块越过 n 行块者乘 (-1)^{mn}，行、列各自重排者还要乘上两个排列的逆序数符号
- 两侧块阶数 m、n 不等时 (-1)^{mn} 必须按实际块阶数计算；两侧块内元素全为同一值时可先相减化成爪形，该衔接仍在本法分支内完成，不得据此判本法失效
- 下标跨越不同行又不同列的组合不能由一次行替换得到，须逐个计算
- 把余子式当代数余子式直接替换行会整体丢符号
- A 奇异时 A*=\|A\|A^{-1} 不成立，不能由逆矩阵读代数余子式
- 题给 A^T=A* 一类等式使 A_{ij} 与矩阵元素本身配对时，替换系数不再是题面数字
- 维数与阶数不匹配（少给一个列向量）时行列式不能确定
- 把 \|A+B\| 当成 \|A\|+\|B\|；加法只对单个列（行）成立，整矩阵相加不满足线性
- 两行列式的元素集合不同（多出一个变量或换了元素来源）时不存在这种倍数关系
- 一行是两向量之和时把整个行列式写成两个行列式之和（加法只对单行单列成立）
- 多线性动作（把某行/列拆成两向量之和、提出整行/列的公因子）必须在同一侧做完，不得一半按行、一半按列；但"对换记 −1、倍乘记 k、倍加不记"这类逐动作记账可在行侧与列侧分别累计后相乘（\|PAQ\|=\|P\|\|A\|\|Q\|），行对换与列对换各贡献一个 −1，只按其中一侧计数会把 \|B\|=\|A\| 误判成 -\|A\|
- 把倍加型变换（含把一行/列整块加到另一行/列、以及块倍加）当成改变行列式的操作是错的，其系数为 1；反之把行侧与列侧各发生过的对换合并成一次计数也是错的，必须分别取奇偶再相乘
- 每行非零元较多，展开后余子式互相嵌套不成同族时递推断链
- 递推式的系数依赖 n 时不能按等比闭合，须改走归纳或拆项
- 拆项后两支行列式的符号与阶数未分别核对，会多算或漏算一项
- 首末行出现不相邻的额外元素时递推式多出不含 D 的余项，须先消元或拆项
- 系数依赖 n 时特征根法失效
- 把递推式中 q 的符号按展开符号写反是最常见的系统性错误
- 加边后仍需展开成多个同族行列式时本法不省算力，应改走递推
- 补的行列取值未配平（第一行取 1 却留下新增列的其余非零元）会改变原式的值
- 各行公共量互不相同、无法表成列乘行时升阶不闭合
- 幂次不连续或某行混入不同幂次时不是范德蒙，须改判加边或递推
- 因子写成 (x_i-x_j) 与下标约定不符会整体差一个符号
- 变量相等时行列式为零，不能再把它当作除数
- 各项没有公共单侧因子时提公因子会改变式子，须先补 E 的等价形
- 把 \|A+B\| 写成 \|A\|+\|B\| 是对本原理最常见的违反
- 因子不可逆时不能提其逆，须改走秩判零或特征值路线
- 矩阵不可交换，左右提取得到的后续化简路径可能不同，需取行列式后再比较
- 混入 A 的多项式加 E（如 A²-A-3E、2A*-3E 的行列式）时应改走特征值路线
- 把 \|A*\| 写成 \|A\|^n 或把 \|kA\| 写成 k\|A\| 是与阶数相关的系统性错误
- 秩等于阶数时行列式可为任意非零值，本法给不出数值
- 由 A(A-E)=O 直接断言 A=O 或 A-E=O 是错的（矩阵环有零因子）
- r(X)+r(Y)≤n 需 XY=O 且阶数相容，维数不匹配时不能套用
- 已知特征值个数不足且 \|A\| 未知时补不出全部特征值，行列式不定
- f 含 A^{-1} 而某特征值为零时不合法，须先证可逆
- 求行列式一律取积 \|f(A)\|=Πf(λ_i)，不得用 Σf(λ_i) 顶替；求 tr(A)、tr(A*) 或主对角线上若干代数余子式之和时取和才是正路，两档按待求量选定后不可混用；漏乘（漏加）某个特征值、重根未按重数计均属阶数差错
- A 的可逆性未定时不得用 A*=\|A\|A^{-1} 作除法：改在等式一侧乘上 A（或 A*），用 A*A=AA*=\|A\|E 把伴随消成 \|A\|E 与 A 的多项式，再取行列式得 \|A\| 的代数方程；方程含零根时用伴随的秩三档（r(A)=n−1 ⇒ r(A*)=1，r(A)≤n−2 ⇒ A*=O）配合"A 非零"排除零根，先证可逆再回到乘积分解档；A 确为奇异时本法的三条出数通道（乘积分解、特征值档、伴随代换）全部失效，只能退回秩判零

### 标准解题步骤

1. 数值组拼阵行变换：行最简形主元列给极大无关组，非主元列读表示系数
2. 相关性判定：秩与个数比较；含参时按消零行分档定参
3. 概念命题翻译成秩语言：以少表多、部分与整体、接长截短逐条判，可疑项用低维反例否证
4. 组合系数矩阵：新组等于无关组乘系数阵，系数阵满秩 ⇔ 新组无关
5. 公共表示向量：两组全部向量拼联合矩阵解齐次方程组，非零解即公共向量
6. 等价与定参：两组秩与联合秩的等式联立，逐档回验排除退化值
7. 抽象无关证明：定义式设组合为零，代入表示式或用矩阵作用造第二关系，收口在已知无关组
8. 几何位置关系（直线交点等）先翻译成解的档位再翻成秩等式

| 组合系数矩阵判新组相关性 | 组合系数矩阵与接长截短判相关 | 把每个新向量写成旧向量组的组合，系数按列排成系数矩阵 → 写出新组等于旧组矩阵乘系数矩阵的等式 → 旧组无关时，新组的相关性等价于系数矩阵的相关性：算它的行列式或秩 → 系数矩阵列满秩判新组无关；降秩时由系数矩阵齐次方程组的非零解读出相关组合 → 涉及接长截短时按「低维无关推接长无关；高维无关推不出截短无关」逐条判 → 用系数的齐次方程组验一次：非零组合系数的存在性与结论一致 | 旧组相关时套用「系数矩阵满秩推新组无关」：该判据要求旧组无关；系数矩阵的行与列排反：新向量的组合系数应作列；接长截短方向记反：截短无关推接长无关，接长无关推不出截短无关；等秩传递时漏写「互为表示」环节：等价来自互相可表示，不只是个数相等 |
| 定义式消元证线性无关 | 设组合为零推系数全零的无关证明 | 设各向量以可能的系数线性组合等于零向量，写出定义式 → 清点题给结构信息：哪些部分组已无关、哪些向量可由谁表示、向量满足什么矩阵关系 → 可表示的向量先代入表示式，把定义式改写成「已知无关组的组合」 → 需要第二条关系时用给定矩阵（或作差）作用在定义式上，与原式相加减消去部分向量 → 对已知无关的部分组令组合系数逐个为零，得到系数的线性方程组 → 解出全部系数为零完成无关证明；若方程组存在非零解则改判相关并给出该组合 | 只验证某一种特定组合为零就断言无关：必须对任意组合成立；消元时漏用「矩阵可逆」「特征向量非零」等前提，系数收不回零；用具体例子代入证明一般性结论：例子只能否证命题；对定义式乘矩阵时漏分配到某些项，得出错误的关系式 |
| 几何位置关系翻译成秩条件 | 直线位置关系翻译成秩的条件 | 把每条几何对象的方程写成一行，识别未知量个数 → 拼出系数阵与增广矩阵，明确「交点」对应方程组的解 → 把几何要求翻译成解的档位：唯一交点对应唯一解，无穷交点对应无穷解，无交点对应无解 → 再翻译成秩：唯一解对应系数秩等于增广秩等于未知量个数，其余档同法 → 把每条直线的系数看成一个向量，把秩条件改写成这些向量组的秩条件 → 回到几何语境复述一遍（如两条相交且第三条过同一交点），核对翻译没有歧义 | 只写系数秩等式漏掉增广秩：有交点要求增广秩等于系数秩，交点唯一还要求秩等于未知量个数；行向量秩与列向量秩混用：直线方程按行拼还是按列拼要与解的写法一致；漏掉每条直线都真实存在（系数非全零）的几何前提，未排除退化档；空间情形把「交于一线」与「交于一点」的秩档混淆 |
| 组等价与矩阵等价三层辨析 | 组等价与矩阵等价的辨析 | 写清两种等价的定义：向量组等价为互相表示，矩阵等价为乘可逆阵互化 → 核对结论落在哪一档：组等价要求秩与联合秩都相等，矩阵等价只要求秩相等 → 乘可逆阵的翻译：右乘对应列向量组等价，左乘对应行向量组等价，两侧乘只对应矩阵等价 → 「齐次方程组同解」对应系数阵行向量组等价，用它处理同解类命题 → 真命题给推导（从秩与表示出发），假命题举反例（同秩但不互相表示的两组） → 汇总各选项真伪，标注「必要不充分」的方向 | 把矩阵等价（秩相等）当成向量组等价：同秩的两组未必互相可表示；两侧乘可逆阵却推出行（列）向量组等价：两侧乘只保证秩相等；「同解」与「行等价」方向写反：行向量组等价才对应齐次同解，与列向量组无关；反例不取同型矩阵：矩阵等价在同型之间讨论才有意义 |

### 失效边界

**适用前提**（39 条）

- 三档入手方式各属一支，命中其一即本法可用：阵以具体数字或低阶含参元素给出、可做行变换（含用明显低阶非零子式给下界、阶梯形给上界的夹逼）→ 实算定秩与等价参数档；条件给的是矩阵乘积、和、转置与秩的数值或不等关系并含"非零""A≠E""某阵秩为定值"这类可作下界的排除条件 → 不等式夹逼档；题给 r(A*)、A*=O 或 A* 的非零元素个数，阵元素含参数且其行列式可分解成少数因子、阶数 n 明确 → 伴随秩分档反推参数
- 结论落在秩上：秩的值、秩随参数的分档、秩的取值范围，或两阵等价的参数条件（等价最终翻译成同型且秩相等）
- 阶数 n 与各阵形状明确：不等式链要用方阵阶数，伴随秩三档要用 n 与 n−1 的对应，长方阵只能数阶梯非零行
- 夹逼的两翼可分别来自不同性质：上界由乘积型不等式（r(AB)≤min{r(A),r(B)}、XY=O ⇒ r(X)+r(Y)≤n）给出，下界除明显低阶非零子式外还可由"和的秩"r(X)+r(Y)≥r(X+Y) 给出（X+Y 化成数量阵或已知秩阵时该下界可直接取值，如 (E+BA)+(E−BA)=2E）
- 长方阵的保秩引理：A 列满秩（A 为 m×n 且 r(A)=n）时 AB 与 BX 同解（ABα=0 ⇒ A(Bα)=0 而 AX=0 只有零解 ⇒ Bα=0），故 r(AB)=r(B)；B 行满秩时右乘同理保秩。该结论只给秩相等，不得据此写"存在 A^{-1}"（A 非方）
- 与「分块初等变换降阶通法」的分工：分块阵的块行块列消元、化块三角与数对角块秩之和由该法给出，本法只接管消元之后落在秩不等式链上的比较（r(AB)≤r(A)、AB=O ⇒ r(A)+r(B)≤n 等）；同一道题不重复做一次块消元
- 结论是可逆性、行列式是否为零、或由乘积秩条件定参数
- 矩阵乘积的两侧维数已知，秩不等式与维数夹逼可用的场合
- 题给乘积秩与因子秩的数值关系
- 向量以具体数字（或含少量参数的分量）给出，可拼成矩阵做初等行变换
- 结论为判线性相关或无关，或由相关性反定参数
- 向量个数与维数的关系便于直接套行列式判据或化阶梯数秩
- 向量以具体数字给出，可拼矩阵做行变换
- 结论要求极大无关组、秩、以及其余向量由极大无关组表示的式子
- 对任意个数的具体向量组皆可用；个数多于维数时必有相关部分，先求组再表示，个数不多于维数时可能整体无关（行变换后全为主元列）
- 概念判别题：给若干表示关系与相关性条件，判结论或选正确命题组合
- 条件与结论都停留在表示与相关的语言层，不需计算具体向量
- 命题真伪可由秩与个数的关系及低维反例完全判定
- 题面只给两组的个数关系与表示方向（或相关性），判必然结论
- 无需具体分量，纯个数与秩的逻辑推理
- 结论为「必相关」「个数不少于」一类强制判断
- 题面给出两个向量组，要求既可由甲组又可由乙组表示的向量或其一般式
- 联合矩阵以具体数字给出，可做行变换
- 结论允许含任意常数（公共向量一般成比例族）
- 题给两组秩相等、向量组等价、或一组可由另一组表示，且元素含参数
- 不含参数那一组的秩可以直接算出，用作秩的锚点
- 参数只出现在个别分量，行列式或消零条件可分解因式
- 新向量组的成员是已知无关向量组的线性组合（具体系数或含参系数）
- 结论为判新组相关性、找使新组无关的参数条件、或经等秩传递判相关性
- 旧组无关性已知（题给或可先判）
- 题面要求证明某组向量线性无关（或相关），且给出向量间的表示式、矩阵作用或部分组的无关性
- 向量抽象给出，无法或不必算具体分量
- 结构信息足以把定义式消元到某个已知无关组
- 题面给平面直线（或空间平面）的位置关系，要求用秩表述充要条件
- 方程组规模小，系数阵与增广阵的秩可分档讨论
- 结论是「位置关系对应秩等式」的双向翻译
- 题面比较向量组等价、矩阵等价、同解、乘可逆阵之间的推出关系
- 条件给矩阵乘积、秩相等或互表示，判哪一档结论成立
- 结论只涉及等价档位的强弱，不需计算具体向量

**失效场景**（55 条）

- 由 AB=O 直接断言 A=O 或 B=O 是错的（零因子），只能得秩的不等式
- r(A)+r(B)≤n 需 AB=O 且阶数相容，维数不匹配时不能套用
- AB=E 只说明 r(A)=r(B)=m（方阵情形才可互逆），长方阵时不等于 B 是 A 的逆
- 不等式给出的界未必取到，未验证存在性就写成等号会放大结论
- 对含参数的行做"乘以含参式"的变换会改变秩的取值分档，只能做加倍与对换
- 把 r(A) 与 \|A\| 混用：非方阵没有行列式，只能数阶梯非零行
- 只验证行列式为零就断言秩为 n-1，未再核有一个 n-1 阶子式非零
- 等价要求同型且同秩，形状不同的矩阵不构成等价
- 只用 \|A\|=0 定参数而不排除 r(A)≤n-2，会把 A*=O 的情形一并纳入
- n=2 时 r(A)=1 ⇒ r(A*)=1 与 n≥3 的写法一致，但 (A*)*=\|A\|^{n-2}A 的幂次为零需单独处理
- 把 r(A*) 与 \|A*\| 混用：\|A*\|=0 只说明降秩，不能定出秩为几
- 把 r(AB)≤r(A) 用成 r(AB)≥r(A)：方向写反全盘皆错
- 维数夹逼只对「内维小」成立，外维小不降秩（行满秩乘积可以满秩）
- 由 AB=E 写 \|A\|\|B\|=1 判可逆时忘了对长方阵 E 的阶数须与乘积一致
- 参数方程漏掉使秩更低的档（行列式为零只是必要条件）
- 向量个数大于维数时还去计算行列式：行列式不存在，应直接判线性相关
- 对行向量组做列变换后按列读表示关系：列变换不保持行向量组的相关性与表示对应
- 只验证行列式为零就写结论：为零只说明降秩，秩的确值须另复核
- 含参时把「行列式为零的参数」与「某行消零的参数」混为一谈，漏掉秩更低的分档
- 中途做了列变换：列向量组被换掉，列位置对应破坏，不能按列号读表示
- 只化到行阶梯就读表示系数：非主元列须在行最简形下才能读出准确系数
- 把主元列自身的数值当成表示系数：主元列读出的是单位列，表示系数只在非主元列上读
- 更换极大无关组后仍沿用旧系数：表示式随所选极大无关组整体改变
- 把「存在某向量可由其余表示」当成「任一向量都可由其余表示」：后者只对特殊结构成立
- 方向写反：部分相关推整体相关成立，反向不成立；整体无关推部分无关成立，反向不成立
- 用特例「确认」一般命题为真：举例只能否证
- 把「不能由某组表示」与「线性无关」混为一谈：前者只是表示关系不成立
- 不看表示方向套个数判据：以多表少不产生任何必然相关
- 表示组自身相关性未知时写死结论：判据要求以无关表多或正确使用逆否
- 把「个数相等」当成「等价」：个数相等且互相表示才等价
- 命题里两组的记号对调后仍沿用原结论
- 只对甲组（或乙组）单独做变换：公共向量必须解联合矩阵的齐次方程组
- 把通解系数直接当成公共向量的分量：系数是表示系数，公共向量要用组内系数组合出来
- 忘记排除零解：参数取零给出零向量，不满足「非零」的要求
- 两组成员维数不一致时联合矩阵无从拼起（正常题目中两组向量必同维），公共向量无从谈起
- 把「秩相等」当成「等价」：等价还要求互相可表示（联合秩也相等），秩相等本身不充分
- 只用行列式为零定参而不回验秩的确值：参数可能使秩掉到更低档
- 等价类问题漏写联合秩条件：必须同时核各组秩与联合秩
- 漏讨论使参照组本身降秩的参数档
- 旧组相关时套用「系数矩阵满秩推新组无关」：该判据要求旧组无关
- 系数矩阵的行与列排反：新向量的组合系数应作列
- 接长截短方向记反：截短无关推接长无关，接长无关推不出截短无关
- 等秩传递时漏写「互为表示」环节：等价来自互相可表示，不只是个数相等
- 只验证某一种特定组合为零就断言无关：必须对任意组合成立
- 消元时漏用「矩阵可逆」「特征向量非零」等前提，系数收不回零
- 用具体例子代入证明一般性结论：例子只能否证命题
- 对定义式乘矩阵时漏分配到某些项，得出错误的关系式
- 只写系数秩等式漏掉增广秩：有交点要求增广秩等于系数秩，交点唯一还要求秩等于未知量个数
- 行向量秩与列向量秩混用：直线方程按行拼还是按列拼要与解的写法一致
- 漏掉每条直线都真实存在（系数非全零）的几何前提，未排除退化档
- 空间情形把「交于一线」与「交于一点」的秩档混淆
- 把矩阵等价（秩相等）当成向量组等价：同秩的两组未必互相可表示
- 两侧乘可逆阵却推出行（列）向量组等价：两侧乘只保证秩相等
- 「同解」与「行等价」方向写反：行向量组等价才对应齐次同解，与列向量组无关
- 反例不取同型矩阵：矩阵等价在同型之间讨论才有意义

### 标准解题步骤

1. 可逆与逆：整理关系式为 A(…)=(…)A=kE 读出逆；伴随公式按 AA*=\|A\|E 派生并写明阶数幂次
2. 矩阵方程：移项集中未知阵化标准形乘逆，不可逆时设元素按列拆方程组
3. 初等变换读写：左行右列逐条翻译成初等阵乘积，反求时两侧乘逆
4. 分块运算：块对角逐块求，副对角交换块行（列）带符号，块初等变换只乘可逆块阵
5. 求幂：判秩一、幂零、实算认关系、相似搬幂、递推或列分块六入口，降到底后合并
6. 转置关系：A^T 与 A 的关系代入待证式，化成自身转置或相反数比较
7. 命题判定：正推不换序不约去，可疑命题用幂零、秩一、对合低阶反例否证
8. 代一个低阶矩阵全程复核方向与幂次

| 转置关系建式证正交 | 转置关系建式与分块正交证明 | 写出题给转置关系的标准形：正交 A^T=A^{-1}、反对称 A^T=-A、对称 A^T=A，并注明阶数与实矩阵前提 → 把待证的行列式或矩阵式中的 E、A 用该关系替换（A=AA^T、A^T A=E），使其化成"自身的转置"或"自身的相反数" → 取行列式后比较两侧化成 x=-x 型等式从而 x=0：先看清负号的两个来源——\|E-A\|=\|(-1)(A-E)\|=(-1)^n\|A-E\| 由奇数阶供负号，替换出的 \|A\| 系数必须为 1（题给 \|A\|=1 或由正交与条件推得）；两条件缺一时只能得 (1±\|A\|)·\|A-E\|=0 一类的恒等式，不得据此断行列式为零 → 分块情形先把分块阵的转置按块写出（转置同时交换块的左右上下位置），再做块乘法 → 由 P^TP=E（或 PP^T=E）逐块对照单位分块阵的对应位置，读出 (1,1) 块 A^TA=E_m、耦合块 A^TC=O 与 (2,2) 块 C^TC+B^TB=E_n；对角块的结论不能从和式直读——先用 A^TA=E_m 得 \|A\|=±1 而知 A 可逆，回代 A^TC=O 左乘 A^{-T} 得 C=O，才能把 (2,2) 块收成 B^TB=E_n；或改用 PP^T=E 直接读 (2,2) 块 BB^T=E_n，再按方阵单侧逆即双侧逆转成 B^TB=E_n → 反对称阵用到二次型时先算 X^TAX 并用它等于其转置的负值推其必为零，再回到解的判定 → 最后核对实矩阵与阶数条件（奇数阶反对称、2n+1 阶正交且 \|A\|=1 等）是否被真正用到，并确认分块时 A、B 确为方阵且块阶数与 E_m、E_n 对应 | 由 A^TA=E 只能说明列向量组单位正交，不能对非方阵随意写 AA^T=E；分块转置时忘记交换块的位置，导致块乘法对不上号；把 \|A^T\|=\|A\| 与 A^T=A 混用，对称条件未证就直接替换；奇数阶反对称阵行列式必为零（\|A\|=\|A^T\|=\|-A\|=(-1)^n\|A\| 且 n 奇），偶数阶可正可零不能一概判；同一处负号用在正交阵的 \|A-E\| 型论证时要两个条件同时成立——阶数为奇数供 (-1)^n=-1，\|A\|=1 使系数为 1；少任一个只剩 (1±\|A\|)·\|A-E\|=0 这类恒等式，不得据此断行列式为零或断 A-E 不可逆 |
| 矩阵命题正推与反例否证 | 矩阵命题的正面推导与反例否证 | 把每条命题改写成"由哪个条件、经哪一步、到什么结论"的形式，列出所依赖的公式 → 正面推导：从乘积等于 E 取行列式定可逆性，再用左乘右乘搬因子，全程不换序、不随意约去 → 否证：为可疑命题准备 2 阶反例库（幂零 [[0,1],[0,0]]、秩一 [[1,1],[1,1]]、对合 [[0,1],[1,0]]、零块拼法），逐条代入 → 检查三处高危动作：由 AB=O 约因子、把 (A+B)^{-1} 当 A^{-1}+B^{-1}、把 AB=BA 当默认成立 → 对含幂与逆混合的命题，先用可逆的定义把关系式化成乘积等于 E 再判断 → 最后把真伪结论按编号汇总，与选项比对，注意"必有"与"存在"的区别 | 只用一个特殊例子确认命题为真（举例只能否证，不能证明一般性断言）；在不可交换处搬动因子顺序，或在未证可逆时约去因子；"不可逆"只等价于 \|A\|=0，秩可为 n−1 也可为更低（此时 A^{*}=O），判"存在"与"必有"时两档要分开；第3步的低阶反例只能否证全称断言，不能确认它——②这类"必不可逆"可一对反例推翻，③这类"必有"必须回到 \|AB\|=\|A\|\|B\| 作正推，不得以特殊例子代替证明 |
| 低阶实算幂认关系分档分支 | 阵以具体数字给出且阶数不高，实算 A^2（必要时 A^3）即与 A、E 呈数量线性关系，可直接写出 A^n=f(n) 的闭式并按 n 的奇偶或周期分档（A²=4E ⇒ 奇档 4^{k-1}A、偶档 4^{k}E 一类）；题目要求对全体 n 归纳证明该关系或计算一个大指数幂者归「低次幂递推经归纳降次分支」，不入本支 | 认出幂之间的线性关系：A^2=cA、A^2=cE、或 A^m 与 A^{m-1}、A^{m-2} 的递推式 → 按该关系逐次降幂，把 A^n 写成 A 与 E 的数量组合（或两个不同幂的差） → 结果随奇偶或周期变化时按 n=2k-1、n=2k（或模周期）分档写出，并注明 k 的取值范围 | 矩阵以具体数字给出且阶数不高，直接相乘代价可控；低次幂之间确存在数量系数的线性关系（含幂零、对合、数量乘 E 三种特例）；失效：A^2、A^3 与 A、E 都线性无关时无法用两步降幂闭合，须改走相似对角化或 Cayley-Hamilton 路线；含参数的矩阵未先定参数就找规律，规律会随参数分档改变 |
| 单位阵加幂零块二项式截断分支 | 可拆成 E+N 或 kE+N，且 N 为严格三角形一类幂零块、其幂零阶可由直接相乘确定；N 的主对角线含非零元且不可分离时不入本支 | 逐次算 N^2、N^3 直到为零，记下幂零阶 m（N^m=O 而 N^{m-1}≠O） → 求幂时用二项式展开 (E+N)^n，把 k≥m 的项一律舍去，剩余项按 N 的各次幂合并 → 求逆时按 (E+N)^{-1}=E-N+N^2-…±N^{m-1} 写出有限和，或先设逆为同形多项式再乘出 E 定系数 | 矩阵可拆成单位阵（或数量乘单位阵）加一个严格三角形／幂零块；幂零阶可由直接相乘确定（不超过矩阵阶数）；失效：N 不幂零（主对角线有非零元且不可分离）时二项式展开不截断，须改走相似对角化；把 A 本身当幂零块而忘记先减去对角部分，导致展开式多出无穷项 |
| 相似关系把幂搬到易算一侧分支 | 题面显式给出 A=P^{-1}BP 或 B=P^{-1}AP 且 P 可逆，另一侧为对角、置换、旋转或低阶周期形，待求式只含这两阵的幂与其线性组合 | 由连乘相消推出 A^n=P^{-1}B^nP，注明该式对一切正整数 n 成立 → 在易算一侧求 B^n：对角的取对角元之幂，置换形与旋转形先算小周期幂 → 把待求表达式中的 A、B 幂全部换成同一侧，再按矩阵加法与数乘合并 | 题面显式给出相似关系与可逆矩阵 P（或说明 P 可逆但未给具体值）；一侧的矩阵具有对角、置换、分块或低阶周期等易算幂的结构；失效：P 不可逆或未给时不能建立幂的搬移，须先证可逆；关系式两侧写反（把 A=P^{-1}BP 当成 A=PBP^{-1}）会使共轭方向颠倒、结果不符 |
| 块副对角平方化块对角分支 | 非零元集中在副对角块位置、可按块划分且副对角块之积为秩一阵或数量阵；块内不满足列乘行结构时不入本支 | 用分块乘法算 A^2，确认结果是块对角且块内为列乘行或数量阵 → 把块内的列乘行按秩一降幂式换成数乘该块，得 A^2 为数乘一个可再乘的块阵 → 按 n=2k 与 n=2k+1 分档：偶次幂为块对角之 k 次方，奇次幂再多乘一次原副对角块 | 非零元集中在副对角块位置，可按块划分且块阶数明确；副对角块之积为秩一阵或数量阵，能继续降幂；失效：块内元素不满足列乘行结构时平方后仍为稠密块，降幂链断开；行列分块尺寸不匹配（块不能相乘）时整个分块乘法不成立 |
| 低次幂递推经归纳降次分支 | 已验得 A^m 可由更低两阶幂与 E 常系数线性表出，题目要求证明该递推并计算一个大指数幂；右端为常矩阵加项（A^n=A^{n-2}+C 一类）时奇偶两档各成等差闭合（A^{2k}=E+kC、A^{2k+1}=A+kC），右端与 n 有关时不入本支 | 假设对 n-1 成立，两端同乘 A（或同减），把 A^n 化成低阶组合，完成归纳步骤 → 写出该递推的特征方程与特征根，判断是等比档、等差档还是周期档 → 按档把目标高次幂逐级降下来（或写成低次幂的线性组合），代已算出的低次幂得数 | 已验得 A 的某次幂可由更低的两次幂与 E 线性表出；递推系数为常数、与 n 无关，初值（A、A^2）可直接算出；失效：关系式右端含与 n 有关的系数时不能按常系数递推闭合；只验 n=3 一档就断言全体成立，缺归纳步骤 |
| 列分块分解降幂分支 | 矩阵按列给出且列向量组秩低于列数（大量列可由极大无关列表示），要求分解或求高次幂 | 用行变换求列向量组的极大无关组并读出其余列的表示系数，把矩阵分解成极大无关列阵 G 乘系数阵 H → 写 Aⁿ=(GH)ⁿ=G(HG)^{n-1}H，把幂转移到低阶方阵 HG 上 → 对 HG 求幂（认低次幂关系、二项式截断或递推闭合），首尾乘回 G 与 H 得结果 | 适用前提：G 所取的列构成极大无关组（列满秩），且 HG 的幂可闭合；坑点：夹心幂不可拆成 GⁿHⁿ，系数阵的行序须与极大无关列的列序对应，分解先经乘回验证再用。 |
| 对角化求幂与数列通项分支 | 矩阵未给相似关系、需自证可对角化后求 Aⁿ，或目标是线性递推数列的通项与极限 | 把递推关系写成矩阵形式 αn=Aαn-1，求 A 的特征对并拼 P 与 Λ（确认可对角化） → 写 Aⁿ=PΛⁿP⁻¹，代入初值把通项表成各特征值幂的线性组合 → 比值极限按特征值增长速率分层，由最大绝对值档控制，代小 n 值验算通项 | 适用前提：A 可对角化（重根几何重数达标）；坑点：Aⁿ 不可写成 PⁿΛⁿ(P⁻¹)ⁿ，负特征值档的符号摆动单独核，初值代入 P⁻¹ 的系数容易错位。 |

### 失效边界

**适用前提**（48 条）

- 四种入手路线各属一档，命中其一即本法可用：题给 A 的多项式等式或含 E±A 的关系式、可整理成两因子之积等于数量乘 E → 配因子除常数档；给定逆或伴随的待定形、需乘开比较系数反解参数 → 待定形档；待求式只含伴随、逆、转置与数乘的组合且阶数 n 明确（结论为公式真伪、伴随的逆、伴随的伴随或某个具体逆阵，A 可逆或可由 AA^T=k\|A\|E 一类等式先解出 \|A\| 判可逆）→ 伴随公式档；题给每行（或每列）元素之和为同一常数（含参数 k）且阵可逆或可由该常数与 \|A\|≠0 证其可逆、结论要求 A^{-1}、A* 或 A^T 的相应行（列）和 → 常向量档
- 只要求证可逆而不需求出逆时，构造出一个乘出来等于 E 的因子即可，或把 \|A\| 写成平方和展开（实矩阵、A 非零）排除 \|A\|=0
- 所除的常数因子、所约的内积与所用的阶数都能由题面条件保证（含 k≠0、A≠O、n 明确；由行和常数 k 证可逆时须先排除 k=0）
- 与「矩阵方程化标准形乘逆」的分工：本法造出的是"某个阵可逆并等于什么"（把关系式配成 A(…)=kE 读出逆、或对已知因子判可逆）；该法处理未知阵 X 混在系数里的方程（先移项合并成 (系数)X=右端 或 X(系数)=右端 再乘逆）。同一道题按动作分步接力：判系数可逆用本法，写出 X 用该法，不得在两处各做一次补 E 提因子
- 系数阵可逆（可由行列式或阶梯形验证），或方程可按列拆成线性方程组
- 未知阵 X 只以一次出现（可与已知阵左右相乘）者即为标准形；X 在等式两侧各出现一次时先移项、用 E 的等价形把含 X 的项并到同一侧提出公因子，化成 (A-kE)X=B(A-kE)、(A^{*}-2E)BA=-8E 一类的 AXB=C 形——能化成此形者仍入本法，化不成（X 与 X^{T} 混排、X 出现在幂上且无公因子可提）时改走设元素档；乘逆后所得若为若干逆阵之积，可并成一个乘积的逆（(A^{*}-2E)^{-1}A^{-1}=[A(A^{*}-2E)]^{-1}）再求，以减少求逆次数
- 三处出口的接力分工：系数阵含 A^{*}、A^{T} 或 A 的多项式时，其可逆性判定归「矩阵可逆性判定与逆的构造通法」；判不出可逆而需化阶梯数秩者归「矩阵秩的定秩与降秩关系通法」；设 X 的元素（或按列分块）后得到的若干非齐次方程组，其增广阵化行阶梯/行最简与通解（含任意常数、解不唯一）归第10章的解的结构主干；本法只负责把矩阵等式整理成标准形、按左右侧乘逆写出 X、以及把方程拆成逐列的方程组
- 题面以文字或图形描述若干次行（列）初等变换，并给出变换前后两阵的关系
- 变换可由单位阵的同种变换一一造出对应的初等矩阵
- 结论要求写出乘积表示、判断可否表示，或据此定行列式符号与幂次周期
- 题给对换型初等阵 P 的幂或以 P 夹出的关系 P^{n}AP^{m}=A 时，由第3步的自逆性直接得 P^{2k}=E、P^{2k+1}=P 的奇偶周期，据此按 (n,m) 的奇偶组合判定等式是否成立（两侧同需为 E 者取 n、m 皆偶）
- 与「矩阵可逆性判定与逆的构造通法」的分工：本法只负责把变换序列翻译成 P、Q 乘积、给出 A^{-1} 与 A^{T} 的反序乘积形式以及 \|A\|=(-1)^t 的符号；由 A^{*}=\|A\|A^{-1} 判伴随是否仍属同一阵类（含 \|A\|=-1 时 A* 不再是置换阵）归该法的伴随公式档，本法不重复认领
- 矩阵已按块给出且块结构清晰（含零块、单位块、可逆子块）
- 块内子阵的行列式、逆或秩可由题给条件求出
- 结论为分块阵的伴随、逆、行列式、秩，或子块满足的性质
- 按路线分档：走消元与舒尔补者须存在可作主元的方阵子块且其行列式非零（题给单位块 E 天然满足）；只比较或数分块阵的秩者不要求存在可逆主元块，倍加与对换型块变换自身即可逆（ch8-C-mc-04 的三个分块阵皆以 E 块为主元做倍加消元）
- 所用块初等变换阵行列式为一时不改变原行列式数值；用块对换（\|=(-1)^{mn}）或块内数乘（\|按该块阶数取幂）使变换阵行列式非一时，必须把该因子补乘回去再取结果
- 与「矩阵秩的定秩与降秩关系通法」的分工：本法承担分块结构的处理（选主元块、块行块列消元、化块三角后数对角块秩之和）；一旦动作落在与分块无关的秩不等式链（r(AB)≤min{r(A),r(B)}、AB=O ⇒ r(A)+r(B)≤n、r(A+B)≤r(A)+r(B)、r(A*) 按档反推）上，该步归该法，两法对同一题各管一半而非重复认领
- 题给条件明确是转置与阵本身的关系（正交、对称、反对称）或其分块版本
- 待证结论是某行列式为零、某子块仍满足同一关系
- 所用阵为实矩阵（复数情形需改用共轭转置）
- 分块正交题须能补出"耦合块归零"的一步才入本法：由 (1,1) 块 A^TA=E_m 知 A 可逆、由 (1,2) 块 A^TC=O 得 C=O，(2,2) 块的和式 C^TC+B^TB=E_n 才收成 B^TB=E_n；或改用 PP^T=E 直接读 (2,2) 块 BB^T=E_n 再转成 B^TB=E_n。只乘开 P^TP 就把 (2,2) 块直读成 B^TB=E_n 的写法不满足本法前提
- 与「矩阵秩的定秩与降秩关系通法」「分块初等变换降阶通法」的分工：反对称条件用于算 X^TAX 并推 (A±E)X=0 只有零解、从而断 A±E 可逆，这一段归本法（第6步）；由此继续比较分块阵的秩、作块消元与秩不等式链归那两法。本法的模板级结论仍限"某行列式为零"与"某子块仍满足同一转置关系"，秩的大小排序本身不归本法
- 题目为若干命题判真伪或选择正确组合，条件只给抽象矩阵关系
- 本法认领"若干条命题组合判真伪并需配低阶反例"的选择题：正推部分（由 ABC=E 取行列式定可逆再搬序、由 (AB)²=E 推 A、B 可逆得 (BA)²=E）复用相应主干的结论，反例部分（幂零、秩一、对合、零块拼法四类 2 阶阵）为本法独有动作；单条公式或单个阵类的真伪（如置换阵的 A^{*} 是否仍为置换阵）由 28-I 的伴随公式档与 22-I 的初等阵分解给出结论后，本法只负责为"必有"与"存在"两种量词各配一次检验，不重复推一遍公式
- 矩阵可写成列向量与行向量之积，或行向量组（列向量组）彼此成比例
- 内积 (beta)^T(alpha) 可先算出且为一个数（可含参数）
- 待求式为 A 的高次幂、A 与 E 之和的幂，或含 A 的幂与向量之积的方程
- 矩阵以具体数字给出且阶数不高，直接相乘代价可控
- 低次幂之间确存在数量系数的线性关系（含幂零、对合、数量乘 E 三种特例）
- 题目要求 A^n 的表达式或某个具体高次幂的值
- 矩阵可拆成单位阵（或数量乘单位阵）加一个严格三角形／幂零块
- 幂零阶可由直接相乘确定（不超过矩阵阶数）
- 待求式为 (E+N) 的正整数幂或它的逆矩阵
- 题面显式给出相似关系与可逆矩阵 P（或说明 P 可逆但未给具体值）
- 非零元集中在副对角块位置，可按块划分且块阶数明确
- 副对角块之积为秩一阵或数量阵，能继续降幂
- 题目要求 A^n 的表达式（按 n 的奇偶分档）
- 已验得 A 的某次幂可由更低的两次幂与 E 线性表出
- 递推系数为常数、与 n 无关，初值（A、A^2）可直接算出
- 题目要求证明幂的递推关系并计算一个很大的幂次
- 题面显式给出相似关系 A=P^{-1}BP（或 B=P^{-1}AP）且 P 只需可逆、不必给出元素，一侧具对角、置换、分块或低阶周期等易算幂的结构，待求式只含这两阵的幂与其数乘、加法；易算一侧的幂化成数量阵时共轭退回同一数量阵（P 的具体值无需求出），另一阵自身的幂留在原侧直接实算，不得搬进 P^{-1}(…)P
- 矩阵列向量组的秩明显低于列数（存在大量可表示的列），具体数值给出
- 题目要求分解成「极大无关列阵乘系数阵」，或求高次幂
- 降成的低阶阵之积的幂可闭合（数量关系、幂零、递推）
- 数列（向量组）的线性递推关系，要求通项公式或极限
- 递推矩阵可对角化（特征值互异或重根几何重数达标）
- 结论为 Aⁿ、通项或极限值

**失效场景**（61 条）

- 由 A(A-E)=O 断言 A=O 或 A=E 是错的，矩阵环有零因子，只能通过补 E 项因式分解
- 把 (A+B)^{-1} 写成 A^{-1}+B^{-1}；必须先把和化成乘积再取逆
- 移项时把 E 当普通数量随意约去，未先证明相应因子可逆
- 待定形反解时把内积当矩阵处理，使含参项无法合并同类
- A 奇异时 A* 仍存在但 \|A\|A^{-1} 无意义，涉及除法与逆的公式全部失效
- 把 (kA)* 写成 kA* 或把 \|A*\| 写成 \|A\|^n，是与阶数相关的系统性错误
- n=2 时 (A*)*=\|A\|^{n-2}A=A 退化为特例，不能按 n≥3 的写法留空
- 把伴随矩阵与代数余子式矩阵的顺序（转置关系）写反
- k=0 时不能除以 k，此时常向量落在 A 的零空间，只能给出 A^{-1} 不存在的结论
- 行和与列和不可混用：行和对应右乘全 1 列，列和对应左乘全 1 行
- 非方阵没有逆时该传递链断开，只能改走广义逆或方程组解的结构
- 矩阵不可交换，把 X=A^{-1}CB^{-1} 写成 X=C A^{-1} B^{-1} 之类换序即为错解
- 系数不可逆时不能乘逆，必须退回设元素解方程组（此时解可能不唯一）
- X 出现在两侧又无公因子可提时，先按可逆因子移项，不能两边"约掉" X
- 方程本身含 X 的幂（如 X^{2}+X=A）或 X 与 X^{T} 混排在同一侧时，乘逆法只给出必要条件，须设元素或补幂关系闭合；结论只是要求已解出的 X 的幂则不受此限——X 呈 (系数)^{-1}B(系数) 的相似形时 X^{m}=(系数)^{-1}B^{m}(系数) 由中间因子相消直接得，降次动作归「矩阵幂降次闭合通法」
- 左乘按列、右乘按行的习惯式误读会把整个变换方向弄反
- 三个以上不同初等矩阵相乘一般不再是初等矩阵，不能反称"某个初等矩阵"
- 把初等变换与初等矩阵混为一谈：等价阵之间存在可逆阵 P、Q 使 PAQ=B，但单侧乘只能管一侧变换
- 倍乘阵作用于行列式时漏乘该对角元 k 是错的；行侧对换与列侧对换各自贡献一个 −1，必须分别按行侧次数与列侧次数取奇偶后再相乘（\|PAQ\|=\|P\|\|A\|\|Q\|），把两侧合并成一次计数会把 \|B\|=\|A\| 误判成 -\|A\|
- 所有子块都不可逆时无法构造主元块，本法失效
- 子块不是方阵时不存在逆块，不能做此消元
- 所乘变换矩阵的行列式不是单位值却未补乘该因子，行列式结果算错
- 行列式不匹配（子块阶数不同）时不能按分块公式拆分
- 块不方或不满足可乘维数时不能按块求逆或取行列式
- 副对角分块直接写成各子块行列式之积而漏掉 (-1)^{mn}
- 把数乘 k 分配到各块时未按该块阶数取幂，导致 \|kC\| 与逐块结果不符
- 块初等变换只要求变换阵本身可逆：倍加型 [[E,M],[O,E]]（或 [[E,O],[M,E]]）的系数块 M 可为任意矩阵（含未知阵、不可逆阵），其行列式恒为 1，左右乘既不改变秩也不改变行列式；只有"用行列式为零的块乘某一行（列）块"或"用未知块作对角缩放"才真正改变秩，不能用来定秩
- 由 A^TA=E 只能说明列向量组单位正交，不能对非方阵随意写 AA^T=E
- 分块转置时忘记交换块的位置，导致块乘法对不上号
- 把 \|A^T\|=\|A\| 与 A^T=A 混用，对称条件未证就直接替换
- 奇数阶反对称阵行列式必为零（\|A\|=\|A^T\|=\|-A\|=(-1)^n\|A\| 且 n 奇），偶数阶可正可零不能一概判；同一处负号用在正交阵的 \|A-E\| 型论证时要两个条件同时成立——阶数为奇数供 (-1)^n=-1，\|A\|=1 使系数为 1；少任一个只剩 (1±\|A\|)·\|A-E\|=0 这类恒等式，不得据此断行列式为零或断 A-E 不可逆
- 只用一个特殊例子确认命题为真（举例只能否证，不能证明一般性断言）
- 在不可交换处搬动因子顺序，或在未证可逆时约去因子
- "不可逆"只等价于 \|A\|=0，秩可为 n−1 也可为更低（此时 A^{*}=O），判"存在"与"必有"时两档要分开；第3步的低阶反例只能否证全称断言，不能确认它——②这类"必不可逆"可一对反例推翻，③这类"必有"必须回到 \|AB\|=\|A\|\|B\| 作正推，不得以特殊例子代替证明
- 秩大于一时中间内积不是数而是矩阵，不能提到前面整体降幂，须改按相似对角化或递推处理
- 把 (beta)^T(alpha) 与 (alpha)^T(beta) 混用或写成矩阵形式会使乘法不闭合，二者均为数但顺序须与内积定义一致
- 展开 (kE+A)^n 时漏掉 n=1 档的 E 项，或把 A^m 仍留在幂次上不降到底
- 内积为零时 A^2=O 属幂零形，(tr A)^{n-1} 在 n=1 处给出 0^0，须单独按幂零截断处理
- A^2、A^3 与 A、E 都线性无关时无法用两步降幂闭合；此时若列向量组的秩低于列数，先改走列分块分解降幂分支，再考虑相似对角化或 Cayley-Hamilton 路线
- 含参数的矩阵未先定参数就找规律，规律会随参数分档改变
- 把只在前几阶成立的"规律"外推而未回代校验，偶数档与奇数档混写成同一式
- N 不幂零（主对角线有非零元且不可分离）时二项式展开不截断，须改走相似对角化
- 把 A 本身当幂零块而忘记先减去对角部分，导致展开式多出无穷项
- N 与 E 之外的部分不满足所需幂零阶，仍按低阶截断会丢非零项
- P 不可逆或未给时不能建立幂的搬移，须先证可逆
- 关系式两侧写反（把 A=P^{-1}BP 当成 A=PBP^{-1}）会使共轭方向颠倒、结果不符
- 待求式含 A 与 B 的乘积但两者不在同一 P 下相似，不能逐项搬移
- 把 P^{-1}B^nP 误写成 P^{-1}B^n 或 B^nP，丢掉一侧的搬运矩阵
- 块内元素不满足列乘行结构时平方后仍为稠密块，降幂链断开
- 行列分块尺寸不匹配（块不能相乘）时整个分块乘法不成立
- 关系式右端含与 n 有关的系数时不能按常系数递推闭合
- 只验 n=3 一档就断言全体成立，缺归纳步骤
- 递推闭合要按右端形状选档：右端为与 n 无关的常矩阵加项时奇偶两档各成等差（偶档自 A^0=E 起算 A^{2k}=E+kC、奇档自 A^1=A 起算 A^{2k+1}=A+kC），右端等比时化成等比，齐次关系才按特征根写通项；把偶次幂的块对角形式直接当成 A^n 的一般式、把该走等差档的题硬套特征根、或特征根为重根与共轭复根时仍按两相异实根写通项，都属闭合方式选错
- 极大无关列阵不列满秩：分解虽在，幂的转移失效
- 把夹心幂写成两因子各自求幂再相乘：矩阵不可交换，只有夹心式成立
- 系数阵的行序与极大无关列的列序错位，乘回去不等于原矩阵
- 低阶阵的幂结构认错：幂零阶数多截或少截、周期档漏档
- 递推矩阵不可对角化时 PΛⁿP⁻¹ 不成立，须改若当形或递推法
- 把 Aⁿ 写成 PⁿΛⁿ(P⁻¹)ⁿ 或丢掉一侧的搬运矩阵
- 极限只看最大特征值的绝对值，负值档的符号摆动要单独核
- 初值向量代入 P⁻¹ 的计算错位导致通项系数错
