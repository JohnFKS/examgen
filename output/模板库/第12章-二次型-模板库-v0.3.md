## 实对称正交对角化流程

### 标准解题步骤

1. 算特征多项式读出特征值及重数
2. 逐个特征值解 (λE−A)x=0 得特征向量
3. 不同特征值之间自动正交，不重复处理
4. 同一重根内的特征向量做施密特正交化（内积除以平方长度再乘投影）
5. 全体单位化，按对角元顺序拼成正交矩阵 Q
6. 写 QᵀAQ=Q⁻¹AQ=Λ，并用 Q 的列两两内积为零验算一遍

### 失效边界

**适用前提**（6 条）

- 实对称矩阵要求正交矩阵 Q 使 QᵀAQ=Λ（或 Q⁻¹AQ=Λ）
- 特征多项式与特征方程组可手算，重根内可施密特
- 结论含 Q 与 Λ
- 要求用正交变换化二次型为标准形，或需要保持长度（几何形状）的变换
- 矩阵为实对称（二次型恒如此）
- 特征多项式可解

**失效场景**（8 条）

- 重根内不做施密特而直接拼 Q：列不正交，Q 不是正交矩阵
- 不同特征值的向量不必正交化（已自动正交），重复改造反而引入计算错误
- 单位化漏除长度，QᵀQ 不是单位阵
- 把 Q⁻¹AQ 与 QᵀAQ 混写而未验证 Q 正交
- 重根内不做施密特：Q 不正交，xᵀx=yᵀy 不再成立
- 把非正交的可逆变换下的标准形系数当特征值
- Q 的列序与标准形系数顺序错位
- 对非对称矩阵谈正交对角化（二次型的矩阵必对称，无需担心，但一般矩阵不可）

## 特征信息反求矩阵

> 编号 **T-LA-68-I** ｜ 版本 **v0.3** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 矩阵由它的特征值与完备特征向量组唯一决定：A=PΛP⁻¹，其中 P 的列是特征向量、Λ 的对角元是相应特征值。题面给出部分特征向量时，缺口用结构信息补齐——实对称用「不同特征值的特征向量正交」解出正交补，一般矩阵用秩或重数补。最后 A=PΛP⁻¹（或 A=PΛPᵀ）一次性算出。 |

| 学科 / 章节 | 线性代数 · 相似矩阵（特征值与特征向量）、二次型 |
| 表面题型 | 由特征信息反求矩阵；由标准形与变换信息反求参数与矩阵 |

| 覆盖题量 | 10 题（分支 2 个） |

### 标准解题步骤

1. 清点已知的特征值与特征向量，数出缺口（还差几个无关特征向量）
2. 实对称时用正交条件（与已知特征向量分别正交）解方程组补出缺口向量
3. 一般矩阵用重数与秩档（r(λE−A)=n−k）或解结构补齐
4. 把特征向量按列拼成 P，对角元按对应顺序拼成 Λ，确认 P 可逆
5. 计算 A=PΛP⁻¹（实对称已正交化时 A=QΛQᵀ），需要伴随或逆时一并换算
6. 代回验算：A 乘每个特征向量确得特征值倍数

### 失效边界

**适用前提**（6 条）

- 题面给出矩阵的部分特征值与特征向量（或解结构、秩条件），反求矩阵
- 特征向量组可补齐到 n 个无关
- 结论为 A 本身或其伴随、逆的某种组合
- 题面给出正交变换下的标准形（全部或部分系数），反求参数、正交矩阵或矩阵本体
- 矩阵实对称，附加条件（迹、行列式、特征向量、伴随关系）足以定参
- 结论为参数、Q、A 或其伴随/逆的组合

**失效场景**（8 条）

- 特征向量未补齐 n 个就写 A=PΛP⁻¹：P 不可逆
- 实对称的正交补漏解（与每一个已知特征向量都要正交）
- P 的列与 Λ 的对角元对应错位
- 由「特征值互异」误推非对称矩阵的向量自动正交
- 可逆（非正交）变换下的标准形系数不是特征值，不能照搬「系数=特征值」
- 标准形系数的顺序与 Q 的列顺序必须对应，反求时错位会拼错 Q
- 重根的特征向量缺口不用正交条件补齐会导致 P 不可逆
- 参数候选值须回验（如 \|A\|=λ₁λ₂λ₃ 的档位核对），否则接受伪解

### 标准解题步骤

1. 分别求 A 与 B 的特征值，确认一致（或重排后一致）
2. 分别解特征向量，拼出 P₁ 与 P₂，使两者对角化到同一个 Λ（对角元顺序对应）
3. 由 P₁⁻¹AP₁=P₂⁻¹BP₂ 移项得 B=(P₁P₂⁻¹)⁻¹A(P₁P₂⁻¹)，令 P=P₁P₂⁻¹
4. 两侧都是正交对角化时 P=Q₁Q₂ᵀ（利用正交阵的逆即转置），并验 P 仍正交
5. 需要 Aᵀ 或 AB=P² 类目标时，把关系式按目标改拼（如 P=AQ 再验 (Qᵀ)²=E）
6. 代回验算 P⁻¹AP 等于目标矩阵

### 失效边界

**适用前提**（9 条）

- 题面要求过渡矩阵 P 使 P⁻¹AP 等于一个给定的具体矩阵 B（或 Aᵀ）
- A 与 B 有相同特征值且都可对角化（或同为实对称）
- 各自的特征向量可求
- 要求用可逆（非正交）线性变换化二次型为标准形，或求合同变换矩阵
- 含交叉项或无平方项的二次型均可处理
- 结论只涉及标准形、秩、惯性指数或可逆变换矩阵
- 题面给出正交变换下的标准形（全部或部分系数），反求参数、正交矩阵或矩阵本体
- 矩阵实对称，附加条件（迹、行列式、特征向量、伴随关系）足以定参
- 结论为参数、Q、A 或其伴随/逆的组合

**失效场景**（12 条）

- 两段对角化的对角元顺序不一致时拼接错位，必须重排对齐
- P=P₁P₂⁻¹ 的方向写反成 P₂P₁⁻¹
- 正交版用逆而非转置（Q₂⁻¹=Q₂ᵀ 是正交性给的，须先验证 Q₂ 正交）
- A 或 B 不可对角化时此桥不成立
- 线性变换必须可逆：把 f=(x₁−x₂)²+(x₂−x₃)²+(x₃−x₁)² 直接令三个差为新变量是不可逆的（秩降档）
- 配方漏掉某变量的交叉项或把交叉项系数错分（对称化时各分一半）
- 把配方法的标准形系数当成特征值：只有正交变换的标准形系数才是特征值
- 换元后自由变量的取值档漏补（新变量个数必须等于变量个数）
- 可逆（非正交）变换下的标准形系数不是特征值，不能照搬「系数=特征值」
- 标准形系数的顺序与 Q 的列顺序必须对应，反求时错位会拼错 Q
- 重根的特征向量缺口不用正交条件补齐会导致 P 不可逆
- 参数候选值须回验（如 \|A\|=λ₁λ₂λ₃ 的档位核对），否则接受伪解

## 无关组坐标化读相似

### 标准解题步骤

1. 把题给的一组作用等式 Aαj=（α 组的线性组合）按列拼成矩阵等式 A C=C B
2. 由 α 组线性无关（C 可逆）得 C⁻¹AC=B，判定 A 与 B 相似
3. 在具体矩阵 B 上算特征值（或秩、行列式），全部属于 A
4. 需要 A 的特征向量时先解 B 的特征向量 η，再搬回 Cη
5. 需要 A 本身时 A=C B C⁻¹ 直接乘出
6. 结论落回题面（特征值、tr、\|·\|、P=C P₁ 等），代一列验算

### 失效边界

**适用前提**（6 条）

- 题面给出一组无关向量及 A 在其上的线性作用（组合系数具体）
- 结论为 A 的特征值、相似对象、秩、或 A 本身
- 坐标矩阵 B 为数值矩阵
- 判定二次型或实对称矩阵正定，或由正定反求参数范围
- 题面比较各正定刻画的强弱（必要/充分/充要）
- 矩阵可对称化且阶数不高或结构清晰

**失效场景**（8 条）

- α 组线性相关时 C 不可逆，坐标化失效（只有相似的方向性结论可用）
- 把 B 的特征向量直接当 A 的特征向量（须先经 C 搬回）
- 坐标矩阵的列序与作用等式的排列错位
- 由相似只搬「相似不变量」，不相似不变量（如特征向量本身）不能直接搬
- 顺序主子式全正是数值矩阵正定的充要条件，但「对角元为正」只是必要条件
- A=CᵀC 中 C 不可逆时得不到正定（须可逆）
- 负惯性指数为零不等于正定（还须 p=n）
- 正定要求对称：非对称矩阵先看能否对称化，否则不谈正定

### 标准解题步骤

1. 分别算各候选矩阵的特征值（或至少算出正、负、零特征值的个数）
2. 相似层：特征值全体（含重数）与目标一致才可能相似
3. 合同层：正惯性指数与负惯性指数分别与目标一致才合同
4. 非对称的候选直接排除合同可能（除非题目限定在对称类内）
5. 两层都过的候选即「既相似又合同」，其余按层排除
6. 用迹或行列式的差快速否证候选（数值不等必不相似）

### 失效边界

**适用前提**（6 条）

- 题面在若干候选中判「与目标矩阵既相似又合同」（或只判其一）
- 目标与候选的特征值（或惯性指数）可算
- 结论为选哪一项或判两层关系
- 题面判两矩阵是否合同、或判「既相似又合同/既不相似也不合同」
- 秩、惯性指数或特征值可读
- 结论为充要条件的选项判定

**失效场景**（8 条）

- 相似与合同的判据不同：相似看特征值全体，合同只看正负个数，不能互相替代
- 对非对称矩阵使用惯性指数（合同以对称矩阵为对象）
- 由「特征值个数相同」就判相似：重数也须一致
- 用迹快速否证时只排了相似层，合同层要另判
- 把「特征值相同」当合同的判据（那是相似的）：合同只看惯性指数
- 合同不保持特征向量与行列式的具体值（只保持 \|A\| 的符号档）
- 由 CᵀAC=B 且 A 对称推出 B 对称是对的，但反向「B 对称则任取 C 都合同」不成立
- 可逆 C 的存在性未验就用惯性判据下「合同」结论

## 低秩矩阵特征值与平移

> 编号 **T-LA-80-I** ｜ 版本 **v0.2** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 适用范围 | 秩一形、数量阵加秩一、正交秩一块之和的特征值读取、可对角化条件与特征向量构造 |

| 覆盖题量 | 4 题（分支 1 个） |

### 标准解题步骤

1. 把矩阵认成秩一形（列乘行）或数量阵加秩一的和，指出内积因子 βᵀα
2. 由 A²=(βᵀα)A 或定义法读出特征值：βᵀα 与零（零为 n−1 重）
3. 数量平移：A=kE+B 时特征值为 k 加 B 的各特征值，特征向量不变
4. 两个正交块的对称和：直接作用在 α+β、α−β 上读出对称特征值，秩的账给出剩余零特征值
5. 判可对角化：非零特征值是单根（βᵀα≠0）才可对角化；βᵀα=0 时 n 重零根只有 n−1 个无关向量
6. 构造特征向量：非零档取 α（或 α±β），零档取 βᵀx=0 的基础解系，拼 P 写 Λ

### 失效边界

**适用前提**（6 条）

- 矩阵为秩一形 αβᵀ、数量阵加秩一、或正交秩一块之和
- 结论为特征值、可对角化条件、或 P⁻¹AP=Λ
- 内积与秩可直接计算
- 要求用可逆（非正交）线性变换化二次型为标准形，或求合同变换矩阵
- 含交叉项或无平方项的二次型均可处理
- 结论只涉及标准形、秩、惯性指数或可逆变换矩阵

**失效场景**（8 条）

- βᵀα=0 时秩一矩阵不可对角化（n 重零根只有 n−1 个无关向量），不能写 P⁻¹AP=Λ
- 把 βᵀα 与 αᵀβ 的书写顺序搞混（两者数值相等但作用方向不同）
- 数量平移时特征向量不变，但不得把平移后的值当原矩阵的特征值
- 秩的账漏算：r(αβᵀ+βαᵀ)≤2 用来夹出零特征值
- 线性变换必须可逆：把 f=(x₁−x₂)²+(x₂−x₃)²+(x₃−x₁)² 直接令三个差为新变量是不可逆的（秩降档）
- 配方漏掉某变量的交叉项或把交叉项系数错分（对称化时各分一半）
- 把配方法的标准形系数当成特征值：只有正交变换的标准形系数才是特征值
- 换元后自由变量的取值档漏补（新变量个数必须等于变量个数）

### 标准解题步骤

1. 写出二次型的矩阵（对称化：交叉项系数各分一半），确认变量个数
2. 含平方项时选一个系数非零的平方项连同其全部交叉项配成完全平方；无平方项时先作两变量和差换元制造平方项

### 标准解题步骤

1. 把正交变换下的标准形系数读成 A 的全部特征值
2. 用迹、行列式或「已知某特征向量」的等式联立定出矩阵中的参数
3. 参数代回后解各特征值的特征方程组，实对称用正交条件补齐未知特征向量
4. 需要含伴随、逆的对象时按特征值换算（\|A\|/λ 一类）后再反求
5. 拼 Q 与 Λ，计算 A=QΛQᵀ
6. 代回验算：每个特征向量乘 A 得特征值倍数、\|A\| 与迹吻合

**失效场景**（4 条）

### 标准解题步骤

### 标准解题步骤

1. 验证给出的特征向量组两两正交（内积为零）且个数等于阶数
2. 单位化拼成正交矩阵 Q，写 A=QΛQᵀ（Λ 对角元为相应特征值）
3. 由 A=QΛQᵀ 直接计算 Aᵀ=A，断定对称
4. 可逆、正交、正定等其余性质须看特征值是否全非零/全为一/全为正，信息不足时不下结论
5. 反例核对：特征向量不正交的实矩阵一般不对称

### 失效边界

**适用前提**（3 条）

- 题面给出实矩阵的若干（两两正交的）特征向量，判矩阵的性质
- 结论为对称、可逆、正交、正定中的哪一项必然成立
- 特征值未知或不全已知

**失效场景**（4 条）

- 由特征向量正交只能断定对称，不能断定正交矩阵或正定（缺特征值信息）
- 特征向量个数不足 n 个时拼不成正交阵，结论 weaken 到部分子空间
- 把「特征向量两两正交」与「矩阵本身正交（AᵀA=E）」混淆
- 实对称的判定不能只验 Aᵀ=A 的个别元素
