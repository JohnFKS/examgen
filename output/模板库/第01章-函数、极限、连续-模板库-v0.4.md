## 分式线性递推数列的不动点通项法

> 编号 **T-HS-01-S** ｜ 版本 **v0.2** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 以两个不动点作交叉比，分式线性递推被共轭化为等比映射，通项可显式求出，极限必落在不动点上 |
| 适用范围 | 一阶递推且右端可整理为前一项的一次分式（分子分母关于前项均为一次），特征方程有两个不同实不动点的数列极限问题 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | 分式线性递推数列求极限；递推数列极限存在性证明；振荡型递推数列极限；线性递推数列求极限 |
| 对应考点 | 数列极限；递推数列；等比数列通项公式；单调有界准则；（二）五种计算手法；（八）压缩映像（了解即可） |
| 覆盖题量 | 1 题（分支 4 个） |

### 标准解题步骤

1. 把递推式整理为前一项的一次分式形式，确认分子与分母对该项的次数都为一
2. 解不动点（特征）方程，即令该项等于递推式两端所得的方程，求出两个不相等的实不动点
3. 分别计算下一项与两个不动点之差，各自通分并把分子按特征方程化简，检验每个分子能写成常数乘以「当前项减同一不动点」
4. 把两个差式相除消去公共分母，构造交叉比序列并确认它满足等比递推（公比是与项数无关的常数）
5. 由首项算出交叉比首项，写出交叉比的等比通项，再反解出原数列的显式通项
6. 比较公比模与 1 的大小定出交叉比的趋向，据此给出原数列极限，并检验极限值确为两个不动点之一
7. 把所得极限回代递推式两端验证自洽，确认舍去了不可达的另一个不动点

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 交叉比等比化分支 | 递推式为一次分式且特征方程有两个不同实根 | 分别写出下一项与两个不动点之差并通分 → 用特征方程把每个差式的分子归并为常数乘以当前项与同一不动点之差 → 两式相除以消去随项变化的分母 → 令交叉比为新数列，确认其公比为常数并写出等比通项 | 两个不动点必须不相等，且递推过程中各项不能落在使分母为零或使交叉比分母为零的取值上 |
| 公比模定极限分支 | 等比公比的模小于 1 或大于 1，数列为振荡型、不需要单调性论证 | 判定公比模与 1 的大小关系 → 模小于 1 时令交叉比趋于零，极限取出现在分子端的不动点 → 模大于 1 时令交叉比发散，极限取出现在分母端的不动点 → 公比为负时说明数列振荡但仍收敛，据此免去单调性证明 | 公比模恰等于 1 时本分支不定案，需改用周期讨论或单调有界准则 |
| 通项回代验证分支 | 题目要求先证明极限存在再求值，或首项取值影响可达的不动点 | 由交叉比反解出原数列的显式通项 → 把通项整体代入极限符号，按等比项的趋向取极限 → 检验所得极限满足不动点方程 → 对照首项所在区间舍去不可达的根，只保留可达不动点 | 初项恰使某不动点与该项重合时交叉比退化，须单独处理该情形 |
| 差分等比化闭式通项分支 | 递推式对相邻项之差是线性齐次的，差分之比可整体提出为与下标无关的常数 | 写出相邻两项差满足的一阶关系，验证差分之比为与下标无关的常数 → 把差分取为辅助数列，求出其首项与公比并写出通项公式 → 判定公比绝对值是否严格小于1，据此决定差分部分和是否收敛 → 把原数列表为首项加差分的前若干项之和，用等比求和公式化为闭式通项 → 对闭式通项取极限得所求值，并检验该值与递推不动点一致 | 前提：递推对差分为线性齐次且系数为常数，首项与差分初值由题设给定；坑点：公比绝对值不小于1时部分和发散使通项法失效，未证收敛性就直接对递推式两端取极限 |

### 失效边界

- **适用前提**：递推式右端是前一项的一次分式（分子分母次数均为一）；特征方程有两个不相等的实根，且常数项使差式可整体提出公因子；首项避开分式奇异点，且后续各项不落入使交叉比无定义的取值；递推对相邻项差是线性齐次的且系数为常数，差分之比可整体提出；公比绝对值小于 1 使差分部分和收敛；首项与差分初值由题设给定，闭式可定
- **失效场景**：递推式含非线性项（根式、指数、反三角等复合结构）时不能被共轭化为等比，本法失效，须改用单调有界准则；特征方程出现重根或复根时，两个不动点的交叉比构造不成立；公比模恰等于 1 时交叉比既不趋零也不发散，数列可能周期或发散，本法给不出极限；递推涉及前若干项之和或高阶递推时不属于一阶分式线性，不能直接套用；只要求证极限存在而不需求通项时，本法计算量远大于单调有界准则，考场上不经济；公比绝对值不小于 1 时部分和发散，通项法失效；差分之比不是常数时不能构造等比数列；未证收敛性就直接对递推式两边取极限定值

### 标准解题步骤

1. 定趋近点：趋近点不是零有限点时先作平移或倒代换，把所有展开统一到零点邻域再处理
2. 列展开式：写出式中出现的每类基本初等函数在该点的幂展开，分数幂与根式改用二项式展开形式
3. 预估所需阶数：以分母（或比较对象）的最低次幂为展开阶数，复合结构逐层保持同一精度
4. 代入并合并：按幂次升序合并同类项，把不低于所需阶的所有项统一归入高阶余项
5. 检验相消：核对首个非零系数是否已出现，分子分母同时归零时必须升一阶重算而不是直接判为零
6. 读出结论：取首个非零幂次的系数之比作为极限值，数列题最后把连续变量代回离散变量

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 非零趋近点平移分支 | 趋近点为非零有限点，常见幂展开表无法直接套用 | 令新变量等于原变量减去趋近点 → 把每个因子改写成一带无穷小的形式后展开 → 按新变量的幂整理，最后还原变量关系 | 平移后各因子须在该点邻域内可展；含分段或绝对值表达式时要分左右两侧分别平移 |
| 分数幂与根式差分支 | 分子或分母为不同次根式之差，有理化或换元计算量偏大 | 把根式统一写成分数幂形式 → 用二项式展开保留到首个非零阶 → 分母同法展开后直接比较系数 | 两侧一阶项不同时保留一阶即可；两侧一阶项相同则必须升阶，否则主项被消掉 |
| 相消升阶定阶分支 | 展开合并后最低次幂系数恰好抵消，出现全零分子或全零分母 | 提高展开阶数直到出现非零系数 → 按最低次幂原则重新配平分子与分母的阶 → 用系数比确认非零极限并复核余项所在阶 | 所需阶数由分母最低次幂决定；展开不足会把非零有限极限误判为零 |
| 复合与积分上限展开分支 | 式中含函数套函数，或分子为变上限积分、被积函数本身需先展开 | 先展开最内层再逐层外推并保持精度一致 → 被积函数展开后逐项积分，按上限的幂次整体抬阶 → 积分结果与外部因子再按最低次幂合并 | 逐项积分要求展开在该区间内一致可控；上限趋于零的幂次会改变结果的整体阶 |
| 数列极限连续化分支 | 离散变量趋于无穷且通项只依赖该变量的倒数或同一函数结构 | 用归结原则把离散变量替换为连续无穷小 → 对连续形式做幂展开求值 → 把结果代回离散变量表述 | 只适用于通项可统一写成某函数在离散点取值的情形；和式与乘积式数列应改用定积分定义或单调有界准则 |
| 无穷小阶比较分支 | 多个无穷小比较阶的高低，或要求挑出最高阶项 | 对各项分别展开并取最低次幂项定阶 → 用幂次大小直接排序，避免逐本作差 → 积分型无穷小先展开被积函数再按上限幂次定阶 | 定阶只看首个非零幂次；加减结构中不得预先使用等价代换，否则可能把决定阶的主项消掉 |
| 同底指数差先提因子再展差式分支 | 分子为同底（或可化为同底）指数函数之差，分母可等价归为自变量整数幂 | 提出分子中一个指数因子，把两指数之差写成该因子乘以幂减一结构 → 确认提出因子的极限为非零常数，先算出并剥离 → 用幂减一等价于指数上的代数差，把超越差转为代数差 → 把指数上的差式展开到与分母同阶，舍去更高阶余项 → 比较同阶项系数得极限值，并复核展开阶数覆盖分母之阶 | 提出因子的极限必须是非零有限常数否则不能分离；指数差主项相消时须继续升阶展开，且不得对加减结构整体作等价替换 |
| 比阶关系翻译为幂次不等式组分支 | 题目给出若干无穷小之间高阶、低阶、同阶关系并要求定参数，参数常取正整数 | 确认全部比较对象在同一过程中确为无穷小，否则阶关系无意义 → 对差型因子展开取首个非零项定其幂次，禁止用一阶等价直接相减 → 用乘积的总幂次等于各因子主项幂次之和写出各对象的幂次 → 把高阶与低阶关系分别译为幂次严格大于与小于的不等式 → 与参数的离散约束取交，并检验端点处是否退化为同阶 | 各因子主项幂次须可由展开或等价形式唯一确定；对加减项分别取等价会使主项相消而阶数虚高，含参幂次非正时展开不成立，把同阶误当高阶会放宽不等式 |
| 乘开对齐比较系数定参分支 | 要求差式与指定幂次同阶或为该幂次的高阶，从而反解多个参数 | 把分式因子按等比级数乘开到指定阶，避免直接对分式作差 → 把指数型等其他因子展开到同一阶并带佩亚诺余项 → 两式相减并按自变量幂次合并同类项 → 令所有低于指定阶的系数为零，联立解出各参数 → 检验指定阶项系数不为零，确认是同阶而非更高阶并回代复核分母不变阶 | 各因子可展开到不低于比较所需阶、参数个数不超过可比系数个数、分式分母趋于非零常数；展开阶数不足定不全参数，把系数全为零的高阶情形误当同阶必错 |
| 倒代换定阶锁参分支 | 无穷远处含参极限要求存在且非零，需倒代换后两侧分别定阶 | 作倒数换元把无穷远处过程化为该点附近的未定式，统一比较基准 → 对分子的指数差与三角因子分别用等价无穷小换成幂次，定出分子阶 → 把分母提取公因式后展开，写出含参主项及其系数 → 取分子分母同阶并要求系数不为零，得到参数的约束条件 → 写出极限值表达式并与各选项逐条比对，检验所得为充要条件而非仅必要性 | 前提：分子分母均为无穷小且主项系数可显式定出，等价替换只作用于乘除因子；坑点：参数取某些值使分母主项系数为零时同阶比较失效，允许极限为零或无穷时不能只用同阶条件，把分母的两项分别替换导致错误相消 |
| 变限积分待定阶求导建方程分支 | 无穷小由变上限或复合上限积分给出，要求定出其阶或由阶反解参数 | 由已知比值极限为非零常数，写出被积函数的等价主项并定出其阶 → 确认积分下限为常数而上限趋于该点，断定变限积分为无穷小 → 设所求阶为待定指数，构造该积分与幂次之商的极限 → 对变限积分用复合求导法则求导，同时对幂次求导，写出两侧幂次对应关系 → 把被积函数等价主项代入导数式比较幂次，建立并求解阶方程 → 回代检验所得商极限存在且不为零 | 前提：被积函数连续且其阶可由已知极限唯一确定，下限固定而上限趋于该点；坑点：把求导降阶写成升阶、上下限同时变化却直接套上限求导公式、在加减结构中用等价替换改变阶 |
| 多对象化幂主项指数排序分支 | 要求把若干无穷小按阶的高低排序，对象含根式差、变限积分与三角指数组合 | 对每个量有理化或恒等变形，消除减法造成的低阶隐藏 → 把变形后的每个量用等价无穷小写成幂函数主项，记录其指数与系数 → 变限积分型先求出积分或对被积函数取主项，再把上限自身的阶乘入 → 比较各主项指数定先后，指数相同者再比较系数 → 作商取极限验证商为零或非零常数，确认排序与选项一致 | 前提：每个量在该过程中确为无穷小且有确定的最低次主项，所有比较在同一过程同一自变量体系内进行；坑点：减法主项相消却未展到次阶使阶被严重低估，含量或振荡项无确定阶，积分下限非零的变限积分被当作无穷小 |
| 幂指化指数展开定阶分支 | 被比较量含以自然常数为底的幂或幂指结构，需展开指数到覆盖分母的阶 | 改写比较问题为一个商式，明确要判断的是商的极限为零、有限非零还是无穷 → 统一幂指式为自然常数的幂，并提出极限非零的常数因子 → 展开指数部分到足以覆盖分母阶的项数，舍去高阶皮亚诺余项 → 用幂减一等价形式把自然常数的幂之差换成其指数上的差式 → 合并同类幂读取最低次项，据其幂次与分母幂次的关系给出高阶、同阶或低阶结论 → 检验是否出现主项相消，若相消则继续增加展开项数 | 前提：两式在同一过程中均为无穷小，涉及的函数在该点可展开到比较所需的阶；坑点：展开阶数不足导致最低次项被误判为高阶，对含参相减结构整体作等价替换，被比较式之一极限不为零时谈阶无意义 |
| 幂指差提因子剥层分支 | 变限积分与幂指差同现，求导消积分号后分子为同底指数函数之差 | 验证分子随上限趋于该点、分母亦趋于零，确认属零比零型未定式 → 对分母的指数差用等价无穷小替换为幂次，简化后续求导结果 → 对分子用积分上限函数求导法则消去积分号，写出被积函数在上限处的值 → 把幂指差提取公因子化为同底指数函数之差，再用等价替换降为对数差 → 剥开复合结构的每一层至最内层，检验每次替换均处于乘除位置 → 合并幂次并代入非零常数因子得出极限值 | 前提：被积函数连续使积分上限函数可导，分子分母在同一过程中同趋于零；坑点：求导后商式极限不存在时不能误判原极限不存在，对加减结构整体使用等价无穷小替换，分母导数在该过程中取零时继续使用洛必达法则 |
| 振荡因子拆主部余项分支 | 求导后商式含无极限的振荡因子，洛必达不能继续，须改以阶估计代替求导 | 先用等价替换把分母的指数差换成幂次，把过程统一到同一比较基准 → 对积分上限函数求导消去积分号，写出求导后的商式 → 检查求导后分子是否含无极限的振荡项，判定洛必达法则能否继续使用 → 把商式按主部与余项拆分，使余项写成有界因子乘趋于零的因子 → 对主部作倒数代换用基本极限求值，对余项用有界量乘无穷小断其趋于零 → 合并各部分结果并逐项验证每部分极限确实存在 | 前提：振荡因子在整个过程中有统一界，拆分后每一部分极限均存在；坑点：把无界的振荡因子当成有界量使用无穷小乘积结论，各部分极限不存在却断言整体极限不存在，对含振荡项的商式继续使用洛必达法则 |
| 按奇性来源逐项配对分支 | 求导后的和式含多处不同来源的奇性，需逐项与分母因子配对分别定阶 | 判断单侧过程中分子与分母的趋于情况，确认适用洛必达法则的类型 → 对积分上限函数求导，同时给分母求导得到相应因子 → 把求导后的和式按奇性来源拆成若干商式，使每处奇性单独与分母因子配对 → 比较各类无穷大与极点型无穷大的阶，识别主导项与被支配项 → 对主导项用三角恒等式或洛必达定值，对被支配项直接判定趋于零 → 把各分项结果相加，并按单侧方向检查绝对值展开与符号 | 前提：过程为单侧趋于奇点且被积函数的奇性在该区间上可积，拆分后每个分项极限均存在；坑点：分项极限不存在时不能对和式逐项取极限，忽略左右侧差异直接去掉绝对值，把趋于无穷的两式误判为零比零型 |
| 指定阶逼近反求系数分支 | 题给误差是高于指定幂次的无穷小这一逼近条件，式中含待定多项式或待定参数需要反解 | 把误差高于指定阶翻译成差式除以指定幂次极限为零的等式 → 把已知函数展开到不小于要求阶的带佩亚诺余项幂和 → 与待定多项式按幂次逐项对齐相减，合并出各次项系数 → 令每一个不超过要求阶的系数为零并联立求解参数 → 回代检验差式最低次项的幂次确实高于要求阶 | 被逼近函数在该点存在到要求阶的展开，待定幂次与展开幂次可一一对齐；展开阶数不足会遗漏低阶约束，函数不可展或含振荡余项时逐项比较失效 |
| 变限积分洛必达消积分号定主项分支 | 分子为变上限积分、分母在无穷端趋于无穷，要求由给定的极限值反解参数 | 验证分子随上限趋无穷、分母亦趋无穷，确认属可用洛必达的无穷比无穷型 → 用变限积分求导法则消去积分号，写出被积函数在上限处的表达式 → 提取同底异指幂差的公因子，化为幂减一结构 → 作倒数代换把无穷端化为内点，展开并保留到与分母同阶的主项 → 令所得含参极限等于给定值解出参数，排除使底数非正与主项相消的取值 | 非无穷比无穷型不得使用洛必达；求导后商式极限不存在不能反推原极限不存在；被积函数不连续时变限求导前提不成立，幂差两项分别取极限会造成无效相消 |
| 恒等式反解作商定阶分支 | 待比较的量由恒等式隐含给出，需先显式解出再作商定阶 | 由给定恒等式把待比较的量显式解出 → 确认两个量都趋于零并构造其商的极限 → 把对数内部配成一加小量的形式，用等价替换去掉对号 → 分子出现相消时用泰勒展开保留到首次非零的阶 → 作连续变量代换，必要时用洛必达收尾 → 按商的极限为零、非零常数或无穷判定高阶、同阶与等价 | 前提：两个量同号且趋于零，等价替换只作用于乘除位置；坑点：展开阶数不足会把高阶误判为同阶，量的符号不定时不能对其取对数 |
| 通分余项二阶展开分支 | 无穷减无穷先通分合并，分子恰为函数增量减去一阶线性主部的余项 | 识别发散项阶数相同，先通分合并成单一商式并确认属零比零型 → 把分子写成函数增量减去一阶线性主部的形式，展开到带佩亚诺余项的指定阶 → 分母中的差商用导数定义替换为非零的一阶导数因子 → 约去同阶无穷小，令余项系数按二阶导数取值算出极限 → 检验一阶导数非零以保证分母主项不消失，并核对展开阶数覆盖被约去的阶 | 前提：函数在该点有二阶导数且一阶导数不为零；坑点：一阶导数为零时分母阶数改变，未通分就分别对两项取极限出现无穷减无穷错误，展开阶数不足时误把高一阶余项当作高阶无穷小舍去 |

### 失效边界

- **适用前提**：趋近点为内点，或可经平移、倒代换化为内点，式中各因子在该点邻域存在幂展开；未定式仅由有限次加减乘除、复合与积分上限运算构成，不含无极限的振荡因子；所需精度可在有限阶内达到，佩亚诺余项对最终比值不产生影响；含参问题中参数不改变各项的阶归属，或可按参数区间分别定阶；各小题确为已知的几种未定式之一；涉及的函数在该极限过程中可展开或可用基本等价形式；振荡因子有统一界且与之相乘的因子确为无穷小；幂指型可先配成一加无穷小的无穷次幂，化为指数上的乘积后再展开定阶，仍属本法；有界振荡因子与无穷小相乘时可被吸收，不破坏展开定阶与系数比较；多种未定式混排的小题组可在同一套操作内逐题定阶；分子为同底指数之差且可整体提出一个指数因子；分母可用等价无穷小归为自变量的整数幂；各因子在同一极限过程中均为无穷小；每个因子的主项幂次可通过展开或等价形式确定；参数取正整数等离散范围便于对不等式取交；各因子在该点都可展开到不低于比较所需阶；分式的分母在该过程中趋于非零常数；参数个数不超过可比系数的个数；分子分母均为无穷小且主项系数可显式定出；等价替换只作用于乘除因子；按参数取值分情况讨论阶的变化；被积函数连续且其自身的阶可由已知极限唯一确定；积分下限为常数、上限趋于该点；求导后幂次可对齐比较；每个量在该过程中确为无穷小且有确定的最低次主项；所有比较在同一过程、同一自变量体系下进行；变形所用的等价关系处于乘除位置；两式在同一过程中均为无穷小；涉及的函数在该点可展开到比较所需的阶；指数部分展开后主项幂次可比；被积函数连续，积分上限函数可导；分子分母在同一过程中同趋于零；求导后所得商式极限存在或为无穷；振荡因子在整个过程中有统一界；拆分后每一部分极限均存在；主部与分母同阶可比；过程为单侧趋于奇点且被积函数的奇性在该区间上可积；拆分后每个分项极限均存在；分母导数在该单侧过程中不为零；被逼近函数在该点存在到要求阶的泰勒展开；待定项的幂次与展开的幂次可一一对齐；分母单调趋于无穷且其导数在邻域内不为零；求导后的商式极限存在或为无穷；被积函数连续，变限积分可导；两个量同号且趋于零；等价替换只作用于乘除位置；函数在该点有二阶导数且一阶导数不为零；两个发散部分通分后分子恰为高一阶的余项；展开只需到与分母同阶即可定值

## 单调有界归纳五段法求数列极限

> 编号 **T-HS-05-S** ｜ 版本 **v0.8** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 先由递推式两端取极限解出的候选值同时充当归纳的界与相邻项比较的分界，存在性于是被化为两个可用数学归纳法机械验证的不等式，单调有界准则随即保证收敛且极限只能是该候选值 |
| 适用范围 | 由首项（或首项所属范围）与单变量自治递推式确定的一元递推数列，要求证明极限存在并求极限值或只证存在；不适用于递推式显式含项数的情形 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | 证明递推数列极限存在并求值；单调有界准则大题；奇偶子列交替型递推数列；隐式递推数列的存在性；只证存在不求值的数列极限题；递推数列收敛性证明与求值；含参方程根的数列极限；比值型数列极限为零证明；函数性质综合判定选择题；递推数列极限与幂指极限；递推数列单调有界证收敛；递推不等式定极限 |
| 对应考点 | 数列极限的定义与性质；单调有界准则；数学归纳法；子数列与数列极限的关系；递推数列的极限计算；函数单调性与不等式证明；利用单调有界准则；利用中值定理；变量连续化；数列极限；（二）幂指函数现；性质及常识；利用夹逼准则 |
| 覆盖题量 | 7 题（分支 13 个） |

### 标准解题步骤

1. 定取值范围：由首项与递推式推出各项的正负与大致区间，并标出根式、分母对取值范围的限制
2. 解不动点方程：把递推式两端同时取极限求出候选极限值，舍去落在取值范围之外的根
3. 定界与方向：比较首项与候选值的大小，并结合递推函数的单调性确定要证的是上界还是下界、递增还是递减
4. 归纳证有界：以合适起始项验证基础、设第若干项成立、由递推式推出下一项仍在界内，三步闭合并注明界的方向
5. 归纳证单调：作相邻项之差并按递推式因式分解，把新差的符号归约为已知差的符号，明确单调性自哪一项起成立
6. 闭合结论：单调且有界则极限存在，再在递推式两端取极限，由极限唯一性确认所求值即候选值
7. 复核交替：若相邻项的大小关系反复变号导致整体不单调，立即转入奇偶子列分别执行上述步骤

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 整体单调直接分支 | 写出前若干项后大小关系一致，相邻项差可按递推式因式分解定号 | 直接以候选值为界做归纳 → 用递推函数的单调性一次定出差的符号 → 界与单调同侧闭合后取极限得值 | 递推函数须在取值区间内单调递增；单调性只需从某项起成立，前面有限项可先剔除 |
| 奇偶子列分支 | 前几项出现大于号与小于号交替，递推函数单调递减使整体不可能单调 | 把递推式作用两次写出隔项递推式 → 奇数列与偶数列分别做定界与定单调的归纳 → 两子列分别取极限并核对候选值相同 → 用子列与数列极限的关系定理合并出原数列极限存在 | 两子列极限必须相等，若收敛到不同值则原数列发散；隔项递推式要能显式写出 |
| 辅助函数定号分支 | 相邻项差无法直接因式分解定号，符号取决于某个超越不等式 | 把差改写成某个连续函数在数列取值处的函数值 → 对连续变量求导或用已知不等式判定符号方向 → 把定号结论嵌入归纳递推，逐项传递 | 只能对连续化的自变量求导，不能对项数求导；所用不等式须在整个取值区间上一致成立 |
| 隐式与多值递推分支 | 递推关系以方程形式给出，含根号或反函数结构，未显式解出下一项 | 由方程与首项所在区间确定所取分支及符号 → 验证各项都落在使表达式有定义的范围内 → 按选定分支的单调性重复判界与判单调 | 必须先确认符号分支唯一确定实数项，否则数列本身定义不明确，后续归纳无从谈起 |
| 候选值无闭式分支 | 两端取极限所得方程没有初等闭式根，或含超越结构无法显式解出 | 用连续函数零点存在性论证候选值存在且唯一 → 以含候选值的区间端点代替具体数值做归纳 → 只回答存在性，不再声称求出具体数值 | 题目要求给出极限数值时不适用；候选值不唯一时必须先用取值范围排除多余根 |
| 界已显然只需证单调分支 | 值域受限使界由递推式或首项范围直接给出，无需另找候选值作界 | 省去归纳证界一步，直接引用已给取值范围 → 集中用相邻项差或辅助函数定单调方向 → 单调与已知界合并即闭合存在性 | 所引范围必须对所有项公用，且界的方向要与单调方向构成同侧结论 |
| 迭代压缩差收缩分支 | 递推函数把区间映入自身且导数绝对值有严格上界，相邻项差可写成介点导数乘前差 | 用归纳法验证迭代像始终落在题设区间内，得到数列有界 → 对迭代函数求导判定其单调性，并用拉格朗日中值定理把相邻项差写成介点导数乘前一项差 → 由导数恒正或绝对值小于一推出各项差的符号与大小受控，确定数列的单调方向 → 用单调有界准则断定极限存在，在递推式两边取极限解出不动点得极限值 → 把所求式子中的递推组合用不动点偏差化简，使分母成为与之同阶的无穷小 → 作变量连续化把数列极限转为函数极限，用中值定理或泰勒展开定阶求值 | 前提：迭代函数在区间内连续可导并把该区间映到自身；坑点：导数变号时差的符号不定使单调性论证断裂，不动点不唯一时取极限只给出候选值而不能定值，数列不趋于所讨论的点时不能作变量连续化替换 |
| 方程根数列单调有界分支 | 数列各项为含参方程在逐个参数下的根，由零点定理与单调性定义而非递推给出 | 固定参数把方程视为单变量函数，验证区间两端函数值异号以用零点定理 → 对函数求导并判定导数在区间内定号，断定根存在且唯一 → 写出相邻两根各自满足的等式，把其中一个代入另一个函数以比较函数值大小 → 依照函数单调方向从函数值大小反推自变量大小，得到数列的单调性 → 取根所在的有界区间并结合单调方向，用单调有界准则断定极限存在，再由根满足的等式取对数定出极限值 → 对所求幂指式取对数并换元为函数极限，用洛必达法则求两无穷小之积后指数还原 | 前提：函数在闭区间连续、开区间可导且导数定号，取对数时底数与真数恒正；坑点：导数变号导致根不唯一时无法定义单一下标数列，数列无界时单调有界准则失效，底数趋于零或负值时对数变换失去意义 |
| 比值门槛反证趋零分支 | 已知相邻项比值的极限绝对值小于一，要证数列趋于零 | 对绝对值数列考察相邻项之比，把已知比值极限取绝对值后与一比较 → 用极限保号性取介于该比值绝对值与一之间的数，求出使比值不超过它的项数门槛 → 由比值严格小于一判定绝对值数列单调递减，并以非负性给出下界 → 依据单调有界准则断言绝对值数列极限存在，记为待定的非负常数 → 用反证法检验：若该常数非零则对比值两端取极限得出一，与题设矛盾 → 由绝对值趋于零推出原数列趋于零，并核对过程中各分母始终不为零 | 前提：比值极限存在且其绝对值严格小于一，从某项起各项非零；坑点：比值极限等于一时本法失效，比值极限不存在仅有上界时不能直接用保号性定门槛，数列含无穷多个零项时比值无定义须先改造表述 |
| 反向双单调数列差趋零的反证存在分支 | 两个单调方向相反的数列之差趋于零，要证两者极限都存在且相等 | 反设其中一个数列极限不存在，由单调性把它推到相应的正或负无穷 → 用差趋于零的条件把另一个数列也推到同号无穷 → 指出这与另一数列相反的单调方向矛盾，从而肯定其极限存在 → 对称地处理另一个数列的存在性 → 对差的等式两端取极限得两极限相等，并用极限存在而非零的例子排除数值为零的误判 | 两数列必须单调且方向相反且差的极限为零；同向单调时可同时趋于无穷使结论不成立，极限存在且相等也不能断言其值为零 |
| 不动点导数定比值幂指分支 | 递推数列已证收敛后，还要求相邻项比值构成的幂指式极限 | 确认递推函数的值域不等式使各项始终落在同一区间内，得到有界性 → 比较相邻两项作差或作商，或用函数差单调性判定数列的单调方向 → 调用单调有界准则宣告极限存在，对递推式两端取极限解不动点方程并舍去不合理解 → 取所求幂指式的对数，转化为相邻项比减一与其指数因子的乘积 → 展开递推函数在不动点处的泰勒式，求出比值主项与误差的同阶关系，算出对数极限后还原指数 | 前提：递推函数在不变区间连续单调，初值落在保证单调性的区间内；坑点：不动点不唯一时未按初值选取正确的根，对递推式两端取极限前未证明极限存在属循环论证，幂指式底数不趋于正数时不能取对数 |
| 拉格朗日差商定号分支 | 递推式中出现差商结构，单调性靠中值定理写成介点导数与步长之积来估计 | 合并递推式中的对数差为单个对数，并改写成等价的指数关系以便比较 → 用基本不等式确认首项满足条件，再由归纳法推出全部项保持同号从而有下界 → 用拉格朗日中值定理估计递推式中出现的差商，得到相邻项的严格大小关系 → 结合单调方向与有下界，用单调有界准则判定极限存在 → 取递推式两端的极限，把极限值代入不动点方程求解并检验其符合范围 | 前提：递推函数在不变区间上连续可导，归纳所需不等式在该区间一致成立；坑点：中值定理的连续可导条件在区间端点被破坏时估计失效，未先证存在性就对递推式两端取极限属循环论证 |
| 均值不等式定界的递推不等式取极限分支 | 数列由含倒数或混合项的递推不等式给出且恒正，要求定出其极限 | 对不等式一侧应用均值不等式，把混合项改写为几何平均形式 → 由几何平均严格小于单位一推出相邻比小于单位一，判定数列单调递减 → 指出数列有下界从而极限存在 → 用反证排除极限为零，保证含倒数的一侧取极限仍有意义 → 对不等式两端同取极限，得到只含极限值的代数方程 → 解方程并按下界与保号条件筛去不合理解 | 数列恒正且不等式两端可同时取极限，极限非零；极限可能为零时不能对含倒数的一侧取极限，不等式方向不明时均值不等式给不出严格收缩 |

### 失效边界

- **适用前提**：递推式为单变量自治形式，下一项仅由前一项决定且对应函数连续；首项给定或给出首项所属区间，足以唯一确定各项的符号分支与取值范围；不动点方程在取值范围内恰有一解，可同时充当界与单调比较的分界；题目只要求存在性与极限值，不要求收敛速度或误差估计；迭代函数在区间内连续可导并把该区间映到自身；导数恒正或绝对值严格小于 1，使差的符号或大小可控；所转函数极限存在，数列项趋于该点从而可作变量连续化；函数在闭区间连续、开区间可导且导数定号；数列单调且有界两个条件同时成立；取对数时底数与真数恒正；比值极限存在且其绝对值严格小于一；从某项起各项非零，使比值运算合法；结论只要求趋于零，不要求给出趋于零的速度；两数列单调方向相反；差的极限存在且为零；递推函数在不变区间上连续且单调；初值落在保证单调性的区间内；不动点处导数存在且比值型幂指式的底趋于正数；递推函数在不变区间上连续可导；初值使各项始终落在可估计的区间内；归纳法所需的单调性与不等式在该区间一致成立；数列恒正且不等式两端可同时取极限；极限非零，含倒数的一侧取极限仍有意义
- **失效场景**：递推式显式含项数（非自治）时，两端取极限所得方程不再成立，五段法整体失效；取值范围内无不动点或有多个不动点时，候选界不存在或界方向不唯一，判界与判单调无法闭合；数列本身无界或发散，任何归纳基础都会失败，须改用其他存在性判据；奇偶子列收敛到不同值时原数列极限不存在，此时仍按合并分支写出结论会得到错误答案；先假设极限存在解出数值再当作存在性证明，属于循环论证，必须先证存在再取极限求值；要求通项公式或收敛阶的问题不能由存在性论证完成，应改走递推求解或压缩映射估计；单调性自第一项不成立且未剔除有限项时，归纳基础选错起始项会使命题链条断裂；导数变号时差的符号不定，单调性论证断裂；不动点不唯一时取极限只给出候选值而不能定值；数列不趋于所讨论的点时不能作变量连续化替换；导数变号导致根不唯一时无法定义单一下标数列；数列无界时单调有界准则失效；底数趋于零或负值时对数变换失去意义；比值极限等于一时本法失效，需改用其他判敛手段；比值极限不存在仅有上界时不能直接用保号性定门槛；数列含无穷多个零项时比值无定义，须先改造表述；比值绝对值大于一时结论反向，数列发散；两数列同向单调时可同时趋于无穷，结论不成立；两极限存在且相等不能进一步断言其数值为零；数列不单调时不能只用单调有界准则，需改用夹逼或子列；对递推式两端取极限前未证明极限存在；不动点不唯一时未按初值选取正确的根；数列不单调时单调有界准则不适用；未先证存在性就对递推式两端取极限；中值定理所需的连续可导条件在区间端点被破坏；极限可能为零时不能直接对含倒数的一侧取极限；不等式方向不明时均值不等式给不出严格收缩

## 夹逼准则三段乘积通法

> 编号 **T-HS-10-S** ｜ 版本 **v0.6** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 先把题写成一个求和式，再只放缩通式中影响最小的因素，使两侧化为同一极限值，由夹逼得解 |
| 适用范围 | n 项和（或可化为 n 项和）的数列极限，放缩后能配成定积分定义或两侧同值收敛 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | n项和式极限；含根式的和式极限；分母扰动项和式极限；偏移下标和式极限；三角函数和式极限；数列极限求值综合题组；积分放缩夹逼数列极限；无穷乘积型数列极限；根号和型数列极限；积分数列夹逼证极限 |
| 对应考点 | 数列极限；夹逼准则；定积分定义；利用夹逼准则；利用基本极限；利用定积分定义；变量连续化；（一）定义及性质 |
| 覆盖题量 | 5 题（分支 8 个） |

### 标准解题步骤

1. 把原式统一写成对指标求和的形式，并先整理分式（通分、有理化、分子分母同乘）
2. 拆分通式中的全部因素：常数项、含指标的项、含项数的项，按对通式影响大小排序
3. 选出影响最小的因素（通常是指标扰动项或纯常数），确定它在求和范围内的最大值与最小值
4. 只改变这个最小因素，分别取其端点值作出放大式与缩小式
5. 把两侧整理成「一项因子乘以关于指标与项数之比的函数」的可控形式，必要时提出仅含项数且极限为一的因子
6. 验证两侧极限存在且相等（同一定积分或同一常数）
7. 由夹逼准则给出原式极限，并计算定积分或求和得最终值

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 配定积分定义分支 | 放缩后两侧都能写成项数分之一乘以关于指标与项数之比的一元函数求和 | 从放缩式中提出每行宽度因子（项数分之一） → 把剩余部分统一写成指标与项数之比的函数 → 识别为区间一端到另一端的黎曼和并写出对应定积分 → 两侧得到同一定积分（或同一定积分乘以极限为一的因子）后取极限 | 通式无法统一化为指标与项数之比的函数时，不能强行配定积分 |
| 同值共趋分支 | 分母主部阶数明显高于分子，放缩后两侧都能直接求和且极限相同（常为零） | 令最小因素取端点值，使每一项变成与指标无关的同型项 → 用项数乘以该项得放大式与缩小式 → 分别取极限确认两侧同值后由夹逼结论 | 两侧极限不相等时该放缩过度，必须改换放缩目标或转配定积分 |
| 偏移指标重置分支 | 放缩后自变量为指标加一再比项数加一之类的偏移形式 | 把项数加一视为新的分割数重记求和 → 对首末多出的有限项单独补上或去掉 → 把相差的因子写成仅含项数且极限为一的乘子 → 按定积分定义取极限 | 补去或多出的项数必须为有限项或有界量，否则需单独检验其极限贡献 |
| 和式裂项与根式和式主导项夹逼分支 | n 项和、可裂项通项、开 n 次根的若干项和与幂指式混在一起的数列极限题组 | 判断通项属于和式、无理差式、根式和式还是幂指式，选定对应化简套路 → 用分母的最小项与最大项分别放大与缩小分母随项数变化的两侧 → 把可拆项通项分解为部分分式，写出相消后仅剩首末项的表达式 → 提取根式和式的主导项，或用常数倍两侧夹逼并配合常数开 n 次根的极限 → 有理化无理差式后把差化为同阶量之商比较主导阶 → 幂指式化为一加无穷小乘无穷小再取指数还原，最后统一检验不等号方向一致 | 和式各项同号且分母变化幅度可控、两侧放缩趋于同值；项数趋于无穷同时每项也在变化时不可当作固定项数处理，夹逼两侧不等时不得结论 |
| 单调端点积分拼接分支 | 和式一般项被单调函数在定长子区间上的端点值双向控制，累加后区间拼成一段积分 | 确认函数在整段区间上单调且定号，写出其在单位子区间上的端点双侧估计 → 对估计式逐段积分，得到级数一般项与积分增量之间的双边不等式 → 对下标累加，使积分区间拼接为一段连续区间、级数拼接为部分和 → 把含部分和的商式同时放大与缩小，构造出上下两个界 → 对上下界分别求极限，必要时作变量连续化转为函数极限并用洛必达法则 → 验证两界极限相等，由夹逼准则断定原商式极限并检验放缩方向未反 | 前提：函数在积分区间上单调且不变号，端点控制方向一致；坑点：函数在区间内振荡变号时端点不再控制积分值，上下界极限不相等时不能据此断言原式发散，对不等式同乘可能为负的量时必须改变方向 |
| 取对数化乘定积分分支 | 无穷乘积因子趋于一，取对数后为含高阶修正项的和式 | 先把对数增量与其线性主项之差双边估计，确认修正项的阶 → 对连乘积整体取对数，把乘积的极限问题转为对数之和的极限问题 → 用第一步的不等式把每个对数项夹在主项与平方修正之间 → 对修正项按指标累加，验证其总和随指标趋于零 → 识别主项和式的黎曼和结构，用定积分求出其极限 → 对和式极限取指数还原，并检验指数函数连续性保证还原合法 | 前提：每个因子为正且其增量随指标趋于零，修正项之和的极限可估计；坑点：因子含非正项或增量不趋于零时取对数与线性替换失效，把无穷乘积按有限项乘积的运算法则逐项处理，修正项之和发散时忽略其贡献 |
| 最大项主导开方分支 | 若干正项之和整体开与项数无关的次方，或和式底数为若干常数之和 | 比较各底数大小，确定随过程量增长的主导项即绝对值最大者 → 提出主导项的幂，把和式写成主导项乘以一加趋于零的因子 → 判断剩余因子是比值绝对值小于一的衰减量，确认其趋于零 → 构造主导项与项数倍主导项的两侧夹逼，并配合常数开次方的基本极限 → 写出极限为主导项开方后的值，检验各项为正以保证开方结果唯一 | 前提：各底数为正且最大者唯一或并列有限个；坑点：存在绝对值相等的多项且符号交替时不能简单归为最大项，出现负项时开偶次方可能无意义，项数随过程量过快增长时夹逼两侧不再同值 |
| 积分不等式夹逼分支 | 数列由含参定积分或变限积分定义，需证两积分的大小关系并用控制函数夹逼 | 构造两被积函数之差，对其求导判定单调性并用区间端点值确定符号 → 由逐点不等式在积分号下保向，得到两积分数列的大小关系 → 对上层被积函数用线性或幂函数控制，积分出可显式求值的上界 → 取指标趋于无穷，由上界趋于零结合非负下界用夹逼准则定出上层极限 → 把大小关系回用于下层数列，检验两数列极限相同 | 前提：积分区间固定且各被积函数连续，逐点不等式在整个积分区间上同向成立；坑点：被积函数在区间内变号时积分不再保持不等式方向，上界积分不趋于零时夹逼给不出结论，积分区间随指标变化时不能直接套用定值估计 |

### 失效边界

- **适用前提**：和式项数已知且与放缩后项数一致或仅差有限项；被放缩的因素在整段求和范围内单调且有确定端点值；放缩后两侧表达式都能求出极限并且极限相等；和式各项同号且分母变化幅度可控，两侧放缩趋于同一值；通项可分解为相邻项之差；根式内主导项唯一且各底数为正；函数在积分区间上单调且不变号，端点控制方向一致；上下界除同一主项后极限存在且相等；拼接后的积分可显式求出或其主项可估；每个因子为正且其增量随指标趋于零；修正项之和的极限可估计且不影响主项；主项和式可化为可求值的定积分或可夹逼；各底数为正且最大者唯一或并列有限个；项数固定或增长远慢于主导项的指数速度；积分区间固定且各被积函数连续；逐点不等式在整个积分区间上同向成立；控制函数的积分可求且其极限为零
- **失效场景**：放缩过度使放大式与缩小式极限不相等，夹逼失效且得不到任何结论；放缩同时改变多个因素，误差阶失控，两侧不再收敛到同一值；含正负交替项时逐项放缩会抵消主阶，方法给出的极限错误；最小因素同时出现在分子与分母时，单方向取值无法保证整体被放大或缩小；题目要求给出渐近展开的下一阶项时，本方法只能定出主值而不能给出误差阶；夹逼两侧极限不等时不能得出数列极限；项数趋于无穷同时每项也在变化却当作固定项数处理；幂指式底数不趋于一时套基本极限失效；函数在区间内振荡变号时端点不再控制积分值；上下界极限不相等时不能据此断言原式发散；对不等式同乘可能为负的量而忘记改变方向；因子含非正或增量不趋于零时取对数与线性替换失效；把无穷乘积按有限项乘积的极限运算法则逐项处理；修正项之和发散时忽略其贡献；存在绝对值相等的多项且符号交替时不能简单归为最大项；项数随 n 指数增长使常数开 n 次根不再趋于一时夹逼失效；出现负项时开 n 次根可能无意义；被积函数在区间内变号时积分不再保持不等式方向；上界积分不趋于零时夹逼给不出结论；积分区间随指标变化时不能直接套用定值估计

## 无穷大阶比较与抓大头等价替换通法

> 编号 **T-HS-13-S** ｜ 版本 **v0.8** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 按对数、幂、指数、阶乘、幂指五档给无穷大定阶，取最高阶主项作等价替换求极限，主项相消时倒代换化归无穷小 |
| 适用范围 | x 趋于无穷（或 n 趋于无穷）的无穷比无穷、无穷减无穷、幂指未定式极限，以及两个无穷大量的阶比较与含参定阶问题 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | 无穷大阶的比较；无穷比无穷型极限；无穷减无穷型极限；含阶乘的极限；幂指未定式极限；对数内指数和极限；函数性质综合判定选择题；待定系数使极限为零求参数；无穷大量阶比较排序；含取整与指数比的左右极限；两侧极限相等反求参数；分段函数有界性判定 |
| 对应考点 | 无穷小与无穷大的概念；无穷小阶的比较；极限的四则运算；洛必达法则；夹逼准则；等价无穷小替换；性质；函数极限；（一）定义及性质；（三）六种计算手法；无穷小比阶；利用基本极限；（四）连续和间断；（二）幂指函数现；（五）知此求彼 |
| 覆盖题量 | 7 题（分支 11 个） |

### 标准解题步骤

1. 把分子、分母（以及差式各项）拆成有限个基本增长块的乘积与和，增长块只取对数、幂函数、指数、阶乘、幂指函数五类
2. 在同一趋近过程中按五档顺序给各块定阶：档与档之间可直接比高阶，同档内部再比底数、指数与幂次的参数
3. 对纯乘除结构只保留每边的最高阶块（抓大头），把低阶块归入趋于零的误差因子
4. 把原式替换为主项之比，化为系数可直接读出的无穷比无穷极限并求值
5. 若替换后结果为零、无穷或出现同档相减抵消，改令倒数代换把无穷端化回零点，用等价无穷小或泰勒展开算到首个非零项
6. 对含正弦、余弦等有界振荡因子的结果，用无穷小乘有界量仍为无穷小复核一次，必要时补夹逼验证

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 五档定阶比较分支 | 题目要求比较两个无穷大的阶，或判断谁是主项 | 把两式化归到同一档或相邻档 → 幂与指数的比较可连续化后用洛必达逐次降幂 → 阶乘无法连续化时先用斯特林公式化为幂指形式 → 仍有困难时取对数比较增长速率作为最终判据 | 阶乘、双阶乘等离散量不能直接连续化用洛必达；取对数比较只对正项乘积结构保序 |
| 抓大头替换分支 | 分子分母均为若干增长块之和，且两边最高档主项不相消 | 逐项定阶并取每边最高档块 → 把低阶项按低阶比高阶趋于零丢入误差项 → 约去主项系数直接读出极限 | 只做乘除意义的替换安全；含加减且主项相消时替换会给出错误的零或常数 |
| 主项相消转无穷小分支 | 差式或和式抓大头后结果恰为零，或出现无穷减无穷 | 令倒数代换把无穷端化为零点 → 提取公因子后对括号内用等价无穷小或泰勒展开 → 按最低幂次原则保留首个非零项再回代 | 展开阶数不够仍会得到零；不同次根式相减必须展开到出现非零系数的阶，否则丢掉有限的非零极限 |
| 有界振荡与对数复合分支 | 式中含正弦余弦等有界因子，或整体位于对数、指数内部 | 先把有界因子用绝对值放缩挂到主项上 → 用无穷小乘有界量为无穷小定值 → 对若干指数项之和取对数的类型，先取最大底数项为主项再约去趋近变量 | 有界因子自身也趋于零时不能当常数处理；对数内部各项底数相同需保留项数带来的加性常数 |
| 有理化定主阶判奇偶有界性分支 | 含根式差的函数在无穷端需同时判奇偶性、有界性与极限存在性的性质选择题 | 把自变量换为相反数逐项对照原式判奇偶，并确认定义域关于原点对称 → 分子有理化根式之差，把无穷减无穷化为幂除以两根式之和的同阶商式 → 比较有理化后分子与分母的最高次幂，定出无穷端的极限值 → 分别考察正负两侧无穷，注意奇函数在两侧极限符号相反 → 由极限存在推出该侧局部有界，再结合连续段覆盖排除整体无界选项 | 根式内在讨论范围内恒正才有理化合法，且化后分母极限非零；忽略根式内主导项符号会写错两侧极限，单侧局部有界不可当作全域有界 |
| 降幂展开逐层消主项定参分支 | 无穷端的有理式减去待定多项式要求极限为零，或由渐近线反求参数 | 通分把差式化为单一有理分式，并按自变量降幂合并分子 → 令最高次项系数为零定出一个参数，相当于消去主项 → 再令次高项系数为零或使分子次数严格低于分母次数，定出其余参数 → 用同阶比较检验整体极限确为零而非有限非零 → 以多项式长除法独立复核系数，并解释结果为斜渐近线 | 要求分母次数比分子低一次使降幂展开首项为一次式，且参数只出现在待匹配修正项中；只消最高次项而忽略次高项会得到有限非零极限，分子次数不低于分母时极限不可能为零 |
| 幂基准作商排序分支 | 要求把多个无穷大按阶排序，或比较两无穷大的相对高低 | 把待比较的各函数两两作商，构成无穷远处的商式极限 → 先化简商式中的对数与幂，再用洛必达法则或等价替换求出极限 → 区分商为零、为非零常数、为无穷三种情形，判定两函数的相对阶 → 取幂函数为中间基准，分别与对数型和指数型比较后串联出完整次序 → 判定各选项与所得次序是否吻合，并检验过程未因底数或符号变化而失真 | 前提：各函数在无穷远处均为正且趋于无穷，比较对象落在标准增长阶序列内；坑点：函数振荡或变号时商式极限不存在，两函数同阶仅差常数因子时无法由阶判定大小，把有限点处的取值当作充分大时的次序 |
| 渐近抵消反参分支 | 无穷远处含根式与多项式之差，待定系数使极限为零或给定值 | 提出根式中的最高次幂因子，把无穷远处问题转化为新变量趋于零的问题 → 利用变换后的极限存在必要条件令分子主项相消，先定出一次项系数 → 用立方差公式有理化已定首项后的根式差，使分母阶高于分子 → 比较有理化后分子分母的阶，求出常数项参数 → 代回两个参数检验原极限确为零而非有限非零或不存在 | 前提：根式内最高次幂与外侧多项式次数可比，展开主项唯一；坑点：根式内次数与修正项次数不匹配时无法同时定出两个参数，偶次根式在两端符号不同却不分左右讨论，有理化后分子分母同阶却仍令极限为零 |
| 分侧主项方程定参分支 | 表达式含取整或倒数指数使左右两侧主项不同，由极限存在且等于给定值定参 | 识别造成分岔的因素：取整函数的跳跃与指数中倒数趋于正负无穷的两个分支 → 求发散一侧的极限，把对数内的主导指数因子提出并用对数拆成主项加趋于零的余项 → 求收敛一侧的极限，此时幂减一可直接等价替换为指数本身，得到趋于零的贡献 → 分别代入取整函数在两侧的取值，写出两个含参的单侧极限式 → 令两单侧极限相等且等于题设值，联立解出系数与极限值 → 检验所解系数不改变分岔判断，避免把跳跃点的函数值误当单侧极限 | 前提：表达式在定点两侧均有定义且可分别求极限，指数型主导项可比出阶；坑点：单侧极限之一不存在或为无穷时无法用相等条件定参，把取整函数在点处的值当成左右极限，对数内主导项判断错误导致等价替换失效 |
| 幂指取对数与定长积分中值两侧反参分支 | 等式一端是底趋于一、指数趋无穷的幂指式，另一端是长度固定而端点同趋无穷的区间积分，需由两侧同值反求参数 | 对幂指侧取对数，把底数偏离一部分恒等变形为等价无穷小，与指数因子的阶相乘定出指数极限 → 确认底数偏离部分的阶只在乘除位置替换，避免在加减结构中非法等价代换 → 对长度固定的区间积分用积分中值定理写成介点处函数值乘区间长，由介点与端点同趋无穷定出右端 → 令两侧所得含参表达式相等，比较指数或再取对数解出参数 → 按参数的符号与正数前提取舍，回代检验两侧极限都存在且非零 | 幂指侧须属一加无穷小乘无穷指数的标准档，被积函数连续且积分区间长度固定；函数在无穷端极限不存在或为负时不能取对数比较，区间长度随参数变化时积分中值定理给不出定值 |
| 分段拼接有界性扫描分支 | 判定分段函数或含可疑点函数在全域的有界性 | 列出全部分段点、分母零点与无穷远处，作为必须单独考察的关键位置 → 分别求每个分段点的左右极限，由极限存在推出该点某邻域内的局部有界性 → 比较无穷远处分子分母的主导阶，判定该侧函数趋于定值或有界 → 覆盖剩下的有限闭区间，引用闭区间上连续函数有界性定理 → 合并各段的界取最大者得整体有界；若某段不成立则指明其无界范围 → 用振荡因子是否被零因子压制复核临界区间上的结论 | 前提：函数在各分段内部连续且分段点处左右极限存在有限；坑点：分段点处为无穷型间断时误用极限存在推出局部有界，无界振荡与有界因子相乘时把整体当作有界，把导数在无穷区间上有界误当作函数有界 |

### 失效边界

- **适用前提**：趋近过程为无穷端，且各增长块可归入对数、幂、指数、阶乘、幂指五档；替换只发生在乘除意义下，或加减后主项不抵消；含参问题中参数不改变各块的档位归属；根式内表达式在讨论范围内始终为正，有理化合法；分子有理化后分母极限非零；定义域关于原点对称；分母次数比分子低一次，展开首项为一次式；参数只出现在待匹配的线性修正项中；各函数在无穷远处均为正且趋于无穷；作商后极限存在或为无穷，可用比较原则；比较对象落在对数、幂、指数等标准增长阶序列内；根式内最高次幂与外侧多项式次数可比，展开主项唯一；有理化所用的因式分解恒等式在讨论范围内成立；表达式在定点两侧均有定义且可分别求极限；指数型主导项可比出阶，取整函数在该点附近取有限个值；幂指侧属标准的一加无穷小与趋于无穷的指数之积结构；被积函数连续，积分区间长度固定且端点同趋于无穷；函数在无穷远处的极限存在且为正，使指数比较有意义；函数在各分段内部连续且分段点处左右极限存在有限；无穷远处的主导阶比较可得有限极限或有界振荡
- **失效场景**：抓大头后主项相消（结果为零）时结论必错，必须转成无穷小重算，这是该方法最主要的失效点；等价无穷大之间不能直接做加减替换：替换后的差与原差可以相差任意常数甚至发散；幂指底数趋于一、指数趋于无穷的幂指未定式不能只比阶，必须先取对数再指数还原；把无穷大当成具体实数参与比较大小、取倒数或当系数运算，破坏极限定义的合法性，概念题上会选错；含阶乘或 n 次根号下 n 阶乘的式子用洛必达连续化失效，须改用斯特林公式或定积分定义；分段函数或含参情形只在单侧定阶会漏条件，必须对每个无穷端与每个奇点分别定阶；五档之外的增长块（如迭代对数、连乘积、递推定义的量）不能直接套用档位顺序，需先化归或单独证明阶关系；有理化时忽略了根式内主导项的符号导致两侧极限写错；把单侧极限存在当作全域有界；根式内出现变号使表达式失去定义时性质讨论失效；分子次数不低于分母时极限不可能为零；只消最高次项而忽略次高项，得到有限非零极限；分式在趋于过程中分母变号或未定义时讨论失效；函数振荡或变号时商式极限不存在；两函数同阶仅差常数因子时无法由阶判定大小；把有限点处的取值当作充分大时的次序；根式内次数与修正项次数不匹配时无法同时定出两个参数；偶次根式在两端的符号不同却不分左右讨论；有理化后分子分母同阶却仍令极限为零；单侧极限之一不存在或为无穷时无法用相等条件定参；把取整函数在点处的值当成左右极限；对数内主导项判断错误导致等价替换失效；函数极限不存在或为负时不能与指数幂比较取对数；积分区间长度随参数变化时积分中值定理给不出确定值；幂指底数不趋于一时套自然常数型基本极限造成错值；两侧极限之一发散时等式无解却仍强行解参数；分段点处为无穷型间断时误用极限存在推出局部有界；无界振荡与有界因子相乘时把整体当作有界；把导数在无穷区间上有界误当作函数有界

## 泰勒公式定阶求极限通法

> 编号 **T-HS-14-S** ｜ 版本 **v0.2.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 分式型未定式的值只由分子与分母各自首个非零幂项的系数之比决定，故两侧须在同一幂次体系内展开到由分母已显含的加减结构反推出的阶，按幂对齐相消后取系数比 |
| 适用范围 | 趋近点可化为零点的分式型未定式极限，分子分母由初等函数经加减、乘积、复合构成 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | 分式型未定式极限；无穷小比阶求极限；无穷远处函数极限；复合函数差式极限；无穷小阶数判定；泰勒展开定阶求极限 |
| 对应考点 | 函数极限；泰勒公式；等价无穷小；利用泰勒公式求极限；无穷小比阶；（四）泰勒不可漏；等价无穷小替换 |
| 覆盖题量 | 2 题（分支 4 个） |

### 标准解题步骤

1. 扫查分子分母的加减结构，由已显含的最低幂次反推必须展开到的阶
2. 对每个超越成分写出该阶带佩亚诺余项的展开式
3. 合并同类项并按幂次对齐，分别保留分子与分母的首个非零项
4. 把纯乘除因子用等价无穷小换成幂函数，保持总阶与主项一致
5. 取主项系数之比给出极限值，核对同阶并检验余项阶严格高于主项阶

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 趋近点归零分支 | 极限过程为 x 趋于非零常数或趋于无穷 | 令新变量为原变量与趋近点之差，或取倒数作倒代换 → 对新变量使用标准的趋于零展开公式 → 含反三角函数时先用互余恒等式把它化回趋于零的形式 | 倒代换后新变量的正负号影响反三角恒等式的常数值，须按左右趋近分别处理 |
| 整体定阶分支 | 出现外层与内层同型的复合结构，如外层函数作用于内层小量 | 把整个复合式视为一个整体去求它的等价单项式 → 由外向内逐层代入并对每一层保留最低幂次 → 禁止先对内层单独取一阶等价再作加减 | 内外层最低幂次相同且相互抵消时，必须再多展开一阶才能显出差项 |
| 加减抵消分支 | 分子为两个及以上同阶小量之差 | 各部分分别展开到第一个不抵消的幂次 → 合并同类项，确认全部低次项已抵消 → 取剩余最低次项作为该部分的等价单项式 | 只展开到公共低阶项时差值恒为零，无法定阶，判定失效 |
| 恒等式化同型定阶分支 | 求单个无穷小关于过程量的阶，乘积成分需先经恒等式化成同一函数的线性组合 | 用倍角等恒等式把乘积成分化为同一函数的线性组合，统一展开对象 → 写出每个成分到足够高幂次的带佩亚诺余项展开式，展开阶数覆盖预期的首个非零项 → 对齐幂次从低到高合并同类项，逐阶检查系数是否相消 → 读出首个非零项的幂次作为阶数，并验证其系数不为零 → 取该幂次为分母作商求极限，检验所得商为非零常数 | 前提：函数在该点存在到所需阶的泰勒展开，各成分可按同一自变量的幂对齐比较；坑点：仅用等价无穷小替换加减项会因主项相消丢失真实阶，展开阶数不足时把余项误当主项，函数在该点不可展开时逐项比较失效 |

### 失效边界

- **适用前提**：分子分母都能展开为有限阶多项式且首个非零项系数不为零；极限过程可统一化为趋于零，且各函数在该点某邻域内存在带佩亚诺余项的展开；各因子的趋近方向一致（同侧趋近或已按左右侧分别讨论）；函数在该点存在到所需阶的泰勒展开；各成分可按同一自变量的幂对齐比较；余项为皮亚诺型且可被主项支配；各成分在该点有到所需阶的泰勒展开；分母主项幂次可预先判定；展开与替换在同一幂次体系内进行；分母主项幂次可由其已显含的加减结构预先判定；乘除因子可先降为幂函数再参与幂次对齐而不改变主阶
- **失效场景**：含振荡因子（自变量倒数作三角函数自变量之类）时不存在确定的等价单项式；展开阶数低于分母阶数会把发散误判为有限值，高于所需阶数则计算量失控；在加减项中对局部因子作等价无穷小替换会改变抵消结构，结果算错；分母在趋近过程中恒等于零或主部系数为零时，幂次比较的分类讨论失效；函数在该点不可展开（如仅在离散点有定义）时本法不可用；仅用等价无穷小替换加减项，因主项相消而丢失真实阶；展开阶数不足时把余项误当主项；函数在该点不可展开时逐项比较失效；展开阶数低于分母主项阶，主项被余项掩盖；对加减项使用不完整的等价替换；分母恒为零或主项系数不可定；展开阶数低于分母主项阶，主项被佩亚诺余项吞没；对加减项使用不完整的等价替换使相消结构改变；分母恒为零或主项系数不可定时幂次比较失效

## 复杂函数等价无穷小最低幂次通法

> 编号 **T-HS-15-S** ｜ 版本 **v0.4** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 复杂函数只经加减、乘积、复合三种方式生成，其等价单项式由最低幂次准则与抵消判定唯一确定 |
| 适用范围 | 求任意初等函数组合在趋于零时的等价无穷小，用于替代逐题记忆等价式 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | 复杂函数等价无穷小；无穷小比阶；复合小量定阶；加减抵消型定阶；等价无穷小反求参数；含参幂乘极限存在定参范围；由已知极限反求另一极限 |
| 对应考点 | 等价无穷小；泰勒公式；无穷小的比较；等价无穷小替换；无穷小比阶；（一）等价小精进；利用基本极限；（五）知此求彼 |
| 覆盖题量 | 3 题（分支 7 个） |

### 标准解题步骤

1. 把目标表达式分解为加减、乘积、复合三种基本运算构成的结构树
2. 对每个原子函数写出到候选幂次的泰勒展开
3. 按运算规则合并：加减看低次项是否抵消，乘积取各因子最低次项系数之积，复合由内向外代入
4. 若合并后最低次项系数为零，则升一阶重算，直到出现非零项
5. 把第一个非零单项式写为该表达式的等价无穷小
6. 用原式与该单项式之比的极限为一来验证所得等价关系

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 纯加减结构分支 | 表达式仅由小量加减构成 | 各部分展开到相同候选阶 → 逐项抵消公共低次项 → 取第一个未被抵消的幂次项 | 展开阶不足时全部项被抵消成零，须升阶重做 |
| 乘积与幂结构分支 | 表达式为若干小量的乘积或同型因子相乘 | 每个因子只取自身的最低次项 → 系数相乘、幂次相加得到等价单项式 → 舍去全部更高次项 | 乘积之外还并联减法时不能先合并再取最低次，须先按加减分支处理 |
| 复合结构分支 | 外层函数作用于内层小量，且内层趋于零 | 先写出外层函数关于其自变量的最低次项 → 把内层小量的等价单项式代入 → 整理为关于原变量的最低次幂并舍去高次项 | 内层小量与外层最低次幂错配（外层首项为常数）时须改用带常数项的展开 |
| 复合混合加减分支 | 复合式再与多项式小量相减 | 复合部分展开到覆盖减法中最高候选阶 → 与另一部分合并并检查幂次逐层抵消 → 取首个非零项，必要时保留多个同阶项的系数之和 | 抵消项数不确定时需逐阶试探，若目标阶次超过考纲常用展开上限本法不再经济 |
| 等价关系反解参数的幂次系数双等式分支 | 题设告知两式为等价无穷小或同阶、高阶关系，要求反解其中的参数 | 确认同一极限过程中两式确为无穷小，否则等价关系无从谈起 → 化含参底数式为幂函数形式，套用幂减一的基本等价形式定出其阶与系数 → 用三角或指数的基本等价形式写出另一式的同阶主项 → 令两式最低幂次相等得第一个方程，令主项系数之比为一得第二个方程 → 解出参数并代回检验主项系数不为零且阶归属未被破坏 | 前提：参数只进入主项的系数或幂次位置；坑点：对加减项整体作等价替换使相消后主项丢失，幂次不同却强行令系数相等，参数落在高阶项时误用主项比较 |
| 幂差提因子化无穷小定净幂次分支 | 两项幂之差外侧再乘自变量的幂，要求由极限存在且有限反解指数参数范围 | 提出差式中的公共指数因子，把剩余部分写成同底指数相减的幂减一形式 → 计算并化简指数之差，明确它关于自变量的衰减阶 → 用幂减一等价无穷小把幂差换成含对数因子的同阶量 → 合并外侧乘幂的指数与所得阶，写出自变量的净幂次 → 按净幂次为正、为零、为负三档判极限是否有限 → 列出存在性所需不等式求参数范围并单独检验端点取值 | 底数为正且不为一、指数差趋于零方可用幂减一等价形式；对指数之差分别取极限会造成主项相消出错，极限为无穷不属于存在 |
| 由已知极限反推等价主项分支 | 给出含未知函数式的极限为非零常数，要求反求另一极限或确定未知函数的系数 | 由已知极限为非零常数，把外层对数型与指数型差替换为各自的等价主项 → 沿复合结构逐层剥去外层函数，写出未知函数关于过程量的等价关系 → 把该等价关系除以目标分母，直接得出目标极限值 → 由商式极限存在且有限反推分子在相应点取零，确定其全部因式 → 设出含待定系数的表达式并依已知次数固定因子个数，用各点极限值联立求解 → 代回检验每步替换均处于乘除位置且主项系数非零 | 已知极限须存在且为非零有限值才可逆推内层主项；对加减结构整体作等价替换会丢阶的信息，分母趋于零时未验分子必趋零即约商会出错 |

### 失效边界

- **适用前提**：所有原子函数在趋零处有带佩亚诺余项的标准展开；表达式最终等价于单个幂次项（系数不为零）；各运算层级的变量趋于同一零点；两式在同一过程中确为无穷小；参数只进入主项的系数或幂次位置；底数为正且不为一，指数差趋于零从而可用幂减一等价形式；极限存在指有限极限，不含发散为无穷的情形；已知极限存在且为非零有限值，保证等价关系可逆推；外层函数在内层趋于相应值时有确定的等价主项；未知函数的次数或结构足以定出全部待定系数

## 含反函数极限的换元归一通法

> 编号 **T-HS-16-S** ｜ 版本 **v0.2** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 反函数与原函数是同一对应的两种写法，把反函数值换回原函数自变量是等价代换，反函数符号消去后只剩原函数的商式 |
| 适用范围 | 已知原函数解析式而反函数解析式难以求出，需求含反函数的无穷型（或趋近点为无穷）差式极限的题目 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | 含反函数的极限求值；无穷大型反函数差式极限；多项式函数反函数的极限；反函数渐近阶判定 |
| 对应考点 | 函数的极限；反函数的概念；等价无穷小与无穷大；复合函数极限运算法则；利用中值定理；洛必达法则；数列极限 |
| 覆盖题量 | 1 题（分支 5 个） |

### 标准解题步骤

1. 确认原函数在所考虑的趋近过程中单调且趋于同一极限点，使反函数唯一且代换合法
2. 把含反函数的分子按项拆开，化成若干「单个反函数项除以同一幂式」的极限
3. 对每一项设反函数值为新变量，即用原函数关系把反函数符号整体替换为其对应的原函数自变量
4. 同时把分母幂式按同一关系换成原函数表达式，使分子分母落在同一个自变量上
5. 调整自变量的倍率：把倍数补进分母幂式并作为常数因子提到极限号外
6. 把极限整理为「自变量的某次幂除以原函数」的形式，由原函数的无穷大主部定阶求值
7. 各部分极限均存在后再相减合并，并用主部的反函数代入原式复核同一结果

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 以反函数值为变量分支 | 给出原函数解析式，反函数解析式无法显式求出 | 设反函数值为新变量，把反函数项整体换成对应的原函数自变量 → 由原函数关系式替换分母中的幂式 → 检验新变量与原变量同步趋于同一极限点 → 化为普通一元极限后定阶求值 | 代换前后趋近点必须对应，原函数在该区间须单调以保证反函数单值 |
| 倍率提取分支 | 分子含自变量成常数倍的反函数项 | 把分母幂式补成与该倍率一致的形式 → 将倍率的幂次作为常数因子提到极限号外 → 对新变量取极限并还原倍率影响 | 只有该项极限单独存在时才能把倍率单独提出，否则拆项非法 |
| 双自变量分别反解分支 | 分子是两处不同自变量取值下的反函数之差 | 为两项分别引入两个原函数自变量 → 由原函数关系分别列出两个等式并各自反解出对应的幂式表达 → 把两个表达式分别代回两项极限 → 分别求极限后再相减合并 | 两个自变量必须都趋于同一无穷远点，否则不能对差式逐项取极限 |
| 等价无穷大主部替换分支 | 原函数可确定其无穷大主部（如多项式、幂式主导的表达式） | 把原函数替换为与其等价的无穷大主部 → 写出主部的反函数（幂式反函数可直接求出） → 用主部反函数代入原差式并约去公共幂次 → 核对替换前后各单项之比的极限相同 | 无穷大等价只能用于乘除因子，整体替换相减的两项会因主部相消而失控 |
| 反函数序列敛散判定分支 | 数列由方程（原函数取值关系）隐式定义，需判定反函数序列的敛散或渐近阶 | 把方程视为某函数在区间上的取值，验证其导数保号且函数无界 → 据此断定反函数序列趋于无穷，排除其收敛的可能 → 用原方程把待考察的比值改写成只含已知量的形式 → 对反函数用反函数求导法则写出其导数表达 → 对仍为无穷比无穷的式子用洛必达并回代导数 → 比较主部系数得出极限值并判定该数列的收敛性 | 前提：原函数连续可导且导数严格保号，原函数无界使反函数趋于无穷；坑点：原函数导数变号时反函数不唯一无法定阶，洛必达后极限不存在且不为无穷时不能反推原数列发散 |

### 失效边界

- **适用前提**：原函数在趋近过程中单调且趋于无穷，反函数存在且随之趋于同一点；分子可拆为有限项，且每一项的极限单独存在；分母幂式与原函数主部的阶数之比可以确定；原函数在所考虑区间连续可导且导数严格保号；原函数在该区间无界，反函数趋于无穷
- **失效场景**：原函数不单调（含周期项或振荡项）时反函数不唯一，换元失去意义；拆项后某一部分极限不存在，仍对差式逐项取极限会得到错误结论；直接用等价无穷大替换整个相减分子时主部相消，误差阶无法控制；趋近点为有限值时应改用等价无穷小与反函数在该点的局部性质，本通法的无穷大定阶手段失效；题目求反函数在某点的导数值（反函数求导法则）而非无穷过程的极限时，本法无关；原函数导数变号时反函数不唯一，无法定阶；洛必达后极限不存在且不为无穷时不能反推原数列发散

### 标准解题步骤

1. 先问有无具体表达式：无表达式（抽象函数、只给性质的函数）或表达式含无法展开的指数嵌套，归入定义概念型
2. 有具体表达式时再排除求和形式与递推形式，剩余一律归入具体函数（数列）型
3. 定义概念型：用极限存在的充要条件逐侧（或逐子列）考察，并以唯一性、局部有界性、保号性作推断
4. 具体式型：先定出分母的无穷小阶，把各部分展开到同阶，合并主部取比值，出现相消时提高展开阶数
5. 和式型：整理为对指标求和的形式，只放缩影响最小的因素使两侧同极限，或识别为定积分定义
6. 递推型：先用数学归纳法证单调有界以确认极限存在，再对递推式两端取极限定值
7. 回检归类是否唯一：间断点分类同样归约为单侧极限计算，确认每一型的判据都已执行

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 定义概念型分支 | 无具体表达式，或表达式含倒数指数等无法直接展开的抽象结构 | 按极限存在的充要条件考察各单侧极限或各子列极限 → 用唯一性、局部有界性、保号性作出存在性或符号推断 → 数列极限必要时与函数极限互化后统一处理 | 仅在使用存在性判据而无表达式可定阶时采用；一旦能定阶即改用展开型分支 |
| 具体式展开定阶分支 | 给出具体函数式或具体数列通项且不含求和记号 | 判定分母的无穷小（或无穷大）阶 → 把分子各部分展开到该阶 → 合并主部后取系数比 → 主部相消时继续提高展开阶数直至出现非零首项 | 展开须在同一个趋近过程内进行，且阶数必须足够，否则丢项致错 |
| 和式放缩分支 | 表达式为若干项求和或可化为求和形式 | 统一写成对指标求和的通式 → 拆分通式各因素并选出影响最小的因素 → 只对该因素取端点值作放大式与缩小式 → 检验两侧同极限或配成定积分定义后取极限 | 本分支只做归类，放缩的精细操作归夹逼准则专题模板，不可与展开型混用于同一和式 |
| 递推单调有界分支 | 给出首项与递推关系，未给通项 | 由递推式解出极限候选并确定不变区间 → 用数学归纳法证明单调性与有界性 → 确认存在后对递推式两端取极限求值 → 数列不单调时分奇偶子列分别讨论 | 递推右端为非线性复合结构时求通项路线过长，仍应以单调有界性为主 |
| 可疑点枚举与左右极限归类分支 | 初等式含分母、对数真数与幂指结构，要求找出全部间断点并判定类型 | 令分母为零、对数真数非正、幂指底数失去意义，解出全部可疑点并筛到给定区间 → 取幂指式的对数，把指数的发散方向与底数趋于临界值的情形分开讨论 → 分别求每个可疑点的左极限与右极限，注意指数趋于正负无穷的两种后果 → 按两侧极限是否都存在且相等、是否为无穷归类为第一类或第二类 → 检查该点是否有定义及定义值是否等于极限，区分可去与跳跃 → 用邻域内表达式的符号变化复核，避免漏掉周期性产生的其他间断点 | 间断点只出现在表达式失去定义之处，各点单侧极限可由基本极限或等价替换算出；振荡无极限者不可强归第一类，无定义不等同于第二类 |
| 无穷大取倒数化无穷小的运算性质分支 | 选项只给定性前提就断言两个无穷大的和、差、积、商仍是某类量 | 把待判表达式改写为关于两个函数的倒数组合，用无穷大与无穷小互化 → 对改写后的和、积、商分别套用无穷小运算法则并写明适用条件 → 还原取倒数，判断原式属无穷大、无穷小还是未定式 → 用同阶与异阶两类具体无穷大构造例子，逐一否证不总成立的选项 → 确认正确选项在任意满足题设的函数下都成立，而非依赖额外的阶条件 | 两函数在同一过程中均严格趋于无穷且不变号，法则所需极限存在性须满足；无穷大相减相除不可直接断言类型，不可默认趋无穷速度同阶 |
| 定义量词强度的点列判据分支 | 选项在无穷小、有界、无界、无穷大之间互相辨析，且表达式含振荡因子或倒数自变量 | 取使振荡因子达到极值的点列，证明函数值沿该列任意大，得无界 → 取使振荡因子为零的点列，证明函数值可反复回到零 → 按无穷大定义要求一切充分接近的点都任意大，用零点列否证无穷大 → 把点列结论翻译回函数过程的极限语言，逐条排除有界与无穷小选项 | 前提是振荡因子在趋近过程中反复取到零与极值且可构造两类点列；坑点是仅凭存在一个趋于无穷的点列就断言函数为无穷大，把存在量词当全称量词使用 |
| 四则运算存在性前提反证分支 | 命题考极限四则运算或性质的存在性前提，需反证推理并配发散反例 | 把每个选项写成蕴含式，明确前件是和或差的极限存在或不存在 → 对可证的选项用反证法：假设结论反面成立，用四则运算组合出与已知矛盾的极限 → 核对该推理要求被组合的两个极限均已存在，确认使用方向合法 → 构造两个发散数列，分别实现和不存在而差存在、和存在而差不存在等情形 → 用反例排除其余选项，核对唯一正确项并检查其前提与题设一致 | 前提：题设仅告知两数列极限的局部信息，反证中涉及的极限均存在；坑点：由和的极限存在直接推出各项极限存在，把子列极限当作整个数列极限使用运算法则，对不存在的极限取绝对值或作除法运算 |
| 保号性与严格号退化分支 | 命题涉及极限与不等号的相容性，需保号性推理或收敛速度不匹配的反例 | 改写每个命题为某个辅助数列如作差式或作商式的极限符号问题 → 利用保号性处理欲证真的命题，由辅助数列极限的正负推出充分大之后的不等式 → 检查命题中的严格不等号是否经过取极限操作，识别只能得到非严格结论的常见误推 → 构造收敛速度与题设不等式方向不匹配的反例数列并逐项代入验证 → 确认反例满足题设全部前提条件，才能判定该命题为错误 → 单独验证有界性与极限相容命题中保号性在等号情形的适用边界 | 前提：命题涉及的两个数列极限均存在有限，反例必须满足原命题的全部前提；坑点：极限仅为非负而非严格为正时不能得严格不等式结论，数列极限不存在时子列结论不能冒充整体结论，逐项成立的不等式取极限后不保持严格号 |
| 概念型全称命题反例否定分支 | 选项只以有界、无界或发散为前提断言乘积、和或极限一定成立，需要逐个证伪或证真 | 把每个选项改写成带前提的全称命题，标明前提与结论 → 为待否定命题构造振荡或让两个无界量相互抵消的反例数列 → 核对反例严格满足该前提却不满足结论，据此判该选项错误 → 对候选正确项用局部保号性或绝对值放缩给出正向论证 → 以排除法定唯一选项，并复核前提是否被偷换 | 前提只给有界性、无界性或发散性而未给保号性；反例必须落在前提之内，不可用个别例子肯定全称命题；无界量交替取零会使乘积恒有界 |
| 复合保收敛性与水平渐近线反例分支 | 选项断言外层函数连续或单调有界时，内外层数列收敛性可以互相推出 | 逐条把命题改写成全称形式并标出所需前提与结论方向 → 检查外层函数在内层取值范围上是否连续、是否单调、是否有界 → 对含水平渐近线的外层函数，给出发散内列而收敛外列的反例 → 对连续外层用极限与函数运算可交换断言收敛性保持 → 对单调有界外层用复合保持单调并配单调有界准则断言收敛 → 汇总为真者作为正确选项组合 | 外层须在内层取值范围上连续或单调有界，反例必须落在命题给定的范围内；有水平渐近线时不可由外列收敛反推内列，仅单调而无界不得收敛结论 |
| 存在性四类判据逐项否证分支 | 选项混合给出含分式倒指数的函数式、振荡幂指、交替符号通项与根式和式，需判极限是否存在 | 标注每个选项的极限类型：函数极限还是数列极限，是否幂指形、根式和式或交替符号形 → 对含分式倒指数或绝对值的式子分别求左右两侧极限并检验是否相等 → 对振荡型幂指式取两条都趋于无穷而函数值不同的点列，用子列与函数极限的关系否证存在性 → 检验含交替符号数列通项是否有界，无界即由必要条件直接否定存在 → 对放缩后开 n 次根的和式用主导项与项数构造双侧夹逼，并与常数开 n 次根的基本极限对比求值 → 汇总各选项否证结论，对唯一未被否证者补出正面求值作交叉检验 | 每个选项须可归入左右极限、子列一致性、有界必要条件、夹逼准则四类判据之一；只验一条子列不可断言存在，有界振荡因子不可当定值替换 |

### 失效边界

- **适用前提**：题目落在求极限或判定连续性与间断点这两类应用之内；表达式的结构特征（有无具体式、有无求和、有无递推）足以唯一归类；概念型题目只考存在性判据与极限三条性质的推断；函数为初等式，间断点只能出现在定义边界处；各可疑点的单侧极限可通过基本极限或等价替换算出；两个函数在同一过程中均严格趋于无穷且不变号；运算法则所需的极限存在性得到满足；振荡因子在趋于过程中反复取到零与极值，可构造两类点列；单调增长的幂因子提供无界性来源；题设仅告知两数列极限不存在，无其他附加约束；反证中使用四则运算时涉及的两个极限都存在；所举反例须同时满足全部前提；命题涉及的两个数列极限均存在有限；保号性要求辅助数列的极限严格为正或严格为负；反例必须满足原命题的全部前提；前提只给出有界性、无界性或发散性而未给出保号性；反例必须严格满足该选项的前提；外层函数在内层取值范围上连续或单调有界；反例必须落在命题给定的取值范围内；每个选项都能归入左右极限、子列一致性、有界必要条件、夹逼准则四类存在性判据之一；夹逼放缩所得上下两侧表达式极限存在且相等
- **失效场景**：同一题兼具求和与递推两种特征时，单一分支不充分，必须先化归再选法；只考极限运算法则或等价替换使用条件时，本分类不提供计算手段；倒代换、零代换、三角代换、洛必达等技巧未被四法覆盖，四法之外的情形不能只靠归类定法；概念型题目要求构造反例时，本框架只给判据不给构造方法；把方法清单当作知识点清单使用（未先判类型即套技巧）会选错工具，此时本通法不被执行；振荡型无极限的表达式不能简单归入第一类或第二类；把函数在某点无定义直接等同于第二类间断；只算一侧极限就断定间断类型；无穷大相减或相除直接断言结果类型；无穷小相减时误用有限个无穷小之和仍为无穷小的结论于变号情形；把趋于无穷的速度差异默认当作同阶处理；仅凭存在一个趋于无穷的点列就断定函数为无穷大；把振荡有界因子当作存在极限的常量参与乘积运算；忽略零点列而误判为无界即无穷大；由和的极限存在直接推出各项极限存在；把子列极限当作整个数列极限使用运算法则；对不存在的极限取绝对值或作除法运算；极限仅为非负而非严格为正时不能得严格不等式结论；数列极限不存在时用子列结论冒充整体结论；把逐项成立的不等式在取极限后仍保持严格号；用个别例子去肯定一个全称命题；无界数列相乘时因子交替取零会使乘积恒有界；外层函数有水平渐近线时不能由外列收敛反推内列收敛；仅有单调性而无有界性时收敛性结论不成立；把振荡但有界的因子当作可等价替换的定值处理，从而误判极限存在；数列已无界仍套用极限四则运算法则；只验证一条子列就断言函数极限存在；对幂指式不分底数趋于的情况直接取指数极限

### 标准解题步骤

1. 先算出前有限项的数值，观察相邻项不等号是否交替出现，判断整体单调性是否失效
2. 由原递推式迭代一次推出隔项（步长为 2）的封闭递推关系，把奇数项子列与偶数项子列各自写成独立递推
3. 解不动点方程得到候选极限值，仅作为归纳法的分界常数，不预先假定极限存在
4. 对两个子列分别用数学归纳法证有界：以候选值为界，验证首项落在界的一侧且递推保持该侧
5. 对两个子列分别证单调：作差后通分，提取出恒正的分母与可判号的分子，由首差符号递推得到全部差的统一符号
6. 由单调有界准则得两个子列极限都存在，各自在隔项递推式两端取极限解出同一候选值
7. 用「奇偶子列极限都存在且相等当且仅当原数列极限存在且等于该值」下最终结论

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 隔项作差定号分支 | 隔项递推式作差后能分解为正常数因子乘以低一阶差 | 计算子列相邻两项之差并通分 → 分离出恒正的因子与待判号的差项 → 由首差的符号递推得到全部差的同号性 | 比例因子变号或分母可能为零时无法定号，须改用压缩映射或先缩小取值区间 |
| 候选界反推分支 | 题目未给出界，需要先确定用哪个常数作界 | 解不动点方程得候选值 → 由前若干项落在候选值的哪一侧确定证上界还是下界 → 把候选值作为归纳法的分界点写入归纳假设 | 不动点方程有多个根时须由首项位置选定正确的根，选错会得到方向相反、无法成立的不等式 |
| 压缩映射替代分支 | 子列单调性难以归纳证明，或递推函数在取值区间上导数绝对值一致小于 1 | 写出递推函数并求导 → 在数列取值区间上估计导数绝对值不超过小于 1 的常数 → 用与邻项差成等比的不等式直接夹出极限 | 只能在局部区间得到压缩估计而数列可能跑出该区间时论证不成立；导数绝对值不小于 1 时不可用 |

### 失效边界

- **适用前提**：递推式右端只依赖前一项，且可迭代化为步长为 2 的封闭递推；递推函数在数列取值区间上连续、可导且保号；不动点方程在数列取值范围内有唯一候选根；题目允许使用数学归纳法与单调有界准则
- **失效场景**：奇偶子列极限都存在但不相等：原数列振荡发散，此时按「极限存在」作答必错；子列无界（递推把值推向无穷）时单调有界准则前提不满足，证不出界；先解不动点方程求出候选值，再把「解出 A」当作「极限存在」的证明，属于循环论证；整体不单调却硬对原数列用单调有界，会在单调性一步写出错误的不等式；递推式含前两项及以上（步长不为 1 的高阶递推）时奇偶分列不再封闭，本方法需先化为一阶系统才可用；数列取值跨过递推函数的间断点时，隔项递推的保号性与单调性传递中断

## 望远镜相消闭合首末项通法

| 适用范围 | 通项具有可精确配对相消结构的 n 项和与 n 项连乘积的数列极限，含裂项相消、倍角或平方差链式相消、倒数差分项等形式，不用于只能单侧放缩的情形 |

### 标准解题步骤

1. 识别通项中可配对的差分或共轭结构，选择共轭、倍角或倒数差分作为配对因子
2. 给通项补上配对因子并把因子乘开，写出相邻项逐对相消后的剩余表达式
3. 核对相消方向与指标范围，确认中间项全部精确抵消且未引入新误差
4. 把闭合后的首末项表达式取极限，由末项的趋向定出极限值
5. 检验配对因子本身不改变原式取值（乘除恒等或取对数合法），防止闭合改造失真

## 变限积分奇偶传递通法

> 编号 **T-HS-39-I** ｜ 版本 **v0.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 适用范围 | 判定或证明含变限积分函数的奇偶性，含多层复合与自变量乘子的场合 |
| 学科 / 章节 | 高等数学 · 函数、极限、连续 |
| 表面题型 | 变限积分奇偶性判定 |
| 对应考点 | （一）定义及性质；（四）连续和间断 |
| 覆盖题量 | 1 题（分支 0 个） |

### 标准解题步骤

1. 拆解选项为内层被积函数与外层积分上限两层结构，逐层标注奇偶性
2. 判定内层因子的整体奇偶性，注意自变量乘子本身为奇函数会改变该层奇偶
3. 代换外层积分的变量，把自变量取相反数并翻折积分区间，利用对称区间上奇函数积分为零化简
4. 套用结论检验：奇函数的变限积分为偶函数，偶函数从对称中心出发的变限积分为奇函数
5. 复合后以相反数代入，比较是否恒等于原式，确认必为偶函数的选项
6. 取常值非零偶函数等简单反例，排除只在特殊起点才成立的选项

### 失效边界

- **适用前提**：被积函数在全轴连续且奇偶性明确；各层积分下限为常数或恰为对称中心
- **失效场景**：被积函数非奇非偶或只在部分区间有定义时对称性判据失效；把偶函数在任意起点下的变限积分误认为奇函数；忽略自变量乘子的奇偶性，直接对复合层套用结论
