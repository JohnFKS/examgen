### 标准解题步骤

1. 找出全部反常来源：无穷区间的端点，以及使被积函数无界的内点与端点瑕点
2. 以反常来源为界把积分拆成若干段，保证每段只含一个反常点
3. 在每段内把被积函数等价变形为幂乘对数幂的标准形式，非幂因子用该趋近点处的等价无穷小或无穷大换成幂或对数幂；标准型覆盖不了时先换元（迭代对数、指数、瑕点平移）化回标准型
4. 读出该段的幂指数与对数指数（同档因子相乘时指数相加），并标明该段是趋于零型还是趋于无穷型
5. 套用判别条件：趋于零时幂指数小于一收敛、等于一且对数指数大于一收敛；趋于无穷时幂指数大于一收敛、等于一且对数指数大于一收敛；其余一律发散，无穷端同时验被积函数是否趋于零
6. 各段全部收敛才判定原积分收敛；含参问题时把各段的条件联立取交集，反解参数范围
7. 求值型改为截断区间算原函数：含对数先分部把对数移出微分号，有理式先拆项，再对每个独立趋向分别取极限并把发散项合并成单一比值
8. 参数出现在积分号内整体时先设其为常数对方程两端积分，按参数分情形定阶后再收口

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 多瑕点分段定阶分支 | 积分区间内部或两端同时存在多个使函数无界的点 | 按每个瑕点切分子区间 → 每段以该瑕点为趋近点单独定阶 → 各段结论取交集，任一段发散即整体发散 | 切分不完备（某子段内仍有无界点）时该段结论无效；只在一端定阶会漏掉另一端的发散条件 |
| 含参反解范围分支 | 题目给出收敛或发散的结论，要求参数的取值范围 | 把参数线性组合进幂指数与对数指数 → 按收敛方向列出不等式并判断临界等号能否取 → 对各反常点的不等式取交集 | 幂指数等于一属临界档，此时必须再看对数指数；把临界等号直接写成严格不等式会丢掉或误含边界值 |
| 非幂因子定阶分支 | 被积函数含对数、反三角、指数减一、三角函数等非幂因子 | 在趋近点处把这些因子等价为其主阶幂或对数幂 → 区分对数的幂与自变量的幂，不要互相代入 → 合并各因子指数得到该段的幂指数与对数指数 | 等价式必须在所论趋近点成立（在趋于一处用另一处的等价会算错阶）；因子之间存在加减相消时不能逐项替换 |
| 分段函数积分分支 | 被积函数按区间分段给出，或在分段点处表达式改变 | 把分段点当作潜在瑕点，在其左右两侧分别定阶 → 检查分段点处函数是否有界，有界则该点不产生反常来源 → 合并各段条件 | 分段点处有跳跃但有界时不是瑕点，误当瑕点重复判别会引入多余的条件 |
| 判断积分存在且不为零 | 逐选项找出被积函数在区间内的瑕点与无穷远过程 | 对含瑕点者按瑕点分段，各段单独取极限判敛，任一段发散则整体不存在 → 对无穷限者用比较审敛法定出主部幂次是否够大 → 对存在者检查奇偶性：对称区间上奇函数积分为零 | 〈1〉对称区间；失效：把发散的奇函数积分当成零 |
| 对数因子除以下限趋于零的变限反常积分定极限 | 先用比较判别确认无穷远端积分收敛并固定一个内部分点 | 按该分点把积分拆为变限段与常数段 → 常数段除以发散的对数因子极限为零，予以舍去 → 对变限段与对数因子用洛必达，分子由变限积分求导直接得被积函数端点值 | 无穷端满足收敛判别条件；失效：无穷端不收敛时不能拆出常数段 |
| 反常积分收敛必要条件的级数视角 | 含指数与三角振荡因子的无穷区间反常积分，特别是幂对数标准型覆盖不到、常规做法需大量分类讨论的含参定范围题 | 判断被积函数在无穷端是否属于幂与对数幂的标准档；含指数或振荡因子时改用级数视角 → 求被积函数在无穷端的极限，即把其当作级数的一般项考察 → 该极限不为零或不存在（含振荡不衰减）时，直接断定反常积分发散 → 该极限为零时，进一步用主导衰减因子给出绝对值的可积控制，再判定收敛 | 可用[积分区间为无穷区间，且被积函数在无穷端有确定的极限行为；用于快速排除发散情形，或由必要条件压缩参数范围；与标准型判别互补：标准型管绝对收敛的阶，本法定振荡与指数型的必要门槛] 失效[一般项趋于零只是收敛的必要条件，据此断言收敛是错的（幂对数档中幂指数不大于零的情形即反例），必须补充分支的充分性控制；瑕积分在瑕点处被积函数必趋于无穷，不存在趋于零的必要条件，误用会把发散说成收敛；需要区分条件收敛与绝对收敛时本方法给不出结论，必须回到定义求原函数的极限] |
| 振荡不衰减排除分支 | 被积函数为纯三角函数或振幅不趋于零的振荡式 | 写出振荡因子的振幅包络 → 判断包络是否趋于零 → 包络不趋于零时原函数极限必不存在，判发散 | 振幅趋于零时本必要条件失效，不能反向断言收敛，需另做绝对收敛或狄利克雷型判别 |
| 指数主导定参分支 | 被积函数为指数因子乘有界因子，只需检验无穷端是否趋于零即可排除发散，不需要化成幂乘对数幂标准型 | 由无穷端极限为零解出使指数衰减的参数条件 → 确认有界因子只影响数值不影响敛散性 → 用分部积分或原函数表达式复核收敛值与参数范围 | 参数使指数因子退化为常数一时，衰减条件不再成立，必须回到振荡分支单独讨论 |
| 两项相消型反常积分定参并求值 | 分别写出两项的原函数（对数型与含根式的对数型），合并成单一对数比式 | 对无穷远处的比式按分子分母的净幂次讨论参数三种情形 → 只有参数使比式趋于有限非零常数时极限才存在，据此锁定参数 → 把下限处的对数值单独算出，注意不要漏掉常数项 | 两项各自的原函数可显式写出；失效：把两项分别按发散处理就断言整体发散 |
| 换元化标准型判反常积分敛散性 | 被积函数为幂、对数（含迭代对数）、指数复合的正项反常积分，包括无穷区间积分与瑕积分，以及标准型判不动的变形情形 | 定位全部反常来源：无穷区间的端点，以及使被积函数无界的瑕点（含区间内部的分母零点与对数变号点） → 以反常来源为界把积分拆成若干段，每段只含一个反常点，逐段判别后再取交集下整体结论 → 对每段选换元把趋近过程化为新变量趋于零或趋于无穷：迭代对数型令最外层对数为新变量，指数型令指数为新变量，非原点瑕点令平移量为新变量 → 把换元后的被积表达式整理成幂乘对数幂的标准形式，同步换算微分因子与积分上下限，读出该段的两个阶参数 | 可用[被积函数在每个子段上不变号（正项），可用等价定阶与比较审敛法的极限形式；换元函数在对应区间上单调可导，并把反常点映到零或无穷；各因子在趋近点处有确定的幂阶或对数阶] 失效[被积函数变号或含振荡因子时，标准型判别只回答绝对收敛，判出发散并不代表原积分发散（可能条件收敛）；换元时漏算微分因子的放大量，幂指数会整体错一个单位，边界情形直接判反；一个积分含多个反常来源却只对一处定阶，会漏掉另一处的发散条件] |
| 迭代对数换元分支 | 分母出现逐层嵌套的对数（对数套对数） | 令最外层对数为新变量 → 反解自变量并求出微分因子的指数型放大量 → 验证放大量恰好抵消原来自变量的幂，得到纯新变量的负幂形式 | 要求每层对数在新变量的取值区间内定号且换元单调；瑕点恰落在某层对数变号处时不能整体换元 |
| 指数换元分支 | 含指数因子且必须令指数（或含指数的整体）为新变量，才能把被积式化成幂乘对数幂标准型后判敛 | 令指数为新变量，把指数因子化为新变量的负幂 → 把原来自变量用对数反解，使多项自变量变成对数的幂 → 整理为幂乘对数幂后读阶参数 | 换元后新变量的下限必须仍为正数，原区间含使新变量非正的点时不可用对数反解 |
| 瑕点平移定阶分支 | 瑕点不在零或无穷处，且因子形如对数一加自变量、幂函数一加自变量 | 令平移量把瑕点移到零 → 用一加自变量的等价式把各因子换成幂或对数幂 → 各因子的阶数相加得总幂指数，对数幂单独记账 | 等价替换只能用于乘除因子；平移后括号内出现同阶相减时必须展开到下一阶，否则幂指数定错 |
| 分段与多瑕点分支 | 同一积分两端或内部同时存在多个反常来源 | 按每个反常来源切段 → 每段各自换元定阶并判别 → 全部段收敛才判收敛，任一段发散即判发散 | 只在一端定阶会漏条件；切分不完备（某子段内仍有无界点）时该段结论无效 |
| 含对数除幂的指数差型反常积分参量判敛 | 按参量的正、零、负分情形检查被积式在无穷端是否趋于零 | 不趋于零的情形直接判发散 → 参量为正时用等价无穷小把指数差换成其指数部分 → 对幂次不大于临界值的情形，用对数因子不小于常数放缩成发散界项 | 被积式在无穷区间上不变号；失效：在加减结构上作等价代换 |

### 失效边界

**适用前提**（67 条）

- 被积函数在每个子段上不变号（正项或定号），可用等价定阶与比较审敛法的极限形式

- 反常来源个数为有限个
- 参数不改变各因子的档位归属
- 被积函数在可疑点邻域不变号，可应用比较型审敛法
- 等价主部是幂函数，其指数与临界值可直接比较
- 多个奇点或无穷端已拆开，逐段独立判定
- 积分区间为无穷区间且被积函数在区间内不变号

- 等价代换只用于乘除主部
- 积分区间关于零点对称或可拆成对称部分
- 瑕点位置可确定并可分段处理
- 内部奇点处的奇异阶与分母导数的奇异阶相同
- 分母在该趋向单调发散
- 被积函数在各段不变号且可比较
- 参照幂积分的临界指数已知
- 被积函数为正且可按段主部化简
- 端点处对数主部可线性化
- 有界因子在两段极限非零有限
- 分母在区间内不为零
- 参数只改变幂次而不改变符号
- 待判别的每一段都能直接化成幂乘对数幂的标准型；须先换元才成标准型的交回换元定阶通法，只用无穷端趋零排除发散的交回必要条件通法
- 积分区间为无穷区间，且被积函数在无穷端有确定的极限行为
- 用于快速排除发散情形，或由必要条件压缩参数范围
- 与标准型判别互补：标准型管绝对收敛的阶，本法定振荡与指数型的必要门槛
- 分母在积分区间内恒不为零
- 拆项后各项对数在端点处极限存在
- 无穷端主部符号恒定
- 两项各自的原函数可显式写出
- 无穷远处的比式可归一为主部之比
- 只用于由无穷端极限行为压缩参数的候选范围；收敛侧的充分性必须交标准型定阶或原函数取极限复核，两条件取交集

- 换元函数在对应区间上单调可导，并把反常点映到零或无穷

- 代换在新区间上单调

**失效场景**（79 条）

- 被积函数变号或含振荡因子时，本判别只回答绝对收敛性，判出发散并不代表原积分发散（可能条件收敛）
- 含指数衰减与三角函数混合的类型不属于幂对数标准档，套用阶参数会得错误条件，应改用收敛的必要条件或求出原函数取极限
- 只在一个反常点定阶就下整体结论，会漏掉另一端的发散条件
- 把幂指数与对数指数记反（临界档上尤其容易），会把收敛判成发散或反之
- 等价替换用于加减项或主项相消时定出的幂指数偏大或偏小，导致边界判断错误
- 分母零点位于积分区间内部却未被识别为瑕点，会漏判发散
- 被积函数在瑕点处趋于零（而非无穷）时该点不是瑕点，强行按瑕积分判别会引入不存在的要求
- 被积函数变号时用比较审敛法判绝对收敛以外的结论
- 把双侧无穷区间对称取极限当成收敛，忽略柯西主值与收敛定义的区别
- 在加减相消的结构上只看单项主部，误估真实衰减阶
- 被积函数在无穷远处不趋于零时不能用无穷小等价代换
- 在加减项上做等价代换
- 漏判临界幂相等时的发散情形
- 把发散的奇函数积分当成零
- 只判奇偶而不先判存在性
- 瑕点在区间内部却按常义积分直接求原函数代端点
- 无穷端不收敛时不能拆出常数段
- 变限求导时忽略下限位置带来的负号
- 洛必达后未验证所得比式仍为未定式
- 两段条件只取并集而不是交集
- 被积函数变号时用比较审敛法判绝对收敛之外的敛散性
- 分界等号情形未单独讨论
- 在端点处把对数当常量处理会漏掉瑕点
- 无穷远段只看对数而忽略幂次的决定作用
- 两段条件互相矛盾时未说明整体发散

- 对数比式在无穷端极限误取为零的对数

## 由导数（偏导）信息反求函数通法

> 编号 **T-HS-116-I** ｜ 版本 **v0.4.5** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |

| 核心本质 | 导数（偏导、微分系数）给出的是原函数的全部局部信息：还原靠逐次积分并把每次的积分常数写成另一变量的待定函数（一元时即绝对常数），其可解性正由混合偏导相等这一相容条件保证——含待定参数时相容条件本身就是定参方程；题给的是偏导所满足的等式时，先按求导法则写出偏导并使含未知导数的项整体消去，归成只含一个未知函数（及其单变量导数）的方程再解 |

### 标准解题步骤

1. 把已知的导数或微分关系整理成导数等于已知表达式的形式，自变量为复合整体时先把该整体设成新变量还原成常规导数式
2. 先用混合偏导相等检验相容性，含参时比较分子系数定出参数；判定式是否为某函数的全微分只看这一步
3. 在关系式两端取不定（逐次）积分，右端按凑微分、换元或分部积分积出；多元时先对一个变量积分，把常数写成另一变量的待定函数
4. 对待定函数求导并与另一个偏导（或题给条件）比较，解出待定函数；出现同族待求量时移项解出它等于已知项之和
5. 化到只含一个未知函数及其单变量导数的方程：代数型直接解，常微分方程型按特征方程定通解，未知函数以复合内层出现时先把内层整体作自变量
6. 用题给的定点函数值、定线条件、周期归化后的自变量取值或边界极限定出积分常数
7. 导数按分段表达式给出时各段分别积分并保留各自常数，再由函数在分段点连续把左右两支绑成同一值；需开方还原时按函数在所论区间的正负选定分支
8. 把所得函数与其导数回代原关系式和附加条件双向验证，确认系数与常数同时吻合

### 失效边界

**适用前提**（15 条）

- 所论区间内原函数符号已知或可定
- 右端积分可初等表出
- 被积式在所选分支上连续
- 定点落在该分支内
- 开根时二次因子带绝对值需按分支定号
- 附加条件足以定出全部待定项
- 系数在所讨论区域有一阶连续偏导且分母不为零
- 待定参数线性进入系数比较式
- 给定的两个偏导（微分系数）在所讨论区域有一阶连续偏导；混合偏导相等这一相容性正由本法第2步检验——含待定参数时相容条件本身就是定参方程，不与「相容条件定参分支」互斥
- 与由偏导等式反解未知函数、变量代换化简二阶偏导两法的分工：题给为偏导或全微分的具体表达式（或其定参问题）走本法；题给偏导所满足的等式且未知量是复合内层一元函数走反解法；题给线性变量代换化简偏微分式走代换化简法，化简后回到本法收官
- 题给关于导数或偏导的等式，未知量是函数本身或其中参数
- 化简后能把等式归成只含一个未知函数及其单变量导数的方程：既含「未知导数项整体相消」的代数型，也含化为二阶线性常微分方程的积分型（后者求解按特征方程，转交微分方程通法）
- 与由偏导（全微分）还原函数与定参通法的分工：题给已是偏导或全微分的具体表达式（或由其定参数）走该法，题给偏导所满足的等式且未知量是复合内层的一元函数走本法
- 化简后含未知导数的项可整体消去
- 给定偏导连续且满足混合偏导相等的相容条件

**失效场景**（14 条）

- 开方不加符号判断会丢分支
- 原函数变号处不可导
- 把乘积关系直接当导数关系处理
- 跨分支统一写一个原函数（两分支常数独立）
- 提因子时把平方根写成平方
- 用反余弦形式却不检查分支上的符号差异
- 两个偏导不满足相容条件，这样的函数不存在
- 条件只给在边界曲线上，无法定出待定函数
- 区域带空洞（如去掉原点）时相容条件不再充分
- 表达式根本不是全微分形式
- 条件不足时只能定出某点的值而非整个函数
- 化简后仍归不到只含一个未知函数的方程（未知函数同时跨多个自变量、或以无法分离的算子形式出现）时本法无出口
- 条件只给在某条定线上且不足以定出待定函数时，须改由偏导（全微分）还原函数与定参通法处理
- 等式含未知函数的高阶导数，须先积分还原

### 标准解题步骤

1. 判定被积式所属结构（根式、指数比、幂乘分式、有理式、三角有理式、含反三角或对数）
2. 有理式型：先判假分式并用多项式除法化成整式加真分式，再按分母因式拆成最简分式逐项定系数积分
3. 三角有理式：先用平方关系与倍角降幂做恒等变形，把全部三角量归到同一函数之后再代换
4. 根式型：根内为一次式取根式整体代换有理化，平方加常数用正切代换、平方减常数用正割代换；指数比型把底数比作为新变量、分母化成平方差后用对数形式
5. 高次幂分式：分子分母同除适当幂次，凑出含倒数的微分
6. 含反三角、对数或幂指混合时把其余因子配成一个函数的微分后分部，连续分部使幂因子与导数阶同步下降；展开后重现同族积分就用相反符号相消，或把原积分设为未知量由等式解出
7. 原函数存在性只看被积函数是否连续：分段函数每段各自积分得独立常数，再靠在分段点处连续把左右两支绑成同一常数；有跳跃间断点时原函数不存在，其变限积分仍连续只是该点不可导
8. 回代原变量并按题给定点定出积分常数，最后求导验证与被积式一致

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 主干流程分支 | 多型不定积分基本计算组 | 判定被积式所属结构（指数比、幂乘分式、含反三角或含对数） → 指数比型：把底数比作为新变量，分母化成平方差后用对数形式积分 → 有理式型：先化假分式为真分式，再把分式拆成部分分式并逐定系数 | 被积式可归为上述标准结构；分母因式分解可行 |
| 含一次根式与平方和根式的积分代换路线选择 | 按根号内表达式的次数与形式选定代换类型（根式整体、正切、指数整体） | 代换时同步把微分因子换成新变量的表达式 → 有理化后若为假分式先化真分式，再拆成部分分式逐项积分 → 含指数乘幂的先凑微分做分部积分，把幂因子转移到微分号外 | 代换在讨论区间上单调可逆；有理化后分母次数高于分子或可拆；失效：代换后不回代原变量；根式分支取错导致符号相反 |
| 由复合关系定出抽象函数再积分 | 内层为代数式、三角式或幂函数等非对数非指数整体，令其为新变量后反解原自变量再积分 | 把已知式中的原自变量整体替换，得到新变量处的函数解析式 → 由根式非负的条件确定反函数分支的符号，避免多值歧义 → 把解析式代回目标积分并约去公因子 | 内层函数在所论区间严格单调从而可反解；已知式对全体内层取值一致；失效：内层在区间内不单调时须分段取反函数分支；只给函数方程而无单调信息时解析式不唯一 |
| 对数内层抽象函数的积分 | 内层恰为对数函数（或与之互反的指数整体），令对数内层或整段对数为新变量并反解出原自变量的指数形式 | 把已知式改写成新变量的函数，得到解析式 → 把负指数因子并入微分号，使对数部分成为被求导方 → 对数求导后拆成两项之差，一项直接积分、一项与余下因子约分 | 内层对数函数单调可反解；新解析式的对数项在讨论区间内有定义；失效：忽略原自变量为正的定义域限制；分部时把指数因子同时求导与积分导致重复 |
| 有理式与三角有理式积分通法 | 分母为多项式正幂的有理积分、三角幂与正余组合的分式积分、拆项后同族对数合并 | 判定被积式关于正余的奇偶次数，决定用共轭乘式还是降次 → 分子分母同乘共轭式，把分母化为单角平方 → 同次幂情形用平方和恒等式把分子展开成可拆的若干项 → 每一项化成正切或余切的微分型直接积分 | 可用[变形后各项均为标准微分型；分母在讨论区间不变号；参数不全为零保证分母非零] 失效[不判奇偶次数盲目用万能代换造成繁复；拆项系数配错使两项不再互补；同除因子时忽略了其零点] |
| 三角分母降幂后配指数有理式积分 | 用半角与降幂恒等式把分母幂次改写成单一三角量的平方 | 把分子中的倍角展开为该三角量与其导数的乘积 → 令该三角量为新变量，指数因子随之化简 → 对有理分式拆成两项之差，使两项分别与指数的微分配对 | 分母可降幂为单一三角量的幂；分子含该三角量导数的因子；失效：分母幂次与分子导数阶次不匹配时拆项不相消；在分母零点处未加分段讨论会丢失定义区间 |
| 分部积分降幂与同族抵消通法 | 幂乘指数、对数与反三角的积分，高阶导数乘幂因子的定积分，分部后同族积分相消或回代的计算与证明 | 选定保持在微分号外的复杂因子，把剩余部分凑成某函数的微分 → 分部积分，用该因子的导数与幂因子相乘 → 把产生的有理式分子做加减同项恒等变形拆成可积项 → 各凑微分项积出并与前项合并 | 可用[所选因子的导数比原式更简单；凑微分部分的原函数易写；循环方程的系数不为零] 失效[把应保留的因子放进微分号导致更复杂；循环解出时漏乘系数；恒等变形拆项后遗漏常数项] |
| 未知函数与其高阶导数同现的定积分求值 | 把积分按项拆开，保留含未知函数的那一项不动 | 对含高阶导数的项把该导数写成其原函数的微分 → 分部积分一次，边界项由三角因子取零而消失 → 对新产生的积分再次把函数微分转移到三角因子上 | 函数具有所需阶数的连续导数；三角因子在区间端点取零使边界项消失；失效：边界项不消失时结果仍含未知的导数值；分部次数不够无法产生同型积分 |
| 变限积分曲线与坐标轴围成面积 | 先由被积函数的符号判定曲线在区间上的正负与端点零值，确定面积就是函数本身的定积分 | 把面积写成对变限积分的定积分 → 对外层积分用分部积分，取变限积分为原函数因子，使边界项因端点零值而消失 → 对变限积分按上限求导（链式因子注意上限的导数），得到只含初等函数的积分 | 被积函数连续使变限积分可导；外层积分区间端点处函数值可定（含零点使边界项消失）；失效：曲线在区间内变号时面积须按零点是分块取绝对值，不能直接积分；分部积分的边界项不为零时必须保留而不能略去 |
| 变限积分作因子的定积分 | 把幂因子并入微分号内，使变限积分成为被求导的一方 | 对变限积分按上限求导，上限含复合表达式时必须补乘上限的导数 → 所得新积分的幂次比原外层因子低，按被积函数结构再次凑微分或换元 → 边界项由上限与下限处的取值算出，注意下限处变限积分为零 | （二）求导；被积函数连续保证变限积分可导；失效：被积函数含跳跃间断点时在其处不可求导；上限含参数时需按参数分侧讨论 |
| 指数因子与被积式拆项相消 | 先把被积式按分母幂次拆成两项之差 | 识别指数复合因子的微分形式，把它整体并入微分号 → 对余下因子找出其导数与被积式中另一项的对应关系 → 两项分别分部积分，写出展开后出现的同族积分 | 被积式可拆成含同一指数复合因子的两项；每项都能配成两个微分的乘积；失效：拆项后某项无法配微分时本法断裂；指数内层导数与三角因子不对应时会多出无法抵消的积分 |
| 只给导数时求函数本身的定积分 | 把待定积分分部，使函数被求导、幂因子被积分 | 把导数表达式中的平移量取为整体变量 → 把平移多项式拆成「整体加常数」两项分别积分 → 认出其中一项就是导数在区间上的积分，用牛顿-莱布尼茨换成端点函数值之差并与边界项抵消 | 积分和微分的互逆关系；导数在闭区间可积且已知一点函数值；失效：不知道任一点函数值时边界项无法定值；分部方向弄反会把高阶积分引入 |
| 高阶导数乘幂因子的定积分 | 把高阶导数写成其一阶低导数的微分，幂因子留在外面 | 分部一次，边界项代入区间端点的导数值 → 余下积分再次配微分并分部，边界项代入端点函数值 → 对剩下的定积分作平移换元，使积分区间与已知条件一致 | 函数在区间上有连续的二阶导数；端点处函数值与导数值已知；失效：区间内二阶导不存在时分部不合法；端点值缺失会使边界项无法定值 |
| 变限积分与三角因子的定积分 | 识别三角因子是某函数的微分，把它塞进微分号 | 分部并把边界项按该三角原函数在两端为零写出 → 对变限积分求导得被积函数在上限处的值 → 把所得乘积式凑成单一变量的微分 | （二）求导；被积函数连续；失效：边界项不为零却直接略去；三角因子与变限积分不匹配时分部会引入更高阶积分 |
| 原函数存在性与分段拼接通法 | 原函数与导函数关系的概念判断题、分段函数求原函数、含间断点时被积函数对应的变限积分性态 | 用周期把目标自变量归化到给出导数表达式的区间内 → 去掉绝对值，按分界点把导数写成分段形式 → 各段分别积分得到含各自常数的二次表达式 → 由函数在分界点连续（可导必连续）联立定出相同常数 | 可用[函数在分界点可导从而连续；周期已知且目标点可归化到一个周期内；各段导数表达式可积] 失效[只给连续而不给可导时两侧导数可不相等；分段点两侧常数不匹配导致函数跳跃；周期归化时方向弄反] |
| 被积函数有跳跃间断点时变限积分的连续性与可导性判定 | 判定被积函数在指定点的间断类型 | 确认被积函数在该区间有界且只有有限个第一类间断点，从而可积 → 由可积推出变限积分在整个区间连续 → 分别求变限积分在该点的左右导数，其值即被积函数在该点的左右极限 | 被积函数有界；间断点为第一类；失效：被积函数无界时连续性结论不成立；第二类间断点处不能直接套用左右极限作导数 |
| 分段函数原函数的拼接与常数确定 | 在每段子区间上分别求不定积分，各引入独立常数 | 求分段点处两支的极限值 → 由原函数必连续定出两常数相等，合并为同一常数 → 取该常数为零写出候选表达式 | 被积函数在分段点连续；各支在其开区间内连续；失效：被积函数有跳跃间断时仍强行拼接原函数；两支常数取成不同值 |
| 奇函数原函数的奇偶性与其和式可积可导性判定 | 由原函数定义确认其导数即被积函数，从而原函数必连续 | 用导数与函数奇偶对应关系判定原函数为偶函数 → 检查被积函数是否必连续，构造导函数带振荡间断的反例 → 把和式的两项按奇偶组合，判断整体有无确定奇偶性 | 讨论区间关于原点对称；原函数存在意味着被积函数有原函数而非连续；失效：把可导误当成导函数连续；在非对称区间上判奇偶 |

### 失效边界

**适用前提**（48 条）

- 被积式可归为上述标准结构
- 分母因式分解可行
- 代换在讨论区间上单调可逆
- 有理化后分母次数高于分子或可拆
- 回代时根式取定符号分支
- 内层函数在所论区间严格单调从而可反解
- 已知式对全体内层取值一致
- 内层对数函数单调可反解
- 新解析式的对数项在讨论区间内有定义
- 被积式含根式、指数、幂指或对数等非有理结构，须经代换才把它有理化或化成基本积分；纯有理式与纯三角有理式交回有理式积分通法
- 变形后各项均为标准微分型
- 分母在讨论区间不变号
- 参数不全为零保证分母非零
- 分母可降幂为单一三角量的幂
- 分子含该三角量导数的因子
- 代换后有理式可拆成相消的两项
- 所选因子的导数比原式更简单
- 凑微分部分的原函数易写
- 循环方程的系数不为零
- 函数具有所需阶数的连续导数
- 三角因子在区间端点取零使边界项消失
- 分部次数与导数阶数匹配
- 被积函数连续使变限积分可导
- 外层积分区间端点处函数值可定（含零点使边界项消失）
- 被积函数连续保证变限积分可导
- 外层因子有原函数的幂形式
- 被积式可拆成含同一指数复合因子的两项
- 每项都能配成两个微分的乘积
- 分部后出现的辅助积分同族且符号相反
- 导数在闭区间可积且已知一点函数值
- 平移后的被积式可用幂次凑微分
- 函数在区间上有连续的二阶导数
- 端点处函数值与导数值已知
- 幂因子分部后仍可用同型积分收尾
- 被积函数连续
- 配出的微分因子在两端取零
- 函数在分界点可导从而连续
- 周期已知且目标点可归化到一个周期内
- 各段导数表达式可积
- 被积函数有界
- 间断点为第一类
- 变限积分的下限取在可积区间内
- 被积函数在分段点连续
- 各支在其开区间内连续
- 拼接后表达式在该点可导
- 讨论区间关于原点对称
- 原函数存在意味着被积函数有原函数而非连续
- 和式中至少一项连续

**失效场景**（54 条）

- 未化真分式就套部分分式公式
- 拆项时漏掉某个分母幂次的待定系数
- 分部时把反三角因子积分而不是求导
- 代换后不回代原变量
- 根式分支取错导致符号相反
- 拆项时漏掉微分带来的倍数
- 内层在区间内不单调时须分段取反函数分支
- 只给函数方程而无单调信息时解析式不唯一
- 直接对复合式求导而不先定出解析式
- 忽略原自变量为正的定义域限制
- 分部时把指数因子同时求导与积分导致重复
- 真数可能为负而未加绝对值

| ch3-C-fp-14 | 变限积分与三角因子的定积分 | 把三角因子并入微分号后分部，变限积分被求导直接还原成被积函数，边界项因该三角原函数在两端为零而消失，剩下的积分恰好可凑微分一次积出 |

| ch3-B-mc-05 | 被积函数有跳跃间断点时变限积分的连续性与可导性判定 | 变限积分本身的连续性与可导性由被积函数的可积性而非连续性决定：只要有界且只有有限个第一类间断点就可积，从而变限积分处处连续；而可导性要求被积函数在该点连续，间断点处左右导数分别等于该点被积函数的左右极限，两者不等则不可导 |
| ch3-B-mc-06 | 分段函数原函数的拼接与常数确定 | 分段函数在每段各自求不定积分得两族原函数，各带一个独立常数；原函数必须处处可导从而必先连续，故在分段点令左右两支极限相等即把两常数绑成同一个，剩余的整体常数可任取。跳跃型被积函数不存在原函数，能拼接的唯一原因恰是它本身连续 |
| ch3-C-mc-01 | 奇函数原函数的奇偶性与其和式可积可导性判定 | 奇函数的原函数必为偶函数，且原函数处处可导故必连续；但被积函数本身只要求存在导数、并不要求连续，因此由原函数反推的导函数可以有间断点。判断和式的性质时先分别确定各项的奇偶与连续性，缺失的一项使整体既非奇也非偶，只能靠连续函数必存在原函数这一条保住了存在性 |

### 标准解题步骤

1. 把被积式按加法拆成若干独立项，逐项判定奇偶性，奇项直接归零、偶项折半保留（二重场合对坐标取反与两变量互换分别判）
2. 区间（区域）关于中点、竖直线或对角线对称时，用反射或轮换取平均消掉变号部分，把系数配成只依赖对称组合
3. 含绝对值的项先用奇偶合并化成单侧积分；分段或含参数时先解出使表达式切换的分点（分界曲线），按分块使每段符号固定再分别积分，上限跨分点时分类讨论并在分点处相接
4. 对根式下平方差的结构改用四分之一圆面积读出数值；分式含根式相加者用共轭乘式有理化后拆项
5. 周期因子与整数倍周期区间先化归一个周期，互倒因子用区间平移把带权积分化为无权积分的常数倍
6. 估值与比较型：在同一区间（区域）上排出被积函数的大小链并检查外层变换是否保序，或用积分中值定理把不变号因子整体提出，比值为常数基准时把比较式写成关于区间长度的函数按系数判定
7. 含阶次参数的积分族用分部积分降阶，降次后用平方关系拆回同族两项使待求项在两端重现，解出跨阶递推；相邻项比值再由被积式逐点大小判整列单调，最后用递推系数夹逼收口
8. 化简后的区间（区域）上用基本公式或选定坐标求值并相加，核对倍数、符号与分段处的相接

- 边界项两端等值

- 三角因子具有确定的奇偶性且在正半段定号

### 标准解题步骤

1. 把待证不等式全部移到一侧，定义以积分上限为自变量的辅助函数，其导数由变限积分求导直接得到
2. 对辅助函数求导并合并上限处的同类项，把导数化成可由被积函数单调性或凸性定号的形式，残存的积分项用积分中值定理改写
3. 导数仍不能直接定号时再求一阶导，或乘一个恒正的积分因子把导数写成某乘积的导数，把定号问题逐层下降到已知条件上
4. 由导数定号判定辅助函数单调，再用它在起点取零的条件推出函数在整段上的符号
5. 含权积分先作一到两次分部积分，使边界项由端点条件消零，把带权式改写成无权积分再积分的形式，使逐点下界可被整体积分
6. 比较型（含同域多个二重积分）先按对称性削去奇项并折到对称半区，再在公共内层变量的取值区间上排出初等函数的大小链，检查外层单调方向与因子是否不变号以保证保序
7. 二重证明型用轮换或拆分把积分改写成对称形式，使被积式配成同一变量增减函数之积或差，由逐点符号给出积分的不等方向
8. 估值型先换序化为一元积分，取绝对值把界放到积分号外并算出权重绝对值的积分定出界
9. 把结论翻译回原不等式，核对取等条件与严格号，双边估计的两端分别构造或一次构造后同法收口

| 带权积分与无权积分的定系数比较 | 把待比较的两项移项并按上限变量构造辅助函数 | 求一阶导，合并上限处的同类项 → 再求一阶导，得到导数项与函数项之差 → 用函数在左端点取零的条件把函数项写成中值点导数乘自变量 | 函数具有所需阶数的连续导数；左端点函数值为零才能做中值改写；失效：缺少左端点条件时无法把函数项换成导数项；自变量变号时二阶导定号失效 |
| 端点消零条件下积分等式的两次分部积分证明 | 把原积分的微分变量补写成自变量减左端点的形式，为构造零边界项做准备 | 第一次分部积分，边界项由函数在右端点取零而消失 → 把剩余积分的微分变量再次凑成权因子幂的微分 → 第二次分部积分，边界项由导数在右端点取零而消失 | 函数具有所需阶数的连续导数；端点条件恰好使每次分部产生的边界项为零；失效：端点条件不足时边界项残留需另行估计；凑微分时权因子幂次与导数阶数不匹配 |
| 下凸函数用切线与弦控制定积分平均值的双侧不等式 | 由二阶导数定号判定曲线整体朝上张开 | 写出中点处切线方程并用凸性得到逐点下界 → 对下界两边积分，识别对称区间上一次项积分为零 → 两边除以区间长度得左侧不等式 | 二阶导数在闭区间严格定号保证逐点控制不恒等；函数连续使积分保号；失效：凸向相反时不等号方向同时反转；仅在个别点凸性成立不能保证严格不等号 |
| 用变限积分单调性证积分不等式并求迭代序列极限 | 右端不等式：用单调递减把被积函数整体放大为区间左端点处的函数值，逐点积分后得到上界 | 左端不等式：构造变限积分除以自变量的平均值函数，对其求导并把分子中的积分用中值定理改写成某中间点的函数值乘自变量 → 由导数分子里两个函数值的大小关系与单调性判定导数符号，得到平均值函数的单调方向 → 用平均值函数在区间内外的取值比较，把单调性翻译成带区间长度的下界 | 被积函数连续且严格单调，能把逐点比较积分成整体比较；变限积分作为被积函数出现时可用积分中值定理改写；失效：函数不单调时仍做逐点放缩，不等号方向失控；用极限方程的唯一解直接断言极限存在，跳过单调有界这一步 |
| 上凸函数积分下界的两段式证明 | 把待证不等式两边之差定义为以上限为变量的辅助函数并验起点取零 | 对辅助函数求导，乘积项按求导法则展开并合并 → 把函数值与起点值的差写成中值点导数乘自变量 → 由二阶导定号判定一阶导单调，定出导数差的符号 | 函数具有连续二阶导数使中值定理可用；辅助函数起点取零；失效：中值点与原函数的单调方向判反导致符号错；分部积分时漏掉上限处的边界项 |
| 二重积分不等式比较与证明通法 | 以单调性、连续性与对称条件为前提，证明含二重积分的不等式或估值 | 先用区域的对称性把各积分中的奇项整块削零、并把区域折到对称半区（该动作按对称性与奇偶性化简二重积分通法执行），使待比较的只剩不变号因子 → 找出各被积函数共有的内层变量及其在区域（或对称半区）上的取值区间 → 在该区间写出初等函数之间的大小关系，检查外层函数的单调方向，递减会把不等号反向 → 含奇次幂或坐标变换时先确认该因子在整个区域上不变号，以保证积分保序 | 可用[区域关于直线或坐标轴对称；被积函数含单调因子，可判逐点符号；所给条件是积分值或导数上界而非具体解析式] 失效[单调方向与因子差积符号相反时硬套结论；区域不对称仍用轮换等价；先取绝对值再放缩时丢掉原式已有的抵消，界变松] |
| 同域被积函数排链比较分支 | 已按对称性削去对称区上的奇项并折到对称半区，各被积函数仍是同一内层变量的初等函数、该变量在半区上落在同一单调区间，只需排出大小链再积分 | 在该区间写出初等函数之间的大小关系 → 检查外层函数单调方向，递减会把不等号反向 → 把不等式整体在同一区域上积分 | 各被积函数定义在同一区域且可积；内层变量在整个区域落在同一单调区间；失效：内层变量跨出单调区间，大小顺序反转；被积函数变号时乘幂改变大小方向 |

### 失效边界

**适用前提**（29 条）

- 被积函数连续保证上限函数可导
- 积分因子恒正不改不等号方向
- 起点条件给出确定取值
- 被积函数连续且单调方向明确
- 积分区间长度非负使中值定理适用
- 辅助函数在起点取零
- 函数具有所需阶数的连续导数
- 左端点函数值为零才能做中值改写
- 自变量非负保证乘因子不改号
- 端点条件恰好使每次分部产生的边界项为零
- 左端点处权因子幂为零使下边界项自动消失
- 二阶导数在闭区间严格定号保证逐点控制不恒等
- 函数连续使积分保号
- 取中点切线时区间关于该点对称
- 被积函数连续且严格单调，能把逐点比较积分成整体比较
- 变限积分作为被积函数出现时可用积分中值定理改写
- 递推由积分算子给出且该算子把区间映进自身
- 函数具有连续二阶导数使中值定理可用
- 辅助函数起点取零
- 权因子在区间内符号可判
- 待证不等式移项后可写成以积分上限为自变量的辅助函数，且其导数能由被积函数的单调性或凸性定号；只比数值大小而无上限变量的走估值定号法
- 区域关于直线或坐标轴对称
- 被积函数含单调因子，可判逐点符号
- 所给条件是积分值或导数上界而非具体解析式
- 各被积函数定义在同一区域且可积
- 内层变量在整个区域落在同一单调区间
- 只要求大小关系而不要求具体值
- 与对称性与奇偶性化简二重积分通法的分工：需要先拆奇偶项或折到对称半区才能排出大小链的，拆项与折半按该法执行，本法只负责不变号因子之间的大小链、积分保序以及证明与估值的收口
- 与定积分对称周期化简与分块计算通法的分工：结论本身是不等式或大小排序（含估值、比较选择题、积分不等式证明）归本法；以算出定（二重）积分的具体值为目标、途中用奇偶与周期化简归该法，本法第6步的削奇项与折半沿用该法的对称判据

**失效场景**（27 条）

- 把被积函数与其积分的变量混淆
- 乘因子时漏掉指数导数
- 在未证正号前直接比大小
- 函数不单调时两点差无法定号
- 中值点位置写错导致不等号反向
- 固定因子未随上限联动改写使求导多出项
- 缺少左端点条件时无法把函数项换成导数项
- 自变量变号时二阶导定号失效
- 只证到一阶导非负就断言原函数定号
- 端点条件不足时边界项残留需另行估计
- 凑微分时权因子幂次与导数阶数不匹配
- 常数系数在两次分部中重复乘或漏乘
- 凸向相反时不等号方向同时反转
- 仅在个别点凸性成立不能保证严格不等号
- 用非中点切线时一次项不为零需补充估计
- 函数不单调时仍做逐点放缩，不等号方向失控
- 用极限方程的唯一解直接断言极限存在，跳过单调有界这一步
- 端点处不等式取等条件与严格单调性混淆，写成严格号失效
- 中值点与原函数的单调方向判反导致符号错
- 分部积分时漏掉上限处的边界项
- 把待证式两边同除变号量
- 单调方向与因子差积符号相反时硬套结论
- 区域不对称仍用轮换等价
- 先取绝对值再放缩时丢掉原式已有的抵消，界变松
- 内层变量跨出单调区间，大小顺序反转
- 被积函数变号时乘幂改变大小方向
- 只能取到非严格不等式却选严格结论

### 标准解题步骤

1. 先定对象所属微元类型（体积、侧面积、弧长、平面面积、功、压力、引力、质心与转动惯量）与所给曲线的表示形式（直角、参数、极坐标）
2. 定旋转轴与区域的相对位置：轴不穿过区域时按同侧单值处理，轴穿过区域或区域有空心部分时必须分段并作内外半径平方之差
3. 选切片方向：圆盘（垫圈）法沿旋转轴积分，半径取微元点到轴的垂直距离；柱壳法垂直于轴积分；平面面积选使每条边界都单值的切片方向，并用对称性压缩区间再乘倍数
4. 把半径与高度用同一积分变量表出，需要时反解曲线方程或由函数值与导数值相等解出切点、交点以定出积分限
5. 写出微元并积分：圆盘为圆周率乘半径平方乘厚度，柱壳为二倍圆周率乘半径乘高度乘厚度，绕不相交水平直线改用补形作两大体积之差，曲面面积换成二倍圆周率乘到轴距离乘弧长微元
6. 弧长按切向量模长乘参数微分写；极坐标下取极径平方加极径导数平方开根乘角度微分，根内配方成完全平方后必须带绝对值并靠对称性缩到定号区间
7. 物理量按微元＝密度或强度×几何微元×距离因子写：功乘该微元被提升的行程、侧压力乘水平薄条面积、引力只保留沿对称轴的分量、质心是加权一阶矩除以总质量
8. 规则区域优先直读矩：由对称性读形心坐标并算面积，一阶矩等于面积乘形心坐标，二阶矩按到定点距离平方加权转极坐标幂积分，旋转体体积用面积乘形心轨迹周长快求
9. 参数曲线与极坐标曲线先化成以参数或极角为自变量的两支坐标再代入微元，同步换算微分因子与上下限，最后核查圆周率因子、对称倍数与绕非坐标轴时的半径平移

- 各段形状相同仅相差平移

- 根式在该段非负

- 区域边界连续且可由两条曲线夹成
- 反函数存在（曲线在所论区间严格单调）
- 交点为重根时函数在该点不变号，仍属同一段
- 函数在每段内连续
- 面积取正向为上

- 积分区间取在半径平方非负处
- 对称倍数与所取区间不重叠
- 曲线关于两坐轴均对称
- 半径平方表达式为三角偶次幂之和
- 偶次幂在对称段上积分相等
- 分段点在极限过程中自然产生且函数在该点连续
- 旋转轴与区域不相交

- 分部积分时把对数幂升而不是降

- 圆支选错一侧造成半径差符号错
- 对竖直轴误用圆盘法
- 段间重叠区域重复累加
- 等比公差不小于一时级数发散

- 用直角坐标公式时上下分支需拆段而漏拆

- 取整圈角度造成重复计数
- 纵坐标误写成极径而漏正弦因子
- 约去极径时其变号未加绝对值
- 改用圆盘法时反函数多分支未拆分
- 上下边界大小判反导致体积为负
- 真分式拆分时漏掉多项式部分
- 代换时把上下限方向漏翻
- 周期段倍数折半时算错段数
- 和式缺步长因子却直接当定积分
- 轴穿过区域时内外半径反转需分段
- 把圆盘微元当圆环微元漏掉内半径
- 对称倍数与所取半段不一致造成重复
- 直接把极径当半径套圆盘公式，漏掉横坐标微分带来的雅可比因子
- 角度区间取得过宽，使同一旋转截面被重复计入或出现负体积
- 在加减项上做等价代换化简三角幂
- 仍用绕横轴的公式切片，混淆旋转轴与积分变量
- 反解时丢开分支或漏改取值范围，使积分区间与图形不符
- 做功时把力臂取成该层高度本身而非到液面的距离，符号与量级都错
- 曲线经过极点时参数化不再一一覆盖，需分段计弧长
- 被开方式不能配方去根号时本法只能化为数值积分

- 被积函数在区间端点无界时全长需取极限，可能发散
- 上限含参数时求导漏乘上限导数
- 去根号不判符号会把异号区间的答案算错
- 两种参数化都写不出显式导数时本法失效，需改用参数方程弧长公式
- 配不出完全平方时弧长积分通常不可初等表出
- 区间内含导数不存在点须分段
- 开根时直接去绝对值导致结果错误
- 整段角度直接积分造成重复
- 倍数与缩半后的区间不匹配
- 参数跨零区间直接开根
- 求导时漏用角度对参数的链式导数
- 倒数项积分写成幂函数形式
- 试图先算出积分再求弧长
- 代换后未换上下限
- 开根时漏绝对值导致定号错误
- 曲线非单调时交点不唯一需分段
- 以高度为变量时反函数分支处理错误
- 只求驻点不与端点值比较
- 区域上下边界交叉时必须分块而不能取一次积分
- 含分段函数边界时先定分界点再谈单值性
- 无界区域不属于本法（需按反常积分判敛散）
- 不判号直接对整个区间积分
- 把不变号的重复交点也当作分段点取负号
- 展开多项式时符号项写错

- 正切代换后上下限未同步改写
- 把导数直接对极径或极角单独求

### 标准解题步骤

1. 提取统一步长与通项结构，把通项改写成分点比（归一化下标）的函数凑成标准黎曼和形式；双重和先确认前置因子恰为分割数平方的倒数，不足时先做代数变形
2. 确认等分分割与取点方式满足可积条件（被积函数在闭区间（闭区域）连续），由分点范围定出积分上下限或两个积分区间
3. 把所得定积分的区间平移到关于零点对称，判断被积函数在新变量下的奇偶性，奇函数时积分为零
4. 检查被积函数能否分离为单变量函数之积，可分离时拆成两个一元定积分相乘，不可分离时逐层累次积分
5. 分母逐项不同或含参数量级时，用一对可显式积分的函数做上下界夹住，两侧化为同一黎曼和再取极限
6. 与被积函数不可判奇偶或无界的情形比较，必要时改按分块积分核算，不跨段合并

### 失效边界

**适用前提**（19 条）

- 和式通项是分点比的连续函数
- 步长与分点区间匹配
- 被积函数在区间上可积
- 拆开的两路极限各自存在
- 夹逼的两界极限相同
- 对数黎曼和的分点严格等距且函数连续
- 曲线在区间上半径非负且连续
- 区域由极径扫过且不自交
- 分点均匀
- 各分子同号且分母一致趋于同一阶
- 分点函数连续可积
- 和式为等距分点且首项偏移可忽略
- 被积函数在积分区间内单调可积
- 拆分点取在使两段各只含一种奇异的方便位置
- 和式通项是归一化下标的连续函数
- 被积函数在闭区域连续从而可积
- 把通项各因子逐一整理后，能提出恰为分割数平方倒数（1/n²）的公共前置因子，且剩余通项只依赖 i/n、j/n 这类归一化下标；提出前先做代数变形属本法的正常入口，不是失效情形
- 区间平移判奇偶只在化出的定积分区间可平移成关于零点对称时启用（属条件步）：单位正方形上的双重和、区间 [0,t] 上的和式等不做此步，直接进分离与累次积分
- 与二重积分区域表示与定序建系通法的分工：本法负责从和式结构认出定（二重）积分并定出积分区间与步长因子，认成累次积分之后的换序、降元、选坐标系与拆块交该法

**失效场景**（18 条）

- 步长不均匀时不能直接归为定积分定义
- 分点跨越被积函数奇点时须按反常积分处理
- 平移后未同步改上下限
- 两路合并后再取极限造成相互干扰
- 夹逼界式取错分母端点
- 把非等距和式当定积分定义
- 漏掉扇形面积中的二分之一因子
- 分点取成左端点却与选项不一致
- 把角度增量写成区间总长
- 分子变号时放缩方向会反转
- 放大缩小系数极限不同则夹逼失败
- 未验证步长与区间匹配就代定积分
- 把非等距和式直接当定积分定义
- 根式代换后未同步换上下限
- 忽略下限奇点而直接代端点
- 前置因子阶数不匹配，未先做代数变形就套定义
- 通项含下标耦合且写不成归一化变量的函数
- 被积函数无界时把黎曼和极限当成普通二重积分
