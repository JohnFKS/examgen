### 标准解题步骤

1. 找出全部反常来源：无穷区间的端点，以及使被积函数无界的内点与端点瑕点
2. 以反常来源为界把积分拆成若干段，保证每段只含一个反常点
3. 在每段内把被积函数等价变形为幂乘对数幂的标准形式，非幂因子用该趋近点处的等价无穷小或无穷大换成幂或对数幂
4. 读出该段的幂指数与对数指数（同档因子相乘时指数相加），并标明该段是趋于零型还是趋于无穷型
5. 套用判别条件：趋于零时幂指数小于一收敛、幂指数等于一且对数指数大于一收敛；趋于无穷时幂指数大于一收敛、幂指数等于一且对数指数大于一收敛；其余一律发散
6. 各段全部收敛才判定原积分收敛；含参问题时把各段的条件联立取交集，反解参数范围

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 多瑕点分段定阶分支 | 积分区间内部或两端同时存在多个使函数无界的点 | 按每个瑕点切分子区间 → 每段以该瑕点为趋近点单独定阶 → 各段结论取交集，任一段发散即整体发散 | 切分不完备（某子段内仍有无界点）时该段结论无效；只在一端定阶会漏掉另一端的发散条件 |
| 含参反解范围分支 | 题目给出收敛或发散的结论，要求参数的取值范围 | 把参数线性组合进幂指数与对数指数 → 按收敛方向列出不等式并判断临界等号能否取 → 对各反常点的不等式取交集 | 幂指数等于一属临界档，此时必须再看对数指数；把临界等号直接写成严格不等式会丢掉或误含边界值 |
| 非幂因子定阶分支 | 被积函数含对数、反三角、指数减一、三角函数等非幂因子 | 在趋近点处把这些因子等价为其主阶幂或对数幂 → 区分对数的幂与自变量的幂，不要互相代入 → 合并各因子指数得到该段的幂指数与对数指数 | 等价式必须在所论趋近点成立（在趋于一处用另一处的等价会算错阶）；因子之间存在加减相消时不能逐项替换 |
| 分段函数积分分支 | 被积函数按区间分段给出，或在分段点处表达式改变 | 把分段点当作潜在瑕点，在其左右两侧分别定阶 → 检查分段点处函数是否有界，有界则该点不产生反常来源 → 合并各段条件 | 分段点处有跳跃但有界时不是瑕点，误当瑕点重复判别会引入多余的条件 |
| 判断积分存在且不为零 | 逐选项找出被积函数在区间内的瑕点与无穷远过程 | 对含瑕点者按瑕点分段，各段单独取极限判敛，任一段发散则整体不存在 → 对无穷限者用比较审敛法定出主部幂次是否够大 → 对存在者检查奇偶性：对称区间上奇函数积分为零 | 〈1〉对称区间；失效：把发散的奇函数积分当成零 |
| 对数因子除以下限趋于零的变限反常积分定极限 | 先用比较判别确认无穷远端积分收敛并固定一个内部分点 | 按该分点把积分拆为变限段与常数段 → 常数段除以发散的对数因子极限为零，予以舍去 → 对变限段与对数因子用洛必达，分子由变限积分求导直接得被积函数端点值 | 无穷端满足收敛判别条件；失效：无穷端不收敛时不能拆出常数段 |

### 失效边界

- **适用前提**：被积函数在每个子段上不变号（正项或定号），可用等价定阶与比较审敛法的极限形式；各因子在趋近点处有确定的幂阶或对数阶；反常来源个数为有限个；参数不改变各因子的档位归属；被积函数在可疑点邻域不变号，可应用比较型审敛法；等价主部是幂函数，其指数与临界值可直接比较；多个奇点或无穷端已拆开，逐段独立判定；积分区间为无穷区间且被积函数在区间内不变号；差式在无穷远处确为无穷小；等价代换只用于乘除主部；积分区间关于零点对称或可拆成对称部分；瑕点位置可确定并可分段处理；内部奇点处的奇异阶与分母导数的奇异阶相同；分母在该趋向单调发散；被积函数在各段不变号且可比较；参照幂积分的临界指数已知；被积函数为正且可按段主部化简；端点处对数主部可线性化；有界因子在两段极限非零有限；分母在区间内不为零；参数只改变幂次而不改变符号；待判别的每一段都能直接化成幂乘对数幂的标准型；须先换元才成标准型的交回换元定阶通法，只用无穷端趋零排除发散的交回必要条件通法
- **失效场景**：被积函数变号或含振荡因子时，本判别只回答绝对收敛性，判出发散并不代表原积分发散（可能条件收敛）；含指数衰减与三角函数混合的类型不属于幂对数标准档，套用阶参数会得错误条件，应改用收敛的必要条件或求出原函数取极限；只在一个反常点定阶就下整体结论，会漏掉另一端的发散条件；把幂指数与对数指数记反（临界档上尤其容易），会把收敛判成发散或反之；等价替换用于加减项或主项相消时定出的幂指数偏大或偏小，导致边界判断错误；分母零点位于积分区间内部却未被识别为瑕点，会漏判发散；被积函数在瑕点处趋于零（而非无穷）时该点不是瑕点，强行按瑕积分判别会引入不存在的要求；被积函数变号时用比较审敛法判绝对收敛以外的结论；把双侧无穷区间对称取极限当成收敛，忽略柯西主值与收敛定义的区别；在加减相消的结构上只看单项主部，误估真实衰减阶；被积函数在无穷远处不趋于零时不能用无穷小等价代换；在加减项上做等价代换；漏判临界幂相等时的发散情形；把发散的奇函数积分当成零；只判奇偶而不先判存在性；瑕点在区间内部却按常义积分直接求原函数代端点；无穷端不收敛时不能拆出常数段；变限求导时忽略下限位置带来的负号；洛必达后未验证所得比式仍为未定式；两段条件只取并集而不是交集；被积函数变号时用比较审敛法判绝对收敛之外的敛散性；分界等号情形未单独讨论；在端点处把对数当常量处理会漏掉瑕点；无穷远段只看对数而忽略幂次的决定作用；两段条件互相矛盾时未说明整体发散；有界因子在某段趋于零或无穷时不能剥离；分母变号使被积函数变号而无法用正项比较审敛；只看无穷远段而漏掉原点段

## 反常积分收敛必要条件的级数视角

> 编号 **T-HS-07-S** ｜ 版本 **v0.2.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 把无穷区间上的反常积分看作连续型的无穷级数，被积函数在无穷端不趋于零则积分必发散，趋于零时再靠主导衰减因子控制判收敛 |
| 适用范围 | 含指数与三角振荡因子的无穷区间反常积分，特别是幂对数标准型覆盖不到、常规做法需大量分类讨论的含参定范围题 |
| 学科 / 章节 | 高等数学 · 一元函数积分学及其应用 |
| 表面题型 | 指数乘三角型积分；振荡型反常积分；含参反常积分定范围；快速判发散；由反常积分收敛反推被积式中的未知系数；两项相消型反常积分定参并求值 |
| 对应考点 | 反常积分的敛散性；无穷级数收敛的必要条件；含参反常积分；比较审敛法；（九）反常判敛散；反常积分；（一）无穷区间；（七）有理函数积分；（二）积分公式；牛顿-莱布尼茨公式 |
| 覆盖题量 | 2 题（分支 3 个） |

### 标准解题步骤

1. 判断被积函数在无穷端是否属于幂与对数幂的标准档；含指数或振荡因子时改用级数视角
2. 求被积函数在无穷端的极限，即把其当作级数的一般项考察
3. 该极限不为零或不存在（含振荡不衰减）时，直接断定反常积分发散
4. 该极限为零时，进一步用主导衰减因子给出绝对值的可积控制，再判定收敛
5. 把「极限为零」解出的参数条件作为候选范围，并用原函数表达式取上限极限复核，排除只满足必要条件的多余取值

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 振荡不衰减排除分支 | 被积函数为纯三角函数或振幅不趋于零的振荡式 | 写出振荡因子的振幅包络 → 判断包络是否趋于零 → 包络不趋于零时原函数极限必不存在，判发散 | 振幅趋于零时本必要条件失效，不能反向断言收敛，需另做绝对收敛或狄利克雷型判别 |
| 指数主导定参分支 | 被积函数为指数因子乘有界因子，只需检验无穷端是否趋于零即可排除发散，不需要化成幂乘对数幂标准型 | 由无穷端极限为零解出使指数衰减的参数条件 → 确认有界因子只影响数值不影响敛散性 → 用分部积分或原函数表达式复核收敛值与参数范围 | 参数使指数因子退化为常数一时，衰减条件不再成立，必须回到振荡分支单独讨论 |
| 两项相消型反常积分定参并求值 | 分别写出两项的原函数（对数型与含根式的对数型），合并成单一对数比式 | 对无穷远处的比式按分子分母的净幂次讨论参数三种情形 → 只有参数使比式趋于有限非零常数时极限才存在，据此锁定参数 → 把下限处的对数值单独算出，注意不要漏掉常数项 | 两项各自的原函数可显式写出；失效：把两项分别按发散处理就断言整体发散 |

### 失效边界

- **适用前提**：积分区间为无穷区间，且被积函数在无穷端有确定的极限行为；用于快速排除发散情形，或由必要条件压缩参数范围；与标准型判别互补：标准型管绝对收敛的阶，本法定振荡与指数型的必要门槛；分母在积分区间内恒不为零；拆项后各项对数在端点处极限存在；无穷端主部符号恒定；两项各自的原函数可显式写出；无穷远处的比式可归一为主部之比；只用于由无穷端极限行为压缩参数的候选范围；收敛侧的充分性必须交标准型定阶或原函数取极限复核，两条件取交集
- **失效场景**：一般项趋于零只是收敛的必要条件，据此断言收敛是错的（幂对数档中幂指数不大于零的情形即反例），必须补充分支的充分性控制；瑕积分在瑕点处被积函数必趋于无穷，不存在趋于零的必要条件，误用会把发散说成收敛；需要区分条件收敛与绝对收敛时本方法给不出结论，必须回到定义求原函数的极限；含两个以上参数时，仅由必要条件得到的范围偏大，不复核充分性会给出错误答案；被积函数在无穷端无极限（振幅发散振荡）时，只能判发散，不能进一步给出收敛侧的任何信息；同次项系数不为零时仍按收敛计算；对数比式在无穷端极限误取为零的对数；拆项时漏掉常数倍因子；把两项分别按发散处理就断言整体发散；参数取其它值时比式趋于零或无穷却仍写对数；对数比值取极限时漏掉下限贡献

### 典型例题

| 题号 | 表面题型 | 本质要点 |

| seed | 纯三角函数在无穷区间上的积分 | 振幅不趋于零，原函数极限不存在，判发散（振荡不衰减排除分支） |
| ch3-B-mc-17 | 由反常积分收敛反推被积式中的未知系数 | 分式分子分母同次时先通分合并，再看其无穷远主部幂次：若分子最高次项系数不为零则被积式与自变量倒数为同阶，积分必发散，故收敛条件先强行令该系数为零；剩下真分式用部分分式拆开，积成对数比式后在无穷端取极限，由给定积分值解出系数 |
| ch3-C-mc-22 | 两项相消型反常积分定参并求值 | 两个各自发散而差可能收敛的项组成的积分，其收敛取决于参数使两项在无穷远处的主部相消到可积阶；先把两项都积出并把常数并入对数比值的极限，再要求该比值趋于有限非零常数定出参数 |

## 换元化标准型判反常积分敛散性

> 编号 **T-HS-08-S** ｜ 版本 **v0.2.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 看似不能用幂对数标准型判别的反常积分，经迭代对数、指数或瑕点平移换元后都化回标准型，敛散性只由阶与趋近方向决定 |
| 适用范围 | 被积函数为幂、对数（含迭代对数）、指数复合的正项反常积分，包括无穷区间积分与瑕积分，以及标准型判不动的变形情形 |
| 学科 / 章节 | 高等数学 · 一元函数积分学及其应用 |
| 表面题型 | 多层对数型反常积分；指数乘幂型反常积分；瑕点非原点的瑕积分；含参反常积分定范围；两端瑕点积分；含对数除幂的指数差型反常积分参量判敛 |
| 对应考点 | 反常积分的概念与敛散性；无限区间上的反常积分；瑕积分；比较审敛法的极限形式；定积分换元法；（九）反常判敛散；反常积分；（一）无穷区间 |
| 覆盖题量 | 1 题（分支 5 个） |

### 标准解题步骤

1. 定位全部反常来源：无穷区间的端点，以及使被积函数无界的瑕点（含区间内部的分母零点与对数变号点）
2. 以反常来源为界把积分拆成若干段，每段只含一个反常点，逐段判别后再取交集下整体结论
3. 对每段选换元把趋近过程化为新变量趋于零或趋于无穷：迭代对数型令最外层对数为新变量，指数型令指数为新变量，非原点瑕点令平移量为新变量
4. 把换元后的被积表达式整理成幂乘对数幂的标准形式，同步换算微分因子与积分上下限，读出该段的两个阶参数
5. 按趋近方向套用判别条件：趋于零时幂指数小于一收敛，幂指数等于一对数指数大于一收敛；趋于无穷时幂指数大于一收敛，等于一对数指数大于一收敛；其余发散
6. 含参数时把阶参数满足的不等式回代为原参数的范围，并对各段条件取交集

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 迭代对数换元分支 | 分母出现逐层嵌套的对数（对数套对数） | 令最外层对数为新变量 → 反解自变量并求出微分因子的指数型放大量 → 验证放大量恰好抵消原来自变量的幂，得到纯新变量的负幂形式 → 按新变量的幂指数判边界 | 要求每层对数在新变量的取值区间内定号且换元单调；瑕点恰落在某层对数变号处时不能整体换元 |
| 指数换元分支 | 含指数因子且必须令指数（或含指数的整体）为新变量，才能把被积式化成幂乘对数幂标准型后判敛 | 令指数为新变量，把指数因子化为新变量的负幂 → 把原来自变量用对数反解，使多项自变量变成对数的幂 → 整理为幂乘对数幂后读阶参数 | 换元后新变量的下限必须仍为正数，原区间含使新变量非正的点时不可用对数反解 |
| 瑕点平移定阶分支 | 瑕点不在零或无穷处，且因子形如对数一加自变量、幂函数一加自变量 | 令平移量把瑕点移到零 → 用一加自变量的等价式把各因子换成幂或对数幂 → 各因子的阶数相加得总幂指数，对数幂单独记账 | 等价替换只能用于乘除因子；平移后括号内出现同阶相减时必须展开到下一阶，否则幂指数定错 |
| 分段与多瑕点分支 | 同一积分两端或内部同时存在多个反常来源 | 按每个反常来源切段 → 每段各自换元定阶并判别 → 全部段收敛才判收敛，任一段发散即判发散 | 只在一端定阶会漏条件；切分不完备（某子段内仍有无界点）时该段结论无效 |
| 含对数除幂的指数差型反常积分参量判敛 | 按参量的正、零、负分情形检查被积式在无穷端是否趋于零 | 不趋于零的情形直接判发散 → 参量为正时用等价无穷小把指数差换成其指数部分 → 对幂次不大于临界值的情形，用对数因子不小于常数放缩成发散界项 | 被积式在无穷区间上不变号；失效：在加减结构上作等价代换 |

### 失效边界

- **适用前提**：被积函数在每个子段上不变号（正项），可用等价定阶与比较审敛法的极限形式；换元函数在对应区间上单调可导，并把反常点映到零或无穷；各因子在趋近点处有确定的幂阶或对数阶；被积式在无穷区间上不变号；等价代换只用于乘除因子；比较界项本身敛散性已知；被积式在原变量下读不出幂乘对数幂的阶，必须经换元把趋近过程归到新变量的零或无穷端后才可定阶
- **失效场景**：被积函数变号或含振荡因子时，标准型判别只回答绝对收敛，判出发散并不代表原积分发散（可能条件收敛）；换元时漏算微分因子的放大量，幂指数会整体错一个单位，边界情形直接判反；一个积分含多个反常来源却只对一处定阶，会漏掉另一处的发散条件；幂指数等于一且对数指数等于一是发散而非收敛，临界档记反是最高频错误；瑕点处分子分母同阶相消时，按剩余因子定阶会误判收敛或发散；换元把非反常点变成新的无界点（或反之）而未重新识别，段划分失效；被积函数含参数且参数改变阶归属（如指数为零）时，必须先按参数分类再套标准型；在加减结构上作等价代换；把对数当幂次使用临界结论；参量为零时仍用等价无穷小

| 题号 | 表面题型 | 本质要点 |
| --- | --- | --- |
| seed | 分母含自变量、对数与嵌套对数幂的无穷积分 | 迭代对数换元化为纯负幂形式，由幂指数与一的关系判别（迭代对数换元分支） |

### 标准解题步骤

1. 把已知的导数或微分关系整理成导数等于已知表达式的形式，自变量为复合整体时先把该整体设成新变量还原成常规导数式
2. 在关系式两端取不定积分，右端按凑微分、换元或分部积分积出，出现同族待求量时移项解出它等于已知项之和
3. 用题给的定点函数值、周期归化后的自变量取值或边界极限定出积分常数
4. 导数按分段表达式给出时各段分别积分并保留各自常数，再由函数在分段点连续把左右两支常数绑成同一值
5. 关系式需开方还原时按函数在所论区间的正负选定分支，必要时用分段表达式分别写出
6. 把所得函数代回原关系式与定点条件双向验证，确认导数值与初值同时吻合

## 不定积分换元选路与回代通法

> 编号 **T-HS-117-I** ｜ 版本 **v0.2.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

### 标准解题步骤

1. 判定被积式所属结构（指数比、幂乘分式、含反三角或含对数）
2. 指数比型：把底数比作为新变量，分母化成平方差后用对数形式积分
3. 有理式型：先化假分式为真分式，再把分式拆成部分分式并逐定系数
4. 高次幂分式：分子分母同除适当幂次，凑出含倒数的微分
5. 反三角或对数因子：把其余因子配成一个函数的微分后分部，余下积分继续拆项

| ch3-C-mc-01 | 奇函数原函数的奇偶性与其和式可积可导性判定 | 奇函数的原函数必为偶函数，且原函数处处可导故必连续；但被积函数本身只要求存在导数、并不要求连续，因此由原函数反推的导函数可以有间断点。判断和式的性质时先分别确定各项的奇偶与连续性，缺失的一项使整体既非奇也非偶，只能靠连续函数必存在原函数这一条保住了存在性 |

### 标准解题步骤

1. 判定被积式关于正余的奇偶次数，决定用共轭乘式还是降次
2. 分子分母同乘共轭式，把分母化为单角平方
3. 同次幂情形用平方和恒等式把分子展开成可拆的若干项
4. 每一项化成正切或余切的微分型直接积分
5. 一次组合情形拆成母式与其导数之和，分别得自变量项与对数项
6. 二倍角与单角混合时先用倍角公式展开、提公因子后凑微分

## 分部积分降幂与同族抵消通法

### 标准解题步骤

1. 选定保持在微分号外的复杂因子，把剩余部分凑成某函数的微分
2. 分部积分，用该因子的导数与幂因子相乘
3. 把产生的有理式分子做加减同项恒等变形拆成可积项
4. 各凑微分项积出并与前项合并
5. 若原积分再次出现，移项解出它等于已知项之和
6. 对分母为平方的情形先把该平方凑成倒数微分再转移

### 标准解题步骤

1. 把被积式按加法拆成若干独立项
2. 逐项判定奇偶性，奇项直接归零、偶项折半保留
3. 含绝对值的项先用奇偶合并化成单侧积分
4. 对根式下平方差的结构改用四分之一圆面积读出数值
5. 分式含根式相加者用共轭乘式有理化后拆项
6. 折半后的区间上用基本公式求值并相加

### 标准解题步骤

1. 解出使分段表达式切换的所有分点（含参数与变号点）
2. 按分点把积分区间拆成若干段，每段写出确定的表达式
3. 各段分别求原函数并代本段上下限
4. 变上限情形按上限与分点的相对位置分类，写出分段结果
5. 含参数的绝对值用分部积分并让分点充当积分上界
6. 开根得到的绝对值按内部表达式的正负再拆一次段后合并

### 失效边界

- **适用前提**：分段点有限且可解出；各段表达式在其段内连续；变上限结果在各段衔接处连续；被积函数的另一因子在区间内定号；分界点随参数单调移动；分段表达式在接点处连续；被积函数关于积分变量单调，使绝对值能按同一分界点一次性去掉；分界点落在积分区间内部，两段拆分互不重叠且覆盖整段；求导后函数值项恰好抵消，导数符号由一个易判定的因子决定；变号点位置与上限成固定比例，拆点不随参量变动；被积三角因子连续；各项幂次与分母同阶
- **失效场景**：跨过零点仍用单一表达式积分；把参数当积分变量求导；开根时直接去掉绝对值；不去绝对值直接求导；拆段后上下限写反；把不可导接点当驻点处理；分界点在积分区间之外时仍强行拆段，得到分段错误的表达式；对变限积分求导时漏掉上下限对参变量的依赖因子；只找驻点而不检验两侧符号，把极值当成最值；直接对绝对值求导；分段后漏掉某段的边界项；对不同阶的项合并后再作等价代换

## 反常积分计算与定参通法

> 编号 **T-HS-127-I** ｜ 版本 **v0.3.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 反常积分求值必须回到截断区间算原函数再对每个独立趋向分别取极限；含对数先分部把对数移出微分号，有理式先拆项并把各发散项合并成单一比值再取极限，被积式含参数时按参数分情形定阶，参数出现在积分号内整体时先设其为常数对方程两端积分 |
| 适用范围 | 无穷区间与瑕积分的求值、由积分值反解参数或系数、两项各自发散而差收敛的积分、含参积分的连续性与可导性 |
| 学科 / 章节 | 高等数学 · 一元函数积分学及其应用 |
| 表面题型 | 分段积分和式的极限化为反常积分并计算；指数分式与带绝对值根式的反常积分及瑕积分计算；含参有理函数无穷区间反常积分的值反定参数；幂指极限等于反常积分定参数；无穷区间三角积分借分部化归已知值；同时对数型与有理型因子的无穷区间反常积分求值；含根式幂与对数差的无穷区间反常积分求值；两项同阶瑕积分相减的定积分求值；被积式中含整体积分常数的积分方程求该常数；含参无界区域面积的无穷区间反常积分与参数最值 |
| 对应考点 | 性质；反常积分；换元法（注意回代）；（一）无穷区间；（九）反常判敛散；（二）积分公式；凑微分法；（七）有理函数积分；步骤二：拆分真分式；（三）计算方法；解题连招；（二）计算方法；微分积分应用专题 |
| 覆盖题量 | 10 题（分支 10 个） |

### 标准解题步骤

1. 定出全部反常来源：无穷区间端点与使被积式无界的瑕点，以其为界把积分拆成每段只含一种奇异的若干段
2. 对每段先按常义积分求原函数：含对数先分部把对数移到微分号外，有理式先拆成真分式差，含根式先把根式整体作新变量并同步改上下限
3. 把每段写成截断区间上的差式，对每个独立趋向分别取极限，不把两个发散端分别代入后再相减
4. 多个对数或反导数项彼此相消时先用对数运算法则合并成单一比值的对数，再对趋向取极限
5. 被积式含参数时按参数的正、零、负分情形定阶，把各段极限存在条件联立取交集反解参数范围
6. 由积分值等于给定常数解出参数后回代，检验参数未使分母在积分区间内出现零点

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 主干流程分支 | 分段积分和式的极限化为反常积分并计算 | 用定积分对区间的可加性把和式合并成单个长区间积分 → 令段数趋于无穷，把结果写成无穷区间上的反常积分 → 按根号为零的位置把积分拆成两段，使每段只含一种奇异 → 用根式整体作新变量代换，同步改写上下限并算出微分 | 各段积分连续可加且被积函数在段内不变号；代换在新区间上单调；两端极限均存在 |
| 指数分式与带绝对值根式的反常积分及瑕积分计算 | 把分母中随自变量增减与递减的指数项提出公共常数因子 | 分子分母同乘使分母成为平方加一形式的因子，凑出反正切型微分 → 在新变量下取上下限，代端点求反正切差并乘回常数因子 → 对绝对值型积分先解出内部表达式的零点并按其拆分区间 | 拆分点取在绝对值变号处；配方后常数项为正才能用反正弦公式，为负的平方在前时用对数公式；失效：绝对值零点不拆段直接积分；瑕点两侧符号判断弄反 |
| 含参有理函数无穷区间反常积分的值反定参数 | 把常数参数提到分母外，将分式拆成倒数因子与剩余因子的差，验证拆分后分子恰好抵消 | 对含幂次因子的第二项凑微分，把分母的导数配进微分号内 → 两项都积分成对数形式，写出带参的原函数 → 用对数运算法则把差式合并为一个比值的对数，避免分别代入发散端 | 分母为不同因子的乘积且分子次数低于分母，属可拆的真分式；拆分系数唯一确定，各项各自可积；失效：假分式未先做多项式除法就直接拆项；把两个发散的对数项分别代入无穷端，误用无穷减无穷 |
| 幂指极限等于反常积分定参数 | 把幂指式的底数写成一带分式结构，取指数凑出标准极限形 | 由标准极限定出左侧值为指数的指数函数 → 对右侧反常积分分部，把幂因子降次并保留同族指数因子 → 上下限代入时先检验无穷远处的边界项为零 | 反常积分收敛且可分部闭合；幂指式的底趋于正数；失效：无穷远处边界项不为零时不能略去；把指数因子也参与约分而忽略其随参数变化 |
| 无穷区间三角积分借分部化归已知值 | 把分母的幂写成倒数因子的微分 | 分部并逐项检查两端边界项的极限为零 → 用倍角恒等式把分子合并成单一三角量 → 对积分作伸缩代换并同步改写上下限 | 参照积分收敛且值已知；边界项在两端的极限都为零；失效：边界项非零时不能略去；参照积分本身条件收敛时随意换序会改变结论 |
| 同时对数型与有理型因子的无穷区间反常积分求值 | 把分母中的幂因子凑成某简单函数的微分，提出负号完成凑微分 | 分部积分转移对数，产生新的有理被积式 → 将新有理式拆成倒式与一次分式之差并积出对数形式 → 整理出统一的原函数，对上下两端各自的趋向分别求极限后相减 | 分部积分后剩余积分可积；两端极限各自存在（积分收敛）；失效：在未确认收敛前直接代入端点；凑微分时漏掉幂次带来的常数因子 |
| 含根式幂与对数差的无穷区间反常积分求值 | 把积分写成截断区间上的极限形式 | 按对数差拆成两个截断积分 → 对每个积分用根式幂凑微分做分部积分，转移对数 → 对分部后产生的根式有理积分做根式代换化为反正切型基本积分 | 两项发散速度同阶因而差式收敛；根式代换后分母恒正；失效：分别求值时把发散的常数项丢掉；未验证单项分部产生的积分仍收敛 |
| 两项同阶瑕积分相减的定积分求值 | 识别对数平方型分式可由对数倒数的微分直接积分 | 另一项按幂型反导写出简单分式原函数 → 在同一上限代入原函数差，下限侧写成趋于奇点的极限 → 把该极限通分为零比零型并用洛必达定出有限值 | 两项在同一位置有相同阶的奇异性；合并后的极限存在有限值；失效：两项奇点阶不同则相消失败、积分发散；分别取极限后再相减（各为无穷无意义） |

| 含参无界区域面积的无穷区间反常积分与参数最值 | 把区域面积写成从下限到正无穷的定积分，识别被积函数中对数幂与倒数因子的配对关系 | 用凑微分把倒数因子并入微分号内，积分变量改为对数整体 → 对新变量写出幂函数原函数，按幂次不为零的情形给表达式 → 在正无穷端判断幂函数的极限是否消失，由此确定反常积分收敛的参数范围 | 积分区间为无穷区间且被积函数在区间内不变号；被积函数含某整体的导数因子，可凑成新变量的幂函数；失效：幂指数恰为零时仍套用幂函数原函数，导致原函数形式失效；忽略收敛条件，把发散端当成有限值代入 |

### 失效边界

- **适用前提**：各段积分连续可加且被积函数在段内不变号；代换在新区间上单调；两端极限均存在；拆分点取在绝对值变号处；配方后常数项为正才能用反正弦公式，为负的平方在前时用对数公式；瑕点处的极限存在；分母为不同因子的乘积且分子次数低于分母，属可拆的真分式；拆分系数唯一确定，各项各自可积；参数保证分母在积分区间上不变号且无零点；反常积分收敛且可分部闭合；幂指式的底趋于正数；参数在两侧的函数形式可比较；参照积分收敛且值已知；边界项在两端的极限都为零；被积函数在无穷远处可积；分部积分后剩余积分可积；两端极限各自存在（积分收敛）；取极限过程相互独立需分别求；两项发散速度同阶因而差式收敛；根式代换后分母恒正；截断上限统一取同一变量便于合并抵消；两项在同一位置有相同阶的奇异性；合并后的极限存在有限值；区间内部无其他奇点；原积分收敛保证可提出为常数；拆项后各积分在无穷端收敛；方程系数不为零；积分区间为无穷区间且被积函数在区间内不变号；被积函数含某整体的导数因子，可凑成新变量的幂函数；参数只出现在幂指数与一次因子中，使驻点方程可解；题目要求算出反常积分的值、由积分值反解参数，或含整体积分常数的积分方程；只问敛散性与参数范围的交回定阶判别与必要条件两法
- **失效场景**：不拆段直接对整个区间用同一上下限；代换后漏掉微分带来的因子；无穷端反正切取错分支；绝对值零点不拆段直接积分；瑕点两侧符号判断弄反；无穷端反正切取值用错分支；假分式未先做多项式除法就直接拆项；把两个发散的对数项分别代入无穷端，误用无穷减无穷；参数取值使分母在区间内有零点，反常积分变为瑕积分而未察觉；无穷远处边界项不为零时不能略去；把指数因子也参与约分而忽略其随参数变化；标准极限的内层未归一就直接代值；边界项非零时不能略去；参照积分本身条件收敛时随意换序会改变结论；未判敛散就直接作代换；在未确认收敛前直接代入端点；凑微分时漏掉幂次带来的常数因子；对数型极限未判趋于零就保留；分别求值时把发散的常数项丢掉；未验证单项分部产生的积分仍收敛；代换后漏掉雅可比因子；两项奇点阶不同则相消失败、积分发散；分别取极限后再相减（各为无穷无意义）；洛必达时分子分母求导不匹配；未验收敛就把积分当常数提出；拆项后某项发散却仍参与合并；方程系数为零时仍强行求解；幂指数恰为零时仍套用幂函数原函数，导致原函数形式失效；忽略收敛条件，把发散端当成有限值代入；把分式函数直接求导后误把极小当极大，不做两侧符号判定

### 标准解题步骤

1. 把待比较或待定号的量统一写成同区间上的积分差式或同一基准的倍数形式，必要时先作伸缩换元对齐两段区间长度
2. 在被积函数层面作逐点比较：用单调性、凹凸性、经典不等式或分子分母的同号放缩定出被积式之间的大小
3. 对逐点不等式两端在同一区间积分，用积分保号性与线性性把点态关系升级为积分关系，注意外层函数单调方向是否改变不等号
4. 需要数值范围时找一对可显式积分的上下界函数分别积出再取极限，或把分母整体放大缩小得到可积的界
5. 被积式含不变号因子时用积分中值定理把该因子整体提出，化成函数在某中间点取值乘区间长度
6. 与端点值、平均值或梯形值比较时写出弦与切线的表达式并积分，识别一次项在对称区间上归零，最后把各关系串成完整排序

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 主干流程分支 | 由单调性与凸性比较积分值、端点值与梯形平均值 | 由一阶导定号写出函数与端点值的逐点大小关系 → 对该逐点不等式在单位区间积分，得积分与该矩形面积的关系 → 由二阶导定号判定曲线朝上张开，写出其在端点弦下方的逐点估计 → 对弦的表达式积分，其值即梯形面积也就是两端点平均值 | 导数定号在整个区间成立；区间长度为一时矩形面积恰为端点值；凸向决定弦在曲线上方还是下方 |
| 凹函数在半段区间与全段区间上积分值的大小比较 | 对区间较短一侧的积分做伸缩换元，把积分限拉伸到与另一侧一致，同时补出换元的常数因子 | 把换元后的被积函数改写成中点形式，使自变量与端点值的平均出现在函数符号内 → 用凹函数的中点不等式把中点函数值向上放缩为两端函数值的平均 → 代入已知端点处函数值为零的条件，使放缩式中只剩待比较的积分 | 函数在闭区间上为凹函数，中点不等式方向明确；两段区间成整数倍关系，可用伸缩换元对齐；失效：函数为凸函数时仍沿用凹函数的放缩方向，不等号反向；试图用被积函数的逐点大小比较替代中点不等式，条件不足 |
| 定积分平均值 | 写出平均值定义：积分总量除以区间长度 | 观察被积函数结构，含根式平方差时先作三角代换并把上下限同步换成新变量 → 代换后用降幂恒等式把偶次幂三角积分化成可直接积分的形式 → 算出定积分值，再除以原区间长度并化简 | 被积函数在所论闭区间可积；区间长度不为零；失效：区间长度为零时定义失效；加权平均需另给权重函数，不能直接除区间长度 |

| 同底同高梯形与曲边梯形面积比的上界估计 | 由曲线方程读出左右两条竖边在区间端点处的高度 | 按梯形面积公式写出直边图形的面积表达式 → 把曲边图形面积写成同区间上曲线函数的定积分并积出 → 两式相除，约去公共的长度因子 | 曲线单调使曲边图形确为梯形变体；被积函数为幂函数可直接求原函数；失效：曲线在区间内变号时面积需取绝对值分段；把曲边图形误用梯形公式代替 |
| 复合三角积分与常数基准值的大小比较 | 确定内层函数在该区间的取值范围与其单调方向 | 用内层函数不超过自变量的经典不等式定出外层复合的逐点关系 → 把逐点不等式在区间上积分，注意外层函数单调方向决定不等号 → 对参照式求原函数并代端点，验其值恰为基准常数 | 内层值域落在外层函数单调段内；逐点不等式在该区间严格成立；失效：内层值域跨出外层单调段时放缩方向不定；单调递减却用递增方向的放缩 |
| 同区间上三个含对数与反正切因子的定积分比大小 | 先估计公共因子在该区间上的取值范围，判断其是否落在零到一之间 | 用该范围内开方变大的一致性比较出两式的被积函数大小 → 对无统一不等号的一对作差，构造差式辅助函数 → 对辅助函数求导并通分，用分子各项定号判定导数非负 | 三式积分区间相同；被积函数连续可积；失效：跨区间比较时直接比被积函数；在加减项上做放缩 |
| 分子异号因子与分母幂型混比的定积分大小判定 | 比较两个分母在同一自变量下的大小，定出同分子两式的顺序 | 对待定的两式作差，合并为同分母的分式差 → 按分子中正负因子的变号点把区间拆成两段 → 对其中一段做关于区间中点的反射代换，同步换上下限与微分符号 | 分子在区间内恰有一个变号点且该点为区间等分点；分母单调且恒正；失效：变号点不在中点时反射后无法对齐；分母变号时不能直接比大小 |
| 由被积函数单调凸性判定其变限积分与平均值的关系 | 对变限积分求导，由题设定出其导数与二阶导数的符号 | 判定该函数单调增且朝上张开，并记录其起点取零 → 写出连接起点与右端点的弦所在直线方程 → 用凸性得到函数在弦上方的逐点不等式 | 被积函数连续且定号，二阶可导；弦连接的两个端点函数值已知关系；失效：凸向相反时逐点不等号方向反转；把变限积分与被积函数的大小关系混用 |
| 极限式化归导数后求平均值 | 把极限式拆成差商因子与三角因子，分别归为导数定义与等价无穷小 | 由原函数关系求导定出被积函数的显式表达 → 写出平均值定义：积分除以区间长度 → 对含导数因子的积分配微分并分部，边界项代端点函数值 | 函数在讨论区间可导；增量趋于零的方向与区间相容；失效：把差商的分母与三角因子的阶配错；函数仅在开区间可导却在端点直接用导数 |
| 幂因子定积分极限的证明 | 在积分区间上找出被积函数的上下界，界要可显式积分 | 对不等式两边同取定积分，用单调性保序 → 算出界的积分并取其极限 → 由夹逼准则定出原积分的极限 | 被积函数在闭区间可积且幂因子在区间上有界；用作中值定理时另一因子不变号且连续；失效：放缩方向弄反会给出错误界；不变号条件不满足时不能套积分中值定理 |

### 失效边界

### 标准解题步骤

1. 把待证不等式全部移到一侧，定义以积分上限为自变量的辅助函数，其导数由变限积分求导直接得到
2. 对辅助函数求导并合并上限处的同类项，把导数化成可由被积函数单调性或凸性定号的形式，残存的积分项用积分中值定理改写
3. 导数仍不能直接定号时再求一阶导，或乘一个恒正的积分因子把导数写成某乘积的导数，把定号问题逐层下降到已知条件上
4. 由导数定号判定辅助函数单调，再用它在起点取零的条件推出函数在整段上的符号
5. 含权积分先作一到两次分部积分，使边界项由端点条件消零，把带权式改写成无权积分再积分的形式，使逐点下界可被整体积分
6. 把辅助函数在右端点的取值翻译回原不等式，核对取等条件与严格号，双边估计的两端分别构造或一次构造后同法收口

### 标准解题步骤

1. 先定旋转轴与区域的相对位置：轴不穿过区域时按同侧单值处理，轴穿过区域或区域有空心部分时必须分段并作内外半径平方之差
2. 选切片方向：圆盘（垫圈）法沿旋转轴积分，半径取微元点到轴的垂直距离；柱壳法垂直于轴积分，半径取到轴的距离、高度取上下边界之差
3. 把半径与高度用同一积分变量表出，需要时反解曲线方程或由函数值与导数值相等解出切点、交点以定出积分限
4. 写出微元并积分：圆盘为圆周率乘半径平方乘厚度，柱壳为二倍圆周率乘半径乘高度乘厚度，绕不相交水平直线改用补形作两大体积之差
5. 求曲面面积时把微元换成二倍圆周率乘到轴距离乘弧长微元，弧长微元按参数式或极坐标式写成根式
6. 参数曲线与极坐标曲线先化成以参数或极角为自变量的两支坐标再代入微元，同步换算微分因子与上下限，最后核查圆周率因子、对称倍数与绕非坐标轴时的半径平移

| 反函数表示的图形绕纵轴旋转体积与抽水做功 | 曲线可反解为横坐标关于纵坐标的函数，只求绕纵轴的旋转体体积或侧面积（同一几何量后续抽水做功归物理微元法） | 用绕纵轴的圆盘公式列体积，被积函数为横坐标平方乘纵坐标微分 → 反解后横坐标平方恰好是某个简单函数，体积积分化为对反三角函数的积分 → 把反三角函数放进微分号外，选幂函数部分凑微分，用分部积分降掉反三角因子 | 曲线在给定区间上单调，能全局反解为纵坐标的函数；旋转轴为纵轴或平行于纵轴的直线，切片方向垂直于旋转轴；失效：仍用绕横轴的公式切片，混淆旋转轴与积分变量；反解时丢开分支或漏改取值范围，使积分区间与图形不符 |

## 曲线弧长计算通法

> 编号 **T-HS-143-I** ｜ 版本 **v0.2.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

### 标准解题步骤

1. 按参数化写出切向量模长：极坐标下为根号内径向分量与角向分量平方和
2. 把根式内的公因式提出，用三角恒等式把被开方式化成完全平方
3. 去根号时按被开方式在参数区间上的符号决定是否加绝对值
4. 对化简后的偶次幂三角积分作变量替换（上下限同步），用降幂公式求值

| 分支 | 触发特征 | 追加操作 | 适用前提 |

| 变限积分定义曲线的弧长 | 先由被积函数的存在范围定出曲线的定义区间，即全长的积分上下限 | 对变限积分求导得纵坐标导数（不需算出原函数） → 代入直角坐标弧长公式，把根号内合并为单一三角表达式 → 用半角恒等式把被开方式写成完全平方后去根号，按区间内符号取正 | 被积函数在所论区间连续，故变限积分可导；由变限积分给出的曲线只需导数而不需原函数；失效：被积函数在区间端点无界时全长需取极限，可能发散；上限含参数时求导漏乘上限导数 |

| 心形线全长的极坐标弧长计算 | 写出极坐标弧长微元的一般式 | 代入半径及其导数并用平方关系化简根号内表达式 → 用半角公式把和式写成某半角三角函数的平方 → 开根后保留绝对值，并利用图形对称性把积分缩到定号区间 | 曲线关于极轴对称且全长可折半计算；所选区间内半角函数定号；失效：开根时直接去绝对值导致结果错误；整段角度直接积分造成重复 |
| 以极径为参数的隐式曲线弧长 | 极角由极径的函数隐式给出，目标是弧长：把极径当参数代入极坐标参数式后按参数积分求长度 | 分别对参数求导，平方相加并用平方和关系消去三角项 → 展开根号内式子，配成两项和的完全平方形式 → 在参数为正且单调的区间上开根去绝对值 | 参数在给定区间恒正保证开根符号确定；角度函数在该区间可导；失效：参数跨零区间直接开根；求导时漏用角度对参数的链式导数 |
| 由变限积分定义的曲线求全长 | 把积分中被积函数的整体自变量作代换，同步改上下限 | 对等式两边关于自变量求导，由变限积分求导得导数表达式 → 由根号内非负定出曲线有定义的自变量范围作为积分限 → 写弧长微元并代入导数，化为平方和开根形式 | 被积函数连续保证求导合法；代换单调可逆以便换算上下限；失效：试图先算出积分再求弧长；代换后未换上下限 |

### 失效边界

- **适用前提**：曲线由极坐标方程给出且参数区间明确；半径与导数在区间上连续；被开方式可化成完全平方；被积函数在所论区间连续，故变限积分可导；由变限积分给出的曲线只需导数而不需原函数；曲线以横坐标为纵坐标的函数给出，在该区间单值；被开方式可配成完全平方；导数在所论区间连续；曲线关于极轴对称且全长可折半计算；所选区间内半角函数定号；半径与导数连续；参数在给定区间恒正保证开根符号确定；角度函数在该区间可导；两支坐标平方和消角后仅剩参数表达式；被积函数连续保证求导合法；代换单调可逆以便换算上下限；根式在该段非负
- **失效场景**：曲线经过极点时参数化不再一一覆盖，需分段计弧长；被开方式不能配方去根号时本法只能化为数值积分；只给角度范围却要求整条闭合曲线长度时需自行补全周期；被积函数在区间端点无界时全长需取极限，可能发散；上限含参数时求导漏乘上限导数；去根号不判符号会把异号区间的答案算错；两种参数化都写不出显式导数时本法失效，需改用参数方程弧长公式；配不出完全平方时弧长积分通常不可初等表出；区间内含导数不存在点须分段；开根时直接去绝对值导致结果错误；整段角度直接积分造成重复；倍数与缩半后的区间不匹配；参数跨零区间直接开根；求导时漏用角度对参数的链式导数；倒数项积分写成幂函数形式；试图先算出积分再求弧长；代换后未换上下限；开根时漏绝对值导致定号错误

## 平面图形面积计算通法

> 编号 **T-HS-146-I** ｜ 版本 **v0.3.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

### 标准解题步骤

1. 解出全部边界两两交点（极坐标下解极径相等得交点角），按交点把积分区间分段并逐段判定上下或左右位置关系
2. 比较两种切片方向各自需要分块的数量，选使每条边界都单值且分块最少的方向；反函数出现多分支时改选另一方向
3. 直角坐标下写成上边界减下边界（或右减左）的定积分，极坐标下写成二分之一极径平方乘角度微分的曲边扇形微元
4. 用关于坐标轴或极轴的对称性把积分区间缩到定号的半段或单叶，并乘回正确倍数，核对倍数与所取区间不重叠
5. 各段分别积出后取绝对值相加；边界由分段表达式或无穷极限给出时，先写出分段解析式再逐段积分
6. 边界随参数变动（分割线、切点、公共部分）时把面积表成该参数的函数，求导解驻点并与区间两端值比较取所需最值

## 物理微元法通法

> 编号 **T-HS-153-I** ｜ 版本 **v0.3.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 连续体的物理量一律先取微元写成密度或强度乘几何微元、再乘一个距离因子：做功是力乘该微元被提升的行程，侧压力是压强乘水平薄条面积，引力只保留沿对称轴的分量，质心是加权一阶矩除以总质量，最后对变量沿整体区间积分 |
| 适用范围 | 抽水与提升做功、液体侧压力、杆与质点引力、变密度细棒质心、变速运动的路程与平均速度 |
| 学科 / 章节 | 高等数学 · 一元函数积分学及其应用 |
| 表面题型 | 变密度细棒的质心；变速直线运动的路程与平均速度；横放椭圆柱形容器储液的体积、液面下降速率与抽出做功；密度与液体相等的球体提出液面所需做功；同一三角形薄板两种朝向入水时侧压力之比；均匀杆对质点的万有引力与移到无穷远克服引力做功 |

| 覆盖题量 | 6 题（分支 6 个） |

### 标准解题步骤

1. 确定所求量的密度或强度函数（线密度、压强、引力强度、功的元素），取一个几何微元写成密度或强度乘几何微元
2. 给该微元乘上距离因子：做功取微元被提升或移动的行程，侧压力取压强乘水平薄条面积，引力只保留沿对称轴的分量而抵消横向分量
3. 把全部因子统一成同一变量的函数，由变量的实际变化范围与液面、轴、端点位置定出积分上下限
4. 沿整体区间积分得总量，积分区间跨越分段点或密度切换点时按段分别积分再相加
5. 求质心与形心时按加权一阶矩除以零阶矩（总质量或总面积）写出比值，并与几何位置核对量纲与所在区间一致
6. 最后用极限情形与对称性检验结果：空区间给零、对称轴上给零点、常数密度给几何中心

### 失效边界

- **适用前提**：密度函数在区间上可积且总质量非零；所求为沿轴的一维质心；速度非负使路程等于位移大小；无穷时段积分收敛（指数压制幂次）；容器轴线水平且截面沿长度不变；液体不可压缩使体积与液位单调对应；行程按各薄层初始位置分别计算；物体密度与液体相等使水下段合力为零；各薄层被提升的行程随其深度线性变化；截面为圆盘且半径随高度变化；液体静止且压强与深度成正比；薄条宽度由边界直线方程线性给出；板的整个高度范围内厚度均匀；杆为均匀细杆，可用线密度乘长度微元表示质量分布；质点位于杆的中垂线上，使对称性足以消去横向分量；力沿位移方向共线，做功可写成力对位置的反常积分；微元必须再乘一个距离或力臂因子（提升行程、液面深度、沿轴分量）才能得到所求量；不带距离因子的体积与面积归几何应用通法
- **失效场景**：总质量为零时定义失效；二维或三维需改用面积元或体积元与相应矩；密度符号变化时不能直接取加权平均；速度变号时路程须取绝对值分块；分部一次就停会留下未闭合的积分；代换后上下限未同步改；把所有薄层行程统一取最大行程；换元时三角限范围取错导致半宽符号反；把对称区间上的奇次项误算为非零；把整体行程当作每片的行程；截面半径用成球半径而漏高度依赖；忽略液面以上部分才计重力；薄条宽度写成常数；深度坐标原点取错位置；两种朝向的坐标方向混用同一表达式；把整根杆的质量集中在某一点套质点公式，忽略距离随微元变化；直接对矢量分量前的系数积分而不做方向投影，得出错误的合力大小；无穷区间上的力积分未验证被积函数衰减够快便直接代入上限

### 标准解题步骤

1. 把和式中的通项改写成分点比的函数
2. 提取统一步长，由分点范围定出积分上下限
3. 把所得定积分的区间平移到关于零点对称
4. 判断被积函数在新变量下的奇偶性，奇函数时积分为零
5. 与被积函数不可判奇偶的情形比较，必要时改按分块积分核算

| 分支 | 触发特征 | 追加操作 | 适用前提 |

| 主干流程分支 | 对数和式极限化为定积分 | 把和式中的通项改写成分点比的函数 → 提取统一步长，由分点范围定出积分上下限 → 把所得定积分的区间平移到关于零点对称 → 判断被积函数在新变量下的奇偶性，奇函数时积分为零 | 和式通项是分点比的连续函数；步长与分点区间匹配；被积函数在区间上可积 |

### 失效边界

- **适用前提**：和式通项是分点比的连续函数；步长与分点区间匹配；被积函数在区间上可积；拆开的两路极限各自存在；夹逼的两界极限相同；对数黎曼和的分点严格等距且函数连续；曲线在区间上半径非负且连续；区域由极径扫过且不自交；分点均匀；各分子同号且分母一致趋于同一阶；分点函数连续可积；和式为等距分点且首项偏移可忽略；被积函数在积分区间内单调可积；拆分点取在使两段各只含一种奇异的方便位置
- **失效场景**：步长不均匀时不能直接归为定积分定义；分点跨越被积函数奇点时须按反常积分处理；平移后未同步改上下限；两路合并后再取极限造成相互干扰；夹逼界式取错分母端点；把非等距和式当定积分定义；漏掉扇形面积中的二分之一因子；分点取成左端点却与选项不一致；把角度增量写成区间总长；分子变号时放缩方向会反转；放大缩小系数极限不同则夹逼失败；未验证步长与区间匹配就代定积分；把非等距和式直接当定积分定义；根式代换后未同步换上下限；忽略下限奇点而直接代端点

## 积分递推与比值极限通法

> 编号 **T-HS-195-I** ｜ 版本 **v0.2.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

### 标准解题步骤

1. 取一个三角因子与权因子一起凑成微分做分部积分
2. 验边界项在两端同时为零而消失
3. 对新出现的积分用平方关系把高次幂拆成同族两项之差
4. 把待求项移到等式一端解出跨阶比例系数
5. 第二问用同区间上幂次的逐点大小判整列单调递减并有正下界
6. 用递推关系把比值夹在趋于单位的两个界之间，由夹逼取极限

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |

| 主干流程分支 | 带一次权三角幂积分的降阶递推及相邻项比值极限 | 取一个三角因子与权因子一起凑成微分做分部积分 → 验边界项在两端同时为零而消失 → 对新出现的积分用平方关系把高次幂拆成同族两项之差 → 把待求项移到等式一端解出跨阶比例系数 | 幂次为不小于二的整数保证拆分与边界项消失；权因子在端点取零或三角幂取零；各项积分同号便于作比 |

- **适用前提**：幂次为不小于二的整数保证拆分与边界项消失；权因子在端点取零或三角幂取零；各项积分同号便于作比；幂次为非负整数使递推可迭代；幂因子在奇点端足以压制对数增长；首项积分易算；分母为不可约二次式的正整数幂；递推系数中参数不为零；分子次数低于分母次数；幂次为非负整数保证递推可用；分部积分的边界项在两端同时为零；代换后的区间与体积式积分区间一致；积分族带阶次参数且相邻项之间可由分部积分建立跨阶线性关系；和式含统一步长与分点的走定积分定义求和法
- **失效场景**：幂次过低时拆项后无法回到同族积分；边界项非零却忽略；比值为负时误用夹逼；幂因子过低时边界项不消失；递推系数漏掉负号造成符号错；把阶乘与二的幂次数写错；分母可约时需先部分分式拆解而不宜递推；配方后出现减号时应用双曲型而非反正切公式；平移代换时漏改微分变量；代换时把微分因子写成余弦而非其导数；递推整理时把相邻阶的系数移项出错；边界项非零时仍强行忽略
