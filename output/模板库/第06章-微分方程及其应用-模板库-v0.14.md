## 微分方程的定型化归与建方程通法

> 编号 **T-HS-265-I** ｜ 版本 **v0.3** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |

### 标准解题步骤

1. 定型：判可分离、齐次、一阶线性或需整体代换的耦合型
2. 耦合型作一次代换拆开（齐次设比值、反视自变量、复合设新变量），化到终端形
3. 一阶线性乘积分因子，左端合成乘积的导数一次积分
4. 方程由积分、抽象等式或几何物理条件给出时：先化标准形、按定义建导数式或按定义逐项翻译成微分方程
5. 初值条件从原方程的特殊取值中提取，最后定常数
6. 代回验算：解代入原方程逐项相等

### 二级分支（按表面题型适配）

| 复合整体代换化线性分支 | 式中出现 f(y) 与 f′(y)y′ 成对因子，或 y 的幂、指数、三角整体连同其导数一起出现（含伯努利 n≠0,1 型） | 令该整体为 u 并把原方程改写成关于 u 的一阶方程（一般为线性或可分离） → 按改写后的类型解出 u 的通解 → 把 u 换回原复合式，必要时取对数、指数或开方还原未知函数，按初值定分支符号 | 含 y 的某个复合式与其导数同时出现，且导数只差已知因子（如 2yy′=(y²)′）；代换后方程关于新变量是一阶线性或可分离；失效：复合式的导数还含无法消去的第三个未知函数，代换不能闭合；代换后需分情形的分支未讨论会得到丢解 |
| 由已知解反定方程与参数分支 | 题给特解、通解或解的形式而反求 P(x)、方程系数或原微分方程（含消去任意常数还原一阶方程） | 代入路线：把解与其各阶导数写出，按相互独立的因子（指数、三角、多项式）合并同类并比较系数，得到关于未知量的线性方程组 → 消常数路线：把通解整理成常数显在的形式，逐次求导得到两三个等式，使常数项系数成比例，两式相减把常数整块消去 → 常系数齐次场合改读特征根：由 e^{rx}、cos、sin 与 x 乘幂因子写出全部特征根（含重数），把各 (r-r_i) 相乘还原特征方程再写回微分方程 | 所给解的个数与待定未知量个数相匹配，其导数可显式算出；未知量只以系数形式出现，比较系数后化为线性方程组；失效：所给解个数少于未知量个数时只能定出约束关系式而非具体方程；解中含无法显式求导的变限积分时比较系数法失效 |

| 反视自变量化线性分支 | 写成 dy/dx 既不可分离也非线性，而写成 dx/dy 后 x 与其一阶导数恰为一次；方程显含 y″ 时本支只承担 dx/dy=1/y′、d²x/dy²=−y″/(y′)³ 的换元动作，所得关于 x(y) 的二阶方程交回缺项降阶或常系数结构主干 | 用反函数导数关系把原方程的 y′、y″ 换成 x′、x″ 的表达式 → 按新自变量 y 解这一阶线性（或可分离）方程，得 x 关于 y 的通解 → 需要回到显式解时再反解 y，无法反解就保留参数式或隐式解 | 原方程关于 y 非线性、但视 x 为未知函数时是一阶线性；导数可作反函数变换且 x′(y)≠0；失效：两种视角都非线性也不可分离时本法无出口；x′=0 的特解（竖直直线解）在换元中被约去须补回 |
| 偏导代入把多元复合归一元分支 | 未知函数只以 √(x²+y²)、y/x 等单变量复合形式出现在偏微分方程或全微分相容条件中，定线条件给在某条曲线或某方向偏导上 | 把偏导代回题给方程，先把同一变量的各项合并，再按新变量整理成常微分方程 → 用题给的定线条件（在某直线上取值或某方向偏导的取值）取出该方程的初值 → 全微分场合先写 ∂P/∂y=∂Q/∂x 的相容条件，把含待定导数的项整体消去后定出函数 | 未知函数以单变量复合形式出现，偏导数代入后变量可整体归一；定线条件足以取出与阶数匹配的初值；失效：内层不止一个独立组合时约不成常微分方程；定线条件只给函数值不给导数值时高阶方程常数定不全 |
| 抽象函数方程按定义建导数式 | 抽象函数方程按导数定义建成微分方程 | 在函数方程中令自变量取特殊值（0、1、相等）定出该点函数值与必要关系 → 按导数定义写差商，把函数方程代入分子，拆开含增量与含 f(x) 的两部分 → 取极限得 f′(x) 关于 f(x) 的方程，识别其类型（一阶线性、可分离或齐次） → 按该类型解出通解并用第一步定出的函数值定常数 → 回代原函数方程检验所得解满足原等式，并检查可导性假设是否成立 | 题面未给可导条件时不能假设导数存在；只用函数方程定值不定常数会漏解族；加法型（f(x+y)）与正切型（f(x+y) 为分式）可直接把 f(x+Δx) 整项代出；乘法型（f(xy)）须先归一（提因子 x(1+δ) 或两边同除 xy）再拆增量；两种归一都造不出差商、或等式并非对所有自变量取值成立时本法失效 |

### 失效边界

**适用前提**（41 条）

- 方程关于未知函数及其一阶导数都是一次的
- P、Q 在同一区间上连续，积分因子可写出
- 含 y 的某个复合式与其导数同时出现，且导数只差已知因子（如 2yy′=(y²)′）
- 代换后方程关于新变量是一阶线性或可分离
- 初值使还原时的开方分支唯一确定
- 所给解的个数与待定未知量个数相匹配，其导数可显式算出
- 未知量只以系数形式出现，比较系数后化为线性方程组
- 通解所含任意常数个数等于方程阶数，逐次求导可全部消去
- P、Q 在所论区间连续即可写出通解；∫Q e^{∫P dx}dx 不能表为初等函数时保留变限积分形式，其极限与有界性交「由通解表达式定解的性态」主干继续处理
- 本法与「一阶方程定型化归可分离通法」的分档：右端可写成 y/x 的函数、含 x±y、xy、x²±y² 的整体复合，或需反视自变量才成标准形者由该法完成化归；一旦方程呈 y′+P(x)y=Q(x)（含换元后关于 x(y) 的一阶线性、伯努利乘 y^{-n} 后、f(y) 整体代换后）即由本法收口，两法不重复给出同一通解
- 与「由导数（偏导）信息反求函数通法」的分档：P(x)≡0、y′ 已是自变量的显式函数只需积分还原者归该法；P(x) 不恒为零、y′ 与 y 在等式两端耦合者归本法
- 方程可写成两因子分别只含 x 与只含 y 的乘积形式
- 分离后两侧积分均可用基本公式积出
- 初值给出后可在积分式上直接代入定常数
- 右端各项关于 x、y 同次（齐次）或可整理成 y/x 的函数
- 分离后 du/(φ(u)-u) 可积出
- 初值使 u 落在 φ(u)-u 不变号的区间内
- 原方程关于 y 非线性、但视 x 为未知函数时是一阶线性
- 导数可作反函数变换且 x′(y)≠0
- 本法第3步的整体代换只针对 x 与 y 的组合整体（x±y、xy、x²±y²、ax²+by+c），代换后须化为只含新变量与单个自变量的可分离形；f(y) 与 f′(y)y′ 配对、代换后成一阶线性者归「一阶线性积分因子定解通法」
- 初值可在新变量下直接代入，代回原变量时以初值确定开方或取对数的分支
- 未知函数出现在变限积分的被积函数内或积分号外，且两端可求导
- 被积函数连续，求导合法
- 初值可由原方程与求导后的方程在特殊点取出
- 未知函数以单变量复合形式出现，偏导数代入后变量可整体归一
- 定线条件足以取出与阶数匹配的初值
- 全微分场合待定函数连续可导使相容条件成立
- 与「含参变限积分的求导与定数通法」的分档：求导之后必须再解一个微分方程（或需由全微分相容条件建方程）者归本法；只求变限积分的导数、比式极限、最值、奇偶与性态而不解微分方程者归该法；该法的「积分方程化微分方程分支」与本法同源，跨章合并时二者比一次本质再定归属
- 与「几何与物理条件建微分方程通法」的分档：等式由切线截距、曲率、弧长、面积或物理定律给出者先由该法翻译成含变限积分的关系式，本法接手消积分并解方程；等式直接以变限积分、含参积分、二重积分或偏导（全微分）相容条件给出者归本法全程处理
- 未知函数只由抽象函数方程与某点导数或函数值给出，无解析表达式
- 函数方程对增量线性可拆，取极限后能闭合
- 特殊值代入可定出积分常数所需的初值
- 本法止于把抽象等式建成 f′(x)=F(x, f(x)) 的一阶方程（含用 f(0) 或某点导数值把系数定成的情形）；建成后的求解由「一阶方程定型化归可分离通法」（可分离终端形）与「一阶线性积分因子定解通法」（y 与 y′ 呈一次）承担，例题实证按建模主干归档不重复计入求解主干
- 题面用几何语言给出曲线满足的等量关系且可唯一翻译成坐标与导数
- 初值条件个数与方程阶数匹配
- 变化率与某个可表出的量成正比，且物理定律给出方程结构
- 力或压强只依赖位置，可用 v·dv/dx 换元
- 初值（或切线、拐点、弧长、面积比、物理初始量）条件个数与方程阶数匹配，且落点分档：给在同一点的 (y₀, y′₀) 用于降阶后的第一个常数，两个纯函数值留到还原之后联立
- 符号按对象分档判定：曲率题由凹凸性定 y″ 的正负再展开绝对值，含倾角时由 cosα=1/√(1+y′²) 的取值范围定号；弧长微元 √(1+y′²) 恒正；面积与截距题先由单调性与初值确定 y、y′ 的正负再写表达式
- 与「积分与偏导条件建微分方程通法」的分档：等式由切线截距、法线、曲率、弧长、面积或物理定律给出者归本法全程（其含变限积分的子步骤即该法第3步的动作，不重复计入该法）；等式直接以变限积分、含参积分、二重积分或偏导相容条件给出、不含任何几何或物理量名者归该法
- 与旋转体体积、面积、弧长、形心等几何物理量计算主干（T-HS-142-I、T-HS-146-I、T-HS-143-I、T-HS-256-I）的分档：这些量作为题给条件反求曲线或运动规律时归本法，本法只管到建出并解出方程；曲线或运动规律已知、只要求这些量本身时归相应的几何应用主干

**失效场景**（34 条）

- 首系数为零的点使标准形的除法失效，须分区间讨论
- 积分因子写反符号会把通解整式变倒
- 复合式的导数还含无法消去的第三个未知函数，代换不能闭合
- 代换后需分情形的分支未讨论会得到丢解
- 把方程两侧同乘含未知函数的因子会引入增解
- 所给解个数少于未知量个数时只能定出约束关系式而非具体方程
- 解中含无法显式求导的变限积分时比较系数法失效
- 非齐次项本身待定时比较系数会引入非线性方程组，须另补条件
- 变系数方程的解不能反读特征根，此路线只适用于常系数线性场合
- 方程含 y 的非一次幂且不成 f′(y)·y′ 配对（如 y′=x+y²、y′=e^{xy}），既不能整体代换也不能分离时本法失效；伯努利 n≠0,1 型因可乘 y^{-n} 配成 (y^{1−n})′ 而确属本法
- 分离时约去含未知函数的因子会丢常值解
- 积分含变限或含参时不能当作一元积分直接积出
- 含 x、y 的非齐次项（如常数项或单独的一次项）时该代换不能消去自变量
- φ(u)-u 有零点时约分会丢常值解
- 根式内符号随 x 变化时未分区间定号会得到错的分支
- 两种视角都非线性也不可分离时本法无出口
- x′=0 的特解（竖直直线解）在换元中被约去须补回
- 反解 x 出现多分支时未定分支会得到多值解
- 齐次比、变量整体代换、反视自变量三种动作都用尽后仍既不可分离也不成线性者（如 y′=sin(xy) 型），本法无出口，须交「一阶线性积分因子定解通法」或改判可降阶型
- 积分上限也含未知函数时求导会引入无法消去的项，本法失效
- 只取一个初值就解二阶方程会留下定不出的常数
- 内层不止一个独立组合时约不成常微分方程
- 定线条件只给函数值不给导数值时高阶方程常数定不全
- 区域含空洞时相容条件不再充分，须另案处理
- 被积函数含 xu、x+y、x−y 等复合整体时未先按第2步换元即对上限求导会漏乘子；只有当该整体在任何换元下都不能与积分变量分离（例如上限与被积变量以不可解形式耦合）时本法才失效
- 题面未给可导条件时不能假设导数存在
- 只用函数方程定值不定常数会漏解族
- 加法型（f(x+y)）与正切型（f(x+y) 为分式）可直接把 f(x+Δx) 整项代出；乘法型（f(xy)）须先归一（提因子 x(1+δ) 或两边同除 xy）再拆增量；两种归一都造不出差商、或等式并非对所有自变量取值成立时本法失效
- 去掉绝对值不判凹凸或倾角范围会得到符号相反的解
- 几何关系中含未知切点而未先解切点时方程无法闭合
- 用整条曲线的对称量代替微元会丢失导数信息
- 阻力依赖速度高次幂时换元后不可分离，本法无出口
- 把速度平方当位移微分漏乘 1/2 因子会使系数差一倍
- 忽略方向符号会把衰减写成发散

## 常系数线性方程求解与解的性态通法

> 编号 **T-HS-273-I** ｜ 版本 **v0.3** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 常系数线性方程的解空间由特征根完全决定：设 y=e^{rx} 把方程折成特征方程，相异实根给指数组合、重根乘 x 补足、共轭复根换成衰减振荡；二阶方程不显含 y 或 x 时先降阶（y′=p，含 x 型直接降、缺 x 型把 y″ 写成 p·dp/dy 以 y 为自变量）再按一阶求解。不求显式解也能定性态：把通解写成积分因子形式后取极限，指数因子衰减快于积分增长时解趋于常数，特征根实部全负时齐次解一致趋于零，含参系数按参数分档判定有界与渐近线。 |

### 标准解题步骤

1. 判能否降阶：不显含 y 或不显含 x 的二阶方程先降为一阶
2. 常系数写特征方程，按相异实根、重根、共轭复根三档写出齐次通解
3. 非齐次按右端形状设特解（多项式、指数、三角的叠加）代定系数
4. 由通解表达式定性态：积分因子形式取极限，特征根实部的符号定衰减与振荡
5. 含参时按参数分档（实部符号、重根档），逐档写结论
6. 代回原方程核对特解与齐次解的线性组合

### 失效边界

**适用前提**（24 条）

- 方程各阶导数的系数都是常数且右端为零（齐次）
- 特征方程可显式求出全部根（含重根与复根）
- 由通解反推方程时各项形式与三种档一一对应
- 方程为常系数线性，右端是多项式、指数、正弦余弦或其乘积与和
- λ（或 α±iβ）与特征根的关系可判定
- 设出的特解形式所含待定系数个数与比较方程个数匹配
- 方程为线性（齐次或非齐次）且已知若干具体解或解的组合形式
- 所给解的个数与线性无关性能凑足阶数所需的独立解
- 判定组合是否仍为解时系数条件唯一
- 方程是变系数但系数为 x 的同次幂乘各阶导数（欧拉型）或含可整体代换的指数因子
- 代换后各阶导数能化成关于新变量的线性组合
- 代换在所论区间单调可逆，可回代定初值
- 本法负责写出特征根表出的通解、定出待定系数与反定方程；只判解的极限、有界性、渐近线或据此反解参数范围而不需要写出特解时，交「由通解表达式定解的性态」主干
- 方程明确不显含 y 或不显含 x，或经代换后可化为这种形式
- 降阶后得到的一阶方程属可分离、一阶线性或齐次三者之一，其求解分别由「一阶方程定型化归可分离通法」与「一阶线性积分因子定解通法」承担；三者都不是（如 p′ 与 p 的非线性耦合无法分离）则本法无出口
- 条件个数与方程阶数匹配，且按其落点分档：给在某点的 (y₀, y′₀) 成对值用于缺 x 型的第一个常数，只给函数值时两个常数一律留到还原积分之后联立
- 与「常系数线性微分方程求解通法」的分档：方程对各阶导数线性且系数为常数（或经一次自变量代换化为常数）者归该法；非线性方程、或线性但系数变且不可统一代换者，按是否缺 x、缺 y 归本法
- 本法只接收已给出的方程：等式由变限积分、几何量或物理定律先建出的二阶方程，建方程动作归「积分与偏导条件建微分方程通法」与「几何与物理条件建微分方程通法」，本法负责建成之后的判缺项与降阶
- 指数衰减与积分增长的阶可比较
- 特征根与参数之间的关系可判实部符号
- 解可写成积分因子形式或特征根表出的组合（含只含变限积分、不可初等表出的形式），被积函数在极限点存在有限极限，或整体有界可用积分中值定理提出
- 特征根按实部与重数分四档可判：实部全负（一致趋零）、相异纯虚根（等幅振荡、有界不趋零）、单零根与重零根（常数项与 x 的一次幂项）、正实部根（发散）；含参数时按判别式分档
- 与「常系数线性微分方程求解通法」的分档：本题只要求判极限、有界性、渐近线或据此反解参数范围者归本法，不必写出非齐次特解；需要求通解、设特解、比较系数或反定方程者归该法，该法给出的特征根表达式即本法的输入
- 与「反常积分定阶判敛与截断求值通法」的分档：本法处理"以积分为指数的解的性态"（如 e^{−∫₀ᵗa(s)ds} 是否趋零，积分的敛散性只是中间判据）；题目直接要求判别含参反常积分的敛散性或求其值时归该法

**失效场景**（17 条）

- 特征根实部符号随参数变化时有界性结论需分情形，不能一概而论
- 把非齐次的特解项当齐次解读会多算自由度
- 右端含 ln、arctan 等无对应待定形时本法不可设，须用常数变易或积分表达
- 变系数方程不能比较系数定待定值
- 齐次解与所设特解重合而未升 x 幂次会使代入恒为零
- 非线性方程不满足叠加原理，作差与线性组合都会失效
- 已知解线性相关时不能据其张出齐次解空间，须另找独立解
- 把非齐次解的组合系数和条件写成 0 会把特解误当齐次解
- 系数无法被同一代换统一约去时本法不能化常系数
- 代换非单调或跨奇点时未分段回代得到错解
- 换元后只换一阶导数漏二阶附加项会使方程形式走样
- 系数含自变量且不存在任何单一自变量代换能把各阶导数的系数统一约成常数时不能设 e^{rx}，本法失效（缺 x 或缺 y 的二阶方程交「缺x缺y的二阶方程降阶求解」）
- 方程同时显含 x、y 与 y′ 的非线性组合时降阶不闭合，须另寻代换
- p=0 的常值解在约分时被丢，须单独补查
- 只给一个初值时无法定出两个常数，通解不能强行特化
- 被积函数无界或极限不存在时不能把主部换成定点值
- 通解含变限积分不是障碍，本法要取的正是其主部；只有被积函数无界、极限不存在，或衰减因子与积分增长不可比较（如指数与 e^{x²} 混排）时本法给不出结论
