### 标准解题步骤

1. 判正项：确认通项最终同号且不趋于非零值，否则本法只能提供绝对意义上的敛散信息
2. 查必要条件：先检验通项是否趋于零，不趋于零者直接判发散，不必再比标尺
3. 化通项结构：把通项整理为分母连乘形式，分离出项数幂、逐层对数幂、指数的幂、阶乘与幂指因子
4. 按增长层级定阶：用对数远慢于幂、幂远慢于指数、指数远慢于阶乘、阶乘远慢于幂指的固定顺序取主项，含阶乘先化为幂指形式
5. 选标尺层数：以通项中实际连续出现的对数层数确定对应标尺级数，层数由外向内逐层核对
6. 补层或降层：嵌套不连续（缺中间某层对数因子）时把标尺降到实际连续出现的层，或用不等式把通项压到某层标尺的一侧
7. 读最内层幂次下结论：仅由最内层对数因子的幂次与临界值比较定敛散，外层幂次不改变结论，最后用单侧放缩复核方向

| 缺层补形分支 | 对数嵌套出现跳跃，中间缺某层因子或幂次只作用于最内层 | 把标尺层数下调到实际连续出现的层 → 利用分母少因子使通项偏大的方向做放大 → 与被放大到的那一层标尺比较，同侧即得该标尺的敛散 | 缺层只能往发散方向放缩，反向需另给收敛控制；不能凭外层幂次大就断言收敛 |

| 含参临界分类分支 | 通项含参数，敛散结论随参数取值改变 | 把参数并入定阶后的最内层幂次或指数位置 → 解出使标尺恰处临界的参数分界值 → 按参数落在分界两侧分别给结论，并单独检验恰取分界值的情形 | 恰取临界值时外层对数与低阶修正项决定结论，必须回到标准嵌套单独判别 |

### 失效边界

**适用前提**（4 条）

- 正项级数，通项分母可分解为项数幂、逐层对数幂与其他可定阶增长块的乘积
- 比较判别法与比值判别法在边界附近失效、积分判别法不易积分时，本法仍可单侧定敛散
- 求和起始项可调整（有限项不影响敛散），以保证各层对数有定义且为正
- 对标准嵌套族本身该判据是充要的；对一般正项级数只保证单侧控制，不能声称已找到收敛最慢的边界级数

**失效场景**（7 条）

- 一般项级数与交错级数不能用本法判条件收敛，本法只对正项部分给出绝对敛散
- 通项不趋于零时必须先用收敛的必要条件判发散，直接套标尺会掩盖这一更基本的检查
- 含正弦、余弦等振荡因子的通项无法定阶，标尺比较失效，须改用绝对值放缩或其他判别法
- 比值判别法在本族标尺上恒给出临界值，看似可用实则无效，不可用它否定标尺结论
- 把增长层级不等式用于有限项或起始下标之前的区间会得出反向结论，比较只在足够大下标后成立
- 缺层放缩方向搞反（用收敛标尺去控放大后的通项或用发散标尺去控缩小后的通项）会得到相反敛散
- 含参情形只检验分界一侧或漏掉恰取临界值的分类，结论不完整

### 标准解题步骤

1. 逐行（列）求元素和，确认所有行（列）之和同为与行号无关的量 s（含 s 为含参表达式）
2. 把其余各列（行）全部加到第一列（行），并声明这一倍加不改变行列式的值
3. 提出第一列（行）的公因子 s；同类操作做过 k 次时提 s^k，并按阶数核对幂次
4. 用提走后全为 1 的那一列（行）把其余各列（行）逐一消成零（各减去它的适当倍数）
5. 按含 1 的列（行）展开降阶，剩下的低阶行列式直接算出并与 s 的幂相乘
6. 各列和只相差常数倍时先把各行乘以相应系数凑成相等的和，再走上面的流程；s 可能为零时按 s=0 与 s≠0 分别结论

### 失效边界

**适用前提**（3 条）

- 每行元素个数相同且和式对称，能一次加出同一常数
- 对角元特殊而其余全同（如对角为 b、其余为 a），和为 b+(n-1)a 这类与行号无关的量
- 允许对行（列）做倍加与整列提因子

**失效场景**（3 条）

- 各行和依赖行号（含互不相同的 a_i）时加出来的列不统一，本法失效
- s=0 时提出 s 等于除以零，此时行列式本身为零或须改判其他结构
- 把行加到列后再按列提因子，行列式的行列对应关系被破坏

## 代数余子式组合逆用展开

> 编号 **T-LA-06-I** ｜ 版本 **v0.1.4** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 展开公式把行列式写成某行（列）元素与其代数余子式乘积之和，因此把该行（列）换成任意一组数所得的行列式，就等于那组数与原来的代数余子式的同系数组合；一组代数余子式的线性组合不必逐个求出，只要拿组合系数去替换对应行造一个新行列式来算，而余子式必须先按 (-1)^{i+j} 转成代数余子式；全行或全部之和则由 A*=\|A\|A^{-1} 从逆矩阵整批读出。 |
| 适用范围 | 求若干代数余子式（或余子式）的定系数线性组合、某行全部之和与全部之和 |
| 学科 / 章节 | 线性代数 · 行列式 |
| 表面题型 | 代数余子式组合逆用展开 |
| 对应考点 | 余子式与代数余子式；（二）展开式逆用；（二）行列式的展开；必备知识点；解题连招；（三）性质（行均可换为列）；（六）“楚河汉界”型 |
| 覆盖题量 | 5 题（分支 0 个） |

### 标准解题步骤

1. 先辨所求量是余子式 M_{ij} 还是代数余子式 A_{ij}，前者乘 (-1)^{i+j} 转成后者（同一行时可直接整体提负号）
2. 看下标是否同属一行或一列：行不变就用系数替换该行，列不变就替换该列
3. 造出替换后的新行列式，按消零降阶、各行和相等或分块等常规手法算出其值
4. 求某一行（列）全部代数余子式之和时把该行（列）换成全 1 造行列式；求全部 A_{ij} 之和时改算 \|A\|A^{-1} 的元素总和
5. 只涉及伴随矩阵主对角元素之和时改用 A* 的特征值 \|A\|/λ_i 求和，避开逐个算余子式
6. 把替换行改回原行本身做一次自检：所得新行列式应回到 \|A\|

## 按列拆分与列向量组合

> 编号 **T-LA-09-I** ｜ 版本 **v0.1.3** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

## 伴随与逆的行列式代换

> 编号 **T-LA-13-I** ｜ 版本 **v0.1.3** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |

| 核心本质 | 伴随矩阵的全部行列式信息由 \|A\| 决定：A*=\|A\|A^{-1}、\|A*\|=\|A\|^{n-1}，转置不改行列式；于是 A^T=kA* 这类等式两边取行列式即给出 \|A\| 的代数方程，含 A*、A^{-1}、A^T 的行列式也都能整体换成 \|A\| 的幂与常数之积。唯一要补的是可逆性——由 a_{ji}=kA_{ji} 按一行展开得到 \|A\| 是若干平方之和，配 A 非零即可排除 \|A\|=0。 |

| 学科 / 章节 | 线性代数 · 行列式 |
| 表面题型 | 伴随与逆的行列式代换 |

| 覆盖题量 | 4 题（分支 0 个） |

### 标准解题步骤

1. 先判可逆：对 A^T=kA* 取行列式得 \|A\|=k^n\|A\|^{n-1}，或由 a_{ji}=kA_{ji} 按第一行展开得 \|A\|=(1/k)Σa_{1j}²>0（需 A 非零）
2. 把式中的 A* 一律换成 \|A\|A^{-1}（或把 A^{-1} 换成 A*/\|A\|），使待求矩阵只剩 A^{-1}（或 A）的线性组合
3. 合并同类项成 k·A^{-1} 或 k·A 的单一数乘形式
4. 取行列式：用 \|kA\|=k^n\|A\|、\|A^{-1}\|=\|A\|^{-1}、\|A*\|=\|A\|^{n-1} 把结果写成 \|A\| 的幂与常数之积
5. 代入由条件解出的 \|A\| 值，核对阶数 n 出现在幂次上而非系数上
6. 条件给出 \|A\| 的两个候选值时，用可逆性、A 非零或实矩阵等限制舍去不合的一支

### 失效边界

**适用前提**（3 条）

- 式子只含 A 的逆、伴随、转置与数乘，不混入 A 的高次多项式加法
- A 可逆，或可由非零条件与平方和展开证明可逆
- A 的阶数 n 明确已知（\|A*\| 与 \|kA\| 两式都依赖 n）

**失效场景**（3 条）

- A 奇异时 A* 仍存在但不可作除法，多数步骤失效
- 混入 A 的多项式加 E（如 A²-A-3E、2A*-3E 的行列式）时应改走特征值路线
- 把 \|A*\| 写成 \|A\|^n 或把 \|kA\| 写成 k\|A\| 是与阶数相关的系统性错误

## 和式因式分解后取行列式

> 编号 **T-LA-14-I** ｜ 版本 **v0.1.3** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 行列式对矩阵乘法是同态（\|XY\|=\|X\|\|Y\|），所以先把待求的矩阵和式通过补乘 E 的等价形、单侧提取公因子或因式分解改写成若干矩阵之积，所求行列式就拆成各因子行列式的乘积；每个因子的行列式再由已知条件与 \|kA\|、\|A^{-1}\|、\|A^T\| 的公式单独求出——先变形后取行列式，绝不把行列式本身拆开。 |
| 适用范围 | 含逆、伴随、转置与 E 的矩阵和式求行列式，可单侧提取公因子或因式分解 |
| 学科 / 章节 | 线性代数 · 行列式 |
| 表面题型 | 和式因式分解后取行列式 |
| 对应考点 | （三）性质（行均可换为列）；必备知识点；低阶行列式运算规则；（一）概念与计算 |
| 覆盖题量 | 4 题（分支 0 个） |

### 标准解题步骤

1. 把式中的 E 写成 AA^{-1}、AA^T 或 A·A*/\|A\| 等等价形，使各次出现公共因子
2. 按左提或右提公共可逆因子写成乘积（矩阵乘法不可交换，左右提取得到的乘积不同但行列式相同）
3. 对每个因子分别求行列式：数乘用 \|kA\|=k^n\|A\|，逆用 \|A^{-1}\|=\|A\|^{-1}，转置不变，乘积拆成模
4. 把各因子行列式相乘，并按阶数 n 核对幂次与常数因子
5. 乘积中出现 (A±E) 这类不可再分解的因子时，把它的行列式整体记为未知量，与题给行列式等式联立解出
6. 用给定数值或 n=1 的具体矩阵代一次，核对符号与幂次

### 失效边界

**适用前提**（3 条）

- 待求矩阵式各项含同一可逆单侧因子（或其逆、伴随、转置）
- 题给若干行列式的数值，足以定出每个因子
- 矩阵等式可因式分解（如 A²B-A-B=E 整理成 (A²-E)B=A+E）

**失效场景**（4 条）

- 各项没有公共单侧因子时提公因子会改变式子，须先补 E 的等价形
- 把 \|A+B\| 写成 \|A\|+\|B\| 是对本原理最常见的违反
- 因子不可逆时不能提其逆，须改走秩判零或特征值路线
- 矩阵不可交换，左右提取得到的后续化简路径可能不同，需取行列式后再比较

**失效场景**（3 条）

### 标准解题步骤

1. 核对幂次结构：逐行（列）检查是否为 1、t、t²、… 的等比排列，注意缺幂次或幂次序与列次序不一致
2. 列（行）顺序与幂次顺序不符时先做行列互换，并按交换次数或逆序数补上整体符号
3. 按"后减前"的下标约定直接写 Π_{i<j}(x_j-x_i)，成对列出全部因子以免漏项或反号
4. 首行（列）是含参多项式而非全 1 时，先按该行（列）拆成若干个低阶范德蒙之和
5. 把所得乘积按题目目标化简：求根、判符号、比较大小或转成函数再求导讨论性态
6. 用两阶或三阶情形展开核对因子个数是否为 n(n-1)/2 与整体符号

### 失效边界

**适用前提**（3 条）

- 存在一行（列）全为 1，其余各行（列）按下标成连续等比幂次
- 变量两两不同时行列式非零，可据此判向量组线性无关
- 拆出的每个子式仍是同一组量少一个变量的范德蒙

**失效场景**（3 条）

- 幂次不连续或某行混入不同幂次时不是范德蒙，须改判加边或递推
- 因子写成 (x_i-x_j) 与下标约定不符会整体差一个符号
- 变量相等时行列式为零，不能再把它当作除数
