## 矩阵幂降次闭合通法

> 编号 **T-LA-20-I** ｜ 版本 **v0.4.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 求 A 的高次幂只有一条路：先靠低次乘法认出 A 的幂与 A、E（或更低两阶幂）之间的固定关系，再把任意次幂折回这个组合——秩一形 A=(alpha)(beta)^T 把中间内积提成数得 A^n=(tr A)^{n-1}A；E 加幂零形用二项式展开并在幂零阶处截断；具体低阶阵先实算 A^2、A^3 认关系并按奇偶或周期分档；块副对角形平方后变块对角再分档；题给相似关系时把幂搬到易算一侧写成 P^{-1}B^nP；已验得递推式时用归纳把 A^n 定成低两阶的组合。六种入口的共同点是高次幂从不独立计算，只由低次幂与少数常数决定 |
| 适用范围 | 列乘行的秩一矩阵及其与 E 之和的任意次幂、含其幂的向量方程 |
| 学科 / 章节 | 线性代数 · 矩阵、向量 |
| 表面题型 | 秩一矩阵的整体降幂；算低次幂认关系分档写通项；单位阵加幂零块二项式截断；相似关系将幂搬到易算一侧；副对角分块平方化块对角求幂；矩阵幂的递推归纳与高次求值；列分块分解与低阶方阵降幂 |
| 对应考点 | 运算；矩阵及相关概念；（一）概念及运算；必备知识点；逆矩阵；（三）伴随与逆；（二）伴随矩阵与求逆；解题连招；（三）分块矩阵；（五）极大无关组；（一）线性表示 |

### 标准解题步骤

1. 先定降次入口：按结构判它属于秩一形、E 加幂零形、低阶可直接实算形、块副对角形、题给相似形，还是已验得递推关系形
2. 秩一形：把矩阵写成列乘行并先算该内积（即 tr A），由 A^2=(tr A)A 逐次相乘得 A^n=(tr A)^{n-1}A；原阵写成 E 加秩一块时先把 E 与秩一块分开再降幂
3. 幂零形：拆成 E+N（或 kE+N），逐次相乘到 N 为零记下幂零阶，二项式展开只保留到该阶前一项；求逆按 E-N+N^2-… 的有限和写出
4. 实算认关系形：先算 A^2、A^3 并与 A、E 逐项对照出数量线性关系，据此逐级降幂；关系随 n 摆动时按奇偶或周期分档写出，并注明各档的取值范围
5. 块副对角形：按非零块划块后先平方得块对角（块内为秩一阵或数量阵），再按 n 的偶档取块对角的 k 次方、奇档在其后多乘一次原阵
6. 相似形：确认 A=P^{-1}BP 的方向（勿把两侧写反），由连乘相消写 A^n=P^{-1}B^nP，只在易算一侧取幂后用同一个 P 搬回；易算一侧的幂化成数量阵（含 E）时共轭即退回同一数量阵，P 的具体值无需求出；待求式里另一阵自身的幂不参与共轭，须留在原侧直接实算，不得把它也搬进 P^{-1}(…)P
7. 递推形：把已验得的 A^n 与 A^{n-1}、A^{n-2} 的关系用数学归纳法对全体 n 固定，再按右端形状选闭合档——齐次关系按特征根或周期写通项；右端为与 n 无关的常矩阵加项（A^n=A^{n-2}+C 一类）时奇偶两档各成等差：偶档 A^{2k}=A^0+kC（自 E 起算）、奇档 A^{2k+1}=A^1+kC，最后代最小两档与直接相乘核对
8. 统一回代校验：代最小的两档与直接相乘核对，逐项检查内积是数不是阵、幂零截断没有漏掉非零项、奇偶档与块阶数没有写串

### 失效边界

**适用前提**（20 条）

- 矩阵可写成列向量与行向量之积，或行向量组（列向量组）彼此成比例
- 内积 (beta)^T(alpha) 可先算出且为一个数（可含参数）
- 待求式为 A 的高次幂、A 与 E 之和的幂，或含 A 的幂与向量之积的方程
- 矩阵以具体数字给出且阶数不高，直接相乘代价可控
- 低次幂之间确存在数量系数的线性关系（含幂零、对合、数量乘 E 三种特例）
- 题目要求 A^n 的表达式或某个具体高次幂的值
- 矩阵可拆成单位阵（或数量乘单位阵）加一个严格三角形／幂零块
- 幂零阶可由直接相乘确定（不超过矩阵阶数）
- 待求式为 (E+N) 的正整数幂或它的逆矩阵
- 题面显式给出相似关系与可逆矩阵 P（或说明 P 可逆但未给具体值）
- 非零元集中在副对角块位置，可按块划分且块阶数明确
- 副对角块之积为秩一阵或数量阵，能继续降幂
- 题目要求 A^n 的表达式（按 n 的奇偶分档）
- 已验得 A 的某次幂可由更低的两次幂与 E 线性表出
- 递推系数为常数、与 n 无关，初值（A、A^2）可直接算出
- 题目要求证明幂的递推关系并计算一个很大的幂次
- 题面显式给出相似关系 A=P^{-1}BP（或 B=P^{-1}AP）且 P 只需可逆、不必给出元素，一侧具对角、置换、分块或低阶周期等易算幂的结构，待求式只含这两阵的幂与其数乘、加法；易算一侧的幂化成数量阵时共轭退回同一数量阵（P 的具体值无需求出），另一阵自身的幂留在原侧直接实算，不得搬进 P^{-1}(…)P
- 矩阵列向量组的秩明显低于列数（存在大量可表示的列），具体数值给出
- 题目要求分解成「极大无关列阵乘系数阵」，或求高次幂
- 降成的低阶阵之积的幂可闭合（数量关系、幂零、递推）

**失效场景**（23 条）

- 秩大于一时中间内积不是数而是矩阵，不能提到前面整体降幂，须改按相似对角化或递推处理
- 把 (beta)^T(alpha) 与 (alpha)^T(beta) 混用或写成矩阵形式会使乘法不闭合，二者均为数但顺序须与内积定义一致
- 展开 (kE+A)^n 时漏掉 n=1 档的 E 项，或把 A^m 仍留在幂次上不降到底
- 内积为零时 A^2=O 属幂零形，(tr A)^{n-1} 在 n=1 处给出 0^0，须单独按幂零截断处理
- A^2、A^3 与 A、E 都线性无关时无法用两步降幂闭合；此时若列向量组的秩低于列数，先改走列分块分解降幂分支，再考虑相似对角化或 Cayley-Hamilton 路线
- 含参数的矩阵未先定参数就找规律，规律会随参数分档改变
- 把只在前几阶成立的"规律"外推而未回代校验，偶数档与奇数档混写成同一式
- N 不幂零（主对角线有非零元且不可分离）时二项式展开不截断，须改走相似对角化
- 把 A 本身当幂零块而忘记先减去对角部分，导致展开式多出无穷项
- N 与 E 之外的部分不满足所需幂零阶，仍按低阶截断会丢非零项
- P 不可逆或未给时不能建立幂的搬移，须先证可逆
- 关系式两侧写反（把 A=P^{-1}BP 当成 A=PBP^{-1}）会使共轭方向颠倒、结果不符
- 待求式含 A 与 B 的乘积但两者不在同一 P 下相似，不能逐项搬移
- 把 P^{-1}B^nP 误写成 P^{-1}B^n 或 B^nP，丢掉一侧的搬运矩阵
- 块内元素不满足列乘行结构时平方后仍为稠密块，降幂链断开
- 行列分块尺寸不匹配（块不能相乘）时整个分块乘法不成立
- 关系式右端含与 n 有关的系数时不能按常系数递推闭合
- 只验 n=3 一档就断言全体成立，缺归纳步骤
- 递推闭合要按右端形状选档：右端为与 n 无关的常矩阵加项时奇偶两档各成等差（偶档自 A^0=E 起算 A^{2k}=E+kC、奇档自 A^1=A 起算 A^{2k+1}=A+kC），右端等比时化成等比，齐次关系才按特征根写通项；把偶次幂的块对角形式直接当成 A^n 的一般式、把该走等差档的题硬套特征根、或特征根为重根与共轭复根时仍按两相异实根写通项，都属闭合方式选错
- 极大无关列阵不列满秩：分解虽在，幂的转移失效
- 把夹心幂写成两因子各自求幂再相乘：矩阵不可交换，只有夹心式成立
- 系数阵的行序与极大无关列的列序错位，乘回去不等于原矩阵
- 低阶阵的幂结构认错：幂零阶数多截或少截、周期档漏档

## 行变换定极大无关组与表示

## 表示与相关的概念推理

> 编号 **T-LA-38-I** ｜ 版本 **v0.2** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 线性相关与线性表示互为表里：一组向量相关等价于其中某个向量可由其余向量表示；部分组无关则整体无关，整体无关则任何部分组无关；线性无关向量组不能由更少的向量线性表示——个数少的一组表示个数多的一组时多者必相关，逆否地被表示组无关则表示组个数不少于它。判定这类命题靠把「谁能表示谁、谁与谁相关、谁多谁少」逐条翻译成秩与个数的比较，可疑命题用低维反例否证。 |
| 适用范围 | 判别线性表示与相关性之间的命题组合（概念题） |
| 学科 / 章节 | 线性代数 · 向量 |
| 表面题型 | 表示关系与相关性的命题推理；以少表多的个数比较 |
| 对应考点 | 线性相关性；（一）线性表示；（二）线性表示及线性相关性；必备知识点；解题连招；涉及定理和推论；向量组的线性表示与等价；（四）向量组等价；（三）向量组的秩及向量组等价；向量的概念 |
| 覆盖题量 | 5 题（分支 1 个） |

### 标准解题步骤

1. 把每条命题拆成两半：条件是「谁可由谁表示/谁相关」，结论是「谁的相关性」
2. 条件与结论都翻译成秩的语言：表示使秩不超过表示组，相关即秩小于个数
3. 逐条推演：部分组无关推整体无关、整体相关推存在某向量可由其余表示
4. 「以少表多，多的相关」作判据并使用其逆否：个数少且无关的一组表示个数多的一组时多者必相关；被表示组无关时反推表示组个数不少于它
5. 涉及个数比较时数清两组各自的向量个数并确认表示方向，把命题写成「个数比较加表示方向」的不等式链，核对方向没有写反
6. 对可疑命题举最低维反例（含零向量、成比例对、三个二维向量）否证
7. 按编号汇总真伪并与选项对照，区分「必有」与「可能」的措辞强度

- 无需具体分量，纯个数与秩的逻辑推理
- 结论为「必相关」「个数不少于」一类强制判断

**失效场景**（8 条）

- 把「存在某向量可由其余表示」当成「任一向量都可由其余表示」：后者只对特殊结构成立
- 方向写反：部分相关推整体相关成立，反向不成立；整体无关推部分无关成立，反向不成立
- 用特例「确认」一般命题为真：举例只能否证

- 命题里两组的记号对调后仍沿用原结论

3. 读出该齐次方程组的通解，把自由未知量取成参数得到一族非零组合系数

### 标准解题步骤

1. 确认待正交化的向量组线性无关（有多余分量先剔除或先求无关部分组）
2. 取第一个向量不动，作为正交组之首
3. 逐个把后续向量减去它在每一个已得正交向量上的投影（内积除以该向量的平方长度再乘它）
4. 需要标准正交组时把每个正交向量除以自身长度，长度保留根号形式
5. 验算相邻正交向量内积为零、单位向量与自身内积为指定值

**适用前提**（3 条）

- 已有一组线性无关向量（具体给出或由解向量、特征向量提供），要求标准正交组
- 结论用于构造正交矩阵、正交三角分解或在解空间里取正交基
- 维数不高，内积可手算

**失效场景**（4 条）

- 向量组自身线性相关时正交化会出现零向量，必须先求极大无关组再正交化
- 投影系数把除数写错：应除以被投影向量的平方长度，不是除以自身内积的别的组合
- 正交化顺序不同得到不同正交组（等价但不相同），两轮的中间量不能混用
- 单位化漏除长度或把长度算错，导致「正交」成立而「单位」不成立

## 组等价与矩阵等价三层辨析

| 覆盖题量 | 4 题（分支 0 个） |

### 标准解题步骤

1. 写清两种等价的定义：向量组等价为互相表示，矩阵等价为乘可逆阵互化
2. 核对结论落在哪一档：组等价要求秩与联合秩都相等，矩阵等价只要求秩相等
3. 乘可逆阵的翻译：右乘对应列向量组等价，左乘对应行向量组等价，两侧乘只对应矩阵等价
4. 「齐次方程组同解」对应系数阵行向量组等价，用它处理同解类命题
5. 真命题给推导（从秩与表示出发），假命题举反例（同秩但不互相表示的两组）
6. 汇总各选项真伪，标注「必要不充分」的方向

### 失效边界

**适用前提**（3 条）

- 题面比较向量组等价、矩阵等价、同解、乘可逆阵之间的推出关系
- 条件给矩阵乘积、秩相等或互表示，判哪一档结论成立
- 结论只涉及等价档位的强弱，不需计算具体向量

**失效场景**（4 条）

- 把矩阵等价（秩相等）当成向量组等价：同秩的两组未必互相可表示
- 两侧乘可逆阵却推出行（列）向量组等价：两侧乘只保证秩相等
- 「同解」与「行等价」方向写反：行向量组等价才对应齐次同解，与列向量组无关
- 反例不取同型矩阵：矩阵等价在同型之间讨论才有意义

## 特征向量展开加权求矩阵幂作用

> 编号 **T-LA-48-I** ｜ 版本 **v0.1.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 不同特征值的特征向量线性无关，可作空间的基；把目标向量按特征向量组展开后，矩阵幂的作用就落在展开系数上——各系数乘以对应特征值的同次幂。于是矩阵幂作用在向量上的问题全部折成两步：解一个以特征向量为列的表示方程组定系数，再按特征值幂加权合并。 |
| 适用范围 | 把向量按互异特征值的特征向量展开，求矩阵幂作用在该向量上的结果 |
| 学科 / 章节 | 线性代数 · 向量 |

| 对应考点 | 线性组合与线性表示：；相关运算；（二）线性表示及线性相关性；（一）概念及其相关运算；必备知识点 |
| 覆盖题量 | 1 题（分支 0 个） |

### 标准解题步骤

1. 确认给出的特征值两两不同（保证对应特征向量线性无关、可作基）
2. 设目标向量为各特征向量的线性组合，组合系数为未知量
3. 以特征向量为列拼矩阵、目标向量为右端，行变换解出唯一的组合系数
4. 用「矩阵幂作用等于特征值同次幂」把作用逐项加权到各系数上
5. 按分量或按特征向量组合两种形式之一合并写出结果
6. 取指数为很小值直接乘矩阵验证与展开式一致

### 失效边界

**适用前提**（4 条）

- 已给矩阵的特征值与对应特征向量（或可验证的特征向量组），目标向量具体给出
- 要求矩阵幂或矩阵多项式作用在某向量上的结果
- 特征值互异，展开存在且唯一
- 只对单个向量求矩阵幂（或矩阵多项式）的作用；要求整阵的幂时属矩阵幂降次闭合通法（T-LA-20-I）的范围

**失效场景**（4 条）

- 特征值有重根时对应特征向量未必无关，须先证无关才能作基展开
- 只对部分特征向量加权而漏掉其余系数项
- 把特征值幂错加到向量分量上或幂次错位
- 表示方程组无解说明目标向量不在张成空间内：先核对分量是否抄错，该情形下此法不适用

## 解空间维数判解向量组相关性

> 编号 **T-LA-49-I** ｜ 版本 **v0.1.2** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 齐次方程组解空间的结构给出解向量组相关性的全部判据：解向量组的秩上界是未知量个数减系数阵的秩，个数超过上界的解组必相关；两个非齐次解之差是齐次解，非齐次解的组合系数和为一才保持非齐次。判「某组解向量是否无关」不求解方程组本身，而是数解空间维数，并用「矩阵作用把右端项消成零」把组合式压进齐次解空间。 |
| 适用范围 | 判方程组解向量组的相关性与秩，或由解的结构证表示关系 |
| 学科 / 章节 | 线性代数 · 向量 |
| 表面题型 | 方程组解向量组的相关性判别 |
| 对应考点 | 相关运算；向量组的秩；（一）概念及其相关运算；（三）向量组的秩及向量组等价；必备知识点；（三）利用定义证明相关性；（一）线性表示；解题连招；（二）用秩判定相关性；涉及定理和推论；（二）线性表示及线性相关性 |
| 覆盖题量 | 3 题（分支 0 个） |

### 标准解题步骤

1. 认清给出的向量是哪个方程组的解（齐次或非齐次），写出系数阵并求秩
2. 算出解空间维数（未知量个数减系数秩），它就是解向量组秩的上界
3. 解向量个数超过维数时直接判线性相关，不必再算
4. 非齐次解两两相减得到齐次解，把要判的组合式逐项翻译成矩阵作用为零或为右端
5. 组合式两边同乘系数阵消去右端项，再用齐次解空间的维数与已知无关解收系数
6. 结论落到该组解的秩、或某解可由其余解表示，并与其对应的基础解系选取对照

### 失效边界

**适用前提**（3 条）

- 题给的向量是某方程组的解（或解的差、和），分量不全给出
- 系数阵的秩已知或可由子式、行变换读出
- 结论为解向量组的相关性、秩、或某解可由其余解表示

**失效场景**（4 条）

- 解空间维数按未知量个数减方程个数来算：方程个数不等于秩，必须用秩
- 把非齐次解的任意组合仍当非齐次解：组合系数和为一才保持非齐次
- 拿非齐次解当基础解系：基础解系必须既是齐次解又线性无关
- 系数阵秩读错一档，解空间维数与相关性判别随之全错
