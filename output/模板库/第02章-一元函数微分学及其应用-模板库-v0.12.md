### 标准解题步骤

1. 收集题目出现的全部点（区间端点、条件给定点、极值点、分点），按大小排成端点链并逐点标注函数值、导数值与符号
2. 把待证结论移项整理为 F(中值点)=0、F(中值点)=常数或 F(中值点)>0（<0）三种标准形态之一
3. 判断结论落在 F 的哪一阶导数上：含函数与其导数的线性组合时先积分还原出辅助函数 F，把原函数信息归到端点
4. 以「结论类别＋导数阶数」为行、以端点链上可得的条件（异号、等值、极值、最值、高阶导）为列查图表，锁定候选定理
5. 有两个以上定理同时满足条件时，选条件已被端点链完全覆盖的那个；条件不足时先补一层定理造出所需端点信息
6. 按选定定理逐条验证前提（闭区间连续、开区间可导、端点等值或异号），再写出中值结论
7. 把所得中值等式回代欲证式做恒等检验，确认中值点落在所论区间内且未混用不同区间的中值点

## 含绝对值分数幂可导性重数判据通法

> 编号 **T-HS-09-S** ｜ 版本 **v0.10.2** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 可导与否只取决于导数定义商式中分子的无穷小阶，而分母恒为一阶无穷小，故把该点各因子的零点重数累加后与一阶比较即穷尽全部情形；绝对值只能把恰好一阶的零点折成左右异号，对高于一阶的零点无从破坏，对低于一阶的零点也无从挽救 |
| 适用范围 | 由若干因子连乘构成、含绝对值或分数幂指数、要求在给定零点处判定可导性并求导数值的函数，亦可用于统计不可导点个数 |
| 学科 / 章节 | 高等数学 · 一元函数微分学及其应用 |
| 表面题型 | 含绝对值函数的可导性判断题；分数幂指数函数的不可导点个数题；给定零点讨论导数存在性的填空题；求分段连乘函数在某点导数值；绝对值乘积不可导点计数；辨析绝对值复合函数的可导性；绝对值乘子可导的充要条件；含绝对值函数最高可导阶数；含绝对值振荡因子函数的参数分阶；绝对值参数曲线在分界点的可导性；四个含绝对值与积分函数的可导性辨析；含参振荡函数导函数连续的参数条件 |
| 对应考点 | 导数的定义；左导数与右导数；可导与连续的关系；绝对值函数的性质；高阶无穷小与无穷小阶的比较；无穷小阶的确定（泰勒展开）；分段函数求导；高阶导数；导数极限定理（选学）；参数方程 |
| 覆盖题量 | 9 题（分支 12 个） |

### 标准解题步骤

1. 圈定可疑点：把绝对值内部为零的点、分数幂因子取零的点以及分段点逐一点出，列成待判清单
2. 剥出零因子：在该点把函数按因子拆成剩余部分与以该点为中心的幂零因子之积，拆分时先无视绝对值符号，把各因子贡献的重数相加得总重数
3. 校验剩余部分：确认剩余因子在该点连续且取值非零，若其在该点也为零则返回上一步把多出的重数计入
4. 定变号性：判断落在绝对值符号内的部分在该点两侧是否变号，不变号时绝对值符号不影响结论
5. 比较总重数与一阶作判别：高于一阶则可导且导数为零，恰好一阶时依变号性决定并给出剩余部分在该点的取值作为导数值，低于一阶则左右商式发散而不可导
6. 遇不可分解因子先局部线性化：把该因子换成它在该点幂展开的首个非零项，以首项幂次充当其重数后再套判别
7. 逐点回检：对清单上每个点各自重算重数，含参数时按零点是否重合分类，并抽取一点用左右导数定义验证判别结论

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 分数幂因子定阶分支 | 出现指数不是整数的幂或根式因子，且该因子在所判点取值为零 | 把该因子的指数直接计入该点零点重数 → 指数落在零与一之间时按低于一阶处理，判定为不可导 → 指数大于一时按高于一阶处理，判定为可导且导数为零 | 指数为负时函数在该点无定义，判据前提不成立，不能套用 |
| 绝对值变号性判别分支 | 只有一个绝对值因子，判别的实质动作是确定其内部在该点两侧是否变号 | 拆开绝对值符号，只看被它包住的那部分因子 → 统计该部分自身的零点重数：偶数重时两侧同号，绝对值不产生折点 → 奇数重（含恰好一重）时两侧异号，才真正引入折点 → 把该部分重数与绝对值符号外重数相加后再回到总判据 | 仅当被包住部分在该点为零时才需判别变号；该部分非零时绝对值符号可直接去掉 |
| 超越因子局部线性化分支 | 绝对值符号内是三角、对数、指数型等不能直接因式分解的因子，且在该点为零 | 在该点对该因子作幂展开并只取首个非零项 → 以首项的幂次充当该因子贡献的零点重数 → 首项系数为负时其符号被绝对值符号吞掉，不影响重数结论 → 展开后回到剥出零因子与总判据两步 | 该因子展开首项不是一阶（例如一减余弦型）时不能按一重计入，必须先定准首项阶 |
| 多因子同零点与参数重合分支 | 参数取某些值时不同零点相互重合，或所判点同时是多个因子的零点，需按重合与否分类 | 把每个因子在该点贡献的重数逐项相加，禁止只看单个因子的指数 → 含参数时按参数是否使零点重合分类，重合各阶的重数抬升后结论可能反转 → 对每个候选点各自独立重算重数，不得把某点的结论平移到另一点 | 各因子必须在同一趋近点展开，否则重数不可相加 |
| 零点重数与外侧因子判可导分支 | 结论要求统计不可导点的个数，动作是逐点把各因子重数累加后与一阶比较 | 拆出各绝对值因子并统计零点重数 → 检查外侧因子在对应零点是否取零 → 恰好一阶且外侧非零者为不可导点 → 计数并复核 | 前提：外侧因子取零会抬高重数使该点可导；坑点：漏拆复合绝对值 |
| 复合绝对值逐项重数分析分支 | 同一表达式里既有绝对值因子又有光滑复合层，需逐项展开定阶后合成总重数 | 逐项定绝对值内零点重数 → 光滑因子求导后在零点的行为定合成阶 → 恰好一阶折断者为不可导 → 汇总作答 | 前提：内函数首项高于一阶时绝对值不打断；坑点：忽略外层抬升会误判 |
| 绝对值乘子可导充要分支 | 绝对值因子乘抽象函数的可导充要条件 | 两侧按定义写差商 → 约去公共无穷小 → 左右相等化成外侧左右极限关系 → 读充要条件 | 前提：漏左右符号差；坑点：附加多余可导要求 |
| 零点重数定最高可导阶分支 | 含绝对值函数在一点最高可导阶数 | 邻域内去掉不变号的绝对值 → 逐项判各成分在该点的可导阶 → 定义验证临界阶 → 取最低者 → 合成最高阶 | 前提：内函数首项高于一阶时不是折点；坑点：逐项阶数判错 |
| 幂次阈值逐级判阶分支 | 含参的负幂次（倒幂）因子乘以有界振荡因子，动作是按参数阈值逐级判断商式是否趋于零 | 连续性定第一阈值 → 差商幂次定可导阈值 → 导函数极限定连续阈值 → 汇总参数范围 | 前提：阈值递增关系记错；坑点：对振荡因子用洛必达 |
| 参数分界点定义判可导分支 | 绝对值参数曲线在分界点的可导性 | 分参数改写绝对值成两支 → 两支分别按参数求导 → 分界点按定义算左右差商 → 比较左右导数与连续性 | 前提：不回定义直接代分段导函数；坑点：漏验连续性 |

| 幂次压制振荡定导连续分支 | 含参振荡因子与幂次相乘，动作是反解参数使导函数在该点连续（只需该点导数式定阶，不要求邻域内的导函数性态） | 定义求右侧单侧导数定第一阈值 → 写分段导函数 → 两支振荡项分别压制定第二阈值 → 联立严格不等式作答 | 前提：阈值取等混淆；坑点：导函数求导漏项 |

### 失效边界

- **适用前提**：所判点是函数的零点且函数在该点有定义，导数定义中的分子可直接写成剩余部分乘以幂零因子；各因子在该点邻域内均可化为「非零连续因子乘以该点距离的某次幂」，即零点重数可定；只需判定单点可导性与该点导数值、统计不可导点的个数，或反解参数使导函数在所论点连续（该点连续仍由该点导数式的阶决定）；绝对值内因式可分解、外侧因子多项式；绝对值内零点结构简单可展首项；外侧因子有连续导数、折点因子标准；绝对值内函数在该点邻域不变号或其零点结构可判；各成分零点重数可分析；绝对值保证两侧对称，振荡因子有界；绝对值因子标准一阶零点；两支参数表达式明确、变限积分可求导；各项结构可归入标准形态；振荡因子有界、幂次控制可判；与 T-HS-11-S 的左右导数分支重叠时本法优先：凡所判点可化为「非零连续因子 × 该点距离的幂（含绝对值折算）」的乘积结构，一律按零点重数判定，不再退回逐侧算左右导数
- **失效场景**：剥出幂零因子后的剩余部分在该点不连续、无极限或本身趋于零却未计入重数时，重数统计失真，判据失效；分段函数在分段点两侧给出互不相关的表达式且均无幂零结构时，只能回到定义分别算左右导数；所判点函数值非零时绝对值符号与分数幂都不制造可疑性，本法多余，应直接用求导法则；函数在该点无定义，或虽有定义值但分子不趋于零（幂次为负且无有界振荡因子压制）时，商式根本不存在，判据前提不成立；反之若分段点单独规定函数值、幂次为负但乘有界振荡因子使商式仍为该点距离的某次幂乘有界量，则判据照常适用（按阈值逐级判阶支处理）；要求给出邻域内的导函数表达式、或判断导函数在一段区间上的连续性时，本法只给单点结论，推不出邻域性态；只要求导函数在所论点连续时不属此失效，该点连续性与该点导数值同由重数决定；绝对值符号内因子的展开首项不是一阶（如偶次型零点）时，把绝对值符号一律当作折点会造成误判；漏拆复合的绝对值；重数统计错误；外侧零点与绝对值零点重合时漏判可导；一律把绝对值当折点；忽略外层光滑因子对重数的抬升；左右导数计算漏符号；漏掉折点项的符号差；把充分性必要性方向弄反；对绝对值直接求导法则化简；绝对值内函数展开首项高于一阶时不能一律按折点降阶；逐项阶数判断错误导致合成阶数错；只看表达式形式而不在定义点上验证；阈值逐级递增关系记错；对振荡因子试图用洛必达；左右两侧指数不同时漏讨论；漏掉左右符号差；把可导条件写成单侧条件；对外侧函数附加多余的可导要求；不回定义直接代分段导函数；漏验连续性；变限积分求导漏项；把可去间断的变限积分误判不可导；折点重数判断错误；漏项分析；阈值取等与取严格不等混淆；导函数求导漏项；左右两侧的定义值未对齐

### 标准解题步骤

1. 改写定义式：把给定的极限或增量关系整理为固定点处函数值之差除以自变量之差的标准差商形式
2. 配凑基准项：分子缺少该基准点函数值时加减该项凑出定义结构，并核对分子分母增量的倍数关系
3. 判增量阶：考察实际增量相对自变量增量的阶，同阶对应非零导数、高阶对应导数为零、低阶或振荡则导数不存在
4. 分侧验证：分界点与含绝对值、最大最小的表达式须分别求左右差商极限，两侧都存在且相等才能断言可导
5. 回溯连续性：需要函数值关系时由可导直接推出连续，并检验是否误把连续当成可导的依据
6. 区分两个概念：涉及导函数在该点是否连续时回到定义单独验证，不能以导函数的极限代替该点导数

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 线性主部定量分支 | 要求写出函数增量、微分或用线性近似估计函数值的变化量 | 设导数存在并把实际增量写成线性项加高阶余项 → 用线性项作为近似值、高阶余项作为误差量 → 检验余项相对于自变量增量确为高阶无穷小 | 仅在一元范围内可微与可导等价，多元情形不能照搬此结论 |
| 概念链判断分支 | 选项式判断可导、连续、可微、左右导数之间的推出关系，且不涉及导函数极限、幂次条件组合或保号性结论 | 把每个命题翻译成增量阶的表述 → 按同阶、高阶、低阶三种情形逐一验证命题方向 → 需要否定逆向命题时用增量低于一阶或振荡型结构构造反例 | 只能由可导推连续，逆向一律不成立；导函数自身的连续性不蕴含在该点可导之内 |
| 左右导数分支 | 分段点或含最大最小的表达式处需分别求左右差商极限，题目不含待反解参数，且结构不可化为幂零因子乘积（可化的归 T-HS-09-S） | 分别按定义求左右差商极限 → 核对两侧极限都存在且相等 → 不相等时明确记为左右导数存在而该点不可导 | 分界点两侧表达式须已知；断言可导还须函数在该点有定义且取值与极限一致 |
| 定义配凑分支 | 极限式中出现该点函数值之差，但增量系数与分母形式与定义不一致 | 提取分子增量与分母增量的倍数关系 → 补成标准差商并乘回系数 → 若同时含两个不同增量，拆成两处导数的线性组合 | 必须先确认该点导数存在，否则配凑只能给出单侧信息而非极限值 |
| 一点导数与导函数极限区分分支 | 题目直接问该点导数是否存在与导函数在该点极限是否相等、能否互推 | 该点导数一律交由定义验证 → 再单独考察导函数在该点的左右极限 → 只有导函数在该点连续时两者才相等，否则只有一点导数存在可言 | 由导函数极限存在推出该点导数存在，需原函数在该点连续这一前提，缺此前提不得换算 |
| 分段点连续条件锁参数分支 | 分段函数在分段点只要求连续（或已知连续），据此反解一个待定参数 | 把连续条件改写为极限值等于分段点定义值的等式，明确方程两端 → 拆项分式逐项判断能否分别取极限，再定各部分的无穷小阶 → 用等价无穷小或凑导数定义求出拆出各项的含参极限 → 令所得极限等于分段点处的定义值解出参数 → 回代分别检验左右极限存在且相等，确保连续而非单侧成立 | 分段点处分子分母同趋于零且未定式可控；拆项后某项极限不存在时不能对和式分项取极限，相消需保留更高阶信息时只用一阶等价会出错 |
| 导数定义结构定间断分支 | 分式在分母零点处的极限可补成分子在该点的差商，且分子在该点可导 | 定位分母为零或分段规则单独规定的那一点，作为唯一可疑点 → 靠拢该点极限与导数定义的结构，用分子在该点的函数值补出差商形式 → 利用可导条件判定该极限存在且有限，从而排除第二类间断 → 比较极限值与该点规定的函数值，相等则连续、不等则间断 → 利用题设导数非零条件检验两者确不相等，避免巧合相等改变结论 | 前提：分子在该点可导且分母为该点的简单一次因子，函数在该点有单独规定的取值；坑点：分子在该点不可导时极限未必存在，分母为高阶零点时商式趋于无穷而变成第二类间断，把极限存在但不等于规定值当作连续 |
| 变限积分左右差商对照分支 | 分段函数中变限积分就是被判可导的那个整体，动作是把差商极限化为被积函数的左右极限 | 分参数为正、为零、为负三种情形对含参极限分别取值，写出分岔后的分段解析式 → 检验分段点处该分段函数的左右极限与定义值，标注间断类型 → 写出变限积分的增量式，利用积分对有限跳跃的抹平性判断其连续性 → 分别求左、右差商极限，并把它们与被积函数在该点的左右极限对照 → 判定左右导数是否相等从而确认可导性，不相等则归为连续但不可导 | 前提：被积函数在积分区间上只有有限个跳跃且处处可积，差商极限可化为被积函数单侧极限；坑点：在间断点直接套用微积分基本定理断言变限积分可导，被积函数含无穷型间断导致积分发散，忘记分岔条件把极限式当作统一解析式处理 |
| 分段点双条件锁参分支 | 分段点处有两个待定参数，须联立连续与可导两个条件求解 | 连续条件列第一个方程 → 两侧差商按定义或法则计算 → 左右导数相等列第二个方程 → 联立解出全部参数 | 前提：只解连续方程就定参会漏参数；坑点：对数一侧差商需化简 |
| 单侧差商定性态分支 | 分段点一侧含抽象有界因子的性态判定 | 两侧分别求极限定连续 → 两侧按定义写差商 → 一侧等价替换降幂、另一侧有界乘无穷小归零 → 比较左右导数下结论 | 前提：等价替换处于乘除位置；坑点：对抽象因子用洛必达或只算一侧 |
| 复合内层差商配凑分支 | 已知导数值求含复合内层的差商极限 | 识别函数值差结构并确认内层趋于定义点 → 分母用等价替换换成同一无穷小 → 拆成差商因子与无穷小比之积 → 差商按定义代值、其余因子求极限后相乘 | 前提：内层必须趋于定义点；坑点：对未知函数本身作等价替换 |
| 任意倍率双点差商分支 | 差式两端是同一点不同倍率增量处的函数值 | 加减该点函数值把差拆成两项 → 每项配凑成标准方向差商并归一倍率 → 按定义分别收口后相加 | 前提：倍率为零时除法非法需单独处理；坑点：两点差不能当一个差商 |
| 已知极限反推导数再配凑分支 | 由含未知函数的极限反推其导数值再求另一差商 | 剥去已知极限的复合外壳 → 由连续性定函数值并把极限读成导数定义 → 所求式按内层增量拆成差商组合 → 各配增量比因子后按定义收口 | 前提：函数必须连续才能剥壳定值；坑点：差商不能漏除增量 |
| 单侧定义函数性态分支 | 函数仅在所论点单侧有定义 | 算单侧极限与函数值比较定单侧连续 → 按定义写单侧差商 → 判差商敛散下结论 | 前提：双侧概念不适用于单侧定义；坑点：右极限存在不等于右导数存在 |
| 函数方程差商定解析式分支 | 函数方程与高阶余项求解析式 | 把小增量识别为自变量增量 → 读出可微性与微分方程 → 分离变量积分 → 初值定常数得解析式 | 前提：余项阶数不足只知连续；坑点：分母零点单独讨论 |
| 微分与增量线性主部比较分支 | 比较微分与自变量增量的阶 | 写出微分定义式 → 作微分与增量的商 → 代该点导数值定阶 | 前提：导数值为零时阶的结论不同；坑点：把微分与增量之差当微分 |
| 洛必达一次后导数定义收口分支 | 低阶信息已知且分式可配成差商 | 确认零比零后洛必达一次 → 把分子配成导数定义差商 → 按定义代值收口 → 警惕高阶导连续性未知不得再洛必达 | 前提：题给只到某阶可导时严禁对更高阶洛必达；坑点：泰勒展开阶数要足 |
| 由含参极限证可导分支 | 由含未知函数的极限证明可导并求导数值 | 把极限写成极限值加无穷小 → 解出函数表达式 → 连续性定该点函数值 → 差商化简归于已知极限收口 | 前提：未先定函数值就写差商；坑点：余项高阶性要利用 |
| 微分增量主部反求导数分支 | 题设给出微分或增量的线性主部关系，据此求含变限积分的比式极限（积分不作为待判对象） | 由增量关系读出该点导数值 → 分母等价替换成主部幂 → 变限积分求导或换元化简 → 剩余差商配成导数定义收口 | 前提：只知连续无增量阶时读不出导数；坑点：变限求导漏上限因子 |
| 可导充分条件幂次匹配辨析分支 | 选项以「某增量被 \|Δx\| 的若干次幂控制」的形式给出，动作是逐个匹配幂次与一阶的关系 | 逐项配凑差商形态 → 核对幂次匹配 → 序列趋近与对称差商只给必要 → 夹逼型给充分 | 前提：序列极限当全极限；坑点：夹逼漏函数值先为零的论证 |
| 差商倍数反解切线斜率分支 | 由差商极限求切线斜率 | 代换统一差式方向 → 配凑导数定义的倍数关系 → 由极限反解导数值 → 导数值即斜率 | 前提：增量方向弄反漏负号；坑点：把极限值直接当斜率 |
| 高阶控制夹逼定导数分支 | 函数绝对值被增量的高次幂控制 | 代入增量零点定函数值 → 写差商取绝对值 → 用界控制成增量的线性函数 → 夹逼得导数值 | 前提：控制不等式须对双侧邻域成立；坑点：夹逼方向弄反 |
| 单点导数保号性辨析分支 | 已知该点导数不为零（多为 f'(x0)>0）要判断能推出哪些邻域内结论；若题设只给导函数在去心邻域的极限而不给该点导数，归「导函数极限与可导性辨析分支」 | 写成单侧差商极限 → 保号性给右侧邻域函数值比较 → 左侧同理反向 → 排除由单点信息推区间单调 | 前提：由一点导数推区间单调；坑点：左右保号结论混同 |
| 切线截距差商定义收口分支 | 求切线截距相关的比式极限 | 切线方程令纵坐标为零解截距 → 比值整理成零比零 → 洛必达一次 → 剩余配成导数定义代值 | 前提：对二阶导继续洛必达需连续性；坑点：截距化简出错 |
| 分段导函数连续性分级判别分支 | 要求一阶导连续而二阶导不存在（或按可导阶数分级），据此定参或判间断 | 连续定常数 → 左右导数相等定参数并保证导函数连续 → 分段导函数写出 → 二阶左右差商不等定参数排除条件 | 前提：跳过导函数连续性；坑点：左右差商漏一侧 |
| 函数方程组合差商定导数分支 | 周期函数与函数方程联立求切线 | 取极限由周期性定基点函数值 → 差商配凑成导数定义组合 → 解出基点导数 → 周期平移后点斜式写切线 | 前提：高阶余项直接丢项；坑点：周期平移点算错 |
| 系数和即导数值夹逼分支 | 三角多项式系数和的界估计 | 求导读出系数和为该点导数 → 写定义差商极限 → 用已知函数界夹住差商 → 极限保序得界 | 前提：绝对值直接塞进极限；坑点：忘用定义点函数值为零 |
| 导函数极限与可导性辨析分支 | 题设只给导函数在去心邻域的极限（常为分段导函数）而不给该点导数值，要求据此判断原函数在该点可导性、连续性或间断类型 | 保号性给去心邻域导函数为正 → 两侧邻域单增 → 跳跃反例：导函数极限存在而函数不连续 → 排除其余选项 | 前提：导函数极限当单侧导数；坑点：反例不满足前提 |

### 失效边界

- **适用前提**：讨论对象是一元函数在一点或一个区间内的可导性、可微性与连续性的关系；该点邻域内的函数表达式已知，或增量与自变量增量的阶可以直接估计；题目形式为概念判断、由定义求差商极限或单点（分界点）可导性讨论；分段点处分母趋于零且分子同趋于零，属可控的未定式；函数在该点的定义值以含参表达式给出；分子在该点可导且分母为该点的简单一次因子；函数在该点有单独规定的取值；被积函数在积分区间上只有有限个跳跃且处处可积；差商极限可化为被积函数单侧极限；分段点两侧表达式已知且参数使函数在该点连续；左右导数可通过定义或洛必达求出；两侧表达式明确且抽象因子有界；等价替换处于乘除位置；已知函数在该点可导且函数值给定；内层增量与分母可化为同一无穷小；函数在该点可导；倍率为任意实数；函数连续使复合外壳可以剥去；各内层增量都趋于同一被减点；函数在该点有定义且单侧表达式已知；分段点两侧表达式已知；参数使函数连续；函数方程对所论范围内任意变量成立；已知一点的导数值；已知低阶导数值且分式可配成差商；函数在该点连续且已知极限有限；无穷小余项的高阶性可利用；函数连续使变限积分可导；增量关系在被减点成立；各选项极限式的结构可配凑；增量与被减方向一致；存在平方型控制不等式对邻域内一切点成立；该点导数存在且符号确定；余项是增量的高阶无穷小使可微性成立；分离变量合法（分母不为零）；二阶导连续恒正使一阶导严格为正；各极限可分步求；各段表达式可求导；差商极限可算；函数周期已知且在基点可导；增量余项为高阶无穷小；各选项结构可完全分析；函数界对一切增量成立；定义点函数值为零；函数在该点附近二阶可导且二阶导数值非零；导函数在去心邻域存在
- **失效场景**：多元函数的偏导、可微与连续关系不适用本骨架，一元下「可微等价可导」在多元端直接失效；只知连续而无增量阶信息时不能推出可导，连续但增量低于一阶正是典型的反例来源；该点导数存在不等于导函数在该点连续，把两者混用会使极限交换与间断点判断出错；抽象函数只给出函数方程或不等式而无具体表达式时，判阶一步无法执行，只能回到定义逐条验证；分界点处只验证单侧差商极限就断言可导，属于结论超出前提的失效用法；拆项后某项极限不存在时不能对和式分项取极限；分子分母相消需要保留更高阶信息却只用一阶等价替换；只验一侧极限就断定连续；分子在该点不可导时极限未必存在，不能先验归类；把极限存在但大于零直接当作连续；分母为高阶零点时商式趋于无穷而变成第二类间断；在间断点直接套用微积分基本定理断言变限积分可导；被积函数含无穷型间断导致积分发散时讨论失效；忘记分岔条件，把极限式当作统一解析式处理；左右极限不相等时连续性已破坏，可导无从谈起；只验左右导数相等而不先验连续，会把参数解错；含绝对值一侧直接用求导法则忽略折点；对含抽象因子的差商用洛必达；只算一侧就下结论；等价替换用于加减结构；内层不趋于定义点时不能配凑导数定义；对未知函数本身作等价替换；把复合差商当连续函数直接代值；把两点差直接当一个差商配凑；倍率为零时除法非法未单独处理；漏掉其中一项；函数不连续时壳内极限不能拆项；把函数值差直接当导数而不除以增量；两个差商混成一项丢失增量比的差异；双侧概念用于单侧定义函数；把右极限存在误当右导数存在；题目要求可导（或须联立连续与可导两条件）时只解连续方程定参，会漏解或增解；只要求连续或已知连续时解连续方程本身就是正解；对数一侧差商不化简；联立时漏解或增解；增量必须使复合变量落在定义域内；把差商直接当导数而不配凑已知点；积分常数定错；把微分与增量差当成微分本身；导数值为零时阶的结论不同；题给只到某阶可导却对更高阶用洛必达；把导数极限当导数值；泰勒展开阶数不足；未先定函数值就写差商；忽略余项项的高阶性；对未知函数作等价替换；只知连续而无增量阶信息时读不出导数；变限积分求导漏乘上限的导数；对未知函数部分作等价替换；把对称差商当可导充要条件；忽略无穷小乘有限量的干扰；配凑时增量方向弄反；增量方向弄反漏负号；把极限值直接当斜率而忽略倍数；变量代换后未同步改极限过程；控制不等式只在单侧成立时结论变弱；夹逼方向弄反；由一点导数正推区间单调；左右两侧的保号结论混同；余项阶数不足时只能得连续不能得可微；分母为零的点需单独讨论；积分后常数定错；对二阶导继续洛必达需连续性条件；截距求导商法则出错；漏掉两极限分别求的过程；跳过导函数连续性直接谈二阶；左右差商漏算一侧；参数取等号情形误判；忽略高阶余项直接丢项；导数定义配凑时符号弄反；周期平移点算错；把特定序列极限当成全极限；夹逼证明漏掉函数值先为零的论证；幂次与增量匹配关系弄错；把绝对值直接塞进极限内不加说明；忘记函数在定义点取零；求导时链式因子漏乘；对二阶导数继续洛必达需要连续性条件；截距表达式化简错误；导数定义配凑方向弄反；把导函数极限当成单侧导数；反例的导函数极限不满足题设；保号性方向弄反

### 标准解题步骤

1. 判定差式结构：确认分子能否看成同一函数在两个随自变量趋近于同一点的对象上的取值之差
2. 决定构造层次：把包含全部内层结构的整体作为一个函数时只需一次中值定理，逐层拆开时需分层使用并各引入一个中值点
3. 在两个取值之间应用拉格朗日中值定理，写出导数值乘以端点差的形式，并明确中值点落在的区间
4. 由中值点被两端点夹住这一事实定出导数因子的极限阶（等价主部或直接代入极限点）
5. 对剩余的端点差再用一次等价无穷小或中值定理，确定其无穷小阶并与分母比阶
6. 中值点位置不确定时，用区间两端点分别替换中值作出放大式与缩小式，两侧同值即由夹逼定案
7. 若曾拆项或凑配，逐项检验各部分极限单独存在后才允许分别取极限再合并

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 整体一次中值分支 | 差式两端是同一函数在两个内层取值上的差，且内层极限已可合并处理，只需一次中值 | 取整个复合结构为外层函数，端点取两个内层表达式 → 只用一次中值定理得导函数在中值处的值乘以端点差 → 把中值处的导数用其等价主部定阶 → 与分母约阶直接得极限 | 端点差与分母必须同阶，否则仍需对端点差二次定阶 |
| 分层两次中值分支 | 外层差式的两个端点本身各是同一内层函数在两个变量处的取值，内外两层各需一个中值点 | 先对外层函数用中值定理 → 再对内层差用中值定理引入第二个中值点 → 分别用夹逼确定两个中值点的趋向与阶 → 放大式与缩小式同值时由夹逼定案 | 夹逼两侧极限不相等说明放缩过度，须退回整体构造层次 |
| 分子分母各用一次分支 | 分子与分母各自都是同一函数结构的两点差，两次中值后各自定阶再相除 | 分子与分母分别选取函数各用一次中值定理 → 约去分子分母中相同的端点差因子 → 剩下的两个导数值之比在中值处取极限 | 被约去的差因子不得恒为零，且分子分母的端点须落在同一区间内 |
| 凑配拆项分支 | 只有一部分能写成两点差，需先加减凑配，其余部分用等价无穷小或已知极限处理，且拆开后各部分极限须各自存在 | 加减同一项把原式拆成两个极限 → 可用等价或导数定义的部分单独求值 → 剩余部分构造合适的函数与区间用中值定理定阶 → 确认两部分极限都存在后再相减合并 | 拆出的任一部分极限不存在时拆项非法，须换一种凑配方式 |
| 对数内比值化差后中值定阶定参分支 | 对数或幂指的真数是两个趋于同一常数的量之比，且由极限存在非零反解参数 | 把对数写成比值减一的形式，用幂减一等价化为两函数值之差 → 对该差式用拉格朗日中值定理，引入介于两端之间的介点并写成导数乘步长 → 论证介点被区间两端夹住，推出其渐近阶与端点相同 → 合并导数主项、步长与分母的渐近常数，得到关于过程量的幂次表达式 → 比较幂次定出使极限存在且非零的幂指数，再算出对应极限值 | 前提：函数在差分区间连续可导且导数在无穷远有确定渐近阶，真数趋于正数方可用比值减一替换；坑点：直接把介点替换成端点而不验证阶一致，导数含振荡项无确定阶时定阶失败 |
| 已知差商链式复合分支 | 内层差商极限已由题设给出，动作是把它与外层导数值相乘直接定阶 | 引用已知差商极限存在，推出内层函数在该点的极限恰为被减常数，确认差式是无穷小 → 用拉格朗日中值定理处理外层函数在两个函数值之间的增量，引入介于其间的介点 → 用夹逼准则由内层极限确定介点的趋于值，进而定出介点处导数因子的极限 → 识别剩余的差商为题设已知的极限值，与导数因子相乘得结果 → 检验中值定理条件：外层函数在包含两端点的区间上连续且可导 | 前提：外层函数在相关区间上连续可导且导数可求，内层差商极限存在有限；坑点：内层差商极限为无穷时介点因子与差商可能相互抵消，外层函数不可导时不能用中值定理折增量，误把已知极限直接代入复合式而不验证内层趋于常数 |
| 指数增量幂指差分支 | 分子为同底不同指的幂之差，可视为指数函数在两点取值之差 | 统一改写所有根式为以自然常数为底、含对数的幂指形式 → 应用拉格朗日中值定理于两个指数之间的指数函数，引入介于其间的介点 → 分别求两个指数趋于的过程，由介点被夹在中间推出介点趋于零，从而定出导数因子的极限 → 通分指数之差并用对数运算合并，写出其关于过程量的主导阶 → 等价替换分母中的幂减一为同阶量，逐项取极限并检验每个因子极限都存在 | 前提：差式可视为某个可导函数在两点上的增量且导数连续，两个指数都趋于同一有限值；坑点：介点范围无法收敛到定点时不能替换其导数值，把幂差当作两项极限直接相减，各因子极限不存在却对乘积整体分项取极限 |
| 导数极限连接两点差分支 | 一阶导数极限与两点差极限建立等式 | 对函数差用拉格朗日中值定理 → 介点被夹论证其极限 → 差式极限等于导数极限 → 与另一极限联立解参数 | 前提：介点极限未论证直接替换；坑点：幂指归一化指数算错 |
| 指数乘子化组合为导数分支 | 题给函数与导数的线性组合在某方向的极限，动作是认出乘子 e^{kx} 使 [e^{kx}f(x)]' 恰为该组合，从而由导数极限推出辅助函数在该方向的趋势 | 凑指数乘子使组合为乘积导数 → 组合极限为正常数推乘子导数有正下界 → 中值定理推乘子趋于无穷 → 洛必达回推函数极限再解导数极限 | 前提：漏指数乘子引入；坑点：洛必达条件未验证 |
| 导数下界推函数下界分支 | 一阶导数有一致正下界且某点函数值给定，动作是用中值定理将下界传成函数值的区间下界，且该下界仅用于夹逼定出极限值（结论为不等式证明时归 T-HS-02-S） | 已知点与目标点间用中值定理 → 导数下界给增量下界 → 结合已知点函数值非负 → 单调延拓到区间 | 前提：中值点区间写错；坑点：延拓方向弄反 |

### 失效边界

- **适用前提**：分子分母均为无穷小且差式具有同一函数两点取值之差的结构；或由导数线性组合、导数一致下界造出辅助函数后定其无穷远性态，此两支不要求差式为无穷小；两个端点随自变量同时趋于所含区间内部的同一点，函数在闭区间连续、开区间可导；分母的无穷小阶已知，只需定出差式的主部阶数；函数在差分区间上连续可导，导数在无穷远处有确定的渐近阶；对数真数趋于正数，可用比值减一替换；介点与端点的幂次可比较；外层函数在相关区间上连续可导且导数可求；内层差商极限存在有限；介点被两端值夹住从而趋于确定定点；两指数趋于同一有限值，介点极限可定；外层函数在介点所在区间上连续可导；分母阶数已知且展开阶数不低于该阶；差式可视为某个可导函数在两点上的增量，且该函数导数连续；两个指数都趋于同一有限值，使介点极限可定；分母的无穷小阶明确可与分子比较；一阶导数在无穷远有极限；介点随过程量趋于无穷；组合系数与指数匹配；洛必达条件可验证；导数在区间上有一致下界；已知点函数值非负
- **失效场景**：两个端点不同阶趋近或其中之一不落入中值区间时，中值定理提供不了有效的阶信息；约去的自变量差因子本身恒为零（结构恒等）时产生虚假相消，结论错误；需要二阶以上精度且一阶导数主部相消时，单次中值只给一阶信息，仍须泰勒展开补足；表达式含绝对值或分段定义使函数在端点不可导时，定理条件不满足；拆项后某部分极限不存在却仍逐项取极限，会得到与真值不符的结果；导数含振荡项而无确定渐近阶时不能定阶；真数不趋于一时使用等价替换失效；直接把介点替换成端点而不验证阶一致；内层差商极限为无穷时介点因子与差商可能相互抵消而失效；外层函数不可导时不能用中值定理折增量；误把已知极限直接代入复合式而不验证内层趋于常数；两指数趋于不同值时不能把介点处的导数值统一替换；展开阶数不足使主项被误判为零；把幂指差的两项分别取极限后相减；介点范围无法收敛到定点时不能替换其导数值；把幂差当作两项极限直接相减；各因子极限不存在却对乘积整体分项取极限；介点极限未论证直接替换；幂指归一化指数算错；漏掉参数非零的前提讨论；漏掉指数乘子的引入；洛必达使用条件未验证；结论序号对应错误；中值点区间写错；下界系数算错；单调延拓方向弄反

### 标准解题步骤

1. 明确内外层结构与各层的表示形式
2. 按链式法则逐层求导相乘，乘积商按法则展开

### 失效边界

- **适用前提**：低阶导数呈现规律；乘积因子之一为低次多项式；函数在该点存在足够阶展开；指数型因子在无穷远处衰减快于任意幂次增长，使各阶导数在该点的极限为零；各阶商式可化为同一标准形态；方程使每阶导数可写成同型函数的幂；函数在零点邻域存在到所需阶的展开；一阶导数可化为标准初等函数；内层为线性函数使链式因子恒定；函数可分解为 (x−a)^m·g(x) 且 g(a)≠0，重数 m 与目标阶数 n 可对照：n<m 时该阶导数为零，n=m 时取 m!·g(a)，n>m 时须再用莱布尼茨逐项补齐；导数关系可整理成多项乘积；特殊点使二次因子取零；结论要求给出某阶导数的具体值或 n 阶通式；若结论只问该点最高可导阶数或是否可导，归 T-HS-09-S 的零点重数判据
- **失效场景**：归纳跳步不验证；莱布尼茨系数算错；展开阶数不足；递推方向弄反；只用求导法则而忽略点值需用定义；洛必达使用前不验型；幂次与系数对应错位；直接逐阶求导计算量失控；系数与阶乘的对应关系弄反；展开到所需阶就停，漏掉更高阶余项的干扰；符号交替规律记错；链式因子的幂次与阶数错位；对数真数为负未加绝对值；未先比对重数 m 与目标阶数 n 的大小就套 m!·g(a)：n>m 时漏掉莱布尼茨逐项，n<m 时把零值误当成需要计算；等价主项系数算错；忘记乘阶乘；奇偶阶归纳跳步

| 曲率圆反求导数分支 | 已知曲率圆方程（圆心与半径），动作是反求曲线在切点处的一阶二阶导数或函数表达式，方向是曲率圆→曲线 | 切点读函数值 → 圆方程求导得一阶导 → 半径与凹向定二阶导 | 隐函数求导别漏项 |

### 失效边界

- **适用前提**：曲线二阶可导；参数方程曲线横坐标导数不为零；参数点对应曲线上一点且各导数存在；曲率公式分子含二阶导数的绝对值，二阶导在所论区间不变号时方可直接去绝对值，否则须逐区间定号后分段计算；最小值点可解；函数有二阶连续导数使局部信息可用；阶条件足以定出二阶信息；曲线二阶可导、弧长函数可微；半径函数可导且驻点唯一或可比较；二阶导数连续使符号可传递；两曲线在切点有公切线且二阶导恒正；曲线有二阶连续导数、曲率圆方程已知
- **失效场景**：曲率与曲率半径弄反；圆心方向与凹向弄反；二阶导漏乘链式因子；二阶导数漏乘参数对自变量的导数是最高频错误；参数点处横坐标导数为零时需改按纵坐标处理；曲率公式分母的幂次写错；分母绝对值处理错误；只求驻点而不确认是最小；阶条件只给一阶信息时定不出曲率；展开唯一性被破坏（用等价替换改变结构）；弧长微分漏掉根式因子；相除时微分对应关系弄反；代值点代错变量；只给半径漏给曲线上的点；判别缺失直接断言最小；洛必达使用时连续性未验证；半径公式幂次写错；二阶变化率漏乘链式因子；曲率半径表达式化简错误；组合式代值时变量混乱；凹函数与切线位置关系记反；排序漏掉切线本身；凹向与二阶导符号弄反；曲率半径代入漏绝对值处理；隐函数求导漏项
