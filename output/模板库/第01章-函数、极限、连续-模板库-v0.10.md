### 标准解题步骤

1. 定趋近点：趋近点不是零有限点时先作平移或倒代换，把所有展开统一到零点邻域再处理；无穷远端先倒代换化为零型
2. 判型归口：无具体表达式者转概念型，含幂指结构先配基本极限或取对数，含反函数先把反函数值换回原函数自变量，含隐式方程先逐次求导并用原方程回代定出该点各阶导数值
3. 列展开式：写出式中出现的每类基本初等函数在该点的幂展开，分数幂与根式改用二项式展开形式
4. 预估所需阶数：以分母（或比较对象）的最低次幂为展开阶数，复合结构逐层保持同一精度；只作乘积因子时可按最低幂次准则取等价主项
5. 代入并合并：按幂次升序合并同类项，把不低于所需阶的所有项统一归入高阶余项
6. 检验相消：核对首个非零系数是否已出现，分子分母同时归零时必须升一阶重算而不是直接判为零
7. 多路径与方向分离：二重极限按极坐标或加权代换写成径因子乘角因子，角因子有界且径因子趋零即判存在，角因子随方向取不同值时取特殊路径证伪
8. 读出结论：取首个非零幂次的系数之比作为极限值，无穷大场合按对数、幂、指数、阶乘、幂指五档比阶后取主项，数列题最后把连续变量代回离散变量

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 非零趋近点平移分支 | 趋近点为非零有限点，常见幂展开表无法直接套用 | 令新变量等于原变量减去趋近点 → 把每个因子改写成一带无穷小的形式后展开 → 按新变量的幂整理，最后还原变量关系 | 平移后各因子须在该点邻域内可展；含分段或绝对值表达式时要分左右两侧分别平移 |
| 分数幂与根式差分支 | 分子或分母为不同次根式之差，有理化或换元计算量偏大 | 把根式统一写成分数幂形式 → 用二项式展开保留到首个非零阶 → 分母同法展开后直接比较系数 | 两侧一阶项不同时保留一阶即可；两侧一阶项相同则必须升阶，否则主项被消掉 |
| 相消升阶定阶分支 | 展开合并后最低次幂系数恰好抵消，出现全零分子或全零分母 | 提高展开阶数直到出现非零系数 → 按最低次幂原则重新配平分子与分母的阶 → 用系数比确认非零极限并复核余项所在阶 | 所需阶数由分母最低次幂决定；展开不足会把非零有限极限误判为零 |
| 复合与积分上限展开分支 | 式中含函数套函数，或分子为变上限积分、被积函数本身需先展开 | 先展开最内层再逐层外推并保持精度一致 → 被积函数展开后逐项积分，按上限的幂次整体抬阶 → 积分结果与外部因子再按最低次幂合并 | 逐项积分要求展开在该区间内一致可控；上限趋于零的幂次会改变结果的整体阶 |
| 数列极限连续化分支 | 离散变量趋于无穷且通项只依赖该变量的倒数或同一函数结构 | 用归结原则把离散变量替换为连续无穷小 → 对连续形式做幂展开求值 → 把结果代回离散变量表述 | 只适用于通项可统一写成某函数在离散点取值的情形；和式与乘积式数列应改用定积分定义或单调有界准则 |
| 无穷小阶比较分支 | 多个无穷小比较阶的高低或挑最高阶项，且非分式结构首个非零项定阶（后者走 T-HS-14-S） | 对各项分别展开并取最低次幂项定阶 → 用幂次大小直接排序，避免逐本作差 → 积分型无穷小先展开被积函数再按上限幂次定阶 | 定阶只看首个非零幂次；加减结构中不得预先使用等价代换，否则可能把决定阶的主项消掉 |
| 同底指数差先提因子再展差式分支 | 分子为同底（或可化为同底）指数函数之差，分母可等价归为自变量整数幂 | 提出分子中一个指数因子，把两指数之差写成该因子乘以幂减一结构 → 确认提出因子的极限为非零常数，先算出并剥离 → 用幂减一等价于指数上的代数差，把超越差转为代数差 | 提出因子的极限必须是非零有限常数否则不能分离；指数差主项相消时须继续升阶展开，且不得对加减结构整体作等价替换 |
| 比阶关系翻译为幂次不等式组分支 | 题目给出若干无穷小之间高阶、低阶、同阶关系并要求定参数，参数常取正整数 | 确认全部比较对象在同一过程中确为无穷小，否则阶关系无意义 → 对差型因子展开取首个非零项定其幂次，禁止用一阶等价直接相减 → 用乘积的总幂次等于各因子主项幂次之和写出各对象的幂次 | 各因子主项幂次须可由展开或等价形式唯一确定；对加减项分别取等价会使主项相消而阶数虚高，含参幂次非正时展开不成立，把同阶误当高阶会放宽不等式 |
| 乘开对齐比较系数定参分支 | 要求差式与指定幂次同阶或为该幂次的高阶，从而反解多个参数 | 把分式因子按等比级数乘开到指定阶，避免直接对分式作差 → 把指数型等其他因子展开到同一阶并带佩亚诺余项 → 两式相减并按自变量幂次合并同类项 | 各因子可展开到不低于比较所需阶、参数个数不超过可比系数个数、分式分母趋于非零常数；展开阶数不足定不全参数，把系数全为零的高阶情形误当同阶必错 |
| 倒代换定阶锁参分支 | 无穷远处含参极限要求存在且非零，需倒代换后两侧分别定阶 | 作倒数换元把无穷远处过程化为该点附近的未定式，统一比较基准 → 对分子的指数差与三角因子分别用等价无穷小换成幂次，定出分子阶 → 把分母提取公因式后展开，写出含参主项及其系数 | 前提：分子分母均为无穷小且主项系数可显式定出，等价替换只作用于乘除因子；坑点：参数取某些值使分母主项系数为零时同阶比较失效，允许极限为零或无穷时不能只用同阶条件，把分母的两项分别替换导致错误相消 |
| 变限积分待定阶求导建方程分支 | 无穷小由变上限或复合上限积分给出，要求定出其阶本身（而非由给定极限值反解参数） | 由已知比值极限为非零常数，写出被积函数的等价主项并定出其阶 → 确认积分下限为常数而上限趋于该点，断定变限积分为无穷小 → 设所求阶为待定指数，构造该积分与幂次之商的极限 | 前提：被积函数连续且其阶可由已知极限唯一确定，下限固定而上限趋于该点；坑点：把求导降阶写成升阶、上下限同时变化却直接套上限求导公式、在加减结构中用等价替换改变阶 |
| 多对象化幂主项指数排序分支 | 要求对若干无穷小给出完整的阶排序而非两两比较或挑单项，对象含根式差、变限积分与三角指数组合 | 对每个量有理化或恒等变形，消除减法造成的低阶隐藏 → 把变形后的每个量用等价无穷小写成幂函数主项，记录其指数与系数 → 变限积分型先求出积分或对被积函数取主项，再把上限自身的阶乘入 | 前提：每个量在该过程中确为无穷小且有确定的最低次主项，所有比较在同一过程同一自变量体系内进行；坑点：减法主项相消却未展到次阶使阶被严重低估，含量或振荡项无确定阶，积分下限非零的变限积分被当作无穷小 |
| 幂指化指数展开定阶分支 | 被比较量含以自然常数为底的幂或幂指结构，需展开指数到覆盖分母的阶 | 改写比较问题为一个商式，明确要判断的是商的极限为零、有限非零还是无穷 → 统一幂指式为自然常数的幂，并提出极限非零的常数因子 → 展开指数部分到足以覆盖分母阶的项数，舍去高阶皮亚诺余项 | 前提：两式在同一过程中均为无穷小，涉及的函数在该点可展开到比较所需的阶；坑点：展开阶数不足导致最低次项被误判为高阶，对含参相减结构整体作等价替换，被比较式之一极限不为零时谈阶无意义 |

| 幂指取对数与定长积分中值两侧反参分支 | 等式一端是底趋于一、指数趋无穷的幂指式，另一端是长度固定而端点同趋无穷的区间积分，需由两侧同值反求参数 | 对幂指侧取对数，把底数偏离一部分恒等变形为等价无穷小，与指数因子的阶相乘定出指数极限 → 确认底数偏离部分的阶只在乘除位置替换，避免在加减结构中非法等价代换 → 对长度固定的区间积分用积分中值定理写成介点处函数值乘区间长，由介点与端点同趋无穷定出右端 | 幂指侧须属一加无穷小乘无穷指数的标准档，被积函数连续且积分区间长度固定；函数在无穷端极限不存在或为负时不能取对数比较，区间长度随参数变化时积分中值定理给不出定值 |
| 分段拼接有界性扫描分支 | 判定分段函数或含可疑点函数在全域的有界性 | 列出全部分段点、分母零点与无穷远处，作为必须单独考察的关键位置 → 分别求每个分段点的左右极限，由极限存在推出该点某邻域内的局部有界性 → 比较无穷远处分子分母的主导阶，判定该侧函数趋于定值或有界 | 前提：函数在各分段内部连续且分段点处左右极限存在有限；坑点：分段点处为无穷型间断时误用极限存在推出局部有界，无界振荡与有界因子相乘时把整体当作有界，把导数在无穷区间上有界误当作函数有界 |
| 归一凑基本极限通法 | 底数趋于一、指数趋于无穷的幂指极限，含幂或对数结构中隐藏的基本极限，以及由幂次关系反解偏差的场合 | 利用对数或指数函数的连续性，把极限符号移入或移出幂指结构 → 配凑底数除以常数因子为一加无穷小的标准形式，写出该无穷小关于过程量的阶 → 凑出指数为该无穷小倒数的倍数，套自然常数基本极限得到幂值 → 取幂的对数或指数还原，把结果化为关于参数的代数式 | 可用[底数为正且趋于常数一，指数趋于无穷，属标准幂指未定式；参数使归一化分母不为零；幂次关系中的偏差确为无穷小，可作等价替换] 失效[参数使底数不趋于一时不能套基本极限；把对数与极限交换时未验证真数极限为正；指数与无穷小阶不匹配时凑形失败] |
| 标准幂指归一化分支 | 底数趋于一、指数趋于无穷的标准幂指未定式，或由幂次关系（底数的指标次幂趋于定值）反解偏差 | 配凑底数为一加无穷小 → 凑指数为该无穷小倒数的倍数套基本极限 → 指数还原后由无穷小系数读出结果 | 底数不趋于一或幂极限为零时不能套基本极限；取对数需真数恒正 |
| 积分闭合幂指分支 | 定积分先经凑微分闭合为含参表达式，随指标变化的上限含幂指结构需归一化 | 先凑微分算出定积分的闭合表达式 → 把上限的幂指部分配成基本极限形态 → 逐因子取极限并复核每个因子极限存在 | 上限随指标变化时不得当作常数处理；被积函数不可积时凑微分路线失效 |
| 幂指结构反求导数值分支 | 幂指极限存在且已知，反求未知函数在某点的导数 | 配成基本极限形态由极限值锁指数 → 指数中复合无穷小用等价替换化简 → 把函数值与增量之比识别为导数定义 | 前提：函数值不趋于零时替换失效；坑点：开方漏负根 |
| 切线交点归一基本极限分支 | 切线与坐标轴交点随参数变化求函数值极限 | 求切点导数得斜率 → 点斜式写切线并解交点 → 代入函数得含参式 | 前提：切线水平时无交点；坑点：指数归一化系数算错 |
| 幂指夹逼定根数列极限分支 | 隐定义根数列的幂指极限 | 零点定理加单调定根存在唯一 → 构造两侧夹逼窗口 → 幂指式两侧化归基本极限 | 前提：夹逼方向弄反；坑点：唯一性未论证 |
| 含反函数极限的换元归一通法 | 已知原函数解析式而反函数解析式难以求出，需求含反函数的无穷型（或趋近点为无穷）差式极限的题目 | 确认原函数在所考虑的趋近过程中单调且趋于同一极限点，使反函数唯一且代换合法 → 把含反函数的分子按项拆开，化成若干「单个反函数项除以同一幂式」的极限 → 对每一项设反函数值为新变量，即用原函数关系把反函数符号整体替换为其对应的原函数自变量 → 同时把分母幂式按同一关系换成原函数表达式，使分子分母落在同一个自变量上 | 可用[原函数在趋近过程中单调且趋于无穷，反函数存在且随之趋于同一点；分子可拆为有限项，且每一项的极限单独存在；分母幂式与原函数主部的阶数之比可以确定] 失效[原函数不单调（含周期项或振荡项）时反函数不唯一，换元失去意义；拆项后某一部分极限不存在，仍对差式逐项取极限会得到错误结论；直接用等价无穷大替换整个相减分子时主部相消，误差阶无法控制] |
| 以反函数值为变量分支 | 给出原函数解析式且需求含反函数的差式或商式极限，反函数解析式无法显式求出（序列本身的敛散判定走反函数序列敛散判定分支） | 设反函数值为新变量，把反函数项整体换成对应的原函数自变量 → 由原函数关系式替换分母中的幂式 → 检验新变量与原变量同步趋于同一极限点 | 代换前后趋近点必须对应，原函数在该区间须单调以保证反函数单值 |

| 增长层级比阶与有界因子分支 | x 趋于无穷时分式的分子分母含指数、幂、对数等多种增长速率的项，且另乘有界（振荡）因子 | 分子分母各取增长最快的主项（指数远快于幂快于对数），把分式极限化成主项之比 → 由主项之比读出极限（低阶比高阶为无穷小） → 振荡因子用有界性收口：无穷小乘有界因子仍为无穷小，合并写出乘积极限 | 适用前提：各主项的增长层级可按指数/幂/对数直接比较，振荡因子绝对值有界；坑点：振荡因子不能单独用洛必达，主项之比不是无穷小时有界性收口失效，x 趋于有限点时改用泰勒定阶。 |

- 幂指底数趋于一、指数趋于无穷的幂指未定式不能只比阶，必须先取对数再指数还原
- 把无穷大当成具体实数参与比较大小、取倒数或当系数运算，破坏极限定义的合法性，概念题上会选错
- 含阶乘或 n 次根号下 n 阶乘的式子用洛必达连续化失效，须改用斯特林公式或定积分定义
- 分段函数或含参情形只在单侧定阶会漏条件，必须对每个无穷端与每个奇点分别定阶
- 五档之外的增长块（如迭代对数、连乘积、递推定义的量）不能直接套用档位顺序，需先化归或单独证明阶关系

- 把单侧极限存在当作全域有界
- 根式内出现变号使表达式失去定义时性质讨论失效
- 分子次数不低于分母时极限不可能为零
- 只消最高次项而忽略次高项，得到有限非零极限
- 分式在趋于过程中分母变号或未定义时讨论失效
- 函数振荡或变号时商式极限不存在
- 两函数同阶仅差常数因子时无法由阶判定大小
- 把有限点处的取值当作充分大时的次序
- 根式内次数与修正项次数不匹配时无法同时定出两个参数
- 偶次根式在两端的符号不同却不分左右讨论
- 有理化后分子分母同阶却仍令极限为零
- 单侧极限之一不存在或为无穷时无法用相等条件定参
- 把取整函数在点处的值当成左右极限
- 对数内主导项判断错误导致等价替换失效
- 函数极限不存在或为负时不能与指数幂比较取对数
- 积分区间长度随参数变化时积分中值定理给不出确定值
- 幂指底数不趋于一时套自然常数型基本极限造成错值
- 两侧极限之一发散时等式无解却仍强行解参数
- 分段点处为无穷型间断时误用极限存在推出局部有界
- 无界振荡与有界因子相乘时把整体当作有界
- 把导数在无穷区间上有界误当作函数有界
- 参数使底数不趋于一时不能套基本极限
- 把对数与极限交换时未验证真数极限为正
- 指数与无穷小阶不匹配时凑形失败
- 幂极限为零或不存在时底数不趋于一，替换失效
- 把幂指关系按有限项四则运算逐项拆开取极限
- 等价替换用于加减相消结构而未展到次阶
- 被积函数不可积或需分部多次时凑微分路线失效
- 上限随 n 变化却把上限当作常数处理
- 对乘积中含趋于零与趋于无穷的两部分直接分项取极限
- 函数值不趋于零时无穷小替换失效
- 开平方时漏掉负根
- 把未知函数当成具体函数展开
- 切线水平时与横轴无交点
- 未化归基本极限而逐项硬算
- 导数计算漏幂法则的系数
- 夹逼方向弄反
- 幂指极限指数处理错误
- 忘记论证唯一性

- 分式符号判错
- 忘记用连续性传递极限值
- 振荡因子无界（含未定参数的振荡幅）时不能直接用有界性收口

### 标准解题步骤

1. 先判结构：给出和式或连乘积的先试闭合——补共轭、倍角或倒数差分因子使中间项相消，同底幂连乘取对数化为指数上的部分和（必须先闭合求和再取极限，不可逐项取极限相乘）
2. 和式型定界：只放缩通式中影响最小的因素，使两侧化为同一极限值由夹逼收口；识别为定积分定义时转黎曼和通法
3. 递推型定取值范围：由首项与递推式推出各项的正负与大致区间，并标出根式、分母对取值范围的限制
4. 解不动点方程：把递推式两端同时取极限求出候选极限值，舍去落在取值范围之外的根；分式线性递推用两个不动点作交叉比化成等比映射求通项
5. 定界与方向：比较首项与候选值的大小，结合递推函数的单调性确定要证的是上界还是下界、递增还是递减
6. 归纳证有界与单调：以合适起始项验证基础、设第若干项成立并由递推式推出下一项仍在界内；作相邻项之差按递推式因式分解，把新差符号归约为已知差的符号
7. 复核交替：相邻项大小关系反复变号导致整体不单调时，按奇偶项分成两个子列分别执行上述步骤，再由两子列同极限等价于原数列极限存在收口
8. 闭合结论：单调有界则极限存在，再在递推式两端取极限，由极限唯一性确认所求值即候选值；恒等闭合型只需定出末项的趋向

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 整体单调直接分支 | 写出前若干项后大小关系一致，相邻项差可按递推式因式分解定号 | 直接以候选值为界做归纳 → 用递推函数的单调性一次定出差的符号 → 界与单调同侧闭合后取极限得值 | 递推函数须在取值区间内单调递增；单调性只需从某项起成立，前面有限项可先剔除 |
| 奇偶子列分支 | 前几项出现大于号与小于号交替，递推函数单调递减使整体不可能单调 | 把递推式作用两次写出隔项递推式 → 奇数列与偶数列分别做定界与定单调的归纳 → 两子列分别取极限并核对候选值相同 | 两子列极限必须相等，若收敛到不同值则原数列发散；隔项递推式要能显式写出 |
| 辅助函数定号分支 | 相邻项差无法直接因式分解定号，符号取决于某个超越不等式且不呈差商结构 | 把差改写成某个连续函数在数列取值处的函数值 → 对连续变量求导或用已知不等式判定符号方向 → 把定号结论嵌入归纳递推，逐项传递 | 只能对连续化的自变量求导，不能对项数求导；所用不等式须在整个取值区间上一致成立 |
| 隐式与多值递推分支 | 递推关系以方程形式给出，含根号或反函数结构，未显式解出下一项 | 由方程与首项所在区间确定所取分支及符号 → 验证各项都落在使表达式有定义的范围内 → 按选定分支的单调性重复判界与判单调 | 必须先确认符号分支唯一确定实数项，否则数列本身定义不明确，后续归纳无从谈起 |
| 候选值无闭式分支 | 两端取极限所得方程没有初等闭式根，或含超越结构无法显式解出 | 用连续函数零点存在性论证候选值存在且唯一 → 以含候选值的区间端点代替具体数值做归纳 → 只回答存在性，不再声称求出具体数值 | 题目要求给出极限数值时不适用；候选值不唯一时必须先用取值范围排除多余根 |
| 界已显然只需证单调分支 | 值域受限使界由递推式或首项范围直接给出，无需另找候选值作界 | 省去归纳证界一步，直接引用已给取值范围 → 集中用相邻项差或辅助函数定单调方向 → 单调与已知界合并即闭合存在性 | 所引范围必须对所有项公用，且界的方向要与单调方向构成同侧结论 |
| 迭代压缩差收缩分支 | 递推函数把区间映入自身且导数绝对值有严格小于一的一致上界，需给出差的收缩量估计而非仅定单调方向 | 用归纳法验证迭代像始终落在题设区间内，得到数列有界 → 对迭代函数求导判定其单调性，并用拉格朗日中值定理把相邻项差写成介点导数乘前一项差 → 由导数恒正或绝对值小于一推出各项差的符号与大小受控，确定数列的单调方向 | 前提：迭代函数在区间内连续可导并把该区间映到自身；坑点：导数变号时差的符号不定使单调性论证断裂，不动点不唯一时取极限只给出候选值而不能定值，数列不趋于所讨论的点时不能作变量连续化替换 |
| 方程根数列单调有界分支 | 数列各项为含参方程在逐个参数下的根，由零点定理与单调性定义而非递推给出 | 固定参数把方程视为单变量函数，验证区间两端函数值异号以用零点定理 → 对函数求导并判定导数在区间内定号，断定根存在且唯一 → 写出相邻两根各自满足的等式，把其中一个代入另一个函数以比较函数值大小 | 前提：函数在闭区间连续、开区间可导且导数定号，取对数时底数与真数恒正；坑点：导数变号导致根不唯一时无法定义单一下标数列，数列无界时单调有界准则失效，底数趋于零或负值时对数变换失去意义 |
| 比值门槛反证趋零分支 | 已知相邻项比值的极限绝对值小于一，要证数列趋于零 | 对绝对值数列考察相邻项之比，把已知比值极限取绝对值后与一比较 → 用极限保号性取介于该比值绝对值与一之间的数，求出使比值不超过它的项数门槛 → 由比值严格小于一判定绝对值数列单调递减，并以非负性给出下界 | 前提：比值极限存在且其绝对值严格小于一，从某项起各项非零；坑点：比值极限等于一时本法失效，比值极限不存在仅有上界时不能直接用保号性定门槛，数列含无穷多个零项时比值无定义须先改造表述 |
| 反向双单调数列差趋零的反证存在分支 | 两个单调方向相反的数列之差趋于零，要证两者极限都存在且相等 | 反设其中一个数列极限不存在，由单调性把它推到相应的正或负无穷 → 用差趋于零的条件把另一个数列也推到同号无穷 → 指出这与另一数列相反的单调方向矛盾，从而肯定其极限存在 | 两数列必须单调且方向相反且差的极限为零；同向单调时可同时趋于无穷使结论不成立，极限存在且相等也不能断言其值为零 |
| 不动点导数定比值幂指分支 | 递推数列已证收敛后，还要求相邻项比值构成的幂指式极限 | 确认递推函数的值域不等式使各项始终落在同一区间内，得到有界性 → 比较相邻两项作差或作商，或用函数差单调性判定数列的单调方向 → 调用单调有界准则宣告极限存在，对递推式两端取极限解不动点方程并舍去不合理解 | 前提：递推函数在不变区间连续单调，初值落在保证单调性的区间内；坑点：不动点不唯一时未按初值选取正确的根，对递推式两端取极限前未证明极限存在属循环论证，幂指式底数不趋于正数时不能取对数 |
| 拉格朗日差商定号分支 | 递推式中出现差商结构，单调性靠中值定理写成介点导数与步长之积来估计 | 合并递推式中的对数差为单个对数，并改写成等价的指数关系以便比较 → 用基本不等式确认首项满足条件，再由归纳法推出全部项保持同号从而有下界 → 用拉格朗日中值定理估计递推式中出现的差商，得到相邻项的严格大小关系 | 前提：递推函数在不变区间上连续可导，归纳所需不等式在该区间一致成立；坑点：中值定理的连续可导条件在区间端点被破坏时估计失效，未先证存在性就对递推式两端取极限属循环论证 |
| 均值不等式定界的递推不等式取极限分支 | 数列由含倒数或混合项的递推不等式给出且恒正，要求定出其极限 | 对不等式一侧应用均值不等式，把混合项改写为几何平均形式 → 由几何平均严格小于单位一推出相邻比小于单位一，判定数列单调递减 → 指出数列有下界从而极限存在 | 数列恒正且不等式两端可同时取极限，极限非零；极限可能为零时不能对含倒数的一侧取极限，不等式方向不明时均值不等式给不出严格收缩 |
| 奇偶分列的单调有界数列极限通法 | 一阶非线性递推（分式线性、含常数与倒数嵌套等）给出的数列极限存在性证明与求值，尤其整体单调性失效的振荡型递推 | 先算出前有限项的数值，观察相邻项不等号是否交替出现，判断整体单调性是否失效 → 由原递推式迭代一次推出隔项（步长为 2）的封闭递推关系，把奇数项子列与偶数项子列各自写成独立递推 → 解不动点方程得到候选极限值，仅作为归纳法的分界常数，不预先假定极限存在 → 对两个子列分别用数学归纳法证有界：以候选值为界，验证首项落在界的一侧且递推保持该侧 | 可用[递推式右端只依赖前一项，且可迭代化为步长为 2 的封闭递推；递推函数在数列取值区间上连续、可导且保号；不动点方程在数列取值范围内有唯一候选根] 失效[奇偶子列极限都存在但不相等：原数列振荡发散，此时按「极限存在」作答必错；子列无界（递推把值推向无穷）时单调有界准则前提不满足，证不出界；先解不动点方程求出候选值，再把「解出 A」当作「极限存在」的证明，属于循环论证] |
| 隔项作差定号分支 | 隔项递推式作差后能分解为正常数因子乘以低一阶差 | 计算子列相邻两项之差并通分 → 分离出恒正的因子与待判号的差项 → 由首差的符号递推得到全部差的同号性 | 比例因子变号或分母可能为零时无法定号，须改用压缩映射或先缩小取值区间 |
| 候选界反推分支 | 题目未给出界，需要先确定用哪个常数作界 | 解不动点方程得候选值 → 由前若干项落在候选值的哪一侧确定证上界还是下界 → 把候选值作为归纳法的分界点写入归纳假设 | 不动点方程有多个根时须由首项位置选定正确的根，选错会得到方向相反、无法成立的不等式 |
| 压缩映射替代分支 | 子列单调性难以归纳证明，或递推函数在取值区间上导数绝对值一致小于 1 | 写出递推函数并求导 → 在数列取值区间上估计导数绝对值不超过小于 1 的常数 → 用与邻项差成等比的不等式直接夹出极限 | 只能在局部区间得到压缩估计而数列可能跑出该区间时论证不成立；导数绝对值不小于 1 时不可用 |
| 分式线性递推数列的不动点通项法 | 一阶递推且右端可整理为前一项的一次分式（分子分母关于前项均为一次），特征方程有两个不同实不动点的数列极限问题 | 把递推式整理为前一项的一次分式形式，确认分子与分母对该项的次数都为一 → 解不动点（特征）方程，即令该项等于递推式两端所得的方程，求出两个不相等的实不动点 → 分别计算下一项与两个不动点之差，各自通分并把分子按特征方程化简，检验每个分子能写成常数乘以「当前项减同一不动点」 → 把两个差式相除消去公共分母，构造交叉比序列并确认它满足等比递推（公比是与项数无关的常数） | 可用[递推式右端是前一项的一次分式（分子分母次数均为一），或递推对相邻项之差是线性齐次且差分之比可整体提出为与下标无关的常数；交叉比构造另需特征方程有两个不相等的实根且常数项使差式可整体提出公因子；差分构造另需公比绝对值小于 1 使部分和收敛；首项避开奇异点，且后续各项不落入使交叉比或交叉分母无定义的取值] 失效[递推式含非线性项（根式、指数、反三角等复合结构）时不能被共轭化为等比，本法失效，须改用单调有界准则；特征方程出现重根或复根时，两个不动点的交叉比构造不成立；公比模恰等于 1 时交叉比既不趋零也不发散，数列可能周期或发散，本法给不出极限] |
| 交叉比等比化分支 | 递推式为一次分式且特征方程有两个不同实根 | 分别写出下一项与两个不动点之差并通分 → 用特征方程把每个差式的分子归并为常数乘以当前项与同一不动点之差 → 两式相除以消去随项变化的分母 | 两个不动点必须不相等，且递推过程中各项不能落在使分母为零或使交叉比分母为零的取值上 |
| 公比模定极限分支 | 等比公比的模小于 1 或大于 1，数列为振荡型、不需要单调性论证 | 判定公比模与 1 的大小关系 → 模小于 1 时令交叉比趋于零，极限取出现在分子端的不动点 → 模大于 1 时令交叉比发散，极限取出现在分母端的不动点 | 公比模恰等于 1 时本分支不定案，需改用周期讨论或单调有界准则 |
| 通项回代验证分支 | 题目要求先证明极限存在再求值，或首项取值影响可达的不动点 | 由交叉比反解出原数列的显式通项 → 把通项整体代入极限符号，按等比项的趋向取极限 → 检验所得极限满足不动点方程 | 初项恰使某不动点与该项重合时交叉比退化，须单独处理该情形 |
| 差分等比化闭式通项分支 | 递推式对相邻项之差是线性齐次的，差分之比可整体提出为与下标无关的常数 | 写出相邻两项差满足的一阶关系，验证差分之比为与下标无关的常数 → 把差分取为辅助数列，求出其首项与公比并写出通项公式 → 判定公比绝对值是否严格小于1，据此决定差分部分和是否收敛 | 前提：递推对差分为线性齐次且系数为常数，首项与差分初值由题设给定；坑点：公比绝对值不小于1时部分和发散使通项法失效，未证收敛性就直接对递推式两端取极限 |
| 夹逼准则三段乘积通法 | n 项和（或可化为 n 项和）的数列极限，放缩后能配成定积分定义或两侧同值收敛 | 把原式统一写成对指标求和的形式，并先整理分式（通分、有理化、分子分母同乘） → 拆分通式中的全部因素：常数项、含指标的项、含项数的项，按对通式影响大小排序 → 选出影响最小的因素（通常是指标扰动项或纯常数），确定它在求和范围内的最大值与最小值 → 只改变这个最小因素，分别取其端点值作出放大式与缩小式 | 可用[和式项数已知且与放缩后项数一致或仅差有限项；被放缩的因素在整段求和范围内单调且有确定端点值；放缩后两侧表达式都能求出极限并且极限相等] 失效[放缩过度使放大式与缩小式极限不相等，夹逼失效且得不到任何结论；放缩同时改变多个因素，误差阶失控，两侧不再收敛到同一值；含正负交替项时逐项放缩会抵消主阶，方法给出的极限错误] |
| 配定积分定义分支 | 放缩后两侧都能写成项数分之一乘以关于指标与项数之比的一元函数求和 | 从放缩式中提出每行宽度因子（项数分之一） → 把剩余部分统一写成指标与项数之比的函数 → 识别为区间一端到另一端的黎曼和并写出对应定积分 | 通式无法统一化为指标与项数之比的函数时，不能强行配定积分 |
| 同值共趋分支 | 分母主部阶数明显高于分子，放缩后两侧都能直接求和且极限相同（常为零） | 令最小因素取端点值，使每一项变成与指标无关的同型项 → 用项数乘以该项得放大式与缩小式 → 分别取极限确认两侧同值后由夹逼结论 | 两侧极限不相等时该放缩过度，必须改换放缩目标或转配定积分 |

| 和式裂项与根式和式主导项夹逼分支 | n 项和可裂项（望远镜型）或幂指式与和式混排的数列极限题组，不含单纯开次方的最大项主导结构 | 判断通项属于和式、无理差式、根式和式还是幂指式，选定对应化简套路 → 用分母的最小项与最大项分别放大与缩小分母随项数变化的两侧 → 把可拆项通项分解为部分分式，写出相消后仅剩首末项的表达式 | 和式各项同号且分母变化幅度可控、两侧放缩趋于同值；项数趋于无穷同时每项也在变化时不可当作固定项数处理，夹逼两侧不等时不得结论 |
| 单调端点积分拼接分支 | 和式一般项不是标准的项数分之一乘函数值形式，而是被单调函数在定长子区间上的端点值双向控制，累加后区间拼接为一段积分 | 确认函数在整段区间上单调且定号，写出其在单位子区间上的端点双侧估计 → 对估计式逐段积分，得到级数一般项与积分增量之间的双边不等式 → 对下标累加，使积分区间拼接为一段连续区间、级数拼接为部分和 | 前提：函数在积分区间上单调且不变号，端点控制方向一致；坑点：函数在区间内振荡变号时端点不再控制积分值，上下界极限不相等时不能据此断言原式发散，对不等式同乘可能为负的量时必须改变方向 |
| 取对数化乘定积分分支 | 无穷乘积因子趋于一，取对数后为含高阶修正项的和式 | 先把对数增量与其线性主项之差双边估计，确认修正项的阶 → 对连乘积整体取对数，把乘积的极限问题转为对数之和的极限问题 → 用第一步的不等式把每个对数项夹在主项与平方修正之间 | 前提：每个因子为正且其增量随指标趋于零，修正项之和的极限可估计；坑点：因子含非正项或增量不趋于零时取对数与线性替换失效，把无穷乘积按有限项乘积的运算法则逐项处理，修正项之和发散时忽略其贡献 |
| 最大项主导开方分支 | 若干正项之和整体开与项数无关的次方，或和式底数为若干常数之和 | 比较各底数大小，确定随过程量增长的主导项即绝对值最大者 → 提出主导项的幂，把和式写成主导项乘以一加趋于零的因子 → 判断剩余因子是比值绝对值小于一的衰减量，确认其趋于零 | 前提：各底数为正且最大者唯一或并列有限个；坑点：存在绝对值相等的多项且符号交替时不能简单归为最大项，出现负项时开偶次方可能无意义，项数随过程量过快增长时夹逼两侧不再同值 |
| 积分不等式夹逼分支 | 数列由含参定积分或变限积分定义，需证两积分的大小关系并用控制函数夹逼 | 构造两被积函数之差，对其求导判定单调性并用区间端点值确定符号 → 由逐点不等式在积分号下保向，得到两积分数列的大小关系 → 对上层被积函数用线性或幂函数控制，积分出可显式求值的上界 | 前提：积分区间固定且各被积函数连续，逐点不等式在整个积分区间上同向成立；坑点：被积函数在区间内变号时积分不再保持不等式方向，上界积分不趋于零时夹逼给不出结论，积分区间随指标变化时不能直接套用定值估计 |

| 递推和式望远镜分支 | 递推数列的求和式通项可写成相邻项差或共轭差分，累加后中间项逐对相消 | 把通项拆成相邻项差或补配对因子 → 累加后只留首末若干项 → 由末项趋向定出和式极限 | 配对因子必须与原式恒等（乘除或取对数合法），否则闭合改造失真 |
| 同底幂乘积化指数部分和通法 | 项数趋于无穷的乘积型数列极限，因子可化为同底幂或可整体取对数的连乘式 | 把每个因子统一写成同一底数的幂，读出指数所成数列的通项 → 用同底幂相乘则指数相加，把乘积化为底数的部分和次幂 → 识别指数部分和的类型并写出闭合表达式，检验公比或差分结构可求和 → 令项数趋于无穷求部分和极限，确认该极限有限以保证幂有意义 | 可用[各因子可化为同底幂或可整体取对数；指数部分和可闭合求和且其极限有限；底数为正且不等于一，使幂运算连续可用] 失效[因子个数为无穷却对每个因子单独取极限再相乘；指数部分和发散时乘积极限不存在或为零；含负因子或零因子时取对数变形失去依据] |
| 连乘积开高次根的极限 | 把每个因子提出统一的尺度使其成为分点比的函数 | 对整体取对数，把根号与乘积换成对数的平均和式 → 识别该和式为定积分定义并写出对应的积分 → 计算积分值（对数型用分部积分） | 各因子恒正使对数有意义；失效：因子含零或变号时不能取对数 |

### 失效边界

**适用前提**（67 条）

- 递推式为单变量自治形式，下一项仅由前一项决定且对应函数连续
- 首项给定或给出首项所属区间，足以唯一确定各项的符号分支与取值范围
- 不动点方程在取值范围内恰有一解，可同时充当界与单调比较的分界
- 题目只要求存在性与极限值，不要求收敛速度或误差估计
- 迭代函数在区间内连续可导并把该区间映到自身
- 导数恒正或绝对值严格小于 1，使差的符号或大小可控
- 所转函数极限存在，数列项趋于该点从而可作变量连续化
- 函数在闭区间连续、开区间可导且导数定号
- 数列单调且有界两个条件同时成立
- 取对数时底数与真数恒正
- 比值极限存在且其绝对值严格小于一
- 从某项起各项非零，使比值运算合法
- 结论只要求趋于零，不要求给出趋于零的速度
- 两数列单调方向相反
- 差的极限存在且为零
- 递推函数在不变区间上连续且单调
- 初值落在保证单调性的区间内
- 不动点处导数存在且比值型幂指式的底趋于正数
- 递推函数在不变区间上连续可导
- 初值使各项始终落在可估计的区间内
- 归纳法所需的单调性与不等式在该区间一致成立
- 数列恒正且不等式两端可同时取极限
- 极限非零，含倒数的一侧取极限仍有意义
- 递推式右端只依赖前一项，且可迭代化为步长为 2 的封闭递推
- 递推函数在数列取值区间上连续、可导且保号
- 不动点方程在数列取值范围内有唯一候选根
- 题目允许使用数学归纳法与单调有界准则
- 递推式右端是前一项的一次分式（分子分母次数均为一），或递推对相邻项之差是线性齐次且差分之比可整体提出为与下标无关的常数
- 交叉比构造另需特征方程有两个不相等的实根且常数项使差式可整体提出公因子；差分构造另需公比绝对值小于 1 使部分和收敛
- 首项避开奇异点，且后续各项不落入使交叉比或交叉分母无定义的取值
- 和式项数已知且与放缩后项数一致或仅差有限项
- 被放缩的因素在整段求和范围内单调且有确定端点值
- 放缩后两侧表达式都能求出极限并且极限相等
- 和式各项同号且分母变化幅度可控，两侧放缩趋于同一值
- 通项可分解为相邻项之差
- 根式内主导项唯一且各底数为正
- 函数在积分区间上单调且不变号，端点控制方向一致
- 上下界除同一主项后极限存在且相等
- 拼接后的积分可显式求出或其主项可估
- 每个因子为正且其增量随指标趋于零
- 修正项之和的极限可估计且不影响主项
- 主项和式可化为可求值的定积分或可夹逼
- 各底数为正且最大者唯一或并列有限个
- 项数固定或增长远慢于主导项的指数速度
- 积分区间固定且各被积函数连续
- 逐点不等式在整个积分区间上同向成立
- 控制函数的积分可求且其极限为零
- 被积函数以正数为周期且在一个周期上可积、不变号
- 分母随上限同步趋于无穷，两侧放缩后极限相同
- 需要的是整体极限而非振荡部分的具体形状
- 内层非负条件与开根分支一致
- 被夹的和式两侧界极限相同
- 黎曼和分点严格等距且函数连续
- 通项可精确化为相邻项之差或相邻因子之商，相消后仅剩有限多个端点项
- 补入的因子在整个求和或求积过程中非零且有确定极限，变形恒等成立
- 各项同号或符号规律明确，末项的极限可独立由单调有界或定阶手段确定
- 各因子结构满足倍角或平方差的递推关系
- 补因子非零，变形在整个过程中恒等成立
- 分母幂次与各因子主项阶可比较
- 一般项可代数化为相邻项之差，形成裂项结构
- 数列各项非零且倒数数列的极限可独立确定
- 相消后仅剩有限多个端点项
- 各因子可化为同底幂或可整体取对数
- 指数部分和可闭合求和且其极限有限
- 底数为正且不等于一，使幂运算连续可用
- 各因子恒正使对数有意义
- 对数和式的分点均匀且函数连续

**失效场景**（85 条）

- 递推式显式含项数（非自治）时，两端取极限所得方程不再成立，五段法整体失效
- 取值范围内无不动点或有多个不动点时，候选界不存在或界方向不唯一，判界与判单调无法闭合
- 数列本身无界或发散，任何归纳基础都会失败，须改用其他存在性判据
- 奇偶子列收敛到不同值时原数列极限不存在，此时仍按合并分支写出结论会得到错误答案
- 先假设极限存在解出数值再当作存在性证明，属于循环论证，必须先证存在再取极限求值
- 要求通项公式或收敛阶的问题不能由存在性论证完成，应改走递推求解或压缩映射估计
- 单调性自第一项不成立且未剔除有限项时，归纳基础选错起始项会使命题链条断裂
- 导数变号时差的符号不定，单调性论证断裂
- 不动点不唯一时取极限只给出候选值而不能定值
- 数列不趋于所讨论的点时不能作变量连续化替换
- 导数变号导致根不唯一时无法定义单一下标数列
- 数列无界时单调有界准则失效
- 底数趋于零或负值时对数变换失去意义
- 比值极限等于一时本法失效，需改用其他判敛手段
- 比值极限不存在仅有上界时不能直接用保号性定门槛
- 数列含无穷多个零项时比值无定义，须先改造表述
- 比值绝对值大于一时结论反向，数列发散
- 两数列同向单调时可同时趋于无穷，结论不成立
- 两极限存在且相等不能进一步断言其数值为零
- 数列不单调时不能只用单调有界准则，需改用夹逼或子列
- 对递推式两端取极限前未证明极限存在
- 不动点不唯一时未按初值选取正确的根
- 数列不单调时单调有界准则不适用
- 未先证存在性就对递推式两端取极限
- 中值定理所需的连续可导条件在区间端点被破坏
- 极限可能为零时不能直接对含倒数的一侧取极限
- 不等式方向不明时均值不等式给不出严格收缩
- 奇偶子列极限都存在但不相等：原数列振荡发散，此时按「极限存在」作答必错
- 子列无界（递推把值推向无穷）时单调有界准则前提不满足，证不出界
- 先解不动点方程求出候选值，再把「解出 A」当作「极限存在」的证明，属于循环论证
- 整体不单调却硬对原数列用单调有界，会在单调性一步写出错误的不等式
- 递推式含前两项及以上（步长不为 1 的高阶递推）时奇偶分列不再封闭，本方法需先化为一阶系统才可用
- 数列取值跨过递推函数的间断点时，隔项递推的保号性与单调性传递中断
- 递推式含非线性项（根式、指数、反三角等复合结构）时不能被共轭化为等比，本法失效，须改用单调有界准则
- 特征方程出现重根或复根时，两个不动点的交叉比构造不成立
- 公比模恰等于 1 时交叉比既不趋零也不发散，数列可能周期或发散，本法给不出极限
- 递推涉及前若干项之和或高阶递推时不属于一阶分式线性，不能直接套用
- 只要求证极限存在而不需求通项时，本法计算量远大于单调有界准则，考场上不经济
- 公比绝对值不小于 1 时部分和发散，通项法失效
- 差分之比不是常数时不能构造等比数列
- 未证收敛性就直接对递推式两边取极限定值
- 放缩过度使放大式与缩小式极限不相等，夹逼失效且得不到任何结论

- 项数随 n 指数增长使常数开 n 次根不再趋于一时夹逼失效
- 出现负项时开 n 次根可能无意义
- 被积函数在区间内变号时积分不再保持不等式方向
- 上界积分不趋于零时夹逼给不出结论
- 积分区间随指标变化时不能直接套用定值估计
- 被积函数变号时，用周期端点做单调放缩不成立
- 忽略分母放缩方向与分子同向，得出两界不收敛于同一值
- 试图直接对被积函数求原函数来处理绝对值，分段无穷
- 忽略内层非负条件而取双分支

- 末项不收敛（含振荡因子或参数使末项趋于无穷）时闭合表达式仍定不出极限
- 对无穷多项的和式或积式直接使用有限项运算法则，或补因子改变了原式定义域

- 参数取使某因子为零的临界值时相消表达式失效

### 标准解题步骤

1. 先问有无具体表达式：无表达式（抽象函数、只给性质的函数）或表达式含无法展开的指数嵌套，归入定义概念型
2. 有具体表达式时再排除求和形式与递推形式，剩余一律归入具体函数（数列）型
3. 定义概念型：用极限存在的充要条件逐侧（或逐子列）考察，并以唯一性、局部有界性、保号性作推断
4. 具体式型：先定出分母的无穷小阶，把各部分展开到同阶，合并主部取比值，出现相消时提高展开阶数
5. 和式型：整理为对指标求和的形式，只放缩影响最小的因素使两侧同极限，或识别为定积分定义
6. 递推型：先用数学归纳法证单调有界以确认极限存在，再对递推式两端取极限定值
7. 逐点分岔型：含 n 次幂等随点分岔的结构，先按底数绝对值与 1 的大小关系写出各段解析式，分岔边界单列为可疑点
8. 分段复合适配：逐层做内层值域与外层分段条件的匹配定出外层表达式，可疑处仅在分段边界
9. 回检归类是否唯一：间断点分类同样归约为单侧极限计算，与函数值比较后按定义归类，确认每一型的判据都已执行

| 逐点极限定被积函数分支 | 含参逐点极限定义的被积函数的变限积分性态 | 逐点算极限得分段函数 → 定间断类型 → 跳跃间断使变限积分连续不可导 | 前提：间断点套基本定理；坑点：奇偶传递弄反 |
| 由对数和式极限定义的分段函数的变限积分可导阶数 | 比较两底数大小分情形提出主导因子，取对数后除以阶数取极限 | 写出所得分段表达式并检查分段点处两支值是否相等 → 由被积函数连续推出其变限积分可导 → 分别求被积函数在分段点的左右导数（按定义取差商极限） | 分段点处两支函数值相等保证连续；失效：分段点函数值不等时误判可导 |
| 间断点逐点单侧归类通法 | 初等函数、分段函数、含变限积分或含参极限的函数的间断点判定、类型分类与个数统计 | 解出分母为零、真数非正、无定义及分段规则单独规定的全部可疑点，穷尽候选 → 对每个候选点拆分表达式为若干因子，逐因子记录单侧极限是零、有限非零还是无穷 → 有界因子乘无穷小先归零，反三角或倒数指数型因子按左右两侧分别取端值或主导项 → 比较左右极限：存在相等且等于函数值则连续，相等而不等函数值为可去，不等为跳跃，至少一侧无穷为无穷间断 | 可用[候选点为有限个且各因子单侧极限可分别求出；复合结构可拆成有界因子与无穷小因子之积，或两侧渐近主项可分别定出；该点是候选间断点且左右两侧渐近行为可分别求出] 失效[有界因子本身振荡无极限时不能用乘积归零结论；忽略两侧符号差异而只求单侧极限；把函数无定义直接判为第二类间断] |
| 双侧渐近主项对照分支 | 指数中含自变量的倒数或取整结构使左右两侧渐近主项不同，需分侧化简后比较左右极限 | 按侧去掉绝对值并判断倒数指数项各侧趋于零还是无穷 → 同除最大项定出该侧主部 → 比较左右极限后按定义归类 | 只算双侧合一的极限会遗漏单侧差异；振荡不存在不得归为跳跃 |
| 有界乘无穷小归零分支 | 复合结构可拆成有界因子与无穷小因子之积，先判能否归零，再对不能归零的因子分侧取端值 | 解出内层分母零点得候选点集 → 有界乘无穷小先归零 → 反三角型因子在正负无穷处取不同端值，分侧求极限后归类 | 有界因子本身振荡无极限时不能用乘积归零结论；忽略两侧符号差异只求单侧极限会误判 |
| 等价主项代换计数分支 | 分母含变限积分或需以等价幂函数主项代替后再逐点定类，统计特定类别间断点个数 | 穷尽分母零点与无定义点为候选 → 变限积分分母换成等价幂函数主项 → 含倒数指数的因子按左右侧分别判断后逐点归类并计数 | 积分下限也随点变化时不能直接等价替换；把振荡无极限归为第一类间断属误判 |
| 分段复合逐层值域归段通法 | 多层分段函数（含取整、符号、最大最小与极限分岔式）复合求值、求解析式与边界点连续性讨论 | 求最内层函数的值域而非逐点解析式，作为后续匹配的起点 → 用当前值域逐段比对分段条件，判断外层自变量整体落入哪一段 → 由内向外逐层求复合，每求完一层立即更新该层的值域 → 检验某层输出是否恒落在同一段上，若是则该层以后各层化为常值或同一表达式 | 可用[各层函数均以分段条件给出且值域易于整体确定；内层值域完全包含在某一段的定义条件内；题目只要求复合后的取值或解析式，不要求一致收敛类结论] 失效[内层值域跨越多个分段条件时必须分段讨论，不能给出统一结果；把分段边界的等号归属写反导致复合结果错误；复合层次或括号嵌套顺序理解错误] |

### 失效边界

**适用前提**（51 条）

- 题目落在求极限或判定连续性与间断点这两类应用之内
- 表达式的结构特征（有无具体式、有无求和、有无递推）足以唯一归类
- 概念型题目只考存在性判据与极限三条性质的推断
- 函数为初等式，间断点只能出现在定义边界处
- 各可疑点的单侧极限可通过基本极限或等价替换算出
- 两个函数在同一过程中均严格趋于无穷且不变号
- 运算法则所需的极限存在性得到满足
- 振荡因子在趋于过程中反复取到零与极值，可构造两类点列
- 单调增长的幂因子提供无界性来源
- 题设仅告知两数列极限不存在，无其他附加约束
- 反证中使用四则运算时涉及的两个极限都存在
- 所举反例须同时满足全部前提
- 命题涉及的两个数列极限均存在有限
- 保号性要求辅助数列的极限严格为正或严格为负
- 反例必须满足原命题的全部前提
- 前提只给出有界性、无界性或发散性而未给出保号性
- 反例必须严格满足该选项的前提
- 外层函数在内层取值范围上连续或单调有界
- 反例必须落在命题给定的取值范围内
- 每个选项都能归入左右极限、子列一致性、有界必要条件、夹逼准则四类存在性判据之一
- 夹逼放缩所得上下两侧表达式极限存在且相等
- 函数在对称区间可导（第一问）
- 原函数导数在邻域内严格单调
- 基准点函数值与导数值已知
- 导函数在无穷远有确定的下界
- 分岔条件由底数所在区间唯一确定且分岔边界有限个
- 每种情形下n次幂的极限易于求出且可写出显式分段式
- 函数在边界点有定义，或题目允许按极限值补定义
- 逐点极限的分岔条件由参数所在区间唯一确定
- 每种情形下的极限易于求出且分岔边界有限个
- 逐点极限可显式算出
- 被积函数可积
- 分段点处两支函数值相等保证连续
- 指数最大项主导极限
- 左右导数各自存在
- 候选点为有限个且各因子单侧极限可分别求出
- 复合结构可拆成有界因子与无穷小因子之积，或两侧渐近主项可分别定出
- 该点是候选间断点且左右两侧渐近行为可分别求出
- 指数倒数项在两侧的极限方向相反
- 绝对值项可按侧写成确定符号
- 分母连续且其零点可解、零点阶可用等价或洛必达确定
- 每个候选点的左右极限可分别求出
- 间断点只来自无定义点或分母零点
- 复合结构可拆成有界因子与无穷小因子之积
- 内层函数在两侧单调趋于确定的正负无穷或有限值
- 可疑点为有限个且各因子单侧极限可分别求出
- 指数中的分母在各侧符号明确可判
- 各层函数均以分段条件给出且值域易于整体确定
- 内层值域完全包含在某一段的定义条件内
- 题目只要求复合后的取值或解析式，不要求一致收敛类结论
- 各层函数均以分段条件给出且值域容易整体确定

**失效场景**（67 条）

- 同一题兼具求和与递推两种特征时，单一分支不充分，必须先化归再选法
- 只考极限运算法则或等价替换使用条件时，本分类不提供计算手段
- 倒代换、零代换、三角代换、洛必达等技巧未被四法覆盖，四法之外的情形不能只靠归类定法
- 概念型题目要求构造反例时，本框架只给判据不给构造方法
- 把方法清单当作知识点清单使用（未先判类型即套技巧）会选错工具，此时本通法不被执行
- 振荡型无极限的表达式不能简单归入第一类或第二类
- 把函数在某点无定义直接等同于第二类间断
- 只算一侧极限就断定间断类型
- 无穷大相减或相除直接断言结果类型
- 无穷小相减时误用有限个无穷小之和仍为无穷小的结论于变号情形
- 把趋于无穷的速度差异默认当作同阶处理
- 仅凭存在一个趋于无穷的点列就断定函数为无穷大
- 把振荡有界因子当作存在极限的常量参与乘积运算
- 忽略零点列而误判为无界即无穷大
- 由和的极限存在直接推出各项极限存在
- 把子列极限当作整个数列极限使用运算法则
- 对不存在的极限取绝对值或作除法运算
- 极限仅为非负而非严格为正时不能得严格不等式结论
- 数列极限不存在时用子列结论冒充整体结论
- 把逐项成立的不等式在取极限后仍保持严格号
- 用个别例子去肯定一个全称命题
- 无界数列相乘时因子交替取零会使乘积恒有界
- 外层函数有水平渐近线时不能由外列收敛反推内列收敛
- 仅有单调性而无有界性时收敛性结论不成立
- 把振荡但有界的因子当作可等价替换的定值处理，从而误判极限存在
- 数列已无界仍套用极限四则运算法则
- 只验证一条子列就断言函数极限存在
- 对幂指式不分底数趋于的情况直接取指数极限
- 把极值点两侧必单调当必然
- 反例不满足题设全部前提
- 奇偶翻转规律用错
- 单调方向与不等号方向弄反
- 两侧结论想当然对称
- 忘记先算基准点差值
- 反例不满足可导前提
- 把单侧过程与双侧混淆
- 忽略下界只保证最终成立
- 把逐点极限当作一致极限，直接对极限式套用连续性法则
- 分岔边界处极限随趋于方式不同而改变时仍合并讨论
- 底数可取负值且偶次幂振荡使分岔表达式写错
- 要求一致收敛、可导性或极限与积分交换等更强结论时
- 分岔边界处极限不存在或随趋于方式不同而变化时不能合并讨论
- 把逐点极限当作一致极限而直接对极限式用连续性法则
- 忘记底数为负时偶次幂的振荡导致分岔写错
- 在间断点套用微积分基本定理
- 奇偶传递方向弄反
- 逐点极限漏掉分界点
- 分段点函数值不等时误判可导
- 用求导法则代替左右导数定义判接点
- 把被积函数的连续与可导混为一层
- 有界因子本身振荡无极限时不能用乘积归零结论
- 忽略两侧符号差异而只求单侧极限
- 把函数无定义直接判为第二类间断
- 把振荡型无界但不趋于无穷误判为无穷间断
- 只算双侧合一的极限而遗漏单侧差异
- 函数在该点已连续时分类讨论无意义
- 把振荡不存在误归为跳跃型第一类间断
- 分子分母同趋于零但未定阶时类型判断错误
- 积分下限也随点变化时不能直接等价替换
- 把振荡无极限归为第一类间断
- 因子间发散与趋于零速度相互抵消时不能只看单个因子
- 振荡型无界但不趋于无穷被误判为无穷间断
- 未区分左右两侧就给出该点类型
- 内层值域跨越多个分段条件时必须分段讨论，不能给出统一结果
- 把分段边界的等号归属写反导致复合结果错误
- 复合层次或括号嵌套顺序理解错误
- 把值域整体判断误当作对个别点的逐点结论

### 标准解题步骤

1. 判型：待求量若由定积分号内的整体构成则记为一个待定常数，若随参数变动则记为一个参数的函数
2. 常数值型：等式两边在同一区间（区域）上再取积分，把右端各块用对称性或极坐标算出，得到常数的线性方程并解出代回原式
3. 确认被积函数连续使变限求导合法；参数在被积式内部时先作整体代换把参数集中到上限或整体上
4. 参数在上下限并存时先换序（由积分限还原区域后按另一顺序定限），使含参的限移到外层
5. 求导写成上限项减下限项，各乘该限对参数（变量）的偏导并保留符号，残留的参数用平移换元集中到积分限
6. 需要时再求一阶导直到被积式只剩单变量形式，代入指定值取数值；解所得微分或代数方程并回代检验，初始值靠代特殊点从原方程取出
7. 零比零型比式：把分子化成单参数的变限积分后逐层求导降次，或用积分中值定理写成中值点函数值乘面积、再按定点展开取主部定极限
8. 结构性质先行：奇函数的变限积分是偶函数、偶函数从对称中心出发的变限积分是奇函数，起点偏移则叠加常函数修正

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 积分方程化微分方程分支 | 积分方程确定函数再求导数或高阶导数，上下限同时含变量时对上限与下限各乘其导数复合求导 | 两端求导消积分号 → 取初始条件 → 解方程并展开读系数 | 漏初始条件是高频错 |
| 被积函数为参数与变量组合的变限积分求导 | 观察组合式的微分，把余下因子并入微分号内并记录倍率 | 以组合式为新变量代换，上下限随之改为参数表达式 → 整理成常数倍的标准变限积分 → 对上限求导并乘上限的导数 | 被积函数只通过单一组合依赖参数与变量；失效：组合式与余因子不匹配时无法整体代换 |
| 变限积分与幂的比式极限 | 按组合代换把积分化为变限积分的标准形式 | 由被积函数在零点的线性主部定出其阶 → 对主部积分得到积分整体的阶与系数 → 与分母的幂比较，同阶时写出系数比 | 被积函数在零点可导且零点值为零；失效：被积函数在零点非零时积分阶为一，与高阶分母之比发散 |
| 含反函数的变限积分方程反求原函数并定值 | 对被积函数的平移自变量做换元，同时把上下限同步平移，使积分号内只剩反函数 | 写出化简后的等式，两侧同对新变量求导 → 左侧用变限积分求导法则，上限为复合函数时补上其导数因子 → 利用反函数与原函数互为逆映射的关系，把反函数在原函数处的取值还原为自变量 | 函数可导且存在反函数，使复合取值能还原为自变量；失效：反函数不存在或多值时把逆映射关系当成恒等式使用 |
| 两个变限积分之比的极限 | 确认分子分母在上限趋于同一点时都趋于零，判定为零比零型未定式 | 对分子求导：被积函数取上限处的值再乘上限对自变量的导数 → 对分母求导：同样先代上限再乘其导数，注意上限本身是三角函数 → 把求导后的表达式按因子拆开，识别出可单独求极限的连续因子 | 被积函数在上限趋向点附近连续或有可去型极限；失效：被积函数在积分路径上变号或无界，先估阶再约项导致结论错误 |
| 上限为三角函数、分母为高次幂的变限积分极限 | 用积分上下限交换把分子改写成下限固定于极限点的形式并补负号 | 确认分子分母同时趋于零，对两者分别求导 → 分子求导：被积函数代上限值，再乘上限对自变量的导数 → 分母求导：幂函数降次，得到低一阶的幂 | 被积函数在上限附近连续，变限求导法则可用；失效：被积函数在对数内部趋于无穷时忽略其符号，导致上下限交换漏负号 |
| 嵌套变限积分与三角幂分母的极限 | 把分母中的三角差式用等价无穷小改写成幂函数乘常数，减少求导轮次 | 确认整体为零比零型，对分子分母各求一次导 → 外层求导时把内层变限积分整体作为被积函数代入外层上限 → 此时分子仍趋于零，对内层变限积分再求导：被积函数代内层上限值 | 各层被积函数在相应上限趋向点连续，逐层求导合法；失效：把内层积分当成常数求导，遗漏其上限依赖 |
| 被积函数含参数幂的变限积分求导及其导数的连续性讨论 | 把被积函数中含参数的整体作为新变量，同步改写上下限并提出参数因子 | 在非零参数处按乘积求导法则展开，包含变限积分求导项与倒数因子求导项 → 在参数为零处改用导数定义，把函数值写成积分除以幂次形式 → 对该未定式用洛必达，分子由变限积分求导直接给出被积函数端点复合值 | 被积函数连续保证变限求导可用；失效：在零点直接用求导法则（表达式无定义） |

### 标准解题步骤

1. 求一阶导数并解驻点与不可导点
2. 列表或按区间判导数符号得单调性
3. 极值候选两侧变号或二阶导定号
4. 闭区间端点与内部候选比较得最值
5. 含参时把驻点与参数联立讨论
6. 二阶导定号判凹凸方向，拐点须二阶导在该点两侧变号，零点与不存在点只是候选，必要时用高阶导数信息经泰勒展开定局部形态
7. 穷尽渐近线候选：无定义点处极限无穷为铅直渐近线，无穷方向先验水平后验斜，斜渐近线由斜率与截距两个极限唯一确定
8. 求曲率与曲率圆：由一阶与二阶导数算曲率、取倒数得半径，圆心沿法线落在凹侧
9. 比较型与链式传递：一阶导（偏导）定号给出单个变量的单调方向，把两点比较拆成逐段移动的一元比较；复合结构须内层值域整体落在外层同一单调区间才能沿链传递

### 标准解题步骤

1. 判定结构归属：显式初等式走固定变量法，抽象复合式先画依赖图，方程（组）给出的隐式关系走两端求导，含代换的先定代换类型
2. 显式式依次固定其余变量按一元法则求一阶偏导；复合式对每个自变量把全部通路相乘后求和，抽象函数偏导按位置编号记录
3. 隐式场合检验相关偏导（或方程组的系数行列式）是否非零，据此确定可解出的因变量，再两端对目标自变量求导并把导数当未知量解出（单方程解单个导数，方程组整理成线性组后消元）
4. 对合代换（自变量变换后方程依然成立）时写出变换后的第二个方程，两式联立消元解出解析式，因不引入新未知量而可直接收口
5. 线性变量代换化简二阶偏导：逐层求导并按新变量合并同类项，令不需要的系数为零定出参数或化成目标标准形
6. 需要高阶偏导时把一阶结果再当作待求式走同一流程，拆项式改套倒数的高阶导数通项
7. 求全微分时把各一阶偏导与对应微分相乘相加，再按题给点取值；代点前先确认该点处偏导存在且表达式不分段

### 失效边界

**适用前提**（24 条）

- 外层为抽象多元函数、内层为可求导的具体表达式
- 中间变量与自变量个数都能明确写出
- 显式初等式走固定变量法时要求偏导在求值点连续且求值点不在定义域边界或分段点上；落在分段点的偏导与可微性一律交多元微分概念关系与可微性判定通法
- 拆项套通项仅限被求式可拆成关于该变量的一次式倒数之和且阶数以符号给出的那一支；其余高阶偏导把一阶结果重新当作待求式逐次求导，只求低阶时直接逐次求导更省
- 依赖变量的导数由方程（组）隐式给出的复合求导交隐式方程（组）确定函数的求导通法，本法只处理依赖关系由显式代换或初等表达式给出的复合
- 单一方程确定单一依赖变量，且其对应变量的偏导不为零
- 约束方程个数与待定因变量个数相同
- 所求导数在求导后的方程组中线性出现
- 各偏导连续且只讨论某点的局部可解性
- 题目问能确定哪些隐函数而非求导数值
- 所求导数的阶数不超过二阶（包括混合偏导的一般表达式与代点值两种），更高阶本法只保证逐层求导而不保证闭式
- 与多元函数求偏导与全微分通法的分工：依赖变量的导数由方程（组）隐式给出时走本法，由显式代换给出时走该法；本法第3步内的链式求导仍按该法的通路相加规则执行
- 未知函数只出现在互为对合的两个自变量处
- 消元所需的系数行列式在题设条件下不为零
- 自变量取值范围对该变换封闭
- 方程中未知函数只出现在互为对合的两个自变量处
- 代换为自变量的线性组合且函数有二阶连续偏导
- 代换后的目标形以「消去一个或若干个纯二阶偏导、只留混合偏导」或化成标准波动型为限，其他目标形须重设代换（系数无法全配即入失效场景）
- 本法止于比较系数定参数或读出目标形式的偏导值；化简后需要由偏导信息（或标准形方程加定线条件）反求函数表达式的，交由偏导（全微分）还原函数与定参通法
- 内层为非线性整体（如指数因子乘三角因子）且待求的是那个一元函数本身时，归由偏导等式反解未知函数通法，不入本法
- 函数由初等表达式显式给出且偏导在求值点连续
- 求值点不在定义域边界或分段点上
- 只需求一阶偏导、一阶全微分或代点二阶导
- 目标形只含混合偏导或标准波动型算子

**失效场景**（20 条）

- 函数在讨论点不可微时链式法则失效，须回到差商定义
- 内层含绝对值或分段点，先判可微性再相乘
- 分段点或绝对值内为零处需改用定义
- 偏导不存在时全微分表达式不成立
- 分式含不可分解的高次因式，通项法不适用
- 只求低阶导数时直接逐次求导更省
- 相应偏导为零，隐函数定理条件不满足
- 分段或绝对值使代点处偏导不存在
- 系数行列式为零，导数不唯一或不存在
- 方程数少于待定因变量数，需补充其他关系
- 所有相关偏导都为零，定理给不出结论
- 需要整体而非局部的解存在性
- 变换不可逆或迭代产生新未知点时方程组无法闭合
- 系数行列式为零时解不唯一或不存在
- 忽略自变量取值范围把结果推广到使原式无意义的点
- 只需求某一点函数值时本法多余，代特殊值即够
- 变换不可逆或产生新的未知点时方程组无法闭合
- 忽略自变量的取值范围限制而把结果误推广到零点
- 代换的雅可比为零时新变量不独立
- 系数无法全部匹配，需重设代换
