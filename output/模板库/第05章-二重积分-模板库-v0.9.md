## 第二型线面积分的定向奇偶对称通法

> 编号 **T-HS-17-S** ｜ 版本 **v0.2.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 对关于坐标轴、坐标面或原点对称的弧段与曲面作对称变换，把被积式拆成系数函数与定向元素的奇偶乘积，奇项归零、偶项化半侧倍数 |
| 适用范围 | 第二型平面曲线积分、第二型空间曲线积分与第二型曲面积分中，积分弧段或曲面具有对称性且取定方向或侧的计算题 |
| 学科 / 章节 | 高等数学 · 二重积分 |
| 表面题型 | 对称闭折线曲线积分；球面柱面组合面积分；坐标面对称空间曲线积分；含绝对值的曲线积分；奇偶混合项线面积分；函数对称性化简定积分 |
| 对应考点 | 第二型曲线积分；第二型曲面积分；积分区域的对称性；曲线积分与路径无关的条件；格林公式；高斯公式；（一）定义及性质；性质 |
| 覆盖题量 | 1 题（分支 5 个） |

### 标准解题步骤

1. 画出积分弧段或曲面，判定它关于什么对称（坐标轴、坐标面、原点、某一点），并确认对称变换把整体映到自身而不是部分重合
2. 写出该对称变换对各坐标的作用，并判断它是否反转积分的方向或侧（闭合回路的镜像、起点终点互换、内外侧改变都要引入额外负号）
3. 由上一步定出每个定向元素（曲线的微分因子、曲面的投影面积分元素）在该变换下的奇偶性
4. 把被积表达式按加法拆成若干「系数函数乘定向元素」的单项，逐个只对被对称变换的变量判定系数函数的奇偶
5. 按奇乘奇为偶、奇乘偶为奇、偶乘偶为偶给每一项定奇偶，奇项在整个对称区域上的积分直接写为零删去
6. 偶项改写为对称倍数（二倍或四倍）的半侧弧段或半曲面（取定同一侧、同一方向）上的积分
7. 对剩下的半侧积分选最省力的算法：投影化为定积分或二重积分、验证与路径无关后改换简单路径、或补线补面用格林公式与高斯公式，最后核对方向与符号

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 平面曲线定向奇偶分支 | 积分弧段关于坐标轴、原点或某点对称 | 列出对称变换对两个坐标的作用 → 由弧段方向是否反转给两个微分因子补上符号 → 逐项定奇偶并只保留偶项 → 化为二倍的半弧积分后投影计算 | 方向反转带来的符号不可漏：同一几何对称在开弧与闭回路上给出的微分因子奇偶性相反 |
| 空间曲线分支 | 空间弧段关于某个坐标面对称 | 按对称面确定被反号的坐标 → 由起点终点是否互换判定定向元素的总符号 → 保留偶项，并先把弧段方程代入被积函数看有无恒为零的项 | 弧段方程本身使某些项恒为零时应先代入化简，否则会把恒零项误当偶项保留翻倍 |
| 曲面侧奇偶分支 | 曲面关于坐标面对称且取定外侧或上侧 | 按对称面判断每个投影面积分元素的变号 → 取侧与对称变换复合产生的符号统一记录 → 偶项取二倍或四倍的单侧部分并写明所取侧 → 必要时补平面片成封闭曲面改用高斯公式 | 曲面分片所取的侧不一致（有的外侧有的内侧）时抵消不成立，直接翻倍会算错 |
| 第一型对照分支 | 积分元素为弧长元素或面积元素的第一型积分 | 只判定被积函数关于对称变换的奇偶 → 定向元素恒正不需补方向符号 → 奇项归零，偶项翻倍到一半弧段或曲面 | 把第二型的定向元素当成恒正、或把第一型误加方向符号，都会整体错号，两类法则不可互换 |
| 一元定积分对称中心平移奇偶分支 | 被积函数满足关于某点中心对称的函数方程，且积分区间关于该点对称的一元定积分求值 | 把几何对称条件翻译成函数方程，写出对称两点处函数值互为相反数的关系 → 作平移变量代换把对称中心移到原点，判断新函数的奇偶性 → 同步改写端点，检查代换后的积分区间仍关于原点对称 → 按奇函数在对称区间上积分为零、偶函数折半计算定出积分值 → 用自变量取相反数后被积式是否反号回代检验对称关系的充要性 | 端点须关于平移后的原点成对对称且函数在整段区间可积；关于直线对称是偶性不可套用归零结论，平移量写错使中心不在原点则奇偶判断失效 |

### 失效边界

- **适用前提**：积分弧段或曲面在所述对称变换下整体不变（不是部分对称）；被积表达式可拆成有限个「系数函数乘定向元素」的代数和；各分片所取方向或侧与原方向一致，或符号差已知；被积函数在对称区域上处处有界可积；本条只约束主干：弧段、曲面或路径的定向元素在所述对称变换下整体映到自身，且该变换对方向（侧）的影响已在第2步单独判定；一元定积分的平移区间前提与「关于点还是关于直线」的选择由各分支触发特征自带，不作为主干的合取条件；与对称性与奇偶性化简二重积分通法的分工：对象为二重积分区域及其面积元时归该法，对象为积分弧段、积分曲面及其定向元素（或有弧长、面积元素的第一型线面积分）时归本法
- **失效场景**：只判断被积函数的奇偶而忽略微分因子与投影面积分元素自身的变号，会把应为零的项翻倍、应翻倍的项判成零；区域仅部分对称（只关于一个坐标面对称却按两个面对称取四倍）时倍数错误；曲线或曲面在对称中心处有奇点、或被积函数在对称点无界时，成对抵消的论证失效；第二型积分与方向（侧）有关，反转方向即整体变号，不能沿用第一型「对称只翻倍不变号」的直觉；被积函数含既非奇也非偶的项时须继续拆分到每一项都能定号，未拆净就定奇偶会漏项；缩到半侧后忘记同步改写积分限或所取侧，结果符号相反；对称变换把弧段映到自身但把方向拆成多段反向时，需分段处理，整体套倍数会错；积分区间不对称时相消不成立，不能得零；只知关于直线对称却误用奇函数结论，符号反号关系不存在；函数在区间内有不可积间断点时配对相失去依据；平移量写错导致中心不在原点，奇偶性判断失效

## 累次积分定序与降元通法

> 编号 **T-HS-247-I** ｜ 版本 **v0.2.1** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 累次积分的值与积分顺序无关，可积性却与顺序有关：一切做法都是先由积分限还原积分区域，再在两种顺序、两个先积变量之间挑能让内层立刻积出的那一路——内层不可积时换序，被积函数少含一个变量时先积那个无关变量把二重积分降为一元积分 |
| 适用范围 | 内层原函数非初等的累次（化为二重）积分，区域可按单值曲线上下或左右分开描述 |
| 学科 / 章节 | 高等数学 · 二重积分 |
| 表面题型 | 累次积分内层不可积时交换积分顺序；由原函数可积性选择先积变量；先积无关变量把二重积分降为一元积分 |
| 对应考点 | 直角坐标系；（三）正向不出错；（二）计算方法；必备知识点；解题连招；（五）分区域积分；极坐标系 |
| 覆盖题量 | 13 题（分支 2 个） |

### 标准解题步骤

1. 由累次积分限写出不等式组，还原并画出积分区域，求出各边界曲线交点作为分界
2. 把被积函数分别视为对两个变量的内层，检查其原函数是否初等，判出可积的一侧
3. 一侧不可积时换序：先积变量的限取左右（上下）边界，后积变量的限取投影区间
4. 被积函数不含某个变量时把该变量放到内层先积，用截面长度作权重降为一元积分
5. 多段拼接的区域先合并成一块，再检查新顺序下是否仍需分块，需分块则逐块写限后相加
6. 先积内层，出现待定原函数时用凑微分把外层变量的微分配进微分号
7. 再积外层，必要时分部积分或代换收尾，并核对定限方向与符号

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 择可积一侧定先积变量分支 | 同一区域两种顺序都合法，但只有一侧内层能积为初等函数 | 一侧内层含不可积因子时，把该变量改到外层，先积另一变量 → 按选定顺序写出上下限，注意边界曲线能否解出单值反函数 → 先积内层得到只含后积变量的函数，再用一元方法完成外层 | 区域既可按横型也可按竖型描述；被积函数至少一侧内层可积为初等函数；失效：两种顺序的内层都不可积，必须换坐标系；边界解不出单值反函数时按新顺序会丢分段 |
| 先积无关变量降元分支 | 被积函数显含的变量少于积分变量数，内层积分给出截面长度 | 先积另一变量，内层写成边界函数之差，得到截面长度作为权重函数 → 逐层使用微积分基本公式，把二重积分写成边界函数值的组合 → 判断剩下的一元积分类型：有理式凑微分、含根式作三角代换、乘积型用分部 | 被积函数显含变量数少于积分变量数；内层积分上下限中至少有一条为常量；失效：被积函数同时含两个变量且不可分离，先积一侧仍得不到初等原函数；边界由参数方程给出，截面长度需另解反函数 |

### 失效边界

- **适用前提**：内层被积函数连续但原函数非初等；区域可用单值曲线上下（左右）分开描述；两段拼接后仍是简单型区域；区域既可按横型也可按竖型描述；被积函数至少一侧内层可积为初等函数；两种顺序的计算量差别明显；被积函数显含变量数少于积分变量数；与二重积分坐标系选择与建系通法的分工：被积函数含平方和、坐标比值、到定点的距离或其平方或呈齐次结构时，先由该法建极坐标（或平移伸缩建系），本法只负责直角坐标下的顺序择优与降元；两法皆可时以先积一侧能否凑出微分或直接用基本公式为判据；（分支级前提，由「先积无关变量降元分支」的触发特征承担）内层积分上下限中至少有一条为常量、换元后新变量的区间仍落在原定义域内；本法主干只要求区域能用单值曲线分开描述且至少一侧内层可积
- **失效场景**：区域按新顺序需分成多块时仍强行写成单个累次积分；区域无界或被积函数变号时未验绝对可积就换序；换序后内层仍不可积，说明该改走极坐标；两种顺序的内层都不可积，必须换坐标系；边界解不出单值反函数时按新顺序会丢分段；被积函数在区域内部有间断线时未先分块；被积函数同时含两个变量且不可分离，先积一侧仍得不到初等原函数；边界由参数方程给出，截面长度需另解反函数；在加减项上做等价替换会破坏阶数

## 对称性与奇偶性化简二重积分通法

### 标准解题步骤

1. 检查区域在坐标取反、同时取反或两变量互换下是否整体不变，确定可用的对称变换
2. 把被积函数按该变换拆成变号部分与不变部分，逐项只对被变换的变量定奇偶
3. 变号部分在整个对称区域上的积分直接写零删去，不再计算
4. 不变部分改写为对称半区的倍数（二倍或四倍），需加辅助线才看出对称性时先分块再逐块判
5. 区域关于对角线不变时，写出变量互换后的第二个积分并声明两者相等
6. 两式取平均消掉反对称项，把系数配成只依赖平方和、两数和积等对称组合
7. 余项在区域内不变号时只用面积与最值定出正负或范围，否则选定坐标系完成计算

### 标准解题步骤

1. 解出被积函数换式或换号所满足的分界曲线方程
2. 按分界曲线切分区域，标出每块的边界与交点

1. 把各边界曲线分别按直角坐标与极坐标写出，判哪个系下区域能用单值边界一次描述
2. 被积函数含平方和、坐标比值或齐次结构时优先极坐标；含平移二次式时先配方读出圆心（或中心）与半径、半轴

### 标准解题步骤

1. 判型：待求量若由定积分号内的整体构成则记为一个待定常数，若随参数变动则记为一个参数的函数
2. 常数值型：等式两边在同一区域上再取二重积分，用轮换对称或极坐标算出右端各块

6. 再求一阶导数，此时被积函数只剩单变量形式，代入指定参数值取最终数值

### 标准解题步骤

1. 判定分子分母同趋于零，确认零比零型：分母关于参数的幂次须等于「区域面积的阶」加上「被积函数在收缩点的消失阶」之和（中值型两阶合一，被积函数含 f(u)-f(0) 或坐标因子时须一并计入）
2. 确认被积函数在含收缩点的闭区域上连续；需展开取主部时要求该函数在收缩点可导（可微）
3. 中值型：积分写成中值点函数值乘区域面积，并单独算出面积关于参数的表达式
4. 变限型：交换积分顺序或改用极坐标，把二重积分化成一个参数的变限积分；极坐标下换序时把极角当横轴、径向当纵轴，在 θOr 平面内重新确定积分限
5. 对分子求导：被积函数代上限再乘上限对参数的导数，分母同步降次，必要时重复求导
6. 剩余未定式用等价无穷小、在收缩点展开取主部，或令中值点趋于定点取函数值
7. 用题给的函数值或导数值定出极限常数；阶不匹配时先改设幂次或补夹逼放缩，不得反复洛必达硬凑

### 失效边界

- **适用前提**：区域以参数为尺度收缩到一点；被积函数在该点连续或可微；换序后的变限积分对参数可导；分母关于参数的幂次等于「区域面积的阶」加「被积函数在收缩点的消失阶」之和：中值型两阶合一（函数取定点值，如面积 t² 对应分母 t²），被积函数含 f(u)-f(0) 或额外坐标因子时须一并计入（如面积 t² 加主部 t² 对应分母 t⁴）；区域整体按参数的倍数收缩到一点（含以参数为半径或直径的缩放），且该缩放倍数对参数的导数非零；被积函数在该闭区域连续（中值型）或在收缩点可导（取主部型）；与面积形心二阶矩直读积分值通法的分工：本法用于分子随参数趋零、需与参数的幂比阶取极限的场合；固定区域的面积、一阶矩、二阶矩直读归该法，本法中的面积只是取阶时的权因子
- **失效场景**：未换序就对参数求导，边界项丢失；分母幂次与分子阶数不匹配，反复洛必达仍不收敛；被积函数在收缩点不可微却用主部展开；被积函数在收缩点附近不连续或无界；把未知中值点直接当定点代入不连续因子；分母幂次与「面积阶加被积函数消失阶」之和不匹配时中值形式无法约去，须先改设幂次或补夹逼放缩，不得反复洛必达硬凑
