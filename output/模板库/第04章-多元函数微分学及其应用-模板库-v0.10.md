### 标准解题步骤

1. 定趋近点：趋近点不是零有限点时先作平移或倒代换，把所有展开统一到零点邻域再处理；无穷远端先倒代换化为零型
2. 判型归口：无具体表达式者转概念型，含幂指结构先配基本极限或取对数，含反函数先把反函数值换回原函数自变量，含隐式方程先逐次求导并用原方程回代定出该点各阶导数值
3. 列展开式：写出式中出现的每类基本初等函数在该点的幂展开，分数幂与根式改用二项式展开形式
4. 预估所需阶数：以分母（或比较对象）的最低次幂为展开阶数，复合结构逐层保持同一精度；只作乘积因子时可按最低幂次准则取等价主项
5. 代入并合并：按幂次升序合并同类项，把不低于所需阶的所有项统一归入高阶余项
6. 检验相消：核对首个非零系数是否已出现，分子分母同时归零时必须升一阶重算而不是直接判为零
7. 多路径与方向分离：二重极限按极坐标或加权代换写成径因子乘角因子，角因子有界且径因子趋零即判存在，角因子随方向取不同值时取特殊路径证伪
8. 读出结论：取首个非零幂次的系数之比作为极限值，无穷大场合按对数、幂、指数、阶乘、幂指五档比阶后取主项，数列题最后把连续变量代回离散变量

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 非零趋近点平移分支 | 趋近点为非零有限点，常见幂展开表无法直接套用 | 令新变量等于原变量减去趋近点 → 把每个因子改写成一带无穷小的形式后展开 → 按新变量的幂整理，最后还原变量关系 | 平移后各因子须在该点邻域内可展；含分段或绝对值表达式时要分左右两侧分别平移 |
| 分数幂与根式差分支 | 分子或分母为不同次根式之差，有理化或换元计算量偏大 | 把根式统一写成分数幂形式 → 用二项式展开保留到首个非零阶 → 分母同法展开后直接比较系数 | 两侧一阶项不同时保留一阶即可；两侧一阶项相同则必须升阶，否则主项被消掉 |
| 相消升阶定阶分支 | 展开合并后最低次幂系数恰好抵消，出现全零分子或全零分母 | 提高展开阶数直到出现非零系数 → 按最低次幂原则重新配平分子与分母的阶 → 用系数比确认非零极限并复核余项所在阶 | 所需阶数由分母最低次幂决定；展开不足会把非零有限极限误判为零 |
| 复合与积分上限展开分支 | 式中含函数套函数，或分子为变上限积分、被积函数本身需先展开 | 先展开最内层再逐层外推并保持精度一致 → 被积函数展开后逐项积分，按上限的幂次整体抬阶 → 积分结果与外部因子再按最低次幂合并 | 逐项积分要求展开在该区间内一致可控；上限趋于零的幂次会改变结果的整体阶 |
| 数列极限连续化分支 | 离散变量趋于无穷且通项只依赖该变量的倒数或同一函数结构 | 用归结原则把离散变量替换为连续无穷小 → 对连续形式做幂展开求值 → 把结果代回离散变量表述 | 只适用于通项可统一写成某函数在离散点取值的情形；和式与乘积式数列应改用定积分定义或单调有界准则 |
| 无穷小阶比较分支 | 多个无穷小比较阶的高低或挑最高阶项，且非分式结构首个非零项定阶（后者走 T-HS-14-S） | 对各项分别展开并取最低次幂项定阶 → 用幂次大小直接排序，避免逐本作差 → 积分型无穷小先展开被积函数再按上限幂次定阶 | 定阶只看首个非零幂次；加减结构中不得预先使用等价代换，否则可能把决定阶的主项消掉 |
| 同底指数差先提因子再展差式分支 | 分子为同底（或可化为同底）指数函数之差，分母可等价归为自变量整数幂 | 提出分子中一个指数因子，把两指数之差写成该因子乘以幂减一结构 → 确认提出因子的极限为非零常数，先算出并剥离 → 用幂减一等价于指数上的代数差，把超越差转为代数差 | 提出因子的极限必须是非零有限常数否则不能分离；指数差主项相消时须继续升阶展开，且不得对加减结构整体作等价替换 |
| 比阶关系翻译为幂次不等式组分支 | 题目给出若干无穷小之间高阶、低阶、同阶关系并要求定参数，参数常取正整数 | 确认全部比较对象在同一过程中确为无穷小，否则阶关系无意义 → 对差型因子展开取首个非零项定其幂次，禁止用一阶等价直接相减 → 用乘积的总幂次等于各因子主项幂次之和写出各对象的幂次 | 各因子主项幂次须可由展开或等价形式唯一确定；对加减项分别取等价会使主项相消而阶数虚高，含参幂次非正时展开不成立，把同阶误当高阶会放宽不等式 |
| 乘开对齐比较系数定参分支 | 要求差式与指定幂次同阶或为该幂次的高阶，从而反解多个参数 | 把分式因子按等比级数乘开到指定阶，避免直接对分式作差 → 把指数型等其他因子展开到同一阶并带佩亚诺余项 → 两式相减并按自变量幂次合并同类项 | 各因子可展开到不低于比较所需阶、参数个数不超过可比系数个数、分式分母趋于非零常数；展开阶数不足定不全参数，把系数全为零的高阶情形误当同阶必错 |
| 倒代换定阶锁参分支 | 无穷远处含参极限要求存在且非零，需倒代换后两侧分别定阶 | 作倒数换元把无穷远处过程化为该点附近的未定式，统一比较基准 → 对分子的指数差与三角因子分别用等价无穷小换成幂次，定出分子阶 → 把分母提取公因式后展开，写出含参主项及其系数 | 前提：分子分母均为无穷小且主项系数可显式定出，等价替换只作用于乘除因子；坑点：参数取某些值使分母主项系数为零时同阶比较失效，允许极限为零或无穷时不能只用同阶条件，把分母的两项分别替换导致错误相消 |
| 变限积分待定阶求导建方程分支 | 无穷小由变上限或复合上限积分给出，要求定出其阶本身（而非由给定极限值反解参数） | 由已知比值极限为非零常数，写出被积函数的等价主项并定出其阶 → 确认积分下限为常数而上限趋于该点，断定变限积分为无穷小 → 设所求阶为待定指数，构造该积分与幂次之商的极限 | 前提：被积函数连续且其阶可由已知极限唯一确定，下限固定而上限趋于该点；坑点：把求导降阶写成升阶、上下限同时变化却直接套上限求导公式、在加减结构中用等价替换改变阶 |
| 多对象化幂主项指数排序分支 | 要求对若干无穷小给出完整的阶排序而非两两比较或挑单项，对象含根式差、变限积分与三角指数组合 | 对每个量有理化或恒等变形，消除减法造成的低阶隐藏 → 把变形后的每个量用等价无穷小写成幂函数主项，记录其指数与系数 → 变限积分型先求出积分或对被积函数取主项，再把上限自身的阶乘入 | 前提：每个量在该过程中确为无穷小且有确定的最低次主项，所有比较在同一过程同一自变量体系内进行；坑点：减法主项相消却未展到次阶使阶被严重低估，含量或振荡项无确定阶，积分下限非零的变限积分被当作无穷小 |
| 幂指化指数展开定阶分支 | 被比较量含以自然常数为底的幂或幂指结构，需展开指数到覆盖分母的阶 | 改写比较问题为一个商式，明确要判断的是商的极限为零、有限非零还是无穷 → 统一幂指式为自然常数的幂，并提出极限非零的常数因子 → 展开指数部分到足以覆盖分母阶的项数，舍去高阶皮亚诺余项 | 前提：两式在同一过程中均为无穷小，涉及的函数在该点可展开到比较所需的阶；坑点：展开阶数不足导致最低次项被误判为高阶，对含参相减结构整体作等价替换，被比较式之一极限不为零时谈阶无意义 |

| 幂基准作商排序分支 | 要求对三个及以上无穷大给出完整的阶排序，需以幂函数为中间基准串联次序 | 把待比较的各函数两两作商，构成无穷远处的商式极限 → 先化简商式中的对数与幂，再用洛必达法则或等价替换求出极限 → 区分商为零、为非零常数、为无穷三种情形，判定两函数的相对阶 | 前提：各函数在无穷远处均为正且趋于无穷，比较对象落在标准增长阶序列内；坑点：函数振荡或变号时商式极限不存在，两函数同阶仅差常数因子时无法由阶判定大小，把有限点处的取值当作充分大时的次序 |
| 渐近抵消反参分支 | 无穷远处含根式（非纯有理式）与多项式之差，待定系数使极限为零或给定值 | 提出根式中的最高次幂因子，把无穷远处问题转化为新变量趋于零的问题 → 利用变换后的极限存在必要条件令分子主项相消，先定出一次项系数 → 用立方差公式有理化已定首项后的根式差，使分母阶高于分子 | 前提：根式内最高次幂与外侧多项式次数可比，展开主项唯一；坑点：根式内次数与修正项次数不匹配时无法同时定出两个参数，偶次根式在两端符号不同却不分左右讨论，有理化后分子分母同阶却仍令极限为零 |
| 分侧主项方程定参分支 | 表达式含取整或倒数指数使左右两侧主项不同，由极限存在且等于给定值定参 | 识别造成分岔的因素：取整函数的跳跃与指数中倒数趋于正负无穷的两个分支 → 求发散一侧的极限，把对数内的主导指数因子提出并用对数拆成主项加趋于零的余项 → 求收敛一侧的极限，此时幂减一可直接等价替换为指数本身，得到趋于零的贡献 | 前提：表达式在定点两侧均有定义且可分别求极限，指数型主导项可比出阶；坑点：单侧极限之一不存在或为无穷时无法用相等条件定参，把取整函数在点处的值当成左右极限，对数内主导项判断错误导致等价替换失效 |
| 幂指取对数与定长积分中值两侧反参分支 | 等式一端是底趋于一、指数趋无穷的幂指式，另一端是长度固定而端点同趋无穷的区间积分，需由两侧同值反求参数 | 对幂指侧取对数，把底数偏离一部分恒等变形为等价无穷小，与指数因子的阶相乘定出指数极限 → 确认底数偏离部分的阶只在乘除位置替换，避免在加减结构中非法等价代换 → 对长度固定的区间积分用积分中值定理写成介点处函数值乘区间长，由介点与端点同趋无穷定出右端 | 幂指侧须属一加无穷小乘无穷指数的标准档，被积函数连续且积分区间长度固定；函数在无穷端极限不存在或为负时不能取对数比较，区间长度随参数变化时积分中值定理给不出定值 |
| 分段拼接有界性扫描分支 | 判定分段函数或含可疑点函数在全域的有界性 | 列出全部分段点、分母零点与无穷远处，作为必须单独考察的关键位置 → 分别求每个分段点的左右极限，由极限存在推出该点某邻域内的局部有界性 → 比较无穷远处分子分母的主导阶，判定该侧函数趋于定值或有界 | 前提：函数在各分段内部连续且分段点处左右极限存在有限；坑点：分段点处为无穷型间断时误用极限存在推出局部有界，无界振荡与有界因子相乘时把整体当作有界，把导数在无穷区间上有界误当作函数有界 |
| 归一凑基本极限通法 | 底数趋于一、指数趋于无穷的幂指极限，含幂或对数结构中隐藏的基本极限，以及由幂次关系反解偏差的场合 | 利用对数或指数函数的连续性，把极限符号移入或移出幂指结构 → 配凑底数除以常数因子为一加无穷小的标准形式，写出该无穷小关于过程量的阶 → 凑出指数为该无穷小倒数的倍数，套自然常数基本极限得到幂值 → 取幂的对数或指数还原，把结果化为关于参数的代数式 | 可用[底数为正且趋于常数一，指数趋于无穷，属标准幂指未定式；参数使归一化分母不为零；幂次关系中的偏差确为无穷小，可作等价替换] 失效[参数使底数不趋于一时不能套基本极限；把对数与极限交换时未验证真数极限为正；指数与无穷小阶不匹配时凑形失败] |
| 标准幂指归一化分支 | 底数趋于一、指数趋于无穷的标准幂指未定式，或由幂次关系（底数的指标次幂趋于定值）反解偏差 | 配凑底数为一加无穷小 → 凑指数为该无穷小倒数的倍数套基本极限 → 指数还原后由无穷小系数读出结果 | 底数不趋于一或幂极限为零时不能套基本极限；取对数需真数恒正 |
| 积分闭合幂指分支 | 定积分先经凑微分闭合为含参表达式，随指标变化的上限含幂指结构需归一化 | 先凑微分算出定积分的闭合表达式 → 把上限的幂指部分配成基本极限形态 → 逐因子取极限并复核每个因子极限存在 | 上限随指标变化时不得当作常数处理；被积函数不可积时凑微分路线失效 |
| 幂指结构反求导数值分支 | 幂指极限存在且已知，反求未知函数在某点的导数 | 配成基本极限形态由极限值锁指数 → 指数中复合无穷小用等价替换化简 → 把函数值与增量之比识别为导数定义 | 前提：函数值不趋于零时替换失效；坑点：开方漏负根 |
| 切线交点归一基本极限分支 | 切线与坐标轴交点随参数变化求函数值极限 | 求切点导数得斜率 → 点斜式写切线并解交点 → 代入函数得含参式 | 前提：切线水平时无交点；坑点：指数归一化系数算错 |
| 幂指夹逼定根数列极限分支 | 隐定义根数列的幂指极限 | 零点定理加单调定根存在唯一 → 构造两侧夹逼窗口 → 幂指式两侧化归基本极限 | 前提：夹逼方向弄反；坑点：唯一性未论证 |
| 含反函数极限的换元归一通法 | 已知原函数解析式而反函数解析式难以求出，需求含反函数的无穷型（或趋近点为无穷）差式极限的题目 | 确认原函数在所考虑的趋近过程中单调且趋于同一极限点，使反函数唯一且代换合法 → 把含反函数的分子按项拆开，化成若干「单个反函数项除以同一幂式」的极限 → 对每一项设反函数值为新变量，即用原函数关系把反函数符号整体替换为其对应的原函数自变量 → 同时把分母幂式按同一关系换成原函数表达式，使分子分母落在同一个自变量上 | 可用[原函数在趋近过程中单调且趋于无穷，反函数存在且随之趋于同一点；分子可拆为有限项，且每一项的极限单独存在；分母幂式与原函数主部的阶数之比可以确定] 失效[原函数不单调（含周期项或振荡项）时反函数不唯一，换元失去意义；拆项后某一部分极限不存在，仍对差式逐项取极限会得到错误结论；直接用等价无穷大替换整个相减分子时主部相消，误差阶无法控制] |
| 以反函数值为变量分支 | 给出原函数解析式且需求含反函数的差式或商式极限，反函数解析式无法显式求出（序列本身的敛散判定走反函数序列敛散判定分支） | 设反函数值为新变量，把反函数项整体换成对应的原函数自变量 → 由原函数关系式替换分母中的幂式 → 检验新变量与原变量同步趋于同一极限点 | 代换前后趋近点必须对应，原函数在该区间须单调以保证反函数单值 |
| 倍率提取分支 | 分子含自变量成常数倍的反函数项 | 把分母幂式补成与该倍率一致的形式 → 将倍率的幂次作为常数因子提到极限号外 → 对新变量取极限并还原倍率影响 | 只有该项极限单独存在时才能把倍率单独提出，否则拆项非法 |
| 双自变量分别反解分支 | 分子是两处不同自变量取值下的反函数之差 | 为两项分别引入两个原函数自变量 → 由原函数关系分别列出两个等式并各自反解出对应的幂式表达 → 把两个表达式分别代回两项极限 | 两个自变量必须都趋于同一无穷远点，否则不能对差式逐项取极限 |
| 等价无穷大主部替换分支 | 原函数可确定其无穷大主部（如多项式、幂式主导的表达式） | 把原函数替换为与其等价的无穷大主部 → 写出主部的反函数（幂式反函数可直接求出） → 用主部反函数代入原差式并约去公共幂次 | 无穷大等价只能用于乘除因子，整体替换相减的两项会因主部相消而失控 |
| 反函数序列敛散判定分支 | 数列由方程（原函数取值关系）隐式定义，需判定反函数序列的敛散或渐近阶 | 把方程视为某函数在区间上的取值，验证其导数保号且函数无界 → 据此断定反函数序列趋于无穷，排除其收敛的可能 → 用原方程把待考察的比值改写成只含已知量的形式 | 前提：原函数连续可导且导数严格保号，原函数无界使反函数趋于无穷；坑点：原函数导数变号时反函数不唯一无法定阶，洛必达后极限不存在且不为无穷时不能反推原数列发散 |
| 反函数求导倒数与对数代换分支 | 反函数导数与对数差商结合的极限 | 反函数求导法则得目标点导数 → 对数差等价替换成线性差 → 重组为差商与平方比 | 前提：倒数关系弄反；坑点：等价替换用于加减 |
| 二重极限定路与代换判别通法 | 二元函数在孤立点（原点型或经平移、幂次适配后可化为原点型）处的二重极限求值与存在性判定 | 判型：确认趋近点是有限孤立点还是无穷远，含绝对值或幂指时先定结构与基本型的差距 → 先试连续代入：初等式且代点使分母与偶次根号内不为零，直接取函数值即得 → 需证存在（多为零）时取绝对值放缩，把式子压在只含趋近距离的趋零上界之间 → 需分离方向时按分母各项齐次阶选极坐标或加权代换，整理为径因子乘角因子 | 可用[代入后可明确分离出仅含极径的因子与仅含极角的因子；被讨论式是初等多元函数且代点在定义域内部；分母与偶次根号内在代点处不为零] 失效[极径因子与极角因子不可分离（混合出现在同一运算中）时，代换后仍无法定案，本法失效；角因子无界且径因子非无穷小（既非零也非无穷）时，判定不出极限是否存在；二元极限不能用洛必达法则，代换后也不得对多个变量分别套洛必达] |
| 标准极坐标求值分支 | 分子分母关于两个变量齐次或约去公因子后角部分可由三角函数有界性控制 | 代入标准极坐标并约去极径公因子 → 把余下的三角因子归为有界量 → 对极径因子用等价无穷小或泰勒展开取一元极限 | 极径因子必须真正趋于零，若约分后仍含非零极径幂则不能判存在 |
| 加权幂次极坐标分支 | 分母各项关于 x、y 的次数不等，普通极坐标无法把各项配成同次幂，需按加权代换（两变量取不同幂次的比例）才能比较主阶；沿直线路径全部得同一值只提示该入此支，不作为结论 | 按主部次数设定某变量的幂等于极径乘三角式 → 限制极角范围以保证开方与代换有意义 → 代入后检查是否仍为极径幂乘以有界角因子 | 代换必须覆盖全部趋近路径的各个符号分支，开方时须同时考虑正负两支 |
| 特殊角证伪分支 | 极坐标或加权代换后的表达式显式依赖极角，或存在使分母为零、对数真数非正的极角，取两个特殊角即可给出不同极限值 | 取使角因子发散、为零或无定义的具体角度 → 把该角度还原成一条显式趋近路径 → 与直线路径所得结果比较 | 单条路径存在不能证明极限存在，本分支只能用于证伪；涉及无定义路径时以考纲口径判定 |
| 平移化归分支 | 趋近点不是原点 | 先作变量平移把趋近点移到原点 → 对新变量施加极坐标代换 → 按角因子有界与径因子无穷小判定极限 | 平移后原表达式在该邻域内须可比较阶数，分母零点方向仍需单独检查 |
| 指对型处理分支 | 含对数因子、指数的负幂，或幂指式的底趋于非一的正数，须取对数把乘除化为加减后比较主部阶 | 把幂指式取对数或写成指数套内层极限的形式 → 对指数部分作极径与极角分离并求极限 → 指数极限存在且角因子有界时再指数还原得原极限 | 对数真数必须在去心邻域内恒正，否则相应路径无定义 |
| 连续点代入分支 | 初等二元式且代点处分母不为零、偶次根号内为正 | 确认代点落在函数定义域内部，因而函数在该点连续 → 把极限号换成代点，按一元法则算出函数值 → 若代入后分母为零或出现不定式，改走放缩或凑型路线 | 被讨论式是初等多元函数且代点在定义域内部；失效：代点使分母为零，出现零比零型不定式 |
| 绝对值夹逼分支 | 需证极限为零的有理整分式，分母总次数高于分子 | 用平方和不小于二倍积等基本不等式放大分子、缩小分母 → 把放缩结果拆成若干单变量趋零量之和 → 两侧同趋零即得绝对值极限为零，再脱去绝对值得原极限 | 待求式为有理整分式且分母次数高于分子总次数；失效：分子分母同次，沿不同路径取值不同，极限不存在 |
| 幂指凑基本极限分支 | 幂指式的底与 1 之差在此过程中趋零而指数绝对值无穷大，且能显式配出该差的倒数凑成基本极限的幂 | 把指数拆成配平因子与"底减一"的倒数之积 → 内层取重要极限，外层剩余因子单独求极限 → 两段合并写成以 e 为底的幂 | 底在该过程下趋于一且指数为无穷大；失效：底趋非一的正数，退化为一元直接代入 |
| 隐式方程回代定阶通法 | 由隐式方程（或微分方程加初值）确定函数的零比零极限、无穷小定阶与主项比较 | 把极限点代入隐式方程确认分母趋于零，判定所属零比零型未定式 → 对隐式方程两端求导解出导函数表达式，并在该点求出导数值以判断分母趋零的阶 → 对分子分母用洛必达法则降阶，检验所得新商式是否仍为未定式 → 把导函数表达式代入商式，并用原方程消去无法直接求极限的差式与高次项 | 可用[隐式方程确定的函数在极限点邻域内连续可导；该点处对因变量求导的系数不为零，保证导函数表达式有意义；分子分母的无穷小阶有限且可通过有限次求导对齐] 失效[导函数表达式在该点分母为零时洛必达链中断；隐函数在该点不唯一或不连续时不能求导比较阶；把隐函数的导数当显式函数导数直接代入而未回代原方程] |
| 隐函数零比零回代分支 | 隐式方程确定的函数出现零比零型极限，需逐次求导并用原方程回代对齐阶数 | 代值确认分母趋零定型 → 隐式求导得导函数表达式并回代 → 洛必达降阶后用原方程消去不可直取的差式 | 导函数表达式在该点分母为零时洛必达链中断；未回代原方程直接代入属误用 |
| 方程回代定拐点参数分支 | 隐函数方程由拐点条件反求参数 | 拐点给该点函数值与二阶导为零 → 方程求导表出二阶导 → 代入该点函数值与一阶导数 | 前提：该点一阶导为零不能约因子；坑点：只令二阶导为零不验变号 |
| 方程回代定二阶导符号分支 | 由方程与极值点证明极小值 | 驻点代入方程解二阶导表达式 → 按与分界点大小分类判号 → 分界点用二阶导连续取极限 | 前提：分类漏分界点；坑点：分式符号判错 |

**失效场景**（182 条）

- 在加减结构中只用一项等价代换替代完整展开，主项被消去后得到错误的零值或错号，这是本方法最典型的失效点
- 展开阶数不足时比值仍为零比零，会把非零有限极限误判为零或不存在，必须先确认首个非零系数已出现
- 函数在趋近点不可展（分段点、含绝对值、仅单侧可导、含自变量倒数的正弦型振荡）时泰勒法失效，须改用夹逼或直接回到定义
- 无穷端的和式、乘积式与项数依赖变量的数列不能直接逐项展开，须先化为无穷小或改用定积分定义、单调有界准则
- 同档主项相消后仍需任意高阶才能定号的临界情形，有限阶展开给不出结论，需借助洛必达或积分估计
- 复合层数过多使展开项数膨胀时方法仍正确但考场上不经济，应先用结构判断能否化简
- 非未定式时套用洛必达法则或等价替换
- 对加减项整体作等价无穷小替换造成主项丢失
- 把有界振荡因子当作存在极限的常量参与四则运算

- 对数内主导项判断错误导致等价替换失效
- 函数极限不存在或为负时不能与指数幂比较取对数
- 积分区间长度随参数变化时积分中值定理给不出确定值
- 幂指底数不趋于一时套自然常数型基本极限造成错值
- 两侧极限之一发散时等式无解却仍强行解参数
- 分段点处为无穷型间断时误用极限存在推出局部有界
- 无界振荡与有界因子相乘时把整体当作有界
- 把导数在无穷区间上有界误当作函数有界
- 参数使底数不趋于一时不能套基本极限
- 把对数与极限交换时未验证真数极限为正
- 指数与无穷小阶不匹配时凑形失败
- 幂极限为零或不存在时底数不趋于一，替换失效
- 把幂指关系按有限项四则运算逐项拆开取极限
- 等价替换用于加减相消结构而未展到次阶
- 被积函数不可积或需分部多次时凑微分路线失效
- 上限随 n 变化却把上限当作常数处理
- 对乘积中含趋于零与趋于无穷的两部分直接分项取极限
- 函数值不趋于零时无穷小替换失效
- 开平方时漏掉负根
- 把未知函数当成具体函数展开
- 切线水平时与横轴无交点
- 未化归基本极限而逐项硬算
- 导数计算漏幂法则的系数
- 夹逼方向弄反
- 幂指极限指数处理错误
- 忘记论证唯一性
- 原函数不单调（含周期项或振荡项）时反函数不唯一，换元失去意义
- 拆项后某一部分极限不存在，仍对差式逐项取极限会得到错误结论
- 直接用等价无穷大替换整个相减分子时主部相消，误差阶无法控制
- 趋近点为有限值时应改用等价无穷小与反函数在该点的局部性质，本通法的无穷大定阶手段失效

- 原函数导数变号时反函数不唯一，无法定阶
- 洛必达后极限不存在且不为无穷时不能反推原数列发散
- 倒数关系弄反
- 等价替换用于加减结构
- 倍数平方漏算
- 极径因子与极角因子不可分离（混合出现在同一运算中）时，代换后仍无法定案，本法失效

- 分子分母同次，沿不同路径取值不同，极限不存在

- 底与指不同步，取对数后按乘积型处理

- 隐函数在该点不唯一或不连续时不能求导比较阶

- 只比阶数而不核对主项系数就断言等价

- 只令二阶导为零而不验变号
- 对方程求导时漏乘链式因子
- 分类漏掉分界点情形
- 分式符号判错
- 忘记用连续性传递极限值

### 标准解题步骤

1. 改写定义式：把给定的极限或增量关系整理为固定点处函数值之差除以自变量之差的标准差商形式；多元时写成增量减线性主部除以距离
2. 配凑基准项：分子缺少该基准点函数值时加减该项凑出定义结构，并核对分子分母增量的倍数关系
3. 判增量阶：考察实际增量相对自变量增量的阶，同阶对应非零导数、高阶对应导数为零、低阶或振荡则不存在；含绝对值与分数幂时把各因子零点重数累加与一阶比较
4. 分侧验证：分界点与含绝对值、最大最小的表达式须分别求左右差商极限，两侧都存在且相等才能断言可导
5. 逐方向与全平面分离：多元场合先用单变量差商定各偏导是否存在，再验全平面一致趋零定可微，必要时取不同路径给反例
6. 回溯连续性：需要函数值关系时由可导（可微）直接推出连续，并检验是否误把连续当成可导的依据
7. 区分两个概念：涉及导函数在该点是否连续时回到定义单独验证，不能以导函数的极限代替该点导数

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 线性主部定量分支 | 要求写出函数增量、微分或用线性近似估计函数值的变化量 | 设导数存在并把实际增量写成线性项加高阶余项 → 用线性项作为近似值、高阶余项作为误差量 → 检验余项相对于自变量增量确为高阶无穷小 | 仅在一元范围内可微与可导等价，多元情形不能照搬此结论 |
| 概念链判断分支 | 选项式判断可导、连续、可微、左右导数之间的推出关系，且不涉及导函数极限、幂次条件组合或保号性结论 | 把每个命题翻译成增量阶的表述 → 按同阶、高阶、低阶三种情形逐一验证命题方向 → 需要否定逆向命题时用增量低于一阶或振荡型结构构造反例 | 只能由可导推连续，逆向一律不成立；导函数自身的连续性不蕴含在该点可导之内 |
| 左右导数分支 | 分段点或含最大最小的表达式处需分别求左右差商极限，题目不含待反解参数，且结构不可化为幂零因子乘积（可化的归 T-HS-09-S） | 分别按定义求左右差商极限 → 核对两侧极限都存在且相等 → 不相等时明确记为左右导数存在而该点不可导 | 分界点两侧表达式须已知；断言可导还须函数在该点有定义且取值与极限一致 |
| 定义配凑分支 | 极限式中出现该点函数值之差，但增量系数与分母形式与定义不一致 | 提取分子增量与分母增量的倍数关系 → 补成标准差商并乘回系数 → 若同时含两个不同增量，拆成两处导数的线性组合 | 必须先确认该点导数存在，否则配凑只能给出单侧信息而非极限值 |
| 一点导数与导函数极限区分分支 | 题目直接问该点导数是否存在与导函数在该点极限是否相等、能否互推 | 该点导数一律交由定义验证 → 再单独考察导函数在该点的左右极限 → 只有导函数在该点连续时两者才相等，否则只有一点导数存在可言 | 由导函数极限存在推出该点导数存在，需原函数在该点连续这一前提，缺此前提不得换算 |
| 分段点连续条件锁参数分支 | 分段函数在分段点只要求连续（或已知连续），据此反解一个待定参数 | 把连续条件改写为极限值等于分段点定义值的等式，明确方程两端 → 拆项分式逐项判断能否分别取极限，再定各部分的无穷小阶 → 用等价无穷小或凑导数定义求出拆出各项的含参极限 | 分段点处分子分母同趋于零且未定式可控；拆项后某项极限不存在时不能对和式分项取极限，相消需保留更高阶信息时只用一阶等价会出错 |
| 导数定义结构定间断分支 | 分式在分母零点处的极限可补成分子在该点的差商，且分子在该点可导 | 定位分母为零或分段规则单独规定的那一点，作为唯一可疑点 → 靠拢该点极限与导数定义的结构，用分子在该点的函数值补出差商形式 → 利用可导条件判定该极限存在且有限，从而排除第二类间断 | 前提：分子在该点可导且分母为该点的简单一次因子，函数在该点有单独规定的取值；坑点：分子在该点不可导时极限未必存在，分母为高阶零点时商式趋于无穷而变成第二类间断，把极限存在但不等于规定值当作连续 |
| 变限积分左右差商对照分支 | 分段函数中变限积分就是被判可导的那个整体，动作是把差商极限化为被积函数的左右极限 | 分参数为正、为零、为负三种情形对含参极限分别取值，写出分岔后的分段解析式 → 检验分段点处该分段函数的左右极限与定义值，标注间断类型 → 写出变限积分的增量式，利用积分对有限跳跃的抹平性判断其连续性 | 前提：被积函数在积分区间上只有有限个跳跃且处处可积，差商极限可化为被积函数单侧极限；坑点：在间断点直接套用微积分基本定理断言变限积分可导，被积函数含无穷型间断导致积分发散，忘记分岔条件把极限式当作统一解析式处理 |
| 分段点双条件锁参分支 | 分段点处有两个待定参数，须联立连续与可导两个条件求解 | 连续条件列第一个方程 → 两侧差商按定义或法则计算 → 左右导数相等列第二个方程 | 前提：只解连续方程就定参会漏参数；坑点：对数一侧差商需化简 |
| 单侧差商定性态分支 | 分段点一侧含抽象有界因子的性态判定 | 两侧分别求极限定连续 → 两侧按定义写差商 → 一侧等价替换降幂、另一侧有界乘无穷小归零 | 前提：等价替换处于乘除位置；坑点：对抽象因子用洛必达或只算一侧 |
| 复合内层差商配凑分支 | 已知导数值求含复合内层的差商极限 | 识别函数值差结构并确认内层趋于定义点 → 分母用等价替换换成同一无穷小 → 拆成差商因子与无穷小比之积 | 前提：内层必须趋于定义点；坑点：对未知函数本身作等价替换 |
| 任意倍率双点差商分支 | 差式两端是同一点不同倍率增量处的函数值 | 加减该点函数值把差拆成两项 → 每项配凑成标准方向差商并归一倍率 → 按定义分别收口后相加 | 前提：倍率为零时除法非法需单独处理；坑点：两点差不能当一个差商 |
| 已知极限反推导数再配凑分支 | 由含未知函数的极限反推其导数值再求另一差商 | 剥去已知极限的复合外壳 → 由连续性定函数值并把极限读成导数定义 → 所求式按内层增量拆成差商组合 | 前提：函数必须连续才能剥壳定值；坑点：差商不能漏除增量 |
| 单侧定义函数性态分支 | 函数仅在所论点单侧有定义 | 算单侧极限与函数值比较定单侧连续 → 按定义写单侧差商 → 判差商敛散下结论 | 前提：双侧概念不适用于单侧定义；坑点：右极限存在不等于右导数存在 |
| 函数方程差商定解析式分支 | 函数方程与高阶余项求解析式 | 把小增量识别为自变量增量 → 读出可微性与微分方程 → 分离变量积分 | 前提：余项阶数不足只知连续；坑点：分母零点单独讨论 |
| 微分与增量线性主部比较分支 | 比较微分与自变量增量的阶 | 写出微分定义式 → 作微分与增量的商 → 代该点导数值定阶 | 前提：导数值为零时阶的结论不同；坑点：把微分与增量之差当微分 |
| 洛必达一次后导数定义收口分支 | 低阶信息已知且分式可配成差商 | 确认零比零后洛必达一次 → 把分子配成导数定义差商 → 按定义代值收口 | 前提：题给只到某阶可导时严禁对更高阶洛必达；坑点：泰勒展开阶数要足 |
| 由含参极限证可导分支 | 由含未知函数的极限证明可导并求导数值 | 把极限写成极限值加无穷小 → 解出函数表达式 → 连续性定该点函数值 | 前提：未先定函数值就写差商；坑点：余项高阶性要利用 |
| 微分增量主部反求导数分支 | 题设给出微分或增量的线性主部关系，据此求含变限积分的比式极限（积分不作为待判对象） | 由增量关系读出该点导数值 → 分母等价替换成主部幂 → 变限积分求导或换元化简 | 前提：只知连续无增量阶时读不出导数；坑点：变限求导漏上限因子 |
| 可导充分条件幂次匹配辨析分支 | 选项以「某增量被 \|Δx\| 的若干次幂控制」的形式给出，动作是逐个匹配幂次与一阶的关系 | 逐项配凑差商形态 → 核对幂次匹配 → 序列趋近与对称差商只给必要 | 前提：序列极限当全极限；坑点：夹逼漏函数值先为零的论证 |
| 差商倍数反解切线斜率分支 | 由差商极限求切线斜率 | 代换统一差式方向 → 配凑导数定义的倍数关系 → 由极限反解导数值 | 前提：增量方向弄反漏负号；坑点：把极限值直接当斜率 |
| 高阶控制夹逼定导数分支 | 函数绝对值被增量的高次幂控制 | 代入增量零点定函数值 → 写差商取绝对值 → 用界控制成增量的线性函数 | 前提：控制不等式须对双侧邻域成立；坑点：夹逼方向弄反 |
| 单点导数保号性辨析分支 | 已知该点导数不为零（多为 f'(x0)>0）要判断能推出哪些邻域内结论；若题设只给导函数在去心邻域的极限而不给该点导数，归「导函数极限与可导性辨析分支」 | 写成单侧差商极限 → 保号性给右侧邻域函数值比较 → 左侧同理反向 | 前提：由一点导数推区间单调；坑点：左右保号结论混同 |
| 切线截距差商定义收口分支 | 求切线截距相关的比式极限 | 切线方程令纵坐标为零解截距 → 比值整理成零比零 → 洛必达一次 | 前提：对二阶导继续洛必达需连续性；坑点：截距化简出错 |
| 分段导函数连续性分级判别分支 | 要求一阶导连续而二阶导不存在（或按可导阶数分级），据此定参或判间断 | 连续定常数 → 左右导数相等定参数并保证导函数连续 → 分段导函数写出 | 前提：跳过导函数连续性；坑点：左右差商漏一侧 |
| 函数方程组合差商定导数分支 | 周期函数与函数方程联立求切线 | 取极限由周期性定基点函数值 → 差商配凑成导数定义组合 → 解出基点导数 | 前提：高阶余项直接丢项；坑点：周期平移点算错 |
| 系数和即导数值夹逼分支 | 三角多项式系数和的界估计 | 求导读出系数和为该点导数 → 写定义差商极限 → 用已知函数界夹住差商 | 前提：绝对值直接塞进极限；坑点：忘用定义点函数值为零 |
| 导函数极限与可导性辨析分支 | 题设只给导函数在去心邻域的极限（常为分段导函数）而不给该点导数值，要求据此判断原函数在该点可导性、连续性或间断类型 | 保号性给去心邻域导函数为正 → 两侧邻域单增 → 跳跃反例：导函数极限存在而函数不连续 | 前提：导函数极限当单侧导数；坑点：反例不满足前提 |
| 含绝对值分数幂可导性重数判据通法 | 由若干因子连乘构成、含绝对值或分数幂指数、要求在给定零点处判定可导性并求导数值的函数，亦可用于统计不可导点个数 | 圈定可疑点：把绝对值内部为零的点、分数幂因子取零的点以及分段点逐一点出，列成待判清单 → 剥出零因子：在该点把函数按因子拆成剩余部分与以该点为中心的幂零因子之积，拆分时先无视绝对值符号，把各因子贡献的重数相加得总重数 → 校验剩余部分：确认剩余因子在该点连续且取值非零，若其在该点也为零则返回上一步把多出的重数计入 → 定变号性：判断落在绝对值符号内的部分在该点两侧是否变号，不变号时绝对值符号不影响结论 | 可用[所判点是函数的零点且函数在该点有定义，导数定义中的分子可直接写成剩余部分乘以幂零因子；各因子在该点邻域内均可化为「非零连续因子乘以该点距离的某次幂」，即零点重数可定；只需判定单点可导性与该点导数值、统计不可导点的个数，或反解参数使导函数在所论点连续（该点连续仍由该点导数式的阶决定）] 失效[剥出幂零因子后的剩余部分在该点不连续、无极限或本身趋于零却未计入重数时，重数统计失真，判据失效；分段函数在分段点两侧给出互不相关的表达式且均无幂零结构时，只能回到定义分别算左右导数；所判点函数值非零时绝对值符号与分数幂都不制造可疑性，本法多余，应直接用求导法则] |
| 分数幂因子定阶分支 | 出现指数不是整数的幂或根式因子，且该因子在所判点取值为零 | 把该因子的指数直接计入该点零点重数 → 指数落在零与一之间时按低于一阶处理，判定为不可导 → 指数大于一时按高于一阶处理，判定为可导且导数为零 | 指数为负时函数在该点无定义，判据前提不成立，不能套用 |
| 绝对值变号性判别分支 | 只有一个绝对值因子，判别的实质动作是确定其内部在该点两侧是否变号 | 拆开绝对值符号，只看被它包住的那部分因子 → 统计该部分自身的零点重数：偶数重时两侧同号，绝对值不产生折点 → 奇数重（含恰好一重）时两侧异号，才真正引入折点 | 仅当被包住部分在该点为零时才需判别变号；该部分非零时绝对值符号可直接去掉 |
| 超越因子局部线性化分支 | 绝对值符号内是三角、对数、指数型等不能直接因式分解的因子，且在该点为零 | 在该点对该因子作幂展开并只取首个非零项 → 以首项的幂次充当该因子贡献的零点重数 → 首项系数为负时其符号被绝对值符号吞掉，不影响重数结论 | 该因子展开首项不是一阶（例如一减余弦型）时不能按一重计入，必须先定准首项阶 |
| 多因子同零点与参数重合分支 | 参数取某些值时不同零点相互重合，或所判点同时是多个因子的零点，需按重合与否分类 | 把每个因子在该点贡献的重数逐项相加，禁止只看单个因子的指数 → 含参数时按参数是否使零点重合分类，重合各阶的重数抬升后结论可能反转 → 对每个候选点各自独立重算重数，不得把某点的结论平移到另一点 | 各因子必须在同一趋近点展开，否则重数不可相加 |
| 零点重数与外侧因子判可导分支 | 结论要求统计不可导点的个数，动作是逐点把各因子重数累加后与一阶比较 | 拆出各绝对值因子并统计零点重数 → 检查外侧因子在对应零点是否取零 → 恰好一阶且外侧非零者为不可导点 | 前提：外侧因子取零会抬高重数使该点可导；坑点：漏拆复合绝对值 |
| 复合绝对值逐项重数分析分支 | 同一表达式里既有绝对值因子又有光滑复合层，需逐项展开定阶后合成总重数 | 逐项定绝对值内零点重数 → 光滑因子求导后在零点的行为定合成阶 → 恰好一阶折断者为不可导 | 前提：内函数首项高于一阶时绝对值不打断；坑点：忽略外层抬升会误判 |
| 绝对值乘子可导充要分支 | 绝对值因子乘抽象函数的可导充要条件 | 两侧按定义写差商 → 约去公共无穷小 → 左右相等化成外侧左右极限关系 | 前提：漏左右符号差；坑点：附加多余可导要求 |
| 零点重数定最高可导阶分支 | 含绝对值函数在一点最高可导阶数 | 邻域内去掉不变号的绝对值 → 逐项判各成分在该点的可导阶 → 定义验证临界阶 | 前提：内函数首项高于一阶时不是折点；坑点：逐项阶数判错 |
| 幂次阈值逐级判阶分支 | 含参的负幂次（倒幂）因子乘以有界振荡因子，动作是按参数阈值逐级判断商式是否趋于零 | 连续性定第一阈值 → 差商幂次定可导阈值 → 导函数极限定连续阈值 | 前提：阈值递增关系记错；坑点：对振荡因子用洛必达 |
| 参数分界点定义判可导分支 | 绝对值参数曲线在分界点的可导性 | 分参数改写绝对值成两支 → 两支分别按参数求导 → 分界点按定义算左右差商 | 前提：不回定义直接代分段导函数；坑点：漏验连续性 |
| 绝对值与积分因子逐项辨析分支 | 给出一组含绝对值或变限积分的候选函数，动作是逐个判断在所判点是否可导 | 逐项定绝对值零点重数与外侧行为 → 变限积分项看被积函数间断类型 → 逐项按定义或结论判定 | 前提：可去间断的变限积分仍可导；坑点：折点重数判错 |
| 幂次压制振荡定导连续分支 | 含参振荡因子与幂次相乘，动作是反解参数使导函数在该点连续（只需该点导数式定阶，不要求邻域内的导函数性态） | 定义求右侧单侧导数定第一阈值 → 写分段导函数 → 两支振荡项分别压制定第二阈值 | 前提：阈值取等混淆；坑点：导函数求导漏项 |
| 含参积分定义的函数在参变量奇值点处的连续性与可导性判定 | 先单独计算参数取特殊值时的积分，识别被积函数在该点的瑕点性质并用带下限极限的反常积分定义处理 | 对反常积分先求原函数，再用洛必达法则处理端点处幂乘对数的极限 → 在参数取一般值时用分部积分，把对数因子留在积分号外，剩下有理式积分 → 把余下的有理式分子配成同分母再分离常数，化为标准反正切型积分 | 含参积分在参数取特殊值时才有奇点，其余参数值下积分正常；失效：不加区分地把分部积分公式套到含瑕点的积分上，边界项失控 |
| 多元微分概念关系与可微性判定通法 | 分段（含绝对值、振荡因子）函数在原点处的偏导存在、可微与偏导连续判别 | 写出偏导、可微、连续三个定义式，标明各自控制单方向还是全平面 → 分段点用偏导定义固定其余变量取差商极限，先定该点偏导是否存在 → 偏导存在后按可微定义考察增量减线性主部除以距离，用有界乘无穷小或路径放缩定其是否趋零 → 在分段区域外求出偏导函数并取极限，检验偏导在该点是否连续 | 可用[函数在原点（或分段面）另行定义，或含绝对值与振荡因子；需要分别判断偏导存在、可微、偏导连续三件事；概念辨析题不给具体解析式，只给存在性条件] 失效[非分段点直接套求导公式即可；偏导不存在时谈不上可微与偏导连续；题设已含可微或偏导连续，可直接用强结论] |
| 概念推出关系分支 | 不给解析式，只给偏导存在或连续等存在性条件 | 由偏导定义直接推出沿坐标方向的极限存在与该方向有定义 → 对反向推断构造沿不同路径取不同值的反例 → 按选项逐条判定，排除只由单方向信息支持的弱结论 | 概念辨析题不给具体解析式，只给存在性条件；失效：题设已含可微或偏导连续，可直接用强结论 |
| 局部展开读偏导分支 | 已知函数等于可展函数加比距离高阶的无穷小 | 把主部系数与全微分定义中的线性主部对照，读出函数值与两个偏导 → 求复合函数微分时把读出的偏导代入链式法则 → 求沿路径的差商极限时把增量代入线性主部并估算余项阶 | 已知形如函数等于可展函数加比距离高阶无穷小的局部信息；失效：余项不是比距离高阶的无穷小，读不出线性主部 |

### 失效边界

**适用前提**（69 条）

### 标准解题步骤

1. 判型：待求量若由定积分号内的整体构成则记为一个待定常数，若随参数变动则记为一个参数的函数
2. 常数值型：等式两边在同一区间（区域）上再取积分，把右端各块用对称性或极坐标算出，得到常数的线性方程并解出代回原式
3. 确认被积函数连续使变限求导合法；参数在被积式内部时先作整体代换把参数集中到上限或整体上
4. 参数在上下限并存时先换序（由积分限还原区域后按另一顺序定限），使含参的限移到外层
5. 求导写成上限项减下限项，各乘该限对参数（变量）的偏导并保留符号，残留的参数用平移换元集中到积分限
6. 需要时再求一阶导直到被积式只剩单变量形式，代入指定值取数值；解所得微分或代数方程并回代检验，初始值靠代特殊点从原方程取出
7. 零比零型比式：把分子化成单参数的变限积分后逐层求导降次，或用积分中值定理写成中值点函数值乘面积、再按定点展开取主部定极限
8. 结构性质先行：奇函数的变限积分是偶函数、偶函数从对称中心出发的变限积分是奇函数，起点偏移则叠加常函数修正

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 积分方程化微分方程分支 | 积分方程确定函数再求导数或高阶导数，上下限同时含变量时对上限与下限各乘其导数复合求导 | 两端求导消积分号 → 取初始条件 → 解方程并展开读系数 | 漏初始条件是高频错 |
| 被积函数为参数与变量组合的变限积分求导 | 观察组合式的微分，把余下因子并入微分号内并记录倍率 | 以组合式为新变量代换，上下限随之改为参数表达式 → 整理成常数倍的标准变限积分 → 对上限求导并乘上限的导数 | 被积函数只通过单一组合依赖参数与变量；失效：组合式与余因子不匹配时无法整体代换 |
| 变限积分与幂的比式极限 | 按组合代换把积分化为变限积分的标准形式 | 由被积函数在零点的线性主部定出其阶 → 对主部积分得到积分整体的阶与系数 → 与分母的幂比较，同阶时写出系数比 | 被积函数在零点可导且零点值为零；失效：被积函数在零点非零时积分阶为一，与高阶分母之比发散 |
| 含反函数的变限积分方程反求原函数并定值 | 对被积函数的平移自变量做换元，同时把上下限同步平移，使积分号内只剩反函数 | 写出化简后的等式，两侧同对新变量求导 → 左侧用变限积分求导法则，上限为复合函数时补上其导数因子 → 利用反函数与原函数互为逆映射的关系，把反函数在原函数处的取值还原为自变量 | 函数可导且存在反函数，使复合取值能还原为自变量；失效：反函数不存在或多值时把逆映射关系当成恒等式使用 |
| 两个变限积分之比的极限 | 确认分子分母在上限趋于同一点时都趋于零，判定为零比零型未定式 | 对分子求导：被积函数取上限处的值再乘上限对自变量的导数 → 对分母求导：同样先代上限再乘其导数，注意上限本身是三角函数 → 把求导后的表达式按因子拆开，识别出可单独求极限的连续因子 | 被积函数在上限趋向点附近连续或有可去型极限；失效：被积函数在积分路径上变号或无界，先估阶再约项导致结论错误 |
| 上限为三角函数、分母为高次幂的变限积分极限 | 用积分上下限交换把分子改写成下限固定于极限点的形式并补负号 | 确认分子分母同时趋于零，对两者分别求导 → 分子求导：被积函数代上限值，再乘上限对自变量的导数 → 分母求导：幂函数降次，得到低一阶的幂 | 被积函数在上限附近连续，变限求导法则可用；失效：被积函数在对数内部趋于无穷时忽略其符号，导致上下限交换漏负号 |
| 嵌套变限积分与三角幂分母的极限 | 把分母中的三角差式用等价无穷小改写成幂函数乘常数，减少求导轮次 | 确认整体为零比零型，对分子分母各求一次导 → 外层求导时把内层变限积分整体作为被积函数代入外层上限 → 此时分子仍趋于零，对内层变限积分再求导：被积函数代内层上限值 | 各层被积函数在相应上限趋向点连续，逐层求导合法；失效：把内层积分当成常数求导，遗漏其上限依赖 |
| 被积函数含参数幂的变限积分求导及其导数的连续性讨论 | 把被积函数中含参数的整体作为新变量，同步改写上下限并提出参数因子 | 在非零参数处按乘积求导法则展开，包含变限积分求导项与倒数因子求导项 → 在参数为零处改用导数定义，把函数值写成积分除以幂次形式 → 对该未定式用洛必达，分子由变限积分求导直接给出被积函数端点复合值 | 被积函数连续保证变限求导可用；失效：在零点直接用求导法则（表达式无定义） |

### 标准解题步骤

1. 求一阶导数并解驻点与不可导点
2. 列表或按区间判导数符号得单调性
3. 极值候选两侧变号或二阶导定号
4. 闭区间端点与内部候选比较得最值
5. 含参时把驻点与参数联立讨论
6. 二阶导定号判凹凸方向，拐点须二阶导在该点两侧变号，零点与不存在点只是候选，必要时用高阶导数信息经泰勒展开定局部形态
7. 穷尽渐近线候选：无定义点处极限无穷为铅直渐近线，无穷方向先验水平后验斜，斜渐近线由斜率与截距两个极限唯一确定
8. 求曲率与曲率圆：由一阶与二阶导数算曲率、取倒数得半径，圆心沿法线落在凹侧
9. 比较型与链式传递：一阶导（偏导）定号给出单个变量的单调方向，把两点比较拆成逐段移动的一元比较；复合结构须内层值域整体落在外层同一单调区间才能沿链传递

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 比式极限定极值分支 | 题设只给 [f(x)-f(x0)] 与某幂次之比的极限值，无各阶导数信息，据保号性直接定两侧符号 | 拆差商得导数值 → 保号性定邻域符号 → 对照定义下结论 | 只算导数不查邻域符号会漏判 |
| 驻点参数化分支 | 驻点随参数变化并求相关极限或切线 | 令导数为零解驻点 → 解含参表达式 → 化归基本极限或点斜式 | 驻点不唯一按题设取 |

## 由导数（偏导）信息反求函数通法

> 编号 **T-HS-116-I** ｜ 版本 **v0.4.5** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

### 标准解题步骤

1. 把已知的导数或微分关系整理成导数等于已知表达式的形式，自变量为复合整体时先把该整体设成新变量还原成常规导数式
2. 先用混合偏导相等检验相容性，含参时比较分子系数定出参数；判定式是否为某函数的全微分只看这一步
3. 在关系式两端取不定（逐次）积分，右端按凑微分、换元或分部积分积出；多元时先对一个变量积分，把常数写成另一变量的待定函数
4. 对待定函数求导并与另一个偏导（或题给条件）比较，解出待定函数；出现同族待求量时移项解出它等于已知项之和
5. 化到只含一个未知函数及其单变量导数的方程：代数型直接解，常微分方程型按特征方程定通解，未知函数以复合内层出现时先把内层整体作自变量
6. 用题给的定点函数值、定线条件、周期归化后的自变量取值或边界极限定出积分常数
7. 导数按分段表达式给出时各段分别积分并保留各自常数，再由函数在分段点连续把左右两支绑成同一值；需开方还原时按函数在所论区间的正负选定分支
8. 把所得函数与其导数回代原关系式和附加条件双向验证，确认系数与常数同时吻合

### 失效边界

**适用前提**（15 条）

- 所论区间内原函数符号已知或可定
- 右端积分可初等表出
- 被积式在所选分支上连续
- 定点落在该分支内
- 开根时二次因子带绝对值需按分支定号
- 附加条件足以定出全部待定项
- 系数在所讨论区域有一阶连续偏导且分母不为零
- 待定参数线性进入系数比较式
- 给定的两个偏导（微分系数）在所讨论区域有一阶连续偏导；混合偏导相等这一相容性正由本法第2步检验——含待定参数时相容条件本身就是定参方程，不与「相容条件定参分支」互斥
- 与由偏导等式反解未知函数、变量代换化简二阶偏导两法的分工：题给为偏导或全微分的具体表达式（或其定参问题）走本法；题给偏导所满足的等式且未知量是复合内层一元函数走反解法；题给线性变量代换化简偏微分式走代换化简法，化简后回到本法收官
- 题给关于导数或偏导的等式，未知量是函数本身或其中参数
- 化简后能把等式归成只含一个未知函数及其单变量导数的方程：既含「未知导数项整体相消」的代数型，也含化为二阶线性常微分方程的积分型（后者求解按特征方程，转交微分方程通法）
- 与由偏导（全微分）还原函数与定参通法的分工：题给已是偏导或全微分的具体表达式（或由其定参数）走该法，题给偏导所满足的等式且未知量是复合内层的一元函数走本法
- 化简后含未知导数的项可整体消去
- 给定偏导连续且满足混合偏导相等的相容条件

**失效场景**（14 条）

- 开方不加符号判断会丢分支
- 原函数变号处不可导
- 把乘积关系直接当导数关系处理
- 跨分支统一写一个原函数（两分支常数独立）
- 提因子时把平方根写成平方
- 用反余弦形式却不检查分支上的符号差异
- 两个偏导不满足相容条件，这样的函数不存在
- 条件只给在边界曲线上，无法定出待定函数
- 区域带空洞（如去掉原点）时相容条件不再充分
- 表达式根本不是全微分形式
- 条件不足时只能定出某点的值而非整个函数
- 化简后仍归不到只含一个未知函数的方程（未知函数同时跨多个自变量、或以无法分离的算子形式出现）时本法无出口
- 条件只给在某条定线上且不足以定出待定函数时，须改由偏导（全微分）还原函数与定参通法处理
- 等式含未知函数的高阶导数，须先积分还原

## 多元函数求偏导与隐式表示求导通法

> 编号 **T-HS-232-I** ｜ 版本 **v0.3.14** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 多元求导只有两种基本动作：固定其余变量做一元求导，以及沿依赖图把各通路乘积相加；依赖关系由方程（组）隐式给出时改为两端同求导再把未知导数当待定量解出（能否解出、能解出哪个因变量由对应偏导或系数行列式非零决定），自变量在对合变换下方程依然成立时用同一变换给出第二个方程消元解出解析式，线性变量代换则逐层求二阶偏导合并同类项后比较系数 |
| 适用范围 | 外层为抽象多元函数、内层为具体表达式的复合结构求一阶与二阶偏导 |
| 学科 / 章节 | 高等数学 · 多元函数微分学及其应用、函数、极限、连续 |
| 表面题型 | 抽象复合函数求偏导；显式函数求偏导全微分；指定阶高阶偏导；隐函数求偏导与全微分；方程组确定函数求导；隐函数存在性判定；母子方程代换求解析式；变量代换化简偏微分式 |
| 对应考点 | 复合函数求导（链式法则）；（二）求导数；联系；隐函数求导；（二）隐函存在前提；解题连招；〈2〉方程组；函数解析式；函数方程；奇偶性；母子同踪迹；（三）母子同踪迹；性质；（五）反问题求解；（一）概念及联系 |
| 覆盖题量 | 22 题（分支 7 个） |

### 标准解题步骤

1. 判定结构归属：显式初等式走固定变量法，抽象复合式先画依赖图，方程（组）给出的隐式关系走两端求导，含代换的先定代换类型
2. 显式式依次固定其余变量按一元法则求一阶偏导；复合式对每个自变量把全部通路相乘后求和，抽象函数偏导按位置编号记录
3. 隐式场合检验相关偏导（或方程组的系数行列式）是否非零，据此确定可解出的因变量，再两端对目标自变量求导并把导数当未知量解出（单方程解单个导数，方程组整理成线性组后消元）
4. 对合代换（自变量变换后方程依然成立）时写出变换后的第二个方程，两式联立消元解出解析式，因不引入新未知量而可直接收口
5. 线性变量代换化简二阶偏导：逐层求导并按新变量合并同类项，令不需要的系数为零定出参数或化成目标标准形
6. 需要高阶偏导时把一阶结果再当作待求式走同一流程，拆项式改套倒数的高阶导数通项
7. 求全微分时把各一阶偏导与对应微分相乘相加，再按题给点取值；代点前先确认该点处偏导存在且表达式不分段

| 变量代换化简二阶偏导 | 线性变量代换下化简二阶偏微分表达式、比较系数定参数或还原函数 | 由新变量与自变量的关系用链式法则求一阶偏导 → 再求一次得二阶偏导，注意一阶结果本身仍是复合函数 → 把二阶式代回原方程，按新变量的二阶偏导合并同类项 → 比较系数确定参数或读出目标形式的偏导值 | 可用[代换为自变量的线性组合且函数有二阶连续偏导；代换后的目标形以「消去一个或若干个纯二阶偏导、只留混合偏导」或化成标准波动型为限，其他目标形须重设代换（系数无法全配即入失效场景）；本法止于比较系数定参数或读出目标形式的偏导值；化简后需要由偏导信息（或标准形方程加定线条件）反求函数表达式的，交由偏导（全微分）还原函数与定参通法] 失效[代换的雅可比为零时新变量不独立；系数无法全部匹配，需重设代换] |

### 失效边界

**适用前提**（24 条）

- 外层为抽象多元函数、内层为可求导的具体表达式
- 中间变量与自变量个数都能明确写出
- 显式初等式走固定变量法时要求偏导在求值点连续且求值点不在定义域边界或分段点上；落在分段点的偏导与可微性一律交多元微分概念关系与可微性判定通法
- 拆项套通项仅限被求式可拆成关于该变量的一次式倒数之和且阶数以符号给出的那一支；其余高阶偏导把一阶结果重新当作待求式逐次求导，只求低阶时直接逐次求导更省
- 依赖变量的导数由方程（组）隐式给出的复合求导交隐式方程（组）确定函数的求导通法，本法只处理依赖关系由显式代换或初等表达式给出的复合
- 单一方程确定单一依赖变量，且其对应变量的偏导不为零
- 约束方程个数与待定因变量个数相同
- 所求导数在求导后的方程组中线性出现
- 各偏导连续且只讨论某点的局部可解性
- 题目问能确定哪些隐函数而非求导数值
- 所求导数的阶数不超过二阶（包括混合偏导的一般表达式与代点值两种），更高阶本法只保证逐层求导而不保证闭式
- 与多元函数求偏导与全微分通法的分工：依赖变量的导数由方程（组）隐式给出时走本法，由显式代换给出时走该法；本法第3步内的链式求导仍按该法的通路相加规则执行
- 未知函数只出现在互为对合的两个自变量处
- 消元所需的系数行列式在题设条件下不为零
- 自变量取值范围对该变换封闭
- 方程中未知函数只出现在互为对合的两个自变量处
- 代换为自变量的线性组合且函数有二阶连续偏导
- 代换后的目标形以「消去一个或若干个纯二阶偏导、只留混合偏导」或化成标准波动型为限，其他目标形须重设代换（系数无法全配即入失效场景）
- 本法止于比较系数定参数或读出目标形式的偏导值；化简后需要由偏导信息（或标准形方程加定线条件）反求函数表达式的，交由偏导（全微分）还原函数与定参通法
- 内层为非线性整体（如指数因子乘三角因子）且待求的是那个一元函数本身时，归由偏导等式反解未知函数通法，不入本法
- 函数由初等表达式显式给出且偏导在求值点连续
- 求值点不在定义域边界或分段点上
- 只需求一阶偏导、一阶全微分或代点二阶导
- 目标形只含混合偏导或标准波动型算子

**失效场景**（20 条）

- 函数在讨论点不可微时链式法则失效，须回到差商定义
- 内层含绝对值或分段点，先判可微性再相乘
- 分段点或绝对值内为零处需改用定义
- 偏导不存在时全微分表达式不成立
- 分式含不可分解的高次因式，通项法不适用
- 只求低阶导数时直接逐次求导更省
- 相应偏导为零，隐函数定理条件不满足
- 分段或绝对值使代点处偏导不存在
- 系数行列式为零，导数不唯一或不存在
- 方程数少于待定因变量数，需补充其他关系
- 所有相关偏导都为零，定理给不出结论
- 需要整体而非局部的解存在性
- 变换不可逆或迭代产生新未知点时方程组无法闭合
- 系数行列式为零时解不唯一或不存在
- 忽略自变量取值范围把结果推广到使原式无意义的点
- 只需求某一点函数值时本法多余，代特殊值即够
- 变换不可逆或产生新的未知点时方程组无法闭合
- 忽略自变量的取值范围限制而把结果误推广到零点
- 代换的雅可比为零时新变量不独立
- 系数无法全部匹配，需重设代换

## 极值与最值的候选定性与比较通法

> 编号 **T-HS-233-I** ｜ 版本 **v0.3.20** ｜ 来源 **增量归纳** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 极值与最值只在两处做文章：定候选点与定该点的性质。候选点来自内部驻点（一阶偏导为零）、边界与约束（代入消元化为一元或配乘数构成乘数方程组）以及由定义或保号性圈出的点；类型由一阶偏导两侧变号或二阶偏导构成的判别式给出，最后把全部候选值列一张表比较取最值，唯一候选点时结合实际意义直接断言 |
| 适用范围 | 等式约束下的距离、面积、取值范围等条件最值问题 |
| 学科 / 章节 | 高等数学 · 多元函数微分学及其应用 |
| 表面题型 | 乘数法求条件最值；对称结构条件极值；无条件极值判别；隐函数极值判别；极值定义与必要条件；闭区域上求最值 |
| 对应考点 | 有条件极值；〈2〉拉格朗日乘数法；（一）提前估存在；解题连招；（三）对称则事半功倍；（七）拉式有技巧；无条件极值；<3>找极值点；（三）求极值、最值；隐函数求导；<2>已知极值点；<1>极值的定义；（四）闭区域最值；<1>化为无条件极值；（五）反问题求解 |
| 覆盖题量 | 26 题（分支 5 个） |

### 标准解题步骤

1. 先估最值是否一定取得到（闭集连续或实际问题唯一性，区域无界时补无穷远处估计），决定是只找极值还是需比较
2. 无条件场合解一阶偏导为零得驻点，并列出不可导点
3. 判别式定类型：二阶偏导组合的判别式为正时由首个二阶偏导符号定极大极小，为负判非极值点，为零或含分段时回到定义用配方或沿路径比较
4. 等式约束场合把目标与每个约束各配乘数构成拉格朗日函数，对各自变量与乘数求偏导并列零
5. 一般场合先消乘数再与约束联立；对称场合两式相减作因式分解，或把变量方程视为齐次线性组令系数行列式为零定乘数
6. 对每个分支回代约束求候选点，保留非对称解并写明被舍分支代入约束后无解
7. 闭区域场合分内部与边界两条线：内部解驻点，边界逐条用代入消元化为一元或配乘数，端点与分点一并入表
8. 逐点比较目标值定最大最小，并用对称性校验应为零的奇项

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 对称结构批量求解分支 | 目标与各约束在变量互换下完全不变或只差常数倍，可用两两相减消去乘数并作因式分解批量得到候选解；仅当目标与约束同为二次型时才改用齐次线性方程组系数行列式为零定乘数 | 两式相减消去乘数，因式分解出变量相等或某线性组合为零的分支 → 二次型场合把前两式看作齐次线性方程组，令系数行列式为零解出乘数 → 对每个分支回代约束求出候选点 | 目标与约束在变量互换下不变或只差常数倍；失效：只看变量相等的分支会漏解除非对称解 |
| 多元函数极值判别与反求通法 | 二元函数在开集或整个定义域内求极值、判极值类型或反定参数条件 | 按已知信息形态选候选点来源：显式解一阶偏导为零，隐式把一阶导为零代回原方程，只给极限或不等式时用保号性直接圈出邻域大小关系 → 已知极值点或极值时先用一阶偏导为零列必要条件，解出参数或驻点坐标 → 求二阶偏导并在候选点取值，组成判别式 → 判别式为正时由首个二阶偏导符号定极大极小，为负则非极值点 | 可用[函数有二阶连续偏导，区域为开集或整个定义域；极值点处一阶导为零从而简化二阶式；已知量是含参极限或不等式而非函数解析式本身] 失效[判别式恰为零，二阶判别法不作结论；边界上的最值属条件极值，不能由驻点判别；二阶式在该点退化，需回到定义比较函数值] |
| 方程定隐函数极值分支 | 依赖变量由单一方程或方程组隐式给出且相应偏导（或系数行列式）非零，可把一阶导为零代回原方程定候选点并再求一阶得二阶判别式 | 把驻点代回原方程确定该点的函数值 → 方程两端再求一次导，整理出二阶导表达式 → 在驻点取二阶值定号，正为极小、负为极大 | 依赖变量由单一方程隐式给出且相关偏导非零；失效：二阶式在该点退化，需回到定义比较函数值 |
| 定义与必要条件分支 | 题中无可求导的解析式，只给含参极限、保号性不等式或已知极值点信息，须直接用极值定义与一阶导为零的必要条件定参数或定号 | 用保号性把局部不等式翻译成函数值与定点值的大小关系 → 按极值定义直接给出极大或极小结论 → 若已知该点为极值点，先用一阶偏导为零列必要条件，再补二阶信息定参数 | 已知量是含参极限或不等式而非函数解析式本身；失效：分母变号，保号性给不出单侧估计 |
| 闭区域最值内外分线 | 二元函数在有界闭区域（或补了无穷远估计的无界区域）上求最大最小值 | 在区域内部令一阶偏导为零求驻点并算函数值 → 把每段边界方程代入目标化为一元函数（或建乘数式）求边界候选点 → 补齐各段边界的端点与交点 → 列表比较全部候选函数值，最大者为最大值、最小者为最小值 | 可用[边界条数有限且每段可参数化或消元；区域为闭区域：有界且函数连续时最值必存在；区域无界但函数在无穷远趋于同一值（或趋于无穷）时，最值存在性由主干第5步的无穷远估计补出，此时本法仍适用；题目需要同时比较区域内部驻点与全部边界段的候选值；只有等式约束而无内部/边界之分时交条件极值与拉格朗日乘数法通法，开区域内给单点定类型时交多元函数极值判别与反求通法] 失效[区域无界时不补无穷远估计可能取不到最值；内部驻点判别不能代替边界比较] |

### 失效边界

**适用前提**（20 条）

- 目标与约束都可微
- 目标与约束在变量互换下不变或只差常数倍
- 乘数以线性方式出现可整体消去
- 约束为一个或若干个等式（组）且约束梯度（雅可比行向量组）线性无关，不可导点与梯度为零的奇点须另案处理
- 约束集为闭集：有界时最值必达；无界时须另验目标函数沿约束集趋于无穷（或补无穷远比较），才能把唯一候选点断言为最大最小
- 与闭区域最值内外分线的分工：本法只处理等式约束下的极值与最值，不列内部驻点与逐段边界的候选表；需要同时比较内部与多条边界时归闭区域最值通法
- 函数有二阶连续偏导，区域为开集或整个定义域
- 极值点处一阶导为零从而简化二阶式
- 已知量是含参极限或不等式而非函数解析式本身
- 分母在去心邻域内定号
- 驻点可离散列出并用通式表出，含周期性或参数族给出的无穷多个驻点（须全部写出再逐个定类型）
- 依赖变量由单一方程隐式给出时，其一阶、二阶导数由隐式方程（组）确定函数的求导通法给出，本法只在其结果上令一阶导为零并组成二阶判别式
- 与闭区域最值内外分线的分工：本法只论开区域内单点的极值类型；凡需要与边界候选值列表比较最大最小的归闭区域最值通法
- 边界条数有限且每段可参数化或消元
- 区域为闭区域：有界且函数连续时最值必存在；区域无界但函数在无穷远趋于同一值（或趋于无穷）时，最值存在性由主干第5步的无穷远估计补出，此时本法仍适用
- 题目需要同时比较区域内部驻点与全部边界段的候选值；只有等式约束而无内部/边界之分时交条件极值与拉格朗日乘数法通法，开区域内给单点定类型时交多元函数极值判别与反求通法
- 约束为等式且约束梯度不为零，可行集封闭无界需另估
- 区域有界闭且函数连续，最值必存在
- 驻点离散且个数有限
- 依赖变量由单一方程隐式给出且相关偏导非零

**失效场景**（12 条）

- 约束是不等式，须另行讨论内部情形
- 乘数法会漏掉梯度为零的奇点与不可导点
- 只看变量相等的分支会漏解除非对称解
- 行列式法只适用于目标与约束同为二次型
- 判别式恰为零，二阶判别法不作结论
- 边界上的最值属条件极值，不能由驻点判别
- 二阶式在该点退化，需回到定义比较函数值
- 方程确定多个分支，需先选定分支
- 分母变号，保号性给不出单侧估计
- 只掌握沿某一方向的信息，不能定全邻域大小
- 区域无界时不补无穷远估计可能取不到最值
- 内部驻点判别不能代替边界比较
