## 标准型定阶判别反常积分敛散性

> 编号 **T-HS-06-S** ｜ 版本 **v0.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 在每个反常来源处把被积函数定阶为幂与对数幂的标准型，由幂指数以及临界档上的对数指数唯一决定该段敛散性 |
| 适用范围 | 含瑕点或无穷区间的正项反常积分判别，以及由收敛结论反解参数范围的选择题；被积函数为幂、对数、指数、反三角、根式的复合 |
| 学科 / 章节 | 高等数学 · 一元函数积分学及其应用 |
| 表面题型 | 幂对数复合型反常积分；含参反常积分定范围；多瑕点分段判别；分段函数无穷区间积分；临界档判敛 |
| 对应考点 | 反常积分的概念与敛散性；无限区间上的反常积分；瑕积分；比较审敛法的极限形式；等价无穷小与等价无穷大 |
| 覆盖题量 | 0 题（分支 4 个） |

### 标准解题步骤

1. 找出全部反常来源：无穷区间的端点，以及使被积函数无界的内点与端点瑕点
2. 以反常来源为界把积分拆成若干段，保证每段只含一个反常点
3. 在每段内把被积函数等价变形为幂乘对数幂的标准形式，非幂因子用该趋近点处的等价无穷小或无穷大换成幂或对数幂
4. 读出该段的幂指数与对数指数（同档因子相乘时指数相加），并标明该段是趋于零型还是趋于无穷型
5. 套用判别条件：趋于零时幂指数小于一收敛、幂指数等于一且对数指数大于一收敛；趋于无穷时幂指数大于一收敛、幂指数等于一且对数指数大于一收敛；其余一律发散
6. 各段全部收敛才判定原积分收敛；含参问题时把各段的条件联立取交集，反解参数范围

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 多瑕点分段定阶分支 | 积分区间内部或两端同时存在多个使函数无界的点 | 按每个瑕点切分子区间 → 每段以该瑕点为趋近点单独定阶 → 各段结论取交集，任一段发散即整体发散 | 切分不完备（某子段内仍有无界点）时该段结论无效；只在一端定阶会漏掉另一端的发散条件 |
| 含参反解范围分支 | 题目给出收敛或发散的结论，要求参数的取值范围 | 把参数线性组合进幂指数与对数指数 → 按收敛方向列出不等式并判断临界等号能否取 → 对各反常点的不等式取交集 | 幂指数等于一属临界档，此时必须再看对数指数；把临界等号直接写成严格不等式会丢掉或误含边界值 |
| 非幂因子定阶分支 | 被积函数含对数、反三角、指数减一、三角函数等非幂因子 | 在趋近点处把这些因子等价为其主阶幂或对数幂 → 区分对数的幂与自变量的幂，不要互相代入 → 合并各因子指数得到该段的幂指数与对数指数 | 等价式必须在所论趋近点成立（在趋于一处用另一处的等价会算错阶）；因子之间存在加减相消时不能逐项替换 |
| 分段函数积分分支 | 被积函数按区间分段给出，或在分段点处表达式改变 | 把分段点当作潜在瑕点，在其左右两侧分别定阶 → 检查分段点处函数是否有界，有界则该点不产生反常来源 → 合并各段条件 | 分段点处有跳跃但有界时不是瑕点，误当瑕点重复判别会引入多余的条件 |

### 失效边界

- **适用前提**：被积函数在每个子段上不变号（正项或定号），可用等价定阶与比较审敛法的极限形式；各因子在趋近点处有确定的幂阶或对数阶；反常来源个数为有限个；参数不改变各因子的档位归属
- **失效场景**：被积函数变号或含振荡因子时，本判别只回答绝对收敛性，判出发散并不代表原积分发散（可能条件收敛）；含指数衰减与三角函数混合的类型不属于幂对数标准档，套用阶参数会得错误条件，应改用收敛的必要条件或求出原函数取极限；只在一个反常点定阶就下整体结论，会漏掉另一端的发散条件；把幂指数与对数指数记反（临界档上尤其容易），会把收敛判成发散或反之；等价替换用于加减项或主项相消时定出的幂指数偏大或偏小，导致边界判断错误；分母零点位于积分区间内部却未被识别为瑕点，会漏判发散；被积函数在瑕点处趋于零（而非无穷）时该点不是瑕点，强行按瑕积分判别会引入不存在的要求

### 典型例题

| 题号 | 表面题型 | 本质要点 |
| --- | --- | --- |
| seed | 分母含高次幂与根式的瑕积分 | 在瑕点处等价定阶读幂指数（非幂因子定阶分支） |
| seed | 含对数幂与幂函数混合、两端皆瑕的积分 | 两端分别定阶后取交集（多瑕点分段定阶分支） |
| seed | 由收敛结论反解两个参数的范围 | 无穷端与零端各列一条不等式（含参反解范围分支） |
| seed | 分段给出、定义在正半轴上的函数判全区间收敛 | 零侧与无穷侧各定一次阶（分段函数积分分支） |

## 反常积分收敛必要条件的级数视角

> 编号 **T-HS-07-S** ｜ 版本 **v0.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 把无穷区间上的反常积分看作连续型的无穷级数，被积函数在无穷端不趋于零则积分必发散，趋于零时再靠主导衰减因子控制判收敛 |
| 适用范围 | 含指数与三角振荡因子的无穷区间反常积分，特别是幂对数标准型覆盖不到、常规做法需大量分类讨论的含参定范围题 |
| 学科 / 章节 | 高等数学 · 一元函数积分学及其应用 |
| 表面题型 | 指数乘三角型积分；振荡型反常积分；含参反常积分定范围；快速判发散 |
| 对应考点 | 反常积分的敛散性；无穷级数收敛的必要条件；含参反常积分；比较审敛法 |
| 覆盖题量 | 0 题（分支 2 个） |

### 标准解题步骤

1. 判断被积函数在无穷端是否属于幂与对数幂的标准档；含指数或振荡因子时改用级数视角
2. 求被积函数在无穷端的极限，即把其当作级数的一般项考察
3. 该极限不为零或不存在（含振荡不衰减）时，直接断定反常积分发散
4. 该极限为零时，进一步用主导衰减因子给出绝对值的可积控制，再判定收敛
5. 把「极限为零」解出的参数条件作为候选范围，并用原函数表达式取上限极限复核，排除只满足必要条件的多余取值

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 振荡不衰减排除分支 | 被积函数为纯三角函数或振幅不趋于零的振荡式 | 写出振荡因子的振幅包络 → 判断包络是否趋于零 → 包络不趋于零时原函数极限必不存在，判发散 | 振幅趋于零时本必要条件失效，不能反向断言收敛，需另做绝对收敛或狄利克雷型判别 |
| 指数主导定参分支 | 被积函数含指数因子乘以有界因子 | 由无穷端极限为零解出使指数衰减的参数条件 → 确认有界因子只影响数值不影响敛散性 → 用分部积分或原函数表达式复核收敛值与参数范围 | 参数使指数因子退化为常数一时，衰减条件不再成立，必须回到振荡分支单独讨论 |

### 失效边界

- **适用前提**：积分区间为无穷区间，且被积函数在无穷端有确定的极限行为；用于快速排除发散情形，或由必要条件压缩参数范围；与标准型判别互补：标准型管绝对收敛的阶，本法定振荡与指数型的必要门槛
- **失效场景**：一般项趋于零只是收敛的必要条件，据此断言收敛是错的（幂对数档中幂指数不大于零的情形即反例），必须补充分支的充分性控制；瑕积分在瑕点处被积函数必趋于无穷，不存在趋于零的必要条件，误用会把发散说成收敛；需要区分条件收敛与绝对收敛时本方法给不出结论，必须回到定义求原函数的极限；含两个以上参数时，仅由必要条件得到的范围偏大，不复核充分性会给出错误答案；被积函数在无穷端无极限（振幅发散振荡）时，只能判发散，不能进一步给出收敛侧的任何信息

### 典型例题

| 题号 | 表面题型 | 本质要点 |
| --- | --- | --- |
| seed | 指数衰减乘余弦在零到正无穷上收敛定参数 | 由一般项趋于零得衰减条件，免去常规做法的四种分类讨论（指数主导定参分支） |
| seed | 纯三角函数在无穷区间上的积分 | 振幅不趋于零，原函数极限不存在，判发散（振荡不衰减排除分支） |

## 换元化标准型判反常积分敛散性

> 编号 **T-HS-08-S** ｜ 版本 **v0.1** ｜ 来源 **种子通法（已有优质归纳）** ｜ 层级 **一级核心通法**

| 项目 | 内容 |
| --- | --- |
| 核心本质 | 看似不能用幂对数标准型判别的反常积分，经迭代对数、指数或瑕点平移换元后都化回标准型，敛散性只由阶与趋近方向决定 |
| 适用范围 | 被积函数为幂、对数（含迭代对数）、指数复合的正项反常积分，包括无穷区间积分与瑕积分，以及标准型判不动的变形情形 |
| 学科 / 章节 | 高等数学 · 一元函数积分学及其应用 |
| 表面题型 | 多层对数型反常积分；指数乘幂型反常积分；瑕点非原点的瑕积分；含参反常积分定范围；两端瑕点积分 |
| 对应考点 | 反常积分的概念与敛散性；无限区间上的反常积分；瑕积分；比较审敛法的极限形式；定积分换元法 |
| 覆盖题量 | 0 题（分支 4 个） |

### 标准解题步骤

1. 定位全部反常来源：无穷区间的端点，以及使被积函数无界的瑕点（含区间内部的分母零点与对数变号点）
2. 以反常来源为界把积分拆成若干段，每段只含一个反常点，逐段判别后再取交集下整体结论
3. 对每段选换元把趋近过程化为新变量趋于零或趋于无穷：迭代对数型令最外层对数为新变量，指数型令指数为新变量，非原点瑕点令平移量为新变量
4. 把换元后的被积表达式整理成幂乘对数幂的标准形式，同步换算微分因子与积分上下限，读出该段的两个阶参数
5. 按趋近方向套用判别条件：趋于零时幂指数小于一收敛，幂指数等于一对数指数大于一收敛；趋于无穷时幂指数大于一收敛，等于一对数指数大于一收敛；其余发散
6. 含参数时把阶参数满足的不等式回代为原参数的范围，并对各段条件取交集

### 二级分支（按表面题型适配）

| 分支 | 触发特征 | 追加操作 | 适用前提 |
| --- | --- | --- | --- |
| 迭代对数换元分支 | 分母出现逐层嵌套的对数（对数套对数） | 令最外层对数为新变量 → 反解自变量并求出微分因子的指数型放大量 → 验证放大量恰好抵消原来自变量的幂，得到纯新变量的负幂形式 → 按新变量的幂指数判边界 | 要求每层对数在新变量的取值区间内定号且换元单调；瑕点恰落在某层对数变号处时不能整体换元 |
| 指数换元分支 | 被积函数含指数因子，或自变量与指数因子相乘 | 令指数为新变量，把指数因子化为新变量的负幂 → 把原来自变量用对数反解，使多项自变量变成对数的幂 → 整理为幂乘对数幂后读阶参数 | 换元后新变量的下限必须仍为正数，原区间含使新变量非正的点时不可用对数反解 |
| 瑕点平移定阶分支 | 瑕点不在零或无穷处，且因子形如对数一加自变量、幂函数一加自变量 | 令平移量把瑕点移到零 → 用一加自变量的等价式把各因子换成幂或对数幂 → 各因子的阶数相加得总幂指数，对数幂单独记账 | 等价替换只能用于乘除因子；平移后括号内出现同阶相减时必须展开到下一阶，否则幂指数定错 |
| 分段与多瑕点分支 | 同一积分两端或内部同时存在多个反常来源 | 按每个反常来源切段 → 每段各自换元定阶并判别 → 全部段收敛才判收敛，任一段发散即判发散 | 只在一端定阶会漏条件；切分不完备（某子段内仍有无界点）时该段结论无效 |

### 失效边界

- **适用前提**：被积函数在每个子段上不变号（正项），可用等价定阶与比较审敛法的极限形式；换元函数在对应区间上单调可导，并把反常点映到零或无穷；各因子在趋近点处有确定的幂阶或对数阶
- **失效场景**：被积函数变号或含振荡因子时，标准型判别只回答绝对收敛，判出发散并不代表原积分发散（可能条件收敛）；换元时漏算微分因子的放大量，幂指数会整体错一个单位，边界情形直接判反；一个积分含多个反常来源却只对一处定阶，会漏掉另一处的发散条件；幂指数等于一且对数指数等于一是发散而非收敛，临界档记反是最高频错误；瑕点处分子分母同阶相消时，按剩余因子定阶会误判收敛或发散；换元把非反常点变成新的无界点（或反之）而未重新识别，段划分失效；被积函数含参数且参数改变阶归属（如指数为零）时，必须先按参数分类再套标准型

### 典型例题

| 题号 | 表面题型 | 本质要点 |
| --- | --- | --- |
| seed | 分母含自变量、对数与嵌套对数幂的无穷积分 | 迭代对数换元化为纯负幂形式，由幂指数与一的关系判别（迭代对数换元分支） |
| seed | 自变量乘指数衰减因子的无穷积分 | 指数换元化为幂乘对数幂，落入标准型（指数换元分支） |
| seed | 瑕点在一的含对数瑕积分 | 平移瑕点到零后用一加自变量等价式定阶（瑕点平移定阶分支） |
