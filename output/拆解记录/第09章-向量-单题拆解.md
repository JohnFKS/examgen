**题干摘要**：已知向量 $ \alpha_1 = (1, 2, 3)^T $, $ \alpha_2 = (2, -1, 1)^T $

| 字段 | 内容 |
| --- | --- |
| 表面题型 | 数值向量组的相关性判定与定参 |
| 核心本质 | 把给定的具体向量按列拼成矩阵，线性相关等价于该矩阵的秩小于向量个数；当向量个数等于维数时又等价于行列式为零，含参时把会消零的行（或行列式因子）写成参数的方程即可定参。判定与定参由此统一为一次秩的计算，秩的档位就是相关性结论的全部来源。 |
| 标准解题步骤 | 把向量按列排成矩阵（行向量组先转置再按列排），写明向量个数与维数；向量个数大于维数时直接判线性相关，不必再做计算；向量个数等于维数时计算行列式：行列式为零判相关，含参时令其为零解出参数候选值；向量个数小于维数或行列式不便展开时，只做初等行变换把矩阵化成阶梯形；数出阶梯形非零行数得秩：秩小于向量个数判相关，秩等于向量个数判无关；含参时按哪一行被消成零分档；把解出的参数代回原矩阵复算一次秩，确认没有漏掉更低秩的参数档 |
| 边界条件 | 可用：向量以具体数字（或含少量参数的分量）给出，可拼成矩阵做初等行变换；结论为判线性相关或无关，或由相关性反定参数；向量个数与维数的关系便于直接套行列式判据或化阶梯数秩 ／ 失效：向量个数大于维数时还去计算行列式：行列式不存在，应直接判线性相关；对行向量组做列变换后按列读表示关系：列变换不保持行向量组的相关性与表示对应；只验证行列式为零就写结论：为零只说明降秩，秩的确值须另复核；含参时把「行列式为零的参数」与「某行消零的参数」混为一谈，漏掉秩更低的分档 |
| 对应考点 | 线性相关性；（二）用秩判定相关性；（二）线性表示及线性相关性；必备知识点；解题连招 |
