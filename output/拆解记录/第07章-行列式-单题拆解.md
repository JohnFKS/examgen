## ch7-B-fp-01 ｜ 基础题·填空题

**题干摘要**：行列式 $ \begin{vmatrix} k & 0 & -1 & 1 \\ 0 & k & 1 & -1 \\ -1

| 字段 | 内容 |
| --- | --- |
| 表面题型 | 各行列和相等先加后提 |
| 核心本质 | 把其余各列（行）全部加到第一列（行）不改变行列式的值，而这一列（行）的元素统统变成同一个和 s，于是 s 可整列提出；提出后该列全为 1，用它把其余各列逐一消零，行列式就降成 s 的幂乘一个低阶行列式——依据是倍加不变性与对单一列的多重线性。 |
| 标准解题步骤 | 逐行（列）求元素和，确认所有行（列）之和同为与行号无关的量 s（含 s 为含参表达式）；把其余各列（行）全部加到第一列（行），并声明这一倍加不改变行列式的值；提出第一列（行）的公因子 s；同类操作做过 k 次时提 s^k，并按阶数核对幂次；用提走后全为 1 的那一列（行）把其余各列（行）逐一消成零（各减去它的适当倍数）；按含 1 的列（行）展开降阶，剩下的低阶行列式直接算出并与 s 的幂相乘；各列和只相差常数倍时先把各行乘以相应系数凑成相等的和，再走上面的流程；s 可能为零时按 s=0 与 s≠0 分别结论 |
| 边界条件 | 可用：每行元素个数相同且和式对称，能一次加出同一常数；对角元特殊而其余全同（如对角为 b、其余为 a），和为 b+(n-1)a 这类与行号无关的量；允许对行（列）做倍加与整列提因子 ／ 失效：各行和依赖行号（含互不相同的 a_i）时加出来的列不统一，本法失效；s=0 时提出 s 等于除以零，此时行列式本身为零或须改判其他结构；把行加到列后再按列提因子，行列式的行列对应关系被破坏 |
| 对应考点 | （三）各行（列）和相等；（三）性质（行均可换为列）；解题连招；必备知识点 |

## ch7-B-mc-01 ｜ 基础题·选择题

**题干摘要**：设行列式 $ D = \begin{vmatrix} 3 & 0 & 4 & 0 \\ 2 & 2 & 2 & 2 \\

| 字段 | 内容 |
| --- | --- |
| 表面题型 | 代数余子式组合逆用展开 |
| 核心本质 | 展开公式把行列式写成某行（列）元素与其代数余子式乘积之和，因此把该行（列）换成任意一组数所得的行列式，就等于那组数与原来的代数余子式的同系数组合；一组代数余子式的线性组合不必逐个求出，只要拿组合系数去替换对应行造一个新行列式来算，而余子式必须先按 (-1)^{i+j} 转成代数余子式；全行或全部之和则由 A*=\|A\|A^{-1} 从逆矩阵整批读出。 |
| 标准解题步骤 | 先辨所求量是余子式 M_{ij} 还是代数余子式 A_{ij}，前者乘 (-1)^{i+j} 转成后者（同一行时可直接整体提负号）；看下标是否同属一行或一列：行不变就用系数替换该行，列不变就替换该列；造出替换后的新行列式，按消零降阶、各行和相等或分块等常规手法算出其值；求某一行（列）全部代数余子式之和时把该行（列）换成全 1 造行列式；求全部 A_{ij} 之和时改算 \|A\|A^{-1} 的元素总和；只涉及伴随矩阵主对角元素之和时改用 A* 的特征值 \|A\|/λ_i 求和，避开逐个算余子式；把替换行改回原行本身做一次自检：所得新行列式应回到 \|A\| |
| 边界条件 | 可用：所求量是若干代数余子式的定系数线性组合，且下标同属一行或一列；A 可逆时可经 A*=\|A\|A^{-1} 把代数余子式整批读出；替换后新行列式出现明显零列或各行和相等，可几步算出 ／ 失效：下标跨越不同行又不同列的组合不能由一次行替换得到，须逐个计算；把余子式当代数余子式直接替换行会整体丢符号；A 奇异时 A*=\|A\|A^{-1} 不成立，不能由逆矩阵读代数余子式；题给 A^T=A* 一类等式使 A_{ij} 与矩阵元素本身配对时，替换系数不再是题面数字 |
| 对应考点 | 余子式与代数余子式；（二）展开式逆用；（二）行列式的展开；必备知识点；解题连招 |

## ch7-B-fp-02 ｜ 基础题·填空题

**题干摘要**：若 $ \begin{vmatrix}\lambda-a&-1&-1\\-1&\lambda-a&1\\-1&1&\la

| 字段 | 内容 |
| --- | --- |
| 表面题型 | 消零降阶算低阶行列式 |
| 核心本质 | 行列式对倍加不变，因此可先把某一行（列）做成只含少数非零元，或先加减出公共因子提走，再按该行（列）用展开公式降一阶；降出的二三阶行列式直接套公式即得数值，而题目只问某个幂次系数时，可先判断哪些元素能与该项配对，只对这几项展开。 |
| 标准解题步骤 | 观察有无成比例、部分相同或大部分为零的行（列），据此选定倍加方向把某一行（列）的零做得尽可能多；能加减出公共因子时先提出该常数（或含参公因子），把余下元素归一成 1 再继续消元；选零最多的一行（列）按展开公式降阶，逐项写出代数余子式并核对 (-1)^{i+j} 的符号；对降出的低阶行列式继续二阶三阶公式计算，或再降一次直到可直接写出；只问某次幂系数或某个分量时，先排除与本项不同族的展开项，只对能配出目标幂次的元素展开；换一条展开路径（改按另一行或另一列）复算，两路同值才算校验通过 |
| 边界条件 | 可用：行列式为具体数字或低阶含参阵列，可显式展开到二三层；存在成比例、相同或多数为零的行（列），一次倍加能造出两个以上零；题目要求数值、幂次系数或参数方程的根，而非 n 阶通项结构 ／ 失效：既无稀疏行又各列和不等时倍加只会增加非零元，应改判加边升阶或递推；n 阶一般项结构按一行展开后子式的形状随之改变，不能逐阶降下去；把某行的倍数加到该行自身，或对已提走的因子又乘回，行列式的值被同时改动 |
| 对应考点 | （一）降阶消零法；低阶行列式运算规则；（一）概念与计算；必备知识点；解题连招 |

| --- | --- |

| 核心本质 | 当行列式除首末一行（列）外的非零元呈阶梯分布时，按那一行（列）展开只产生少数几个余子式，而这些余子式要么是纯三角阵（直接取对角元之积），要么与原式同族而阶数更低；于是原式被写成同族项的线性组合，逐阶递推或一次拆项即可闭合，必要时对首末行先拆项使每块都能展开成三角。 |
| 标准解题步骤 | 选出只含一到两个非零元的行（列）（常为首行、末行或首列）作为展开对象；按该行（列）展开，逐个写出余子式并核对 (-1)^{i+j} 的符号；判每个余子式的形状：纯三角者直接取对角元之积，同族者记为低一阶或低两阶的 D；把原式写成含低阶 D 的等式，代 D_1、D_2 初值逐阶递推，或用数学归纳法验证猜想式；末行（列）与原式不同族时，先把该行（列）拆成两项之和（利用对单行的线性），两块各自展开；所得通项回代 n=1、2、3 与直接计算核对，并检查符号与阶乘项个数 |
| 边界条件 | 可用：存在只含少数非零元的行（列），展开后余子式不超过两个；余子式与原式同族，或为可一眼看出的三角阵；递推所需的两个初值能由一阶二阶行列式直接算出 ／ 失效：每行非零元较多，展开后余子式互相嵌套不成同族时递推断链；递推式的系数依赖 n 时不能按等比闭合，须改走归纳或拆项；拆项后两支行列式的符号与阶数未分别核对，会多算或漏算一项 |

## ch7-B-mc-02 ｜ 基础题·选择题

**题干摘要**：设 $ \alpha_1, \alpha_2, \alpha_3, \beta_1, \beta_2 $ 均是 4 维列

| 字段 | 内容 |
| --- | --- |
| 表面题型 | 按列拆分与列向量组合 |
| 核心本质 | 行列式是列向量的多重线性交替函数：某一列写成若干向量之和就能按该列拆成几个行列式之和，某列整体乘常数可提到行列式外，交换两列则整体变号；而由列向量的线性组合关系写成的矩阵等式 (b)=(a)C 两边取行列式，就把未知的 \|b\| 化成 \|a\| 与组合系数行列式 \|C\| 之积，反向也可由已知解出 \|a\|。 |
| 标准解题步骤 | 把各行列式统一写成以列向量为元素的记号，核对列数与阶数（缺的列先由已知等式补全）；需要调整列序时用相邻交换把目标列序排成已知列序，只按交换次数定最终符号；出现同一列是两个向量之和时按该列拆成两个行列式之和，逐个回落到已知行列式；某列各元素同倍数时把倍数提出（n 列同时提出即 k^n 因子），一次提清再比系数；列向量组线性无关时写成矩阵乘积 (b)=(a)C，两边取行列式得 \|b\|=\|a\|\|C\|，反解所求；系数矩阵 C 的行列式按一列展开算出，并与逐步拆分所得结果互相核对 |
| 边界条件 | 可用：对象明确是列向量拼成的行列式，维数与阶数匹配；列向量组线性无关使 C 可逆、可作除法；同一列至多是两个向量之和（更多时拆项数量成倍增长） ／ 失效：维数与阶数不匹配（少给一个列向量）时行列式不能确定；行向量与列向量混用：行的多线性规则与列的符号规则不可同时套用；把 \|A+B\| 当成 \|A\|+\|B\|；加法只对单个列（行）成立，整矩阵相加不满足线性 |
| 对应考点 | （三）性质（行均可换为列）；必备知识点 |

## ch7-B-fp-03 ｜ 基础题·填空题

**题干摘要**：行列式 $ D_{4}=\left|\begin{matrix}1&0&0&1\\ 0&2&0&1\\ 0&0&3&1\

| 字段 | 内容 |
| --- | --- |
| 表面题型 | 爪形行列式消去一个爪 |
| 核心本质 | 爪形（箭形）行列式的非零元只分布在一条整行（列）与主对角线上：把主对角元逐个提走使其变为 1，它们就成了现成的消元系数，用它依次把爪所在行（列）的其余元素消成零，行列式化为三角阵，其值为对角元之积减去爪上元素与对角元之比构成的加权和。 |
| 标准解题步骤 | 认出爪形结构：一整行（列）非零，而其余非零元只落在主对角线上；把主对角元逐个提出行列式（记在行列式外），使其归一为可用的消元系数；用归一后的第 i 行（列）倍加消去爪所在行（列）的第 i 个元素，逐列执行直到爪上只剩一个非零元；按只剩一个非零元的爪行（列）展开，余下的三角行列式取对角元之积；把先前提出去的对角元因子乘回，并按消元顺序核对有无额外符号；若两条爪接在一起（每行都含两个爪元素）本法不闭合，改按逐项相消或加边升阶处理 |
| 边界条件 | 可用：非零元恰为一条整行（列）加主对角线；主对角元全不为零，可作为归一与消元的除数；爪上元素与对角元之间有可整体提出的公因子时先行提出 ／ 失效：主对角线出现零元时无法归一消元，须先行列互换或按该行列展开；两爪相接（例：除对角外每行两个非零元）时消元不闭合；消元时把倍数加到自身所在行，行列式值被改动 |
| 对应考点 | （五）爪形行列式；（一）降阶消零法；解题连招 |

## ch7-B-fr-03 ｜ 基础题·解答题

**题干摘要**：计算 n 阶行列式 $ D_{n}=\left|\begin{matrix}2&-1&0&\cdots&0&0\\ -1

| 字段 | 内容 |
| --- | --- |
| 表面题型 | 三对角行列式二阶递推 |
| 核心本质 | 三对角行列式按首行展开只出两项，其中余子式仍是三对角但少一格，再展开一次便把 D_n 写成 pD_{n-1}+qD_{n-2} 的二阶线性递推；设 t²-pt-q=0 的两根为 α、β，则 D_n-αD_{n-1}=β(D_{n-1}-αD_{n-2}) 构成等比数列，两次求和即得通项——带状结构保证递推只牵涉前两阶。 |
| 标准解题步骤 | 按第一行（列）展开，把出现的余子式再按它的第一列展开，得 D_n=pD_{n-1}+qD_{n-2}（首尾行特殊时单独核算最后两阶）；由一阶与二阶行列式直接算出 D_1、D_2 两个初值；解特征方程 t²-pt-q=0 得 α、β，把递推改写成 D_n-αD_{n-1}=β(D_{n-1}-αD_{n-2})；两根相等时改用 D_n-αD_{n-1} 为等差；对等比式从 2 到 n 累乘（或两边同除 α^n 作差），把 D_n 表成 α^n 与 β^n 的线性组合；用 D_1、D_2 定出组合系数写出通项，并核对 α=β、q=0 两个退化档；把通项代 n=1、2、3 与直接计算核对符号，尤其检查 q 前的正负 |
| 边界条件 | 可用：非零元只落在主对角线与紧邻的两条对角线上；递推系数 p、q 与阶数无关；特征方程的根可显式解出（相异或重根） ／ 失效：首末行出现不相邻的额外元素时递推式多出不含 D 的余项，须先消元或拆项；系数依赖 n 时特征根法失效；把递推式中 q 的符号按展开符号写反是最常见的系统性错误 |
| 对应考点 | （九）三对角型；（八）逐项相消型；解题连招 |

> 归属：T-LA-11-I ｜ 相似度：15% ｜ 动作：new
