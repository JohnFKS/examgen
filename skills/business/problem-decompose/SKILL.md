# 单题标准化拆解Skill（业务执行层）

借鉴 LIMO 的认知模板思想：把每道题固定拆解为 5 段，保证抽取逻辑标准化；借鉴 ReGFT：**把标准解析当脚手架**，提炼底层数学本质与通用步骤，而不是复制解题过程。

## 输出 5 字段（无易错点）

| 字段 | 含义 | 硬性要求 |
| --- | --- | --- |
| `surface_type` 表面题型 | 题目外观形式分类 | 4~12 字短语；同批外观同类用完全相同短语 |
| `essence` 核心本质 | 一句话底层数学原理 | 回答「为什么这样做一定有效」；不含具体数值 |
| `steps` 标准解题步骤 | 通用可复用步骤 | 动词开头 4~7 步，含判别/检验点；禁止出现本题数值与函数式 |
| `boundaries` 边界条件 | 适用前提 + 失效场景 | 两端都必须填 |
| `exam_points` 对应考点 | 匹配的考纲知识点 | 优先复用本章考点清单原文，1~3 个 |

## 知识支撑的注入

提示词中注入三样东西，全部来自输入 md 文件，按题干做检索命中（非全量塞入，控制 token）：

1. **本章考点清单**：来自讲义/考点 md 的 2~4 级标题 + 加粗定理/准则术语；
2. **相关教材片段**：同目录树检索命中的小节摘要；
3. **相关公式**：公式 md 中命中的条目（作为「本质判断的依据」）。

## 批量与逐题的关系

推理按批（默认 6 题/次，可配 `batch.problemsPerCall`）以节省 token 与降低时延，但**拆解与迭代记录仍逐题落库、按题序串行应用**，保持「逐题迭代」语义与可审计性。

## 确定性

该 Skill 的输出与模板库状态无关（不读取模板库），因此可独立重放，是流水线可重放性的基础。
