# 数学等价校验Skill（质量校验层）

通法手册里最怕的是「方法本身写错了」。本 Skill 只验证**核心逻辑正确性**，不纠结字面差异——这是 K12-KGraph / MathOdyssey 式校验的关键：改写过、术语不同的步骤，只要数学等价就算通过。

## 三个维度

| 维度 | 校验问题 |
| --- | --- |
| `algebraic` 代数等价 | 表达式变形、恒等变换、公式使用是否符合数学规则 |
| `numeric` 数值等价 | 把通法步骤代入典型数值，结果是否与题库标准解析一致 |
| `logical` 逻辑等价 | 因果链是否成立、充分必要方向是否搞反、边界条件是否漏项 |

模板级 `verdict` 由模型给出；章级汇总是「有 fail 就报 `N fail`，否则有 warn 报 `N warn`，否则 `pass`」（有待答任务时显示「待作答」），报告同时逐模板列出三维结论与 `evidence` 摘要。

## 实证材料

每个模板带最近 3 条例题的**题干 + 标答 + 参考解析**片段，外加按模板本质检索命中的公式/教材条目作为判定依据。校验不是让模型凭记忆判对错，而是让它对着可核对的材料判。

## 纠错必须可执行

发现错误必须给出 `corrected_steps`——**完整替换用**的步骤数组，不许写「第 3 步有点问题」。`evidence` 字段要求一句话说明代入检验用了什么数值或做了哪步等价变形，防止空口判定。

## 自动修复链路

`verdict=fail` 且 `corrected_steps` 非空 → 流水线直接用替换步骤更新模板，**大版本升级**，并在 `history` 追加 `equivalence-fix` 记录（含问题摘要）。校验报告写 `output/qa/第NN章-数学等价校验.md`。

## 批次

每 4 个模板一次调用；本阶段有待答任务时中止并标记 `pending`，不产生半份报告。
